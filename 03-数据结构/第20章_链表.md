## 💡 生活类比

### 火车车厢连接

单链表就像一列**火车**：每节车厢里装着货物（数据），车厢之间靠**挂钩**（指针）连接。

```
车头 → [货物|挂钩] → [货物|挂钩] → [货物|挂钩] → NULL
        1            2            3
```

- 想在车头加一节车厢？只需把新车厢的挂钩挂到原车头，再让新车厢成为车头——**灵活增删**。
- 想找第 3 节车厢？只能从车头一节一节往后走——**不能随机跳转**。
- 数组则像**一排连座**的固定座位，找第 3 个直接坐下，但中间插人要把后面所有人往后挪。

### 图书馆借阅记录

每本书的借阅卡上写着"下一本书在 5 号柜"。你不需要把所有书放在一起，只要顺着卡片找即可。这就是链式存储的本质：**用"地址"代替"位置相邻"**。

!!! tip "一句话记忆"
    数组靠"位置"定位，链表靠"指针"接力。

## 第三节 核心概念

### 3.1 链式存储 vs 顺序存储

| 维度 | 顺序存储（数组） | 链式存储（链表） |
|------|----------------|----------------|
| 内存 | 连续分配 | 分散分配，靠指针串联 |
| 随机访问 `a[i]` | $O(1)$ | $O(n)$，必须从头遍历 |
| 头部插入/删除 | $O(n)$，需移动元素 | $O(1)$，改指针即可 |
| 指定位置后插入/删除 | $O(n)$ | $O(1)$（已知节点位置） |
| 空间开销 | 仅数据 | 数据 + 指针（1~2 个） |
| 内存预分配 | 需预估大小 | 按需分配（动态）/ 数组预分配（静态） |
| 缓存友好性 | 高（连续） | 低（分散） |

### 3.2 核心操作复杂度表

| 操作 | 单链表（已知节点） | 备注 |
|------|------------------|------|
| 头插 `insertHead` | $O(1)$ | 改 head 指针 |
| 尾插 `insertTail` | $O(1)$（维护尾指针）/ $O(n)$（无尾指针） | 需遍历找尾 |
| 指定位置后插入 | $O(1)$ | 改两个指针 |
| 删除头节点 | $O(1)$ | 改 head 指针 |
| 删除指定节点 | $O(n)$（单链表需找前驱）/ $O(1)$（已知前驱） | 双向链表 $O(1)$ |
| 按值查找 | $O(n)$ | 遍历 |
| 按下标访问第 i 个 | $O(n)$ | 不能像数组直接下标 |
| 遍历 | $O(n)$ | 从 head 走到 NULL |

### 3.3 单链表 ASCII 示意图

```
节点结构：
┌──────┬──────┐
│ data │ next │ ──→ 指向下一个节点（下标或指针）
└──────┴──────┘

整体（结构体指针版）：
head → [1|•] → [3|•] → [7|•] → [9|NULL]
                                  ↑ 末节点 next 为空(NULL/-1)

整体（静态链表版，数组下标）：
head=2
下标 idx:   0     1     2     3
          ┌─────┬─────┬─────┬─────┐
  e[]     │  9  │  3  │  1  │  7  │
 ne[]     │ -1  │  3  │  1  │  0  │
          └─────┴─────┴─────┴─────┘
访问顺序：head=2(e=1) → ne[2]=1(e=3) → ne[1]=3(e=7) → ne[3]=0(e=9) → ne[0]=-1 停
```

!!! info "关键认知"
    静态链表中，`head`、`ne[i]` 存的都是**数组下标**而非内存指针，`-1` 等价于 `NULL`。

## 第四节 结构体模拟实现 ⭐（轨道一）

### 4.1 节点定义与完整模板

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node { 
    int data; 
    Node* next; 
};

// 头插法：把 x 插到链表头部              O(1)
void insertHead(Node* &head, int x) { 
    head = new Node{x, head};   // 新节点 {data=x, next=原head}，并成为新 head
}

// 在节点 p 之后插入 x                    O(1)
void insertAfter(Node* p, int x) { 
    if(!p) return;              // 边界检查：p 为空直接返回，避免解引用空指针
    p->next = new Node{x, p->next}; 
}

// 删除头节点                            O(1)
void deleteHead(Node* &head) { 
    if(!head) return;           // 边界检查：空链表
    Node* t = head; 
    head = head->next; 
    delete t;                   // 释放内存，防止内存泄漏
}

// 删除节点 p 的下一个节点               O(1)
void deleteAfter(Node* p) {
    if(!p || !p->next) return;  // 边界检查：p 为空，或 p 已是末节点（无后继）
    Node* t = p->next;
    p->next = t->next;          // 跳过被删节点
    delete t;
}

// 查找值为 x 的第一个节点               O(n)
Node* find(Node* head, int x) {
    for(Node* p = head; p; p = p->next)   // p 非空即继续
        if(p->data == x) return p;
    return nullptr;             // 未找到返回空指针
}

// 遍历输出                              O(n)
void print(Node* head) {
    for(Node* p = head; p; p = p->next)
        cout << p->data << " ";
    cout << "\n";
}

int main() {
    Node* head = nullptr;       // 初始空链表（务必初始化为空）
    insertHead(head, 1);        // 链表：1
    insertHead(head, 2);        // 链表：2 → 1
    insertAfter(head, 5);       // 在头(2)后插5：2 → 5 → 1
    print(head);                // 输出：2 5 1
    deleteHead(head);           // 删头(2)：5 → 1
    print(head);                // 输出：5 1
    cout << (find(head, 5) ? "found" : "not found") << "\n"; // found
    return 0;
}
```

### 4.2 扩展操作：按值删除与尾插

```cpp
// 删除链表中第一个值为 x 的节点             O(n)
void deleteByValue(Node* &head, int x) {
    if(!head) return;                  // 边界检查：空链表
    if(head->data == x) {              // 特判：删头节点
        deleteHead(head);
        return;
    }
    Node* p = head;
    while(p->next && p->next->data != x) p = p->next;  // 找前驱
    if(p->next) deleteAfter(p);        // 找到了，删其后继
}

// 尾插法（维护尾指针 tail 时为 O(1)）       O(1)
void insertTail(Node* &head, Node* &tail, int x) {
    Node* node = new Node{x, nullptr};
    if(!head) head = tail = node;      // 边界检查：空链表，头尾都指向新节点
    else { tail->next = node; tail = node; }
}
```

!!! tip "尾指针的取舍"
    若不维护 `tail`，尾插要遍历找尾，复杂度 $O(n)$。建链表常用**头插**（$O(1)$），就是因为它无需找尾。但头插会**逆序**，需要正序时改用尾插 + 尾指针。

### 4.3 实现要点

1. **`head` 用引用传递** `Node* &head`：修改头指针必须传引用，否则修改的是副本，外部 `head` 不变。
2. **`new Node{x, head}`** 是 C++11 列表初始化，等价于先 `new` 再赋 `data/next` 两步。
3. **删除顺序不能反**：必须先让前驱指向后继（`p->next = t->next`），再 `delete t`。若先 `delete`，则 `t->next` 已是非法访问。
4. **边界检查三件套**：空链表（`!head`）、空指针参数（`!p`）、末节点无后继（`!p->next`）。
5. **删除分两类**：删头节点需改 `head`（特判）；删中间节点需先找前驱（$O(n)$ 查找 + $O(1)$ 删除）。

!!! warning "指针引用是高频考点"
    面试/笔试常考："为什么 `insertHead` 要传 `Node* &head` 而不是 `Node* head`？"
    答：传值时函数内修改的是 head 的拷贝，调用方的 head 不变；传引用才能真正改外部 head。

## 第五节 静态链表（数组模拟）⭐（轨道一·竞赛首选）

### 5.1 为什么用数组模拟

竞赛中结构体指针有三大痛点：①`new` 较慢；②忘记 `delete` 导致内存泄漏；③野指针难调试。**静态链表用数组下标代替指针**，速度快、不易错，是 CSP-S 标准做法。

### 5.2 完整模板（AcWing 风格，必须熟记）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100010;
int head, e[N], ne[N], idx;

// 初始化                              O(1)
void init() { 
    head = -1;  // -1 表示"空指针"（链表为空）
    idx = 0;    // idx 是"内存分配器"，指向下一个可用下标
}

// 头插法：把 x 插到链表头部             O(1)
void addHead(int x) { 
    e[idx] = x;         // 在 idx 处存数据
    ne[idx] = head;     // 新节点指向原头节点
    head = idx++;       // head 更新为新节点，idx 后移（"分配"了一块）
}

// 在下标为 k 的节点之后插入 x           O(1)
void addAfter(int k, int x) { 
    e[idx] = x;         // 存数据
    ne[idx] = ne[k];    // 新节点指向 k 的原后继
    ne[k] = idx++;      // k 指向新节点，idx 后移
}

// 删除下标为 k 的节点后面的节点         O(1)
void deleteAfter(int k) { 
    if(ne[k] != -1) ne[k] = ne[ne[k]];  // 边界检查：k 有后继才删
}

// 删除头节点                          O(1)
void deleteHead() {
    if(head != -1) head = ne[head];     // 边界检查：非空才删
}

// 遍历输出                            O(n)
void print() {
    for(int i = head; i != -1; i = ne[i])
        cout << e[i] << " ";
    cout << "\n";
}

int main() {
    init();                    // 务必先初始化！
    addHead(1);                // 链表：1
    addHead(2);                // 链表：2 → 1
    addAfter(head, 5);         // 在头(2)后插5：2 → 5 → 1
    print();                   // 输出：2 5 1
    deleteHead();              // 删头(2)：5 → 1
    print();                   // 输出：5 1
    return 0;
}
```

### 5.3 实现要点

1. **三数组分工**：`e[]` 存数据，`ne[]` 存"下一个节点的下标"，`head` 存头节点下标；`idx` 是分配计数器。
2. **`-1` 即 `NULL`**：`head = -1` 表示空链表，`ne[i] = -1` 表示节点 i 是末节点。遍历终止条件是 `i != -1`。
3. **`idx` 单调递增不复用**：被删除节点的下标不回收（竞赛题通常够用）。如需回收，要维护空闲链表（S 组进阶）。
4. **`addAfter(k, x)` 的 k 是下标而非位置**：注意题目里"第 k 个插入的节点"对应下标 `k-1`（`idx` 从 0 开始）。

!!! tip "删除操作的精髓"
    `deleteAfter(k)` 只需一行：`ne[k] = ne[ne[k]]`。让 k 直接指向"下下个"，被删节点就被"旁路"了。无需 free，因为用的是静态数组。

### 5.4 扩展操作：查找与按序号访问

```cpp
// 查找值为 x 的第一个节点的下标            O(n)
int findByValue(int x) {
    for(int i = head; i != -1; i = ne[i])
        if(e[i] == x) return i;   // 找到返回下标
    return -1;                    // 未找到返回 -1
}

// 访问链表中第 k 个节点（0 起下标）        O(n)
int getKth(int k) {
    int i = head;
    while(k-- && i != -1) i = ne[i];
    return i;                     // i == -1 表示越界
}
```

!!! warning "静态链表不能随机访问"
    `getKth(k)` 是 $O(n)$ 的——这正是链表与数组的根本差异。若题目频繁按下标访问，应改用数组而非链表。

## 第六节 STL 实现 ⭐（轨道二）

### 6.1 STL list 完整示例

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    list<int> L;                       // 空的双向链表
    
    // 插入
    L.push_back(1);                    // 尾插：1
    L.push_back(3);                    // 尾插：1 → 3
    L.push_front(0);                   // 头插：0 → 1 → 3
    L.insert(++L.begin(), 2);          // 在第2个位置插：0 → 2 → 1 → 3
    
    // 遍历
    for(int x : L) cout << x << " ";   // 输出：0 2 1 3
    cout << "\n";
    
    // 访问首尾（注意：list 不支持 [] 和 at）
    cout << "front=" << L.front() << " back=" << L.back() << "\n"; // 0 3
    
    // 删除
    L.pop_front();                     // 删头：2 → 1 → 3
    L.pop_back();                      // 删尾：2 → 1
    L.remove(1);                       // 删除所有值为1的节点：2
    
    // 大小与判空
    cout << "size=" << L.size() << " empty=" << L.empty() << "\n"; // 1 0
    
    // 排序与反转（list 自带，因为不能用 std::sort）
    L.push_back(5); L.push_back(3);
    L.sort();                          // 升序：2 3 5
    L.reverse();                       // 反转：5 3 2
    for(int x : L) cout << x << " ";
    cout << "\n";
    return 0;
}
```

### 6.2 `list` 成员函数速查表

| 函数 | 作用 | 复杂度 |
|------|------|--------|
| `push_back(x)` | 尾插 | $O(1)$ |
| `push_front(x)` | 头插 | $O(1)$ |
| `pop_back()` | 删尾 | $O(1)$ |
| `pop_front()` | 删头 | $O(1)$ |
| `insert(it, x)` | 在迭代器 it 处插入 | $O(1)$ |
| `erase(it)` | 删除迭代器 it 处元素 | $O(1)$ |
| `front()` / `back()` | 访问首/尾元素 | $O(1)$ |
| `size()` | 元素个数 | $O(1)$ |
| `empty()` | 是否为空 | $O(1)$ |
| `clear()` | 清空 | $O(n)$ |
| `remove(x)` | 删除所有等于 x 的元素 | $O(n)$ |
| `sort()` | 排序（成员函数版） | $O(n \log n)$ |
| `reverse()` | 反转 | $O(n)$ |
| `merge(L2)` | 合并两个有序链表 | $O(n)$ |
| `unique()` | 去除相邻重复 | $O(n)$ |
| `splice(it, L2)` | 把 L2 接到 it 处 | $O(1)$ |

!!! warning "list 不能用 std::sort"
    `std::sort` 要求随机访问迭代器，而 `list` 是双向迭代器。必须调用成员函数 `L.sort()`。同理 `lower_bound` 也只能用成员函数版。

### 6.3 迭代器与删除的安全用法

```cpp
// ✅ 安全删除：erase 返回下一个有效迭代器
for(auto it = L.begin(); it != L.end(); ) {
    if(*it % 2 == 0) it = L.erase(it);  // 删偶数，it 更新为下一个
    else ++it;                          // 不删才前进
}

// ❌ 危险：删除后 it 已失效，++it 是未定义行为
for(auto it = L.begin(); it != L.end(); ++it) {
    if(*it % 2 == 0) L.erase(it);       // it 失效！
}
```

!!! warning "迭代器失效"
    `list::erase(it)` 后，`it` 立即失效，再 `++it` 是未定义行为。正确做法是用 `it = L.erase(it)` 接收返回值（指向被删元素的下一个）。这是链表题最常见的 WA/RE 来源。

## 第七节 双轨对比总结

### 7.1 三种实现横向对比

| 维度 | 结构体指针 | 静态链表（数组） | STL `list` |
|------|-----------|----------------|-------------|
| 内存管理 | `new`/`delete` 动态 | 静态数组预分配 | 自动管理 |
| 速度 | 较慢（堆分配） | 最快 | 较快 |
| 出错风险 | 高（野指针/泄漏） | 低 | 最低 |
| 代码量 | 中等 | 短，可默写 | 最短 |
| 支持双向 | 加 `prev` 即可 | 加 `l[]` 数组 | 天生双向 |
| 随机访问 `[]` | 否 | 否 | 否 |
| 竞赛适用 | 教学/理解用 | **CSP-S 首选** | 简单题/快速实现 |
| 调试难度 | 难 | 易（可打印数组） | 中 |

### 7.2 赛场建议

- **CSP-S 复赛**：一律用**静态链表**。背熟 `init/addHead/addAfter/deleteAfter` 四件套，5 分钟默写完成，剩下的时间专注解题逻辑。
- **CSP-S 初赛/笔试**：可读题用结构体指针版，写题用静态版。读得懂指针、写得了数组。
- **快速验证思路**：用 STL `list` 快速写一版对拍，再用静态链表交正式版。
- **大模拟题**：优先静态链表 + 数组，避免指针调试地狱。

!!! tip "选择口诀"
    "理解用指针，比赛用数组，验证用 STL。"

## ⚠️ 常见误区

### 误区 1：空指针解引用

```cpp
// ❌ 错误：head 可能为空
void print(Node* head) {
    while(head->next) { ... }     // head 为空时崩溃
}

// ✅ 正确：先判空
void print(Node* head) {
    while(head) { ... }           // head 非空才进入循环
}
```

**症状**：程序段错误（Segmentation Fault / RE）。
**预防**：每次用 `->` 访问成员前，确认指针非空。

### 误区 2：静态链表忘记初始化 `head = -1`

```cpp
// ❌ 错误：全局变量 head 默认为 0，会指向 idx=0 的节点，导致死循环或越界
int head, e[N], ne[N], idx;
int main() {
    // 忘记 init()
    addHead(1);                   // ne[0] = head = 0（指向自己！）→ 死循环
}

// ✅ 正确：先 init
int main() {
    init();                       // head = -1, idx = 0
    addHead(1);
}
```

**症状**：遍历时死循环（TLE）或输出乱码。
**预防**：`main` 第一行必写 `init()`。

### 误区 3：删除节点未检查 next 是否为空

```cpp
// ❌ 错误：k 是末节点时 ne[k] = -1，ne[ne[k]] = ne[-1] 越界！
void deleteAfter(int k) {
    ne[k] = ne[ne[k]];           // 若 ne[k] == -1，访问 ne[-1] 数组越界
}

// ✅ 正确：检查后继存在
void deleteAfter(int k) {
    if(ne[k] != -1) ne[k] = ne[ne[k]];
}
```

**症状**：数组越界，未定义行为（可能 WA 也可能 RE）。
**预防**：凡是用 `ne[ne[k]]`，必先确认 `ne[k] != -1`。

### 误区 4：头插法忘记改 head

```cpp
// ❌ 错误：新节点没成为新 head，原链表丢失
void addHead_wrong(int x) {
    e[idx] = x; ne[idx] = head;  // 只接上，没改 head
    idx++;
}

// ✅ 正确：head = idx++
void addHead(int x) {
    e[idx] = x; ne[idx] = head; head = idx++;
}
```

### 误区 5：结构体版删除顺序写反

```cpp
// ❌ 错误：先 delete 再访问 next，next 已失效
delete t; p->next = t->next;     // 野指针访问！

// ✅ 正确：先改指针，再释放
p->next = t->next; delete t;
```

## 典型例题（双版本）：约瑟夫问题

**题目**：n 个人围成一圈，从第 1 个人报数，数到 m 的人出圈，求出圈顺序。（洛谷 P1996）

**思路**：用循环链表，每数 m 步删除当前节点并输出。删除只需改前驱的 next 指针。

### 版本一：结构体指针版

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node { int data; Node* next; };

int main() {
    int n, m; cin >> n >> m;
    // 建立循环链表 1→2→...→n→1
    Node* head = new Node{1, nullptr};
    Node* tail = head;
    for(int i = 2; i <= n; i++) {
        tail->next = new Node{i, nullptr};
        tail = tail->next;
    }
    tail->next = head;            // 首尾相连成环

    Node* p = tail;               // p 指向"当前节点的前驱"，从尾开始
    while(p->next != p) {         // 只剩一个时停止
        for(int i = 1; i < m; i++) p = p->next;  // 走 m-1 步
        Node* t = p->next;        // t 是出圈者
        cout << t->data << " ";
        p->next = t->next;        // 旁路 t
        delete t;
    }
    cout << p->data << " ";       // 最后幸存者
    delete p;
    return 0;
}
```

### 版本二：静态链表版（竞赛推荐）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 105;
int ne[N];                        // ne[i] 表示 i 的下一个

int main() {
    int n, m; cin >> n >> m;
    for(int i = 1; i <= n; i++) ne[i] = i + 1;  // 串联
    ne[n] = 1;                    // 成环

    int pre = n, cnt = 0;         // pre 是当前的前驱，从 n 开始
    int cur = 1;                  // 当前节点
    while(cnt < n) {
        for(int i = 1; i < m; i++) { pre = cur; cur = ne[cur]; }  // 走 m-1 步
        cout << cur << " ";       // cur 出圈
        ne[pre] = ne[cur];        // 旁路 cur
        cur = ne[cur];            // 下一个起点
        cnt++;
    }
    return 0;
}
```

!!! tip "双版本对比"
    - 结构体版直观易懂，适合教学；但有 `new`/`delete` 开销，且环形结构易出错。
    - 静态版省内存、速度快，删除只需 `ne[pre] = ne[cur]` 一行，是复赛首选。
    - 两版时间复杂度均为 $O(nm)$。若 n、m 都很大，需改用递推 $f(i)=(f(i-1)+m)\bmod i$，$O(n)$ 出解。

## 【进阶】双向链表（S 组）

### 10.1 为什么需要双向链表

单链表只能"往后走"。要删除一个**已知节点**，需 $O(n)$ 找其前驱。双向链表每个节点记录前驱 `l[]` 和后继 `r[]`，删除已知节点只需 $O(1)$。

### 10.2 静态双链表实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100010;
int e[N], l[N], r[N], idx;

// 初始化：建立左右端哨兵 0 和 1，互相指向     O(1)
void init() {
    r[0] = 1;    // 0 号是左端哨兵，右指向 1
    l[1] = 0;   // 1 号是右端哨兵，左指向 0
    idx = 2;    // 数据节点从 2 号开始分配
}

// 在下标 k 的节点右侧插入 x             O(1)
void addRight(int k, int x) {
    e[idx] = x;
    l[idx] = k;                 // 新节点左指 k
    r[idx] = r[k];              // 新节点右指 k 的原右邻
    l[r[k]] = idx;              // k 的原右邻 左指新节点
    r[k] = idx;                 // k 右指新节点
    idx++;
}

// 删除下标为 k 的节点                  O(1)（双向链表的核心优势）
void remove(int k) {
    l[r[k]] = l[k];             // 右邻的左指针 跳过 k
    r[l[k]] = r[k];             // 左邻的右指针 跳过 k
}

// 从左到右遍历                        O(n)
void print() {
    for(int i = r[0]; i != 1; i = r[i])  // 从哨兵右走，到右哨兵停
        cout << e[i] << " ";
    cout << "\n";
}

int main() {
    init();
    addRight(0, 1);             // 在左哨兵右插：1
    addRight(0, 2);             // 在左哨兵右插：2 1
    addRight(2, 3);             // 在 2 号节点右插：2 3 1
    print();                    // 输出：2 3 1
    remove(3);                 // 删除下标3的节点（值3）
    print();                    // 输出：2 1
    return 0;
}
```

### 10.3 在节点左侧插入与删除已知节点

```cpp
// 在下标 k 的节点左侧插入 x           O(1)（双向链表的核心优势）
void addLeft(int k, int x) {
    addRight(l[k], x);         // 左侧插 = 在 k 的前驱右侧插，复用 addRight
}

// 删除下标为 k 的节点（已知 k）        O(1)
//   见上文 remove(k)：l[r[k]]=l[k]; r[l[k]]=r[k];
```

!!! tip "左右插入的对称美"
    单链表"在 k 左侧插"需 $O(n)$ 找前驱；双向链表只需 `addRight(l[k], x)` 一行，$O(1)$ 搞定。这正是 P1160 "在某人左边插队"的高效解法。

### 10.4 哨兵节点的妙用

`0` 和 `1` 是**哨兵节点**（dummy node），不存真实数据：

```
[0哨兵] ⇄ [数据2] ⇄ [数据3] ⇄ [数据1] ⇄ [1哨兵]
```

- **好处**：插入/删除时永远不必检查"是否为头/尾"，代码统一，边界情况消失。
- **代价**：多两个节点空间，遍历时跳过哨兵。

!!! info "对应 P1160 队列安排"
    静态双链表是 P1160（队列安排）的标准解法。题目要求在某人左边/右边插队、删除某人——双向链表 $O(1)$ 完成，单链表则需 $O(n)$ 找前驱。

### 10.5 双向 vs 单向

| 操作 | 单链表 | 双向链表 |
|------|--------|---------|
| 删除已知节点 | $O(n)$ 找前驱 | $O(1)$ 直接用 `l[]` |
| 反向遍历 | ✗ | ✓ |
| 插入到某节点左侧 | $O(n)$ | $O(1)$ |
| 空间开销 | 1 个指针 | 2 个指针 |
| 代码复杂度 | 简单 | 略复杂（4 处指针修改） |

## 📖 本章总结

### 思维导图

- **链表**
  - **核心概念**
    - 链式存储 vs 顺序存储（不连续 vs 连续）
    - 节点 = 数据 + 指针（下标）
    - `NULL` / `-1` 终止遍历
  - **轨道一：手写实现**
    - 结构体指针版
      - `Node { data; Node* next; }`
      - 引用传参 `Node* &head`
      - `new` / `delete` 内存管理
    - 静态链表（数组模拟）⭐竞赛首选
      - `e[N]` + `ne[N]` + `head` + `idx`
      - `init / addHead / addAfter / deleteAfter`
      - 全 $O(1)$ 增删
  - **轨道二：STL**
    - `#include <list>`
    - 双向链表，`push/pop/insert/erase/size/sort`
    - 不能 `[]`，不能 `std::sort`
  - **进阶**
    - 双向链表：`l[N]` + `r[N]` + 哨兵
    - 删除已知节点 $O(1)$
    - P1160 标准解法
  - **典型应用**
    - 约瑟夫问题（P1996）
    - 队列安排（P1160）
    - 合并有序链表
  - **常见陷阱**
    - 空指针解引用 → RE
    - 忘记 `init` → 死循环
    - 删末节点未检查 → 越界
    - 删除顺序写反 → 野指针

### 速记口诀

```
数组模拟四件套：init、addHead、addAfter、deleteAfter。
-1 是空，idx 是分配器，head 是入口。
增删 O(1)，访问 O(n)，遍历从 head 走到 -1。
双向加 l[]，哨兵去边界，P1160 是练手题。
```

### 复杂度总览

| 操作 | 结构体版 | 静态版 | STL list |
|------|---------|--------|----------|
| 头插/头删 | $O(1)$ | $O(1)$ | $O(1)$ |
| 指定位置后插/删 | $O(1)$ | $O(1)$ | $O(1)$ |
| 按值查找 | $O(n)$ | $O(n)$ | $O(n)$ |
| 随机访问 | $O(n)$ | $O(n)$ | $O(n)$ |
| 排序 | — | — | $O(n\log n)$ |
