## 核心内容

### 58.1 二叉搜索树（BST）的定义与性质

**二叉搜索树**（Binary Search Tree）是一种二叉树，满足以下性质：

1. **左子树**所有节点的值 **小于** 根节点的值
2. **右子树**所有节点的值 **大于** 根节点的值
3. 左右子树也分别是 BST（递归定义）

BST 的三大核心操作：

- **查找**：从根开始，比根小往左走，比根大往右走
- **插入**：查找路径走到空位置时插入
- **中序遍历**：得到**有序序列**（这是 BST 最重要的性质）

```cpp
#include <bits/stdc++.h>
using namespace std;
struct Node {
    int val;
    Node *left, *right;
    Node(int v) : val(v), left(nullptr), right(nullptr) {}
};
// 插入
Node* insert(Node* root, int v) {
    if (!root) return new Node(v);
    if (v < root->val) root->left = insert(root->left, v);
    else if (v > root->val) root->right = insert(root->right, v);
    return root;
}
// 查找
bool search(Node* root, int v) {
    if (!root) return false;
    if (v == root->val) return true;
    return v < root->val ? search(root->left, v) : search(root->right, v);
}
// 中序遍历（得到有序序列）
void inorder(Node* root) {
    if (!root) return;
    inorder(root->left);
    cout << root->val << " ";
    inorder(root->right);
}
int main() {
    Node* root = nullptr;
    int a[] = {5, 3, 8, 1, 4, 7, 9};
    for (int x : a) root = insert(root, x);
    cout << "中序遍历: ";
    inorder(root);
    cout << "\n";
    cout << "查找4: " << (search(root, 4) ? "yes" : "no") << "\n";
    cout << "查找6: " << (search(root, 6) ? "yes" : "no") << "\n";
    return 0;
}
// 输入：（无输入）
// 输出：中序遍历: 1 3 4 5 7 8 9
//       查找4: yes
//       查找6: no
```

### 58.2 BST的退化问题

如果按**有序序列**插入 BST（如 1, 2, 3, 4, 5），每个节点都只有右子节点，BST 退化为一条链，树高为 $n$。此时查找、插入、删除的时间复杂度从 $O(\log n)$ 退化为 $O(n)$。

```
    1                    退化后：
     \                   1
      2                   \
       \                    2
        3                    \
         \                     3
          4                     \
           \                      4
            5                       \
                                      5
```

这是 BST 的致命缺陷，**平衡树**就是为了解决这个问题而诞生的。

### 58.3 平衡的动机

**目标**：保持树高 $O(\log n)$，从而保证所有操作 $O(\log n)$。

**核心思想**：通过"旋转"操作调整树的结构，使其保持"平衡"（左右子树高度差有界）。

不同平衡树采用不同的平衡策略：

| 平衡树 | 平衡策略 | 期望/保证树高 |
|--------|---------|--------------|
| AVL树 | 严格平衡因子 $\leq 1$ | 保证 $O(\log n)$ |
| Treap | 随机优先级 | 期望 $O(\log n)$ |
| Splay | 伸展操作 | 均摊 $O(\log n)$ |
| 替罪羊树 | 重构比例阈值 | 均摊 $O(\log n)$ |

### 58.4 AVL树

**AVL树**是最早发明的自平衡二叉搜索树，要求每个节点的**平衡因子**（左子树高度 - 右子树高度）的绝对值不超过 1。

**平衡因子**：$BF(u) = h(\text{left}) - h(\text{right})$，要求 $|BF(u)| \leq 1$。

**旋转操作**：当插入/删除导致不平衡时，通过旋转恢复平衡。

- **右旋（LL型）**：左子树的左子树过高
- **左旋（RR型）**：右子树的右子树过高
- **左右旋（LR型）**：左子树的右子树过高
- **右左旋（RL型）**：右子树的左子树过高

```
右旋示意（LL型）：
      y                x
     / \              / \
    x   C    =>      A   y
   / \                  / \
  A   B                B   C
```

AVL 树是**严格平衡**的，树高严格保证 $O(\log n)$，但旋转操作较多，插入删除常数较大。

### 58.5 Treap

**Treap** = Tree + Heap，在 BST 的每个节点上额外赋予一个**随机优先级**，同时满足：

- 按 val 满足 BST 性质
- 按 priority 满足堆性质（大根堆或小根堆）

通过**随机优先级**，在期望意义下保证树高 $O(\log n)$（类似随机 BST 的期望树高）。

插入时先按 BST 方式插入叶子，再通过旋转上浮到满足堆性质的位置。删除时先将节点旋转到叶子再删除。

```cpp
#include <bits/stdc++.h>
using namespace std;
struct Node {
    int val, priority;
    Node *left, *right;
    Node(int v) : val(v), priority(rand()), left(nullptr), right(nullptr) {}
};
// 右旋
Node* rotateRight(Node* y) {
    Node* x = y->left;
    y->left = x->right;
    x->right = y;
    return x;
}
// 左旋
Node* rotateLeft(Node* x) {
    Node* y = x->right;
    x->right = y->left;
    y->left = x;
    return y;
}
// 插入
Node* insert(Node* root, int v) {
    if (!root) return new Node(v);
    if (v < root->val) {
        root->left = insert(root->left, v);
        if (root->left->priority > root->priority)
            root = rotateRight(root);
    } else if (v > root->val) {
        root->right = insert(root->right, v);
        if (root->right->priority > root->priority)
            root = rotateLeft(root);
    }
    return root;
}
void inorder(Node* root) {
    if (!root) return;
    inorder(root->left);
    cout << root->val << " ";
    inorder(root->right);
}
int main() {
    srand(42);
    Node* root = nullptr;
    int a[] = {1, 2, 3, 4, 5};  // 有序插入也不会退化
    for (int x : a) root = insert(root, x);
    cout << "中序遍历: ";
    inorder(root);
    cout << "\n";
    return 0;
}
// 输入：（无输入）
// 输出：中序遍历: 1 2 3 4 5
// 说明：虽然有序插入，但随机优先级保证树高期望 O(log n)，中序遍历仍有序
```

### 58.6 Splay树

**Splay树**（伸展树）的核心思想：**每次访问一个节点后，通过旋转将它移到根**（splay操作）。

- **优点**：最近访问的节点在根附近，适合有"局部性"的访问模式；无需额外存储平衡信息；均摊 $O(\log n)$
- **应用**：LCT（Link-Cut Tree）、区间翻转等高级数据结构的基础
- **splay操作**：通过 zig（单旋）、zig-zig、zig-zag 三种情况将节点旋转到根

Splay 代码量较大，CSP-S 中一般只需理解原理，不要求手写。

### 58.7 替罪羊树

**替罪羊树**（Scapegoat Tree）的平衡策略：设定一个平衡因子 $\alpha$（如 0.7），当某节点的某子树大小超过总大小的 $\alpha$ 倍时，对该子树进行**暴力重构**（中序遍历后重建为完全平衡的树）。

- **优点**：实现简单，无需旋转，思路直观
- **缺点**：重构是 $O(\text{子树大小})$ 的，但均摊仍为 $O(\log n)$
- **适用**：需要简单实现平衡树的场景

### 58.8 各平衡树对比与选择建议

| 特性 | AVL | Treap | Splay | 替罪羊树 |
|------|-----|-------|-------|---------|
| 平衡依据 | 平衡因子 | 随机优先级 | 访问局部性 | 大小比例 |
| 复杂度 | 严格 $O(\log n)$ | 期望 $O(\log n)$ | 均摊 $O(\log n)$ | 均摊 $O(\log n)$ |
| 实现难度 | 中 | 较低 | 高 | 低 |
| 额外空间 | 高度 | 优先级 | 无 | 无 |
| 持久化 | 较难 | 容易 | 难 | 一般 |
| 推荐场景 | 查询多 | 通用 | 区间操作/LCT | 实现简单 |

**CSP-S 建议**：竞赛中首选 **Treap**（实现相对简单、支持各种操作），或用 STL 的 set/multiset 替代。

### 58.9 CSP-S中平衡树的考法

CSP-S 中平衡树的考查方式：

1. **概念理解题**：选择/填空考查 BST 性质、平衡树原理、复杂度分析
2. **set/multiset 替代**：大部分"动态维护有序集合"的问题可用 `multiset` 解决
3. **手写模板题**（较少）：如 P3369，需要实现插入、删除、排名、kth 等操作
4. **结合其他算法**：平衡树作为工具，配合 DP、图论等使用

### 58.10 用STL替代平衡树的场景

| 操作 | STL替代 | 说明 |
|------|---------|------|
| 插入/删除 | `multiset::insert/erase` | $O(\log n)$ |
| 查找第k小 | 不能直接，需配合 | `multiset` 不支持 $O(\log n)$ kth |
| 查询排名 | `lower_bound` 配合 | $O(\log n)$ |
| 前驱/后继 | `prev/next` 迭代器 | $O(\log n)$ |
| 区间最值 | `set` + 迭代器 | $O(\log n)$ |

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    multiset<int> s;
    s.insert(5); s.insert(3); s.insert(8); s.insert(3); s.insert(7);
    // 遍历（有序）
    cout << "全部: ";
    for (int x : s) cout << x << " ";
    cout << "\n";
    // 前驱：比 5 小的最大值
    auto it = s.lower_bound(5);
    if (it != s.begin()) cout << "5的前驱: " << *prev(it) << "\n";
    // 后继：比 5 大的最小值
    auto it2 = s.upper_bound(5);
    if (it2 != s.end()) cout << "5的后继: " << *it2 << "\n";
    // 排名（<5的个数）
    cout << "5的排名(<=5): " << distance(s.begin(), s.upper_bound(5)) << "\n";
    return 0;
}
// 输入：（无输入）
// 输出：全部: 3 3 5 7 8
//       5的前驱: 3
//       5的后继: 7
//       5的排名(<=5): 3
```

## 常见误区

1. **误区**：以为 BST 的中序遍历结果不一定有序。
   **纠正**：BST 的中序遍历**一定**是升序序列，这是 BST 的基本性质。

2. **误区**：以为随机数据插入 BST 也会退化。
   **纠正**：随机数据插入 BST 的期望树高为 $O(\log n)$，只有**有序或接近有序**的数据才会导致退化。

3. **误区**：混淆 AVL 的平衡因子定义（左-右 还是 右-左）。
   **纠正**：两种定义都可以，关键是一致使用。常用 $BF = h_L - h_R$，要求 $|BF| \leq 1$。

4. **误区**：以为 Treap 的优先级需要手动指定。
   **纠正**：优先级用**随机数**生成，这是保证期望平衡的关键。确定性优先级可能被构造数据卡。

5. **误区**：CSP-S 中所有有序集合问题都手写平衡树。
   **纠正**：绝大部分可用 `multiset`/`set` 解决，手写仅在需要 kth、区间翻转等高级操作时才必要。

6. **误区**：以为 Splay 的单次操作是 $O(\log n)$。
   **纠正**：Splay 是**均摊** $O(\log n)$，单次操作最坏可到 $O(n)$，但总代价均摊后为 $O(\log n)$。

## 典型例题

### 例题1：P3369 【模板】普通平衡树（Treap实现）

**题意**：实现一个数据结构，支持：插入、删除、查询排名、查询第k小、查询前驱、查询后继。

**思路**：用 Treap 实现。每个节点维护子树大小，支持 rank 和 kth 操作。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int INF = 1e9;
struct Node {
    int val, pri, size, cnt;
    Node *l, *r;
    Node(int v) : val(v), pri(rand()), size(1), cnt(1), l(nullptr), r(nullptr) {}
};
int sz(Node* t) { return t ? t->size : 0; }
void upd(Node* t) { if (t) t->size = sz(t->l) + t->cnt + sz(t->r); }
void split(Node* t, int v, Node*& a, Node*& b) {
    if (!t) { a = b = nullptr; return; }
    if (t->val <= v) { a = t; split(t->r, v, a->r, b); upd(a); }
    else { b = t; split(t->l, v, a, b->l); upd(b); }
}
Node* merge(Node* a, Node* b) {
    if (!a || !b) return a ? a : b;
    if (a->pri > b->pri) { a->r = merge(a->r, b); upd(a); return a; }
    else { b->l = merge(a, b->l); upd(b); return b; }
}
void insert(Node*& root, int v) {
    Node *a, *b, *c, *d;
    split(root, v - 1, a, b);
    split(b, v, c, d);
    if (c) c->cnt++, upd(c);
    else c = new Node(v);
    root = merge(merge(a, c), d);
}
void del(Node*& root, int v) {
    Node *a, *b, *c, *d;
    split(root, v - 1, a, b);
    split(b, v, c, d);
    if (c) {
        if (c->cnt > 1) c->cnt--, upd(c);
        else c = nullptr;
    }
    root = merge(merge(a, c), d);
}
int rankOf(Node* root, int v) {
    Node *a, *b;
    split(root, v - 1, a, b);
    int r = sz(a) + 1;
    root = merge(a, b);
    return r;
}
int kth(Node* root, int k) {
    if (!root) return 0;
    if (k <= sz(root->l)) return kth(root->l, k);
    else if (k <= sz(root->l) + root->cnt) return root->val;
    else return kth(root->r, k - sz(root->l) - root->cnt);
}
int main() {
    srand(42);
    ios::sync_with_stdio(false);
    cin.tie(0);
    int n;
    cin >> n;
    Node* root = nullptr;
    while (n--) {
        int op, x;
        cin >> op >> x;
        if (op == 1) insert(root, x);
        else if (op == 2) del(root, x);
        else if (op == 3) cout << rankOf(root, x) << "\n";
        else if (op == 4) cout << kth(root, x) << "\n";
        else if (op == 5) cout << kth(root, rankOf(root, x) - 1) << "\n";
        else cout << kth(root, rankOf(root, x + 1)) << "\n";
    }
    return 0;
}
// 输入：10
//       1 106465
//       4 1
//       1 317721
//       1 460929
//       1 644985
//       1 84185
//       1 89851
//       6 81968
//       1 472054
//       5 89851
// 输出：106465
//       84185
//       84185
// 说明：插入后集合={84185,89851,106465,317721,460929,472054,644985}
//       第2行：查询81968的后继(>81968的最小值)=84185
//       第3行：查询89851的前驱(<89851的最大值)=84185
```

### 例题2：P6136 【模板】普通平衡树（数据加强版）

**题意**：与 P3369 类似，但数据范围更大（$n \leq 10^6$），要求更高的效率。

**思路**：使用 FHQ Treap（无旋 Treap），通过 split/merge 操作实现，代码简洁且效率高。对大量查询使用异或强制在线。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int N = 2000005;
struct Node {
    int val, pri, size;
    int l, r;
} t[N];
int tot, root;
int newNode(int v) {
    t[++tot] = {v, (int)rand(), 1, 0, 0};
    return tot;
}
int sz(int x) { return x ? t[x].size : 0; }
void upd(int x) { if (x) t[x].size = sz(t[x].l) + 1 + sz(t[x].r); }
void split(int x, int v, int& a, int& b) {
    if (!x) { a = b = 0; return; }
    if (t[x].val <= v) { a = x; split(t[x].r, v, t[a].r, b); upd(a); }
    else { b = x; split(t[x].l, v, a, t[b].l); upd(b); }
}
int merge(int a, int b) {
    if (!a || !b) return a | b;
    if (t[a].pri > t[b].pri) { t[a].r = merge(t[a].r, b); upd(a); return a; }
    else { t[b].l = merge(a, t[b].l); upd(b); return b; }
}
void ins(int v) {
    int a, b;
    split(root, v - 1, a, b);
    root = merge(merge(a, newNode(v)), b);
}
void del(int v) {
    int a, b, c, d;
    split(root, v, a, b);
    split(a, v - 1, c, d);
    if (d) d = merge(t[d].l, t[d].r);  // 删除一个
    root = merge(merge(c, d), b);
}
int rnk(int v) {
    int a, b;
    split(root, v - 1, a, b);
    int r = sz(a) + 1;
    root = merge(a, b);
    return r;
}
int kth(int x, int k) {
    if (!x || k <= 0) return 0;  // 空树或k无效，返回0
    if (sz(t[x].l) >= k) return kth(t[x].l, k);
    else if (sz(t[x].l) + 1 == k) return t[x].val;
    else return kth(t[x].r, k - sz(t[x].l) - 1);
}
int main() {
    srand(42);
    ios::sync_with_stdio(false);
    cin.tie(0);
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        int v;
        cin >> v;
        ins(v);
    }
    int last = 0, sum = 0;
    while (m--) {
        int op, x;
        cin >> op >> x;
        x ^= last;
        if (op == 1) ins(x);
        else if (op == 2) del(x);
        else if (op == 3) { last = rnk(x); sum ^= last; }
        else if (op == 4) { last = kth(root, x); sum ^= last; }
        else if (op == 5) {
            int a, b;
            split(root, x - 1, a, b);
            last = kth(a, sz(a));
            root = merge(a, b);
            sum ^= last;
        } else {
            int a, b;
            split(root, x, a, b);
            last = kth(b, 1);
            root = merge(a, b);
            sum ^= last;
        }
    }
    cout << sum << "\n";
    return 0;
}
// 输入：4 5
//       1 2 3 4
//       1 5
//       3 3
//       4 1
//       2 5
//       6 3
// 输出：3
// 说明：初始集合={1,2,3,4}，last=0,sum=0
//       操作1：插入5^0=5，集合={1,2,3,4,5}（插入不更新last）
//       操作3：查询3^0=3的排名，≤2的有2个，排名=3，last=3，sum=3
//       操作4：查询第1^3=2小，第2小=2，last=2，sum=3^2=1
//       操作2：删除5^2=7，7不存在（删除不更新last）
//       操作6：查询3^2=1的后继，后继=2，last=2，sum=1^2=3
```

## 📖 本章总结

- 平衡树基础概念
  - 二叉搜索树（BST）
    - 性质：左<根<右，中序遍历有序
    - 操作：查找/插入 $O(h)$
    - 退化问题：有序插入退化为链，$O(n)$
  - 平衡的动机
    - 保持树高 $O(\log n)$
    - 通过旋转/重构调整结构
  - AVL树
    - 平衡因子 $|BF| \leq 1$
    - 左旋/右旋，严格平衡
  - Treap
    - Tree + Heap，随机优先级
    - 期望 $O(\log n)$，实现较简单
    - FHQ Treap（split/merge）推荐
  - Splay
    - 伸展操作，访问后移到根
    - 均摊 $O(\log n)$，支持区间操作
  - 替罪羊树
    - 大小比例阈值触发重构
    - 实现最简单
  - CSP-S考法
    - 概念理解为主
    - 可用 set/multiset 替代大部分功能
    - 手写仅在需 kth/区间操作时
