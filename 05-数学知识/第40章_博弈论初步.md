# 第40章 博弈论初步

> 前面的章节里，我们处理的都是"单人"问题——找一个最优解、一条最短路、一个最大值。但有一类问题截然不同：**两个人轮流操作，每个人都想赢**。这就是博弈论（Game Theory）。本章从最经典的 NIM 游戏入手，讲清楚必胜态/必败态的判定规则，再引入 SG 函数这一通用工具，让你能分析任意公平组合游戏。

!!! info "本章内容"
    - 公平组合游戏（ICG）的定义与四个条件
    - 必胜态 N 与必败态 P 的判定规则
    - NIM 游戏：NIM 和（异或和）定理
    - SG 函数与 mex 运算：游戏和的 SG 定理
    - NIM 定理是 SG 定理的特例
    - 常见变形：反 NIM、阶梯 NIM 简介
    - 常见误区与配套习题精讲

## 💡 生活类比

打个比方：你和同桌面前有两堆糖果，一堆 3 颗、一堆 5 颗。规则很简单——轮流拿，每次只能从**一堆**里拿任意多颗（至少拿 1 颗），拿到**最后一颗**的人赢。你先拿，怎么拿才能保证必胜？

直觉上你会想"让对手面对一个不舒服的局面"。博弈论就是在回答这个问题：什么样的局面"不舒服"（必败），什么样的局面"舒服"（必胜），以及怎么把不舒服的局面扔给对手。

关键洞察：两堆数量**相同**时，先手必败——因为无论你从一堆拿几颗，对手都可以从另一堆拿同样多，始终保持两堆相等，最终对手拿走最后一颗。所以你第一步应该把 (3, 5) 变成 (3, 3)——从第二堆拿 2 颗，对手就陷入了"两堆相等"的必败态。这个"两堆相等必败"的直觉，推广到任意多堆就是著名的 **NIM 定理**。

## 第一节 公平组合游戏

### 1.1 什么是公平组合游戏

博弈论竞赛题考察的大多是**公平组合游戏**（Impartial Combinatorial Game, ICG）。一个游戏要成为 ICG，必须同时满足四个条件：

| 条件 | 内容 | 说明 |
|------|------|------|
| ① 两人轮流 | 两名玩家交替操作，每次一步 | 不能跳过回合 |
| ② 信息完全 | 双方都知道当前局面和所有历史操作 | 没有暗牌、没有随机性 |
| ③ 有限步结束 | 游戏一定在有限步内分出胜负 | 不能无限循环 |
| ④ 操作相同 | 双方面对同一局面时，合法操作集合完全一样 | 不像象棋红黑子不同 |

!!! tip "怎样判断是不是 ICG"
    核心看条件④：如果双方可执行的操作完全相同（如取石子），就是 ICG；如果操作不同（如象棋红黑方），就不是 ICG。CSP-S 博弈题几乎都是 ICG。

### 1.2 反例：哪些游戏不是 ICG

| 游戏 | 不满足的条件 | 原因 |
|------|:----------:|------|
| 国际象棋 | ④ | 红方只能走红子，黑方只能走黑子 |
| 斗地主 | ② | 手牌对对手隐藏 |
| 麻将 | ②③ | 有随机性（摸牌）和隐藏信息 |
| NIM 取石子 | 全部满足 ✅ | 典型 ICG |

## 第二节 必胜态 N 与必败态 P

### 2.1 核心定义

在 ICG 中，每个局面（状态）要么是**必胜态**（N-position），要么是**必败态**（P-position）：

| 名称 | 含义 | 记法 |
|------|------|------|
| **必胜态 N** | 当前操作的玩家**存在**一种走法使对手必败 | N = Next player wins |
| **必败态 P** | 当前操作的玩家**无论怎么走**都让对手必胜 | P = Previous player wins |

### 2.2 三条递推规则

N 和 P 的判定遵循三条规则，这是所有博弈分析的基石：

1. **终态是 P 态**：没有合法操作的状态（无法行动者输）是必败态
2. **能到 P 的是 N 态**：只要存在**一个**后继是 P 态，当前就是 N 态（把 P 扔给对手）
3. **只能到 N 的是 P 态**：如果**所有**后继都是 N 态，当前就是 P 态（怎么走都给对手 N）

!!! info "记忆口诀"
    **"能到 P 就是 N，只能到 N 就是 P，终点是 P。"** 这三条规则构成了一个自洽的判定系统。

### 2.3 小状态转移表演示

以"两堆石子、每次从一堆取任意多、取光者胜"为例（2 堆 NIM），列出小状态的 N/P：

| 状态 (a, b) | a ⊕ b | N/P | 说明 |
|:-----------:|:-----:|:---:|------|
| (0, 0) | 0 | **P** | 终态，无路可走 |
| (0, 1) | 1 | **N** | 取走 1 → (0,0) 即 P 态 |
| (1, 0) | 1 | **N** | 取走 1 → (0,0) 即 P 态 |
| (1, 1) | 0 | **P** | 只能到 (0,1)/(1,0) 均为 N |
| (1, 2) | 3 | **N** | 从第二堆取 1 → (1,1) 即 P |
| (2, 2) | 0 | **P** | 只能到 N 态 |
| (1, 3) | 2 | **N** | 从第二堆取 2 → (1,1) 即 P |
| (2, 3) | 1 | **N** | 从第二堆取 1 → (2,2) 即 P |

观察规律：**a ⊕ b = 0 时为 P 态，≠ 0 时为 N 态**。这正是 NIM 定理在两堆时的体现。

## 第三节 NIM 游戏与 NIM 定理

### 3.1 NIM 游戏规则

地上有 $n$ 堆石子，数量分别为 $a_1, a_2, \dots, a_n$。两人轮流操作，每次从**任意一堆**中取走**至少 1 颗**石子（可以取光），取走**最后一颗**石子的人获胜。

### 3.2 NIM 定理

!!! info "NIM 定理（Bouton 定理）"
    定义 **NIM 和** $S = a_1 \oplus a_2 \oplus \dots \oplus a_n$（$\oplus$ 为异或）：
    - $S \neq 0$：先手**必胜**（N 态）
    - $S = 0$：先手**必败**（P 态）

### 3.3 用小例子验证

**例**：两堆石子，分别为 3 和 5。

```
3 = 011（二进制）
5 = 101（二进制）
3 ⊕ 5 = 110 = 6 ≠ 0 → 先手必胜
```

先手必胜策略：找到一堆 $a_i$，使得 $a_i \oplus S < a_i$（从这堆取走若干，使剩余 $a_i' = a_i \oplus S$，新 NIM 和变为 0）。

```
S = 6
堆1 (3): 6 ⊕ 3 = 5,  5 < 3? 否（不能"加"石子）
堆2 (5): 6 ⊕ 5 = 3,  3 < 5? 是！取走 5−3=2 颗，剩 3
```

操作后局面变为 (3, 3)，$3 \oplus 3 = 0$，对手陷入 P 态。此后无论对手怎么取，先手都可以"对称"操作保持异或和为 0。

### 3.4 NIM 定理的证明思路

只需验证三条递推规则：

1. **终态**：$(0, 0, \dots, 0)$ 的异或和 $= 0$，是 P 态 ✓
2. **S ≠ 0 能变 S = 0**：设 $S$ 最高位为第 $k$ 位，则至少有一堆 $a_i$ 的第 $k$ 位为 1。令 $a_i' = a_i \oplus S$，则 $a_i'$ 的第 $k$ 位变为 0 且高位不变，故 $a_i' < a_i$（合法操作）。新异或和 $= S \oplus a_i \oplus a_i' = S \oplus a_i \oplus (a_i \oplus S) = 0$ ✓
3. **S = 0 只能变 S ≠ 0**：改变任意一堆 $a_i \to a_i'$（$a_i' < a_i$），新异或和 $= 0 \oplus a_i \oplus a_i' = a_i \oplus a_i' \neq 0$（因为 $a_i \neq a_i'$）✓

### 3.5 NIM 游戏判定代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int T; cin >> T;
    while (T--) {
        int n; cin >> n;
        int nimSum = 0;
        for (int i = 1; i <= n; i++) {
            int a; cin >> a;
            nimSum ^= a;              // 逐堆异或
        }
        cout << (nimSum ? "Yes" : "No") << "\n";
    }
    return 0;
}
```

## 第四节 SG 函数与 mex 运算

### 4.1 为什么需要 SG 函数

NIM 定理只适用于"每次从一堆取任意多"的游戏。如果规则变了——比如每次只能取 1、2 或 3 颗，或者有更复杂的操作——NIM 定理就不直接适用了。**SG 函数**是分析**任意**公平组合游戏的通用工具。

### 4.2 mex 运算

$$\text{mex}(S) = \text{不属于集合 } S \text{ 的最小非负整数}$$

| 集合 S | mex(S) |
|--------|:------:|
| {0, 1, 2} | 3 |
| {1, 3, 5} | 0 |
| {0, 2, 4} | 1 |
| {} (空集) | 0 |

### 4.3 SG 函数定义

对于游戏中的状态 $x$，其 SG 值为：

$$SG(x) = \text{mex}\{SG(y) \mid y \text{ 是 } x \text{ 的后继状态}\}$$

- **终态**（无后继）：$SG = \text{mex}(\varnothing) = 0$（P 态）
- **SG = 0**：P 态（必败）
- **SG ≠ 0**：N 态（必胜）

这与 N/P 的递推规则完全对应：SG = 0 意味着 0 不在后继 SG 集合中（即没有 P 态后继）。

### 4.4 计算示例：每次取 1~3 颗

单堆石子 $n$ 颗，每次取 1、2 或 3 颗，取光者胜。

| n | 后继状态 | 后继 SG 集合 | SG(n) = mex |
|:-:|---------|:----------:|:-----------:|
| 0 | 无 | {} | **0** |
| 1 | {0} | {0} | **1** |
| 2 | {0,1} | {0,1} | **2** |
| 3 | {0,1,2} | {0,1,2} | **3** |
| 4 | {1,2,3} | {1,2,3} | **0** |
| 5 | {2,3,4} | {2,3,0} | **1** |
| 6 | {3,4,5} | {3,0,1} | **2** |

规律：$SG(n) = n \bmod 4$。SG = 0 当且仅当 $n$ 是 4 的倍数——这正是 Bash 博弈的结论。

### 4.5 游戏和定理（SG 定理）

!!! info "SG 定理（Sprague-Grundy 定理）"
    若游戏由若干**独立**的子游戏 $G_1, G_2, \dots, G_k$ 组成（每回合选一个子游戏操作），则整个游戏的 SG 值：
    $$SG_{\text{总}} = SG(G_1) \oplus SG(G_2) \oplus \dots \oplus SG(G_k)$$

这是博弈论最强大的工具：把复杂游戏拆成独立子游戏，分别算 SG，再异或起来。

## 第五节 NIM 定理是 SG 定理的特例

### 5.1 NIM 中每堆的 SG 值

NIM 游戏中，一堆 $a_i$ 颗石子，可以取任意多（1 到 $a_i$ 颗），后继状态为 $0, 1, \dots, a_i - 1$。

$$SG(a_i) = \text{mex}\{SG(0), SG(1), \dots, SG(a_i - 1)\}$$

递推可知：$SG(0) = 0$，$SG(1) = \text{mex}\{0\} = 1$，$SG(2) = \text{mex}\{0,1\} = 2$，……，$SG(a_i) = a_i$。

### 5.2 代入 SG 定理

NIM 有 $n$ 堆，每堆是一个独立子游戏，$SG(a_i) = a_i$。由 SG 定理：

$$SG_{\text{总}} = a_1 \oplus a_2 \oplus \dots \oplus a_n = \text{NIM 和}$$

$SG_{\text{总}} = 0$ 即 P 态（必败），$\neq 0$ 即 N 态（必胜）。**NIM 定理就是 SG 定理在"每次取任意多"游戏中的特例**。

!!! tip "理解层次"
    SG 定理是"通用定理"，NIM 定理是"特殊结论"。做题时，如果游戏规则就是标准 NIM，直接算异或和即可；如果规则有变化，就需要算 SG 函数。

## 第六节 SG 函数的递归计算与记忆化

### 6.1 SG 函数的递归计算

当游戏规则不是标准 NIM（每次取任意多），而是有特殊限制（如每次只能取 1~k 颗、取法依赖状态等）时，需要**直接按定义递归计算 SG 值**：

$$SG(x) = \text{mex}\{SG(y) \mid y \text{ 是 } x \text{ 的后继状态}\}$$

递归思路：
1. 枚举当前状态 $x$ 的所有合法后继 $y$
2. 递归求出每个 $SG(y)$，收集到一个集合
3. $SG(x) = \text{mex}$（集合中最小未出现的非负整数）
4. 边界：无后继的状态 $SG = 0$

### 6.2 记忆化避免重复计算

朴素递归会重复计算同一状态的 SG，时间爆炸。用**记忆化数组** `sg[x]` 缓存：算过的直接返回，没算过的才递归。

### 6.3 通用 SG 模板（递归 + 记忆化）

下面以"每次可取 1、3、4 颗石子，取光者胜"为例，给出通用 SG 计算模板：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1005;
int sg[MAXN];                  // 记忆化数组，-1 表示未计算
bool vis[105];                 // 标记后继 SG 值是否出现

// 计算 sg[x]：x 颗石子时的 SG 值
int getSG(int x) {
    if (sg[x] != -1) return sg[x];    // 已记忆化，直接返回
    if (x == 0) return sg[x] = 0;     // 边界：无后继，SG=0

    memset(vis, 0, sizeof(vis));       // 收集后继 SG 集合
    // 枚举所有合法操作：取 1、3、4 颗
    int moves[] = {1, 3, 4};
    for (int m : moves) {
        if (x >= m) {
            vis[getSG(x - m)] = true;  // 后继状态 x-m 的 SG 值
        }
    }
    // mex：最小未出现的非负整数
    int mex = 0;
    while (vis[mex]) mex++;
    return sg[x] = mex;
}

int main() {
    memset(sg, -1, sizeof(sg));
    // 输出前 20 个状态的 SG 值，打表找规律
    for (int i = 0; i <= 20; i++) {
        printf("sg[%d] = %d\n", i, getSG(i));
    }
    return 0;
}
```

!!! tip "打表找规律"
    算出前若干个 SG 值后，通常会呈现**周期性**规律。例如本题打表后发现 sg 序列以周期 7 循环，于是可用 $O(1)$ 判断任意 $x$ 的 SG。竞赛中"算 SG → 打表 → 找规律"是标准流程。

### 6.4 多堆游戏的 SG 定理应用

若游戏有多个独立子游戏（如多堆石子），由 **SG 定理**：

$$SG_{\text{总}} = SG(G_1) \oplus SG(G_2) \oplus \dots \oplus SG(G_k)$$

- $SG_{\text{总}} = 0$：先手必败（P 态）
- $SG_{\text{总}} \neq 0$：先手必胜（N 态）

!!! info "Nim 是 SG 定理的特例"
    标准 NIM 中每堆 $SG(x) = x$，所以 $SG_{\text{总}} = a_1 \oplus a_2 \oplus \dots \oplus a_n$，正是 NIM 和。当规则改变后，把每堆的 $SG$ 算出来再异或即可。

### 6.5 阶梯 Nim 的 SG 视角

阶梯 NIM 中，石子放在若干级台阶，每次从一级取若干放到下一级，最底层取出消失。其结论是**只看奇数级台阶异或和**：

- 奇数级异或和 $\neq 0$：先手必胜
- 奇数级异或和 $= 0$：先手必败

**SG 视角理解**：偶数级台阶的石子可以被对手"对称回应"（你往下挪几颗，对手也往下挪几颗），相当于不影响胜负；只有奇数级台阶构成真正的 Nim 游戏。这也是 SG 定理"独立子游戏异或"思想的一个直观体现。

```cpp
// 阶梯 NIM 判定
#include <bits/stdc++.h>
using namespace std;
int main() {
    int n; cin >> n;          // n 级台阶，编号 1~n
    int xorSum = 0;
    for (int i = 1; i <= n; i++) {
        int a; cin >> a;
        if (i % 2 == 1) xorSum ^= a;   // 只异或奇数级
    }
    cout << (xorSum ? "Yes" : "No") << "\n";
    return 0;
}
```

!!! warning "SG 函数计算注意"
    - `sg[]` 初始化为 `-1` 表示未计算，避免与合法 SG 值 0 混淆
    - 每次算 `mex` 前要清空 `vis`，且 `vis` 大小要覆盖可能的 SG 值范围
    - 状态空间大时（如 $10^9$）不能直接记忆化，必须打表找周期规律

!!! tip "SG 要点"
    - SG 函数按定义递归计算：枚举后继 → 取 mex；用记忆化避免重复计算
    - 多子游戏总 SG = 各子游戏 SG 异或和；NIM 是 $SG(x)=x$ 的特例
    - 阶梯 NIM 只看奇数级异或和；状态空间大时打表找规律

## 第七节 常见变形

### 7.1 反 NIM（取光者负）

规则与 NIM 相同，但**取走最后一颗石子的人输**（misère play）。判定结论有所变化：

| 情况 | 反 NIM 结论 |
|------|-----------|
| 所有堆都只有 1 颗 | 堆数为**奇数**时先手**必败**，偶数时必胜 |
| 至少一堆 > 1 | NIM 和 ≠ 0 → 先手必胜；NIM 和 = 0 → 先手必败（与正常 NIM 相同） |

### 7.2 阶梯 NIM

石子放在若干级台阶上，每次可以从**一级台阶**取若干石子**扔到下一级**，最底级的石子扔出（消失）。取最后一个石子者胜。

**关键转化**：只看**奇数级**台阶的石子异或和。偶数级台阶的石子可以"对称回应"消除影响。

| 阶梯 NIM 结论 | 说明 |
|-------------|------|
| 奇数级异或和 ≠ 0 | 先手必胜 |
| 奇数级异或和 = 0 | 先手必败 |

### 7.3 变形小结

| 变形 | 核心思路 | 关键结论 |
|------|---------|---------|
| 反 NIM | 分类讨论"全 1 堆"情况 | 至少一堆 > 1 时与正常 NIM 一致 |
| 阶梯 NIM | 只看奇数级台阶 | 奇数级异或和判定 |
| 合并/分裂 NIM | 视具体规则算 SG | 通常需打表找规律 |

!!! warning "变形题不能套公式"
    以上结论仅适用于对应变形。遇到新规则，**第一反应是算 SG 函数打表找规律**，而不是硬套 NIM 定理。

## 第八节 常见误区

!!! warning "误区一：混淆 N 态和 P 态的定义"
    N 态是"当前操作的玩家必胜"（Next player wins），不是"先手必胜"。只是在初始局面下，当前操作者就是先手，两者重合。在推导中间状态时，务必明确"当前轮到谁"。

!!! warning "误区二：以为 SG 值越大越"好""
    SG 值只看**是否为 0**：SG = 0 是 P 态，SG ≠ 0 是 N 态。SG = 100 和 SG = 1 的性质相同（都是 N 态）。SG 值的具体大小只影响"有哪些后继"，不直接代表"优势大小"。

!!! warning "误区三：多堆异或漏算堆或写成加法"
    异或满足交换律和结合律，顺序无关，但必须**每堆都参与异或**。常见错误：循环从 $i = 2$ 开始（漏了第一堆），或把 `nimSum ^= a` 写成 `nimSum += a`。建议初始化 `nimSum = 0`，从 $i = 1$ 开始异或所有堆。

!!! warning "误区四：把非 ICG 游戏套用 NIM/SG 定理"
    如果双方可执行的操作**不同**（如带颜色的棋子），不满足 ICG 条件④，不能直接用 SG 定理。必须先确认是 ICG。

!!! warning "误区五：反 NIM 直接套用 NIM 定理"
    反 NIM（取光者负）在"全 1 堆"情况下的结论与正常 NIM **相反**。不能无脑算异或和。

## 第九节 配套习题精讲

### 9.1 [P2197] 【模板】NIM 游戏

**题意**：多组数据，每组 $n$ 堆石子，每次从一堆取任意多，取光者胜。判断先手是否必胜。输出 `Yes` 或 `No`。

**思路**：直接套 NIM 定理，算异或和。$S \neq 0$ 输出 `Yes`，否则 `No`。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false); cin.tie(0);
    int T; cin >> T;
    while (T--) {
        int n; cin >> n;
        int nimSum = 0;
        for (int i = 1; i <= n; i++) {
            int a; cin >> a;
            nimSum ^= a;              // 逐堆异或
        }
        cout << (nimSum ? "Yes" : "No") << "\n";
    }
    return 0;
}
```

**复杂度**：时间 $O(n)$，空间 $O(1)$。

### 9.2 [P1247] 取火柴游戏

**题意**：$k$ 堆火柴，每次从一堆取若干根，取走最后一根者胜。若先手必胜，输出第一步方案（从第几堆取几根）及取后状态；若必败，输出 `lose`。多解时输出堆编号最小、再取数最小的方案。

**思路**：先算 NIM 和 $S$。若 $S = 0$，输出 `lose`。否则从小到大枚举堆 $i$，找到第一个满足 $S \oplus a_i < a_i$ 的堆，取走 $a_i - (S \oplus a_i)$ 根，剩余 $S \oplus a_i$ 根。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 500005;
int a[MAXN];

int main() {
    int k;
    scanf("%d", &k);
    int s = 0;
    for (int i = 1; i <= k; i++) {
        scanf("%d", &a[i]);
        s ^= a[i];                   // 计算 NIM 和
    }
    if (s == 0) {
        printf("lose\n");
        return 0;
    }
    for (int i = 1; i <= k; i++) {
        int t = s ^ a[i];            // 第 i 堆操作后剩余数
        if (t < a[i]) {              // 合法：只能减少不能增加
            printf("%d %d\n", i, a[i] - t);   // 堆编号, 取走量
            a[i] = t;                // 更新该堆
            break;
        }
    }
    for (int i = 1; i <= k; i++)
        printf("%d%c", a[i], i < k ? ' ' : '\n');
    return 0;
}
```

!!! tip "为什么 t = S ⊕ a_i < a_i 时一定合法"
    $S$ 的最高位为 1，$a_i$ 在该位也为 1（否则 $S$ 该位不可能为 1）。异或后该位变 0，更高位不变，故 $t < a_i$，操作合法（只减不增）。

**复杂度**：时间 $O(k)$，空间 $O(k)$。

### 9.3 [P2594] [ZJOI2009] 染色游戏

**题意**：$n \times m$ 的硬币阵列，每个硬币正面（H）或反面（T）。每次选一个连通块翻转，要求存在一个"锚点"硬币，其余硬币都在它左上方，且锚点从反面翻为正面。无法操作者输。判断先手是否必胜，胜输出 `-_-`，败输出 `=_=`。

**思路**：这是**翻硬币博弈**，属于 ICG。关键结论：
1. 整局 SG 值 = 各反面硬币**单独** SG 值的异或和（翻硬币博弈的独立性）
2. 单个反面硬币的 SG 值通过**打表找规律**得到——所有 SG 值都是 2 的幂：

| 位置 $(i,j)$ | SG 值 |
|:---:|:---:|
| $i=1$ 或 $j=1$（第一行/列） | $\text{lowbit}(i+j-1)$ |
| $i > 1$ 且 $j > 1$ | $2^{i+j-2}$ |

用 `vis[k]` 记录"SG = $2^k$ 的反面硬币个数的奇偶"，若存在奇数则异或和非零，先手必胜。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXS = 210;
bool vis[MAXS];          // vis[k] = SG 值为 2^k 的反面硬币个数的奇偶
char s[110];

// 返回 (i,j) 位置单个反面硬币 SG 值的指数 k（SG = 2^k）
int getSG(int i, int j) {
    if (i == 1 || j == 1) {
        int x = i + j - 1;
        return __builtin_ctz(x);    // 等价于 log2(lowbit(x))
    } else {
        return i + j - 2;           // SG = 2^(i+j-2)
    }
}

int main() {
    int T;
    scanf("%d", &T);
    while (T--) {
        memset(vis, 0, sizeof(vis));
        int n, m;
        scanf("%d%d", &n, &m);
        for (int i = 1; i <= n; i++) {
            scanf("%s", s + 1);
            for (int j = 1; j <= m; j++) {
                if (s[j] != 'H') {              // 反面朝上的硬币
                    vis[getSG(i, j)] ^= 1;      // 对应指数奇偶翻转
                }
            }
        }
        int win = 0;
        for (int i = 0; i <= n + m; i++) {      // 任一位为奇 → 异或和非零
            if (vis[i]) { win = 1; break; }
        }
        puts(win ? "-_-" : "=_=");
    }
    return 0;
}
```

!!! tip "翻硬币博弈的核心结论"
    若每次操作必须将某个硬币从 T 翻为 H（其余硬币任意翻转），则整局 SG = 各 T 硬币单独 SG 的异或和。这是因为只有 T 硬币能作为"锚点"，各 T 硬币的贡献相互独立。本题所有 SG 值恰好是 2 的幂，因此用奇偶数组即可判定异或和是否为零。

**复杂度**：时间 $O(nm)$，空间 $O(n+m)$。

## 📖 本章总结

### 知识脉络

- **公平组合游戏 ICG**：四条件（轮流/完全信息/有限步/操作相同）
- **N 态与 P 态**：能到P即N，只能到N即P，终点为P
- **NIM 定理**：异或和≠0 先手胜，=0 先手败
- **SG 函数**：SG(x)=mex{后继 SG}；SG=0 为 P 态
- **SG 定理**：游戏和的 SG = 各子游戏 SG 异或和
  - NIM 定理是 SG 定理的特例（每堆 SG=aᵢ）
- **常见变形**：反 NIM / 阶梯 NIM / 合并 NIM
- **常见误区**
  - 混淆 N/P 定义
  - SG 值只看是否为 0，不是越大越好
  - 异或漏算堆 / 写成加法
  - 非 ICG 不能套定理
- **配套习题**：P2197 模板 / P1247 输出方案 / P2594 翻硬币 SG

### 核心口诀

| 口诀 | 含义 |
|------|------|
| **能到 P 就是 N，只能到 N 就是 P** | N/P 判定的三条规则 |
| **异或为零先手败，非零先手胜** | NIM 定理一句话 |
| **mex 后继取最小缺数** | SG 函数的计算方法 |
| **子游戏 SG 异或和** | SG 定理处理组合游戏 |
| **SG 为零即必败** | 不管 SG 值多大，只看是否为 0 |
