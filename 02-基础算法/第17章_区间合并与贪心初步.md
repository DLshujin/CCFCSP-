## 核心概念

### 区间合并的定义

**区间合并**：给定 $n$ 个区间 $[l_i, r_i]$，把所有有交集（含端点相邻）的区间合并成一个新区间，输出合并后**互不相交**的区间集合。

```
输入：[1,3] [2,6] [8,10] [15,18]
        ↓ 合并相邻/重叠的区间
输出：[1,6] [8,10] [15,18]
```

### 贪心思想的引入

区间合并为什么是贪心？因为我们做出的是一个**局部最优决策**：

> 按左端点排序后，从左到右扫描，**能合并就立刻合并**（让当前区间的右端点尽可能向右延伸）。

每一步"贪心地延伸右端点"看似只关注眼前，但累积起来得到的合并结果就是全局最优——没有任何一个该合并的区间被遗漏。这就是"局部最优 → 全局最优"的典型体现。

!!! info "贪心的两个关键问题"
    学习贪心，永远要回答两件事：

    1. **策略是什么**：每一步按什么规则做选择？（区间合并：按左端点排序 + 能并则并）
    2. **为什么是对的**：凭什么局部最优能保证全局最优？（用交换论证 / 反证法证明）

### 算法执行过程演示

以输入 `[1,3] [2,6] [8,10] [15,18]` 为例（已按左端点排序）：

```
步骤  当前区间    curL,curR   判断              动作
────────────────────────────────────────────────────────
初始  [1,3]       1, 3        —                 设为当前合并段
 1    [2,6]       1, 3        2 ≤ 3 → 重叠      curR = max(3,6) = 6
 2    [8,10]      1, 6        8 > 6 → 不重叠    输出[1,6]，开新段[8,10]
 3    [15,18]     8,10        15 > 10 → 不重叠  输出[8,10]，开新段[15,18]
结束  —           15,18       —                 输出[15,18]

最终结果：[1,6] [8,10] [15,18]
```

可以看到，每一步只关注"当前区间能否并入"，这种局部判断最终拼出了完整的合并结果。

### 为什么按左端点排序是对的（交换论证）

**直觉**：按左端点排序后，所有可能"挨在一起"的区间都连续排列了，扫描时只需关注右端点能延伸多远。

**交换论证**：假设最优合并方案中，某区间 $A$ 排在了左端点更小的区间 $B$ 前面处理。由于我们按左端点排序，$B$ 的左端点更小，更可能被并入当前合并段；交换 $A$、$B$ 的处理顺序不会让任何本应合并的区间被拆开。因此"按左端点排序"得到的方案就是最优的——**贪心交换不劣化**，这正是贪心成立的信号。

### 区间操作速查表

| 操作 | 排序依据 | 贪心准则 | 典型问题 |
|------|---------|---------|---------|
| **区间合并** | 左端点↑ | 右端点能延伸就延伸 `curR=max(curR,r)` | 火烧赤壁 P1496 |
| **贪心选区间（区间调度）** | 右端点↑ | 左端点 ≥ 上次右端点则选 | 线段覆盖 P1803 |
| **区间选点** | 右端点↑ | 在右端点放点覆盖该区间 | 种树 P1250 |
| **区间覆盖** | 左端点↑ | 每次选能延伸到最右的区间 | 区间覆盖模板 |

!!! warning "最易混淆的排序准则"
    **区间合并、区间覆盖**按**左端点**排序；**贪心选区间、区间选点**按**右端点**排序。初学者最常在此处翻车，务必记牢。

    记忆口诀：**合并看左边，选择看右边**。

### 复杂度分析

- 排序：$O(n \log n)$
- 贪心扫描：$O(n)$（每个区间只访问一次）
- 总时间复杂度：$O(n \log n)$，空间复杂度 $O(n)$

!!! info "为什么扫描是 O(n) 而非 O(n²)"
    合并扫描中指针 `i` 单调递增，每个区间只被访问一次，故扫描部分仅 $O(n)$。瓶颈在排序的 $O(n \log n)$。

## 代码实现

### 模板一：区间合并标准模板

按左端点排序，扫描合并重叠区间：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;

int n;
struct Interval { int l, r; } a[MAXN];

// 按左端点排序；左端点相同则按右端点排序
bool cmp(const Interval &x, const Interval &y) {
    if (x.l != y.l) return x.l < y.l;
    return x.r < y.r;
}

int main() {
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i].l >> a[i].r;

    sort(a, a + n, cmp);            // 第一步：排序

    // 第二步：贪心合并
    vector<Interval> ans;
    if (n == 0) { cout << 0 << "\n"; return 0; }
    int curL = a[0].l, curR = a[0].r;
    for (int i = 1; i < n; i++) {
        if (a[i].l <= curR) {       // 有重叠（或相邻）
            curR = max(curR, a[i].r);   // 合并：取右端点较大者
        } else {                    // 无重叠
            ans.push_back({curL, curR});
            curL = a[i].l;
            curR = a[i].r;
        }
    }
    ans.push_back({curL, curR});    // 别忘了最后一个

    for (auto &p : ans) {
        cout << p.l << " " << p.r << "\n";
    }
    return 0;
}
```

!!! tip "合并时必须取 max 右端点"
    合并 `[1,6]` 与 `[2,4]`，结果应为 `[1,6]` 而非 `[1,4]`——后一区间可能完全被包含。故 `curR = max(curR, a[i].r)`，不能直接赋值。

!!! tip "注意区间的开闭性"
    - **闭区间** $[l,r]$：相邻即合并，条件 `a[i].l <= curR`（看题意是否把相邻端点视为重叠）
    - **左闭右开** $[l,r)$：`a[i].l < curR` 表示有重叠，`a[i].l == curR` 表示刚好相邻不重叠
    - 长度计算：闭区间是 `r - l + 1`，左闭右开是 `r - l`

    读题务必看清开闭约定，这会直接影响合并条件与长度公式。

### 模板一变式：求合并后总长度（火烧赤壁 P1496 思路）

合并后把每个区间的长度累加即可。注意左闭右开区间长度为 `r - l`，坐标较大时用 `long long`：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 20005;

int n;
struct Interval { long long l, r; } a[MAXN];

bool cmp(const Interval &x, const Interval &y) {
    if (x.l != y.l) return x.l < y.l;
    return x.r < y.r;
}

int main() {
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i].l >> a[i].r;

    sort(a, a + n, cmp);

    long long ans = 0;
    long long curL = a[0].l, curR = a[0].r;
    for (int i = 1; i < n; i++) {
        if (a[i].l <= curR) {           // 有重叠
            curR = max(curR, a[i].r);   // 延伸右端点
        } else {
            ans += curR - curL;         // 累加当前合并区间长度
            curL = a[i].l;
            curR = a[i].r;
        }
    }
    ans += curR - curL;                 // 最后一个区间

    cout << ans << "\n";
    return 0;
}
```

### 模板二：贪心选区间（区间调度）

选**最多**互不相交的区间，按右端点排序：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1000005;

int n;
struct Interval { int l, r; } a[MAXN];

bool cmp(const Interval &x, const Interval &y) {
    return x.r < y.r;               // 按右端点升序排序
}

int main() {
    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i].l >> a[i].r;

    sort(a, a + n, cmp);

    int cnt = 0;
    int lastEnd = -0x3f3f3f3f;      // 上一个选中区间的右端点
    for (int i = 0; i < n; i++) {
        if (a[i].l >= lastEnd) {    // 与已选区间不相交
            lastEnd = a[i].r;       // 选中该区间
            cnt++;
        }
    }
    cout << cnt << "\n";
    return 0;
}
```

**为什么按右端点排序？** 结束得越早的区间越值得先选——它结束早，给后面留下的时间窗口越大。这是贪心"局部最优"的体现：每一步选当前结束最早的，累积起来就是最多不相交区间数。

!!! info "两个模板的排序准则对比"
    - 区间合并 → 按**左端点**（让可能相邻的区间连续排列）
    - 贪心选区间 → 按**右端点**（让"结束最早"的区间优先被选，给后面留更多空间）

    一字之差，策略迥异。考场上下笔前先默念口诀"合并看左边，选择看右边"。

## ⚠️ 常见误区

!!! danger "误区一：区间未按左端点排序就直接合并"
    若区间未排序，相邻扫描时 `[8,10]` 可能排在 `[1,3]` 前面，导致本应合并的 `[1,3]`、`[2,6]` 被拆开。**排序是区间合并的前提**，缺了它结果必然错误。

    **正确做法**：合并前必须 `sort(a, a+n, cmp)`，且 `cmp` 以左端点为主键。

!!! danger "误区二：合并条件或右端点更新写错"
    常见错误写法：`curR = a[i].r`（未取 max）或漏判 `a[i].l <= curR`。

    - 不取 max：遇到 `[1,6]` 与 `[2,4]` 会把 `curR` 错误缩小到 4，丢失覆盖范围。
    - 条件写反：把 `<=` 写成 `<`，会把"端点相邻"的区间误判为不重叠。

    **正确写法**：`if (a[i].l <= curR) curR = max(curR, a[i].r);`

!!! danger "误区三：以为所有问题都能贪心"
    贪心并非万能。例如"01 背包"中按性价比排序贪心**不一定**最优（高性价比物品可能超重，挤掉了更优组合）。判断贪心是否成立，要么**证明**（交换论证 / 反证法），要么**举反例**验证不成立后改用 DP。

    区间合并与区间调度之所以贪心成立，是因为排序后"相邻性"被保序，局部决策不会损害后续选择——这种"贪心交换不劣化"的结构正是贪心成立的信号。

!!! warning "误区四：忘记处理最后一个合并区间"
    循环结束时，当前 `[curL, curR]` 还没压入答案。务必在循环后补一句 `ans.push_back({curL, curR})`，否则会漏掉最后一段，是考场上的高频低级失分点。

!!! warning "误区五：混淆区间合并与贪心选区间的排序准则"
    把贪心选区间（P1803）误按左端点排序，会得到错误答案。两者目标不同：合并是"归并重叠"，选区间是"挑最多不冲突"。**先想清题目目标，再定排序准则**。

## 典型例题

### 洛谷 P1803 凌乱的yyy / 线段覆盖

!!! example "题目大意"
    给定 $n$ 个区间 $[a_i, b_i)$，求最多能选多少个**互不相交**的区间。

    这是"区间调度"的经典模板题，CSP-J/S 高频考点。

**分析**

要选最多不相交区间，关键直觉是：**结束得越早的区间越值得先选**——它结束早，给后面留下的时间窗口就越大。因此按**右端点升序**排序，依次贪心选择。

**正确性证明（交换论证）**：设最优解选了 $k$ 个区间，其第一个区间右端点为 $r^*$。我们贪心选的第一个区间右端点 $r_1 \le r^*$（因为按右端点排序，贪心选的是最小的）。把最优解的第一个区间换成我们的贪心区间，不会让剩余可选区间变少（结束更早只会腾出更多空间），故仍可选出 $\ge k$ 个。归纳即得贪心解不劣于最优解。

**执行过程演示**

设输入为 `[1,4] [2,3] [3,5] [0,1] [5,6]`，按右端点排序后：`[0,1] [2,3] [1,4] [3,5] [5,6]`：

```
步骤  区间     lastEnd  判断            动作        cnt
──────────────────────────────────────────────────────
 1    [0,1]   -∞       0 ≥ -∞ → 选    lastEnd=1    1
 2    [2,3]   1        2 ≥ 1  → 选    lastEnd=3    2
 3    [1,4]   3        1 < 3  → 跳过  —            2
 4    [3,5]   3        3 ≥ 3  → 选    lastEnd=5    3
 5    [5,6]   5        5 ≥ 5  → 选    lastEnd=6    4

答案：4
```

**完整代码**

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1000005;

int n;
struct Interval { int l, r; } a[MAXN];

bool cmp(const Interval &x, const Interval &y) {
    return x.r < y.r;               // 按右端点升序
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i].l >> a[i].r;

    sort(a, a + n, cmp);

    int cnt = 0;
    int lastEnd = -0x3f3f3f3f;      // 上一个选中区间的右端点
    for (int i = 0; i < n; i++) {
        if (a[i].l >= lastEnd) {    // 不相交（左闭右开：>= 即不重叠）
            lastEnd = a[i].r;
            cnt++;
        }
    }
    cout << cnt << "\n";
    return 0;
}
```

!!! tip "左闭右开区间的判断细节"
    P1803 是左闭右开 $[a_i, b_i)$：一个区间结束于 $b_i$，下一个从 $b_i$ 开始不算重叠，故判断条件是 `a[i].l >= lastEnd`（而非 `>`）。读题务必看清开闭约定。

!!! tip "数据规模与读入优化"
    P1803 的 $n$ 可达 $10^6$，加上 `ios::sync_with_stdio(false); cin.tie(nullptr);` 加速读入可避免 TLE。这是大数据量题目的通用技巧。

**练习 5**：[P2887] [USACO07NOV] Sunscreen - https://www.luogu.com.cn/problem/P2887

**练习 6**：[P1043] [NOIP2003] 数字游戏 - https://www.luogu.com.cn/problem/P1043
> $n$ 个数字成环分成 $m$ 段，求各段和之积的最大/最小值。**提示**：区间 DP。把环断成链（复制一倍），$f[i][j][k]$ 表示 $[i,j]$ 分 $k$ 段的最值。体会"区间划分"思维与本章区间模型的内在联系。

## 📖 本章总结

### 核心要点回顾

- ✅ **区间合并**：按左端点排序，扫描时 `curR = max(curR, r)` 能延伸就延伸
- ✅ **贪心选区间**：按右端点排序，左端点 ≥ `lastEnd` 就选
- ✅ **贪心思想**：局部最优 → 全局最优；成立需证明（交换论证）
- ✅ **排序准则记忆**：合并看左边，选择看右边
- ✅ **贪心非万能**：不成立时（如 01 背包）改用 DP
- ✅ 区间合并常与**离散化**配合处理大坐标问题

### 知识脉络思维导图

- **第17章 区间合并与贪心初步**

  - **常见误区**

    - 漏处理最后区间
    - 混淆两类排序准则
