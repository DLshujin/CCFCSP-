## 💡 生活类比

### 类比一：家族族谱 / 公司组织架构

二叉树最直观的类比就是**家族族谱**或**公司组织架构图**：最顶端是老祖宗（CEO），下面分出两个分支，每个分支再继续分叉……每个节点**最多两个孩子**，这就是"二叉"的由来。

```
                爷爷（根）
               /        \
            爸爸          叔叔
           /    \        /    \
         你    妹妹    堂哥   堂妹
        （叶子）                （叶子）
```

- **根**：族谱最顶端那个人（爷爷），没有父亲
- **叶子**：没有孩子的人（你、妹妹、堂妹），族谱到此为止
- **深度**：从根算起，你在第 3 层，深度为 3
- **度**：爸爸有 2 个孩子，度数为 2；你是 0
- **父子关系**：爸爸是你的父亲，你是爸爸的孩子

!!! tip "一句话记忆"
    二叉树 = 每个节点**最多两个孩子**的层级结构。递归地看：一棵二叉树要么为空，要么由「根 + 左子树 + 右子树」组成。

## 第一节 树的基本术语

### 1.1 什么是树

「树 tree」是一种**层次化**的数据结构，由 $n(n \geq 0)$ 个节点组成的有限集合：当 $n=0$ 时为**空树**；当 $n>0$ 时，有且仅有一个**根 root**节点，其余节点可分为若干互不相交的有限集合，每个集合本身又是一棵树，称为根的**子树**。

### 1.2 核心术语速查表

| 术语 | 定义 | 类比 |
|------|------|------|
| **根 root** | 没有父节点的唯一节点 | 族谱顶端的老祖宗 |
| **叶子 leaf** | 没有子节点的节点 | 没有后代的族人 |
| **内部节点** | 既非根也非叶子的节点 | 中间辈分的人 |
| **父节点 parent** | 节点直接上方连接的节点 | 你的父亲 |
| **子节点 child** | 节点直接下方连接的节点 | 你的孩子 |
| **兄弟 sibling** | 同一个父节点的节点 | 你的兄弟姐妹 |
| **度 degree** | 节点子节点的个数 | 你有几个孩子 |
| **树的度** | 所有节点度的最大值 | 整棵树里谁孩子最多 |
| **深度 depth** | 从根到该节点的路径长度（根深度为 0，本书采用边数定义） | 你在第几层 |
| **高度 height** | 从该节点到最远叶子的路径长度 | 你这一脉传了多少代 |
| **树的高度** | 根节点的高度 | 整个家族传了多少代 |
| **层 level** | 深度相同的节点属于同一层 | 同辈人 |

!!! warning "深度 vs 高度（易混点）"
    - **深度**：从**根**往下数到该节点（自顶向下）
    - **高度**：从该节点往下数到最远叶子（自底向上）
    - **树的高度** = 根的高度 = 最深叶子到根的距离

    约定有两种：根深度为 0 或 1。本书采用**根深度为 0**的约定（边数定义，与多数竞赛教材一致）：路径长度按"边数"计，叶子高度为 0，根高度 = 树的高度 = 最长路径的边数。

### 1.3 树的 ASCII 示意图

```
            A           ← 根，深度 0，高度 3
           / \
          B   C         ← 深度 1，B 高度 2，C 高度 1
         / \   \
        D   E   F       ← 深度 2，D 高度 1，E/F 高度 0（叶子）
       /
      G                 ← 深度 3，叶子，高度 0

度数：A=2, B=2, C=1, D=1, E=0, F=0, G=0
树的度 = 2（A 和 B 都是 2）
树的高度 = 3（最深到 G，共 3 条边）
叶子：E, F, G（D 不是叶子，因为它有孩子 G）
```

!!! tip "判断叶子的标准"
    叶子 = **没有孩子**的节点，不是"在最底层"。上图中 D 在第 3 层但有孩子 G，不是叶子；E、F 在第 3 层没有孩子，是叶子。

## 第二节 二叉树的定义与性质

### 2.1 二叉树的定义

「二叉树 binary tree」是一种特殊的树：每个节点**最多有两个子节点**，分别称为**左孩子**和**右孩子**。

```
        A
       / \
      B   C
     / \   \
    D   E   F
```

注意：B 的左孩子是 D，右孩子是 E；C 只有右孩子 F，**左孩子为空**。**左右孩子是有区别的**，不能互换。

### 2.2 满二叉树与完全二叉树

**满二叉树 full binary tree**：每一层的节点数都达到最大值。

```
            A           高度 2 的满二叉树
           / \          节点数 = 2^{2+1} - 1 = 7
          B   C
         / \ / \
        D  E F  G
```

**完全二叉树 complete binary tree**：除最后一层外全满，最后一层节点**从左到右**连续排列。

```
            A           完全二叉树
           / \          最后一层 D、E、F 连续靠左
          B   C
         / \ /
        D  E F
```

!!! warning "完全二叉树的"连续靠左""
    最后一层不能"跳着"放。比如下图中 G 出现在 F 左边空着的位置，就**不是**完全二叉树：
    ```
            A
           / \
          B   C
         / \   \
        D  E    G    ← 错！F 位置空着却放了 G
    ```

### 2.3 二叉树的五大性质

| 性质 | 内容 | 说明 |
|------|------|------|
| 性质 1 | 第 $i$ 层最多有 $2^i$ 个节点（$i \geq 0$，根为第 0 层） | 第 0 层 1 个，第 1 层 2 个，第 2 层 4 个 |
| 性质 2 | 高度为 $h$ 的二叉树最多有 $2^{h+1} - 1$ 个节点 | 等比数列求和 $1+2+4+\dots+2^h$ |
| 性质 3 | 叶子数 $n_0$ = 度为 2 的节点数 $n_2$ + 1 | $n_0 = n_2 + 1$，常用结论 |
| 性质 4 | $n$ 个节点的完全二叉树高度为 $\lfloor \log_2 n \rfloor$（$n \geq 1$） | 由性质 2 反推 |
| 性质 5 | 完全二叉树中，节点 $i$ 的左孩子是 $2i$，右孩子是 $2i+1$，父节点是 $\lfloor i/2 \rfloor$ | 数组模拟的基础 |

**性质 3 证明（重要）**：设 $n$ 为总节点数，$n_0, n_1, n_2$ 分别为度 0、1、2 的节点数。

- $n = n_0 + n_1 + n_2$（按度分类）
- 总边数 = $n - 1$（除根外每个节点有一条边连向父节点），也 = $n_1 + 2n_2$（按度计算）

联立：$n_0 + n_1 + n_2 - 1 = n_1 + 2n_2$，化简得 $n_0 = n_2 + 1$。

!!! tip "性质 3 的记忆口诀"
    "叶子比二度节点多一个"。考试中常给 $n_2$ 求 $n_0$，或反之。

## 第三节 二叉树的存储方式

### 3.1 存储方式对比

| 存储方式 | 适用场景 | 空间 | 优势 |
|----------|----------|------|------|
| **数组模拟** | 完全二叉树、堆 | $O(2^h)$ | 编码快，父子下标直接算 |
| **结构体指针** | 普通二叉树（教学） | $O(n)$ | 直观，但赛场少用（怕指针） |
| **结构体数组** | 普通二叉树（赛场推荐） | $O(n)$ | 兼顾直观与速度 |

### 3.2 轨道一：数组模拟（完全二叉树）

完全二叉树用数组存最省心：根存下标 1，节点 $i$ 的左孩子 $2i$，右孩子 $2i+1$，父亲 $\lfloor i/2 \rfloor$。

```
完全二叉树：          数组下标：1   2   3   4   5   6
        A              数组内容：A   B   C   D   E   F
       / \
      B   C
     / \ /
    D  E F
```

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1e6 + 10;
int val[N];                 // val[i] 存节点 i 的值

int main() {
    val[1] = 1; val[2] = 2; val[3] = 3;   // 建完全二叉树
    val[4] = 4; val[5] = 5; val[6] = 6;
    int i = 2;
    cout << val[2*i] << " " << val[2*i+1] << " " << val[i/2] << endl;   // 左孩子 右孩子 父亲
    return 0;
}
```

!!! warning "数组模拟的陷阱"
    普通二叉树（非完全）用数组存会**大量浪费空间**。比如一棵退化为链的树，高度 $n$ 需要 $2^n$ 大小的数组。所以数组模拟**只适合完全二叉树**（或堆）。

### 3.3 轨道二：结构体数组模拟（普通二叉树，赛场推荐）

赛场为了避免指针带来的不确定性，常用**结构体数组**模拟普通二叉树。每个节点存「值 + 左孩子下标 + 右孩子下标」，下标 0 表示空。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1e6 + 10;

struct Node {
    char val;              // 节点值
    int lc, rc;            // 左孩子、右孩子的下标，0 表示空
} tree[N];

int root = 0;              // 根节点下标，0 表示空树
int idx = 0;               // 节点计数器

// 新建一个节点，返回其下标
int newNode(char v) {
    tree[++idx].val = v;
    tree[idx].lc = tree[idx].rc = 0;
    return idx;
}
```

!!! tip "为什么用下标 0 表示空"
    全局数组默认初始化为 0，所以 `tree[0].lc = 0` 自然满足"空节点的孩子也是空"。递归遍历时写 `if(u==0) return;` 即可终止，非常优雅。竞赛中**少用结构体指针**（怕内存泄漏、怕忘记初始化），统一采用结构体数组版。

## 第四节 二叉树的四种遍历

遍历是二叉树所有操作的基石。四种遍历方式：**前序、中序、后序**（递归）+ **层序**（BFS）。

### 4.1 三种递归遍历的定义

设当前节点为 $u$，左子树 $L$，右子树 $R$：

| 遍历方式 | 访问顺序 | 助记 |
|----------|----------|------|
| **前序** Preorder | 根 → 左 → 右 | **根**在**前** |
| **中序** Inorder | 左 → 根 → 右 | **根**在**中**间 |
| **后序** Postorder | 左 → 右 → 根 | **根**在**后** |

### 4.2 示例树

```
            A
           / \
          B   C
         / \   \
        D   E   F
```

- 前序：`A B D E C F`
- 中序：`D B E A C F`
- 后序：`D E B F C A`
- 层序：`A B C D E F`

### 4.3 递归遍历代码（核心模板）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1e6 + 10;

struct Node {
    char val;
    int lc, rc;
} tree[N];

int root, idx;

int newNode(char v) {
    tree[++idx].val = v;
    tree[idx].lc = tree[idx].rc = 0;
    return idx;
}

// 前序遍历：根 → 左 → 右
void preorder(int u) {
    if (u == 0) return;              // 基准条件：空节点直接返回
    cout << tree[u].val;             // 先访问根
    preorder(tree[u].lc);            // 再遍历左子树
    preorder(tree[u].rc);            // 最后遍历右子树
}

// 中序遍历：左 → 根 → 右
void inorder(int u) {
    if (u == 0) return;              // 基准条件
    inorder(tree[u].lc);             // 先遍历左子树
    cout << tree[u].val;             // 再访问根
    inorder(tree[u].rc);             // 最后遍历右子树
}

// 后序遍历：左 → 右 → 根
void postorder(int u) {
    if (u == 0) return;              // 基准条件
    postorder(tree[u].lc);           // 先遍历左子树
    postorder(tree[u].rc);           // 再遍历右子树
    cout << tree[u].val;             // 最后访问根
}
```

!!! warning "递归基准条件的位置（最常见误区）"
    `if (u == 0) return;` **必须放在函数第一行**，在访问 `tree[u]` 之前。如果放错位置（比如放在访问根之后），当 `u=0` 时会先访问 `tree[0]`，导致逻辑错误甚至段错误。

    ```cpp
    // ❌ 错误：cout 在 if 之前，u=0 时访问 tree[0]
    void preorder(int u) { cout << tree[u].val; if(!u) return; ... }

    // ✅ 正确：if 在最前面
    void preorder(int u) { if(!u) return; cout << tree[u].val; ... }
    ```

!!! tip "三种遍历的代码差异只有一行"
    三种遍历的递归结构完全相同，**唯一区别**是 `cout << tree[u].val;` 的位置：前序在最前、中序在中间、后序在最后。理解这一点，默写时就不会混淆。

### 4.4 层序遍历（BFS + 队列）

层序遍历按"从上到下、从左到右"的顺序访问节点，借助队列实现。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1e6 + 10;
struct Node {
    char val;
    int lc, rc;
} tree[N];

void levelorder(int root) {
    if (root == 0) return;
    queue<int> q;                    // 队列存节点下标
    q.push(root);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        cout << tree[u].val;         // 访问队首
        if (tree[u].lc) q.push(tree[u].lc);   // 左孩子入队
        if (tree[u].rc) q.push(tree[u].rc);   // 右孩子入队
    }
}
```

**层序遍历运行追踪**（以示例树为例）：

```
弹出 A → 输出 A，B、C 入队   弹出 D → 输出 D（无孩子）
弹出 B → 输出 B，D、E 入队   弹出 E → 输出 E（无孩子）
弹出 C → 输出 C，F 入队      弹出 F → 输出 F（无孩子）
最终输出：A B C D E F
```

### 4.5 四种遍历对比表

| 遍历 | 实现方式 | 根的位置 | 时间复杂度 | 空间复杂度 |
|------|----------|:--------:|:----------:|:----------:|
| 前序 | 递归 | 第一个 | $O(n)$ | $O(h)$ 递归栈 |
| 中序 | 递归 | 中间 | $O(n)$ | $O(h)$ 递归栈 |
| 后序 | 递归 | 最后一个 | $O(n)$ | $O(h)$ 递归栈 |
| 层序 | BFS + 队列 | 按层 | $O(n)$ | $O(w)$ 队列宽度 |

其中 $h$ 为树高，$w$ 为最大层宽。

## 第五节 由遍历序列还原二叉树（S 组高频）

这是 CSP-S 复赛的**高频考点**，必须熟练掌握。核心思想：**前序/后序定位根，中序划分左右子树**。

### 5.1 为什么需要两种序列

- **前序 + 后序**：一般**不能**唯一确定二叉树（当某节点只有一个孩子时，无法区分左右）
- **前序 + 中序**：可以唯一确定
- **后序 + 中序**：可以唯一确定

### 5.2 前序 + 中序 → 还原二叉树

**核心思路**：

1. 前序序列的第一个元素一定是**根**
2. 在中序序列中找到根的位置，**左边**是左子树的中序，**右边**是右子树的中序
3. 由左子树节点数，在前序序列中划分出左子树的前序和右子树的前序
4. 递归处理左右子树

**示例**：

```
前序：A B D E C F
中序：D B E A C F

第1步：前序首元素 A 是根，在中序中找 A，左 "D B E" 是左子树，右 "C F" 是右子树
第2步：左子树 3 个节点 → 前序左子树 "B D E"，右子树 "C F"
第3步：递归——左子树 B D E / D B E → B 根，左 D 右 E；右子树 C F / C F → C 根，右 F
```

还原结果：

```
        A
       / \
      B   C
     / \   \
    D   E   F
```

**完整代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100;
string pre, in;
int idx = 0;

struct Node {
    char val;
    int lc, rc;
} tree[N];

int newNode(char v) {
    tree[++idx].val = v;
    tree[idx].lc = tree[idx].rc = 0;
    return idx;
}

// 由前序 pre[pl..pr] 和中序 in[il..ir] 还原二叉树，返回根下标
int buildPreIn(int pl, int pr, int il, int ir) {
    if (pl > pr) return 0;                  // 空区间，返回空
    int rt = newNode(pre[pl]);              // 前序第一个是根
    int k = il;
    while (in[k] != pre[pl]) k++;           // 在中序中找根
    int leftLen = k - il;                   // 左子树长度
    // 递归建左子树：前序 [pl+1, pl+leftLen]，中序 [il, k-1]
    tree[rt].lc = buildPreIn(pl + 1, pl + leftLen, il, k - 1);
    // 递归建右子树：前序 [pl+leftLen+1, pr]，中序 [k+1, ir]
    tree[rt].rc = buildPreIn(pl + leftLen + 1, pr, k + 1, ir);
    return rt;
}

void postorder(int u) {
    if (u == 0) return;
    postorder(tree[u].lc);
    postorder(tree[u].rc);
    cout << tree[u].val;
}

int main() {
    cin >> pre >> in;
    int n = pre.size();
    int root = buildPreIn(0, n - 1, 0, n - 1);
    postorder(root);                        // 求后序
    cout << endl;
    return 0;
}
```

!!! tip "区间划分的口诀"
    - 前序首元素是根 → `pre[pl]`
    - 中序找根位置 $k$ → 左子树 `[il, k-1]`，右子树 `[k+1, ir]`
    - 左子树长度 `leftLen = k - il`
    - 前序左子树 `[pl+1, pl+leftLen]`，右子树 `[pl+leftLen+1, pr]`

### 5.3 后序 + 中序 → 还原二叉树

**核心思路**与前序+中序类似，区别在于：**后序的最后一个元素是根**。存储结构、`newNode`、遍历函数均与 5.2 节相同，仅 `build` 函数的根位置和区间划分不同：

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100;
string post, in;
int idx = 0;
struct Node { char val; int lc, rc; } tree[N];

int newNode(char v) {
    tree[++idx].val = v;
    tree[idx].lc = tree[idx].rc = 0;
    return idx;
}

// 由后序 post[pl..pr] 和中序 in[il..ir] 还原二叉树，返回根下标
int buildPostIn(int pl, int pr, int il, int ir) {
    if (pl > pr) return 0;                  // 空区间
    int rt = newNode(post[pr]);             // 后序最后一个是根（区别于前序的 pre[pl]）
    int k = il;
    while (in[k] != post[pr]) k++;          // 在中序中找根
    int leftLen = k - il;
    tree[rt].lc = buildPostIn(pl, pl + leftLen - 1, il, k - 1);   // 后序左子树 [pl, pl+leftLen-1]
    tree[rt].rc = buildPostIn(pl + leftLen, pr - 1, k + 1, ir);   // 后序右子树 [pl+leftLen, pr-1]
    return rt;
}

void preorder(int u) {
    if (u == 0) return;
    cout << tree[u].val;
    preorder(tree[u].lc);
    preorder(tree[u].rc);
}

int main() {
    cin >> in >> post;
    int root = buildPostIn(0, post.size() - 1, 0, in.size() - 1);
    preorder(root);                         // 求前序
    cout << endl;
    return 0;
}
```

### 5.4 两种还原方法对比表

| 维度 | 前序 + 中序 | 后序 + 中序 |
|------|-------------|-------------|
| 根的位置 | 前序**第一个** `pre[pl]` | 后序**最后一个** `post[pr]` |
| 中序的作用 | 划分左右子树 | 划分左右子树 |
| 前序/后序左子树区间 | `[pl+1, pl+leftLen]` | `[pl, pl+leftLen-1]` |
| 前序/后序右子树区间 | `[pl+leftLen+1, pr]` | `[pl+leftLen, pr-1]` |
| 常见题目要求 | 求后序 | 求前序 |

!!! warning "区间边界的易错点"
    前序还原时，根在前序区间**第一个**，所以左子树前序从 `pl+1` 开始；后序还原时，根在后序区间**最后一个**，所以右子树后序到 `pr-1` 结束。这两种区间边界容易写反，建议对照表格仔细检查。

## 第六节 常见误区

!!! warning "误区一：递归基准条件位置错误"
    最致命的错误。`if (u == 0) return;` 必须在函数**第一行**，在访问 `tree[u]` 之前。若写成 `cout << tree[u].val; if(!u) return;`，当 `u=0` 时会先访问 `tree[0]`，导致逻辑错误甚至段错误（参见 4.3 节代码对比）。

!!! warning "误区二：混淆深度与高度"
    - 深度：从**根**往下数（根深度为 0，本书采用边数定义）
    - 高度：从**叶子**往上数（叶子高度为 0）
    - 树的高度 = 根的高度 = 最大深度

!!! warning "误区三：误以为前序+后序能唯一还原"
    前序 + 后序**不能**唯一确定二叉树。只有当每个非叶子节点都有两个孩子时才能唯一确定；若某节点只有一个孩子，无法判断是左孩子还是右孩子。

!!! warning "误区四：完全二叉树与满二叉树混淆"
    满二叉树：每层都满；完全二叉树：除最后一层外都满，最后一层**从左到右连续**。

!!! warning "误区五：数组模拟普通二叉树导致空间爆炸 + 层序忘判空"
    普通二叉树（尤其退化成链的）用数组模拟会浪费 $O(2^n)$ 空间，必须用结构体数组。此外，层序遍历中孩子入队前必须判 `if (tree[u].lc)`，否则空节点（下标 0）会入队，导致访问 `tree[0]` 出错。

## 第七节 典型例题

### 7.1 表达式树

「表达式树 expression tree」：用二叉树表示算术表达式。

- **叶子**：操作数（数字）
- **内部节点**：运算符
- **中序遍历**：得到中缀表达式（需加括号处理优先级）
- **前序遍历**：得到前缀表达式（波兰式）
- **后序遍历**：得到后缀表达式（逆波兰式）

```
表达式：(a + b) * (c - d)

        *
       / \
      +   -
     / \ / \
    a  b c  d

前序：* + a b - c d      （前缀式）
中序：a + b * c - d       （中缀式，省略括号）
后序：a b + c d - *       （后缀式）
```

!!! tip "后缀表达式求值"
    后缀表达式可用栈直接求值（见第 18 章）。表达式树的后序遍历正是后缀表达式，体现了树与栈的深刻联系。

### 7.2 哈夫曼树

「哈夫曼树 Huffman tree」用于构造**最优前缀编码**，是数据压缩的基础。

**构造方法**（贪心）：将每个叶子视为单节点树，每次选出**权值最小的两棵树**合并，新树根权值 = 两子树权值之和，重复直到只剩一棵树。

**示例**：4 个叶子，权值 `1, 2, 3, 4`

```
合并 1 和 2 → 3；合并 3（原）和 3（新）→ 6；合并 4 和 6 → 10

         10
        /  \
       4    6
           / \
          3   3
         / \
        1   2
```

**带权路径长度 WPL** = $\sum$ (叶子权值 × 叶子到根的路径长度) = $4 \times 1 + 3 \times 2 + 1 \times 3 + 2 \times 3 = 19$，是所有可能构造中**最小**的。

!!! info "哈夫曼编码"
    每个叶子到根的路径（左分支记 0、右分支记 1）就是该字符的编码。频率高的字符离根近、编码短；频率低的离根远、编码长。这是 ZIP、JPEG 等压缩算法的核心思想。

## 第八节 📚 本节练习

### 8.1 [P4715] 淘汰赛

**题意**：有 $2^n$ 支队伍参加淘汰赛，给出每支队伍的能力值，能力值大的战胜小的。给出对阵图（完全二叉树），求亚军是谁。

**思路**：用完全二叉树模拟淘汰赛。叶子是各队伍，两两比较，较大者晋级。冠军 = 全场最大；亚军 = **决赛中被冠军击败**的那支队伍（即与冠军对阵的另一半区胜者）。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1 << 10;
int a[N];

int main() {
    int n;
    cin >> n;
    int leaf = 1 << n;              // 叶子数 = 2^n
    for (int i = 0; i < leaf; i++) cin >> a[i];

    // 用队列模拟淘汰赛：两两比较，较大者晋级
    queue<int> q;
    for (int i = 0; i < leaf; i++) q.push(i);

    int secondWinner = 0;
    while (q.size() > 1) {
        int x = q.front(); q.pop();
        int y = q.front(); q.pop();
        if (a[x] > a[y]) q.push(x); else q.push(y);
        if (q.size() == 1)          // 决赛结束，被淘汰的是亚军
            secondWinner = (a[x] > a[y]) ? y : x;
    }

    cout << secondWinner + 1 << endl;   // 编号从 1 开始
    return 0;
}
```

### 8.2 [P1305] 新二叉树

**题意**：输入一棵二叉树，每个节点用一个字符表示。给出每个节点的左孩子和右孩子，根是没有作为任何节点孩子出现的节点。求前序遍历。

**思路**：读入每个节点及其左右孩子；找根（未被任何节点当作孩子的节点）；从根开始前序遍历。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 200;
struct Node {
    char val;
    int lc, rc;                // 存字符的 ASCII 值，0 表示空
} tree[130];                   // 下标用字符 ASCII 值

bool isChild[130];

void preorder(int u) {
    if (u == 0) return;
    cout << tree[u].val;
    preorder(tree[u].lc);
    preorder(tree[u].rc);
}

int main() {
    int n;
    cin >> n;
    memset(isChild, false, sizeof(isChild));

    for (int i = 1; i <= n; i++) {
        char v, l, r;
        cin >> v >> l >> r;
        int idx = v - 'A' + 1;
        tree[idx].val = v;
        tree[idx].lc = (l == '*') ? 0 : (l - 'A' + 1);
        tree[idx].rc = (r == '*') ? 0 : (r - 'A' + 1);
        if (l != '*') isChild[l - 'A' + 1] = true;
        if (r != '*') isChild[r - 'A' + 1] = true;
    }

    // 找根：未被当作孩子的节点
    int root;
    for (int i = 1; i <= 26; i++) {
        if (tree[i].val != 0 && !isChild[i]) {
            root = i;
            break;
        }
    }

    preorder(root);
    cout << endl;
    return 0;
}
```

!!! tip "找根的通用技巧"
    根 = 没有父亲的节点。统计每个节点是否被当作孩子出现过，没出现过的就是根。这个技巧在树的各种题目中通用。

### 8.3 [P1030] 求先序排列

**题意**：给出一棵二叉树的中序遍历和后序遍历，求它的前序遍历。

**思路**：直接套用 5.3 节的「后序 + 中序 → 还原二叉树」模板，还原后做前序遍历。完整代码与 5.3 节完全相同，此处不再重复。

!!! tip "本题的简化技巧"
    不必显式建树，可直接在还原过程中输出前序：把 5.3 节 `build` 函数里的 `newNode(post[pr])` 改成 `cout << post[pr];`，其余递归逻辑完全不变，省去建树空间：

    ```cpp
    void solve(int pl, int pr, int il, int ir) {
        if (pl > pr) return;
        cout << post[pr];               // 根，前序先输出
        int k = il;
        while (in[k] != post[pr]) k++;
        int leftLen = k - il;
        solve(pl, pl + leftLen - 1, il, k - 1);
        solve(pl + leftLen, pr - 1, k + 1, ir);
    }
    ```
