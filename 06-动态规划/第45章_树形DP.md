# 第45章 树形DP

> 前面的 DP 都是在"线性"结构（序列、区间）上做的，状态转移沿着下标推进。当问题的结构是一棵树时，DP 的转移方向就变成了"从叶子到根"——这就是树形 DP。树形 DP 是 CSP-S 的高频考点，它把树的层次结构与 DP 的最优子结构完美结合，核心框架就是一句口诀："先递归儿子，再用儿子更新父亲"。

!!! info "本章内容"
    - 树形 DP 的核心思想与通用 DFS 框架
    - 树上最大独立集（没有上司的舞会）：选/不选两态模型
    - 树的直径 DP 解法：维护最深与次深路径，对比 BFS 解法
    - 树形背包：在树上做分组背包（选课、二叉苹果树）
    - 常见误区：DFS 递归深度过大导致栈溢出

---

## 💡 生活类比

打个比方：你是一家公司的 CEO，管理着一棵"组织架构树"。你的直属下属是各部门总监，他们下面又有各自的主管……信息从最底层员工**逐级向上汇报**，每一级在做决策时，只看"直属下属汇报上来的结论"，不需要了解更底层的细节。

树形 DP 就是这个过程：

- **后序 DFS** = 先让最底层员工（叶子节点）算好自己的结论
- **状态转移** = 每个管理者把所有下属的结论"汇总加工"，得出自己的结论
- **根节点** = CEO 最终拿到全局最优解

关键特征：**每个节点只和它的直接子节点交换信息**，不存在"跨级汇报"。这保证了 DP 的无后效性——你不需要关心子树内部的细节，只需要子树汇报上来的"摘要状态"。

## 核心概念

### 45.1 树形DP的核心思想

普通 DP 在序列上做，状态沿"下标 i → i+1"推进。树形 DP 在树上做，状态沿**父子边**推进——从叶子向根逐层汇总。

为什么树天然适合 DP？因为树有两大特性：

| 树的性质 | 对 DP 的意义 |
|---------|------------|
| **无环** | 不存在循环依赖，子问题的求解顺序确定 |
| **唯一父节点** | 每棵子树独立，互不影响（无后效性） |

!!! info "树形DP的三要素"
    - **阶段**：树的深度（从叶子到根的层次）
    - **状态**：`f[u][...]`，以 u 为根的子树的某种最优值
    - **转移**：`f[u][...]` 由所有 `f[v][...]`（v 是 u 的子节点）组合而成

通用框架（后序 DFS）：

```
dfs(u):
    初始化 f[u] 的边界值
    for v in u 的子节点:
        dfs(v)              # 先递归处理子树
        用 f[v] 更新 f[u]    # 再用子树结果更新自己
    返回
```

这个"先递归儿子、再更新自己"的顺序，本质上是**后序遍历**：先处理完所有子树，最后处理当前节点。这保证了更新 `f[u]` 时，所有 `f[v]` 已经计算完毕。

### 45.2 树上最大独立集（没有上司的舞会）

**问题**：一棵树有 n 个节点，每个节点有一个权值。选出若干节点使权值和最大，要求**相邻节点（父子）不能同时选中**。

**状态设计**——经典的"选/不选"两态模型：

- `f[u][0]`：子树 u 中，**不选 u** 时的最大权值和
- `f[u][1]`：子树 u 中，**选 u** 时的最大权值和

**状态转移**：

$$f[u][0] = \sum_{v \in \text{children}(u)} \max(f[v][0], f[v][1]) \quad \text{（u 不选，子节点选不选都行）}$$

$$f[u][1] = \text{val}[u] + \sum_{v \in \text{children}(u)} f[v][0] \quad \text{（u 选了，子节点都不能选）}$$

**图解过程**：

```
        节点3(权值=4)
       /          \
   节点1(2)      节点2(3)
    /
 节点4(5)

从叶子向上算：
  叶子4: f[4][0]=0,  f[4][1]=5
  节点1: f[1][0]=max(0,5)=5   (不选1，选4更优)
         f[1][1]=2+0=2         (选1，不选4)
  节点2: f[2][0]=0,  f[2][1]=3
  节点3: f[3][0]=max(5,2)+max(0,3)=5+3=8   (不选3，子节点自由)
         f[3][1]=4+5+0=9                     (选3，子节点都不选)

答案 = max(f[3][0], f[3][1]) = max(8, 9) = 9
（选节点3和节点4，权值 4+5=9）
```

!!! tip "为什么这个DP是对的？"
    关键在于**无后效性**：一旦确定了 u 选/不选，子树 v 的最优解就完全由 `f[v][0]` 或 `f[v][1]` 决定，与 u 之外的节点无关。树的"子树独立"性质天然保证了这一点。

### 45.3 树的直径（DP解法）

**问题**：求一棵树上**距离最远的两点**之间的路径长度（边数或边权之和）。

**思路**：树上任意一条路径，一定有一个"最高点"（离根最近的点，即路径上所有点的 LCA 中深度最小的）。以最高点 u 为中心，路径 = u 向下走的两条最长路径之和。枚举所有 u 取最大值即可。

**状态设计**：

- `depth[u]`：从 u 向下走到叶子的最长路径长度

**转移**：对 u 的每个子节点 v（边权为 w）：

$$d = \text{depth}[v] + w \quad \text{（经过 v 的下行路径长度）}$$

用 $d$ 更新 u 的最深、次深下行路径，则：

$$\text{depth}[u] = \max_{v \in \text{children}(u)}(\text{depth}[v] + w) \quad \text{（最深下行路径）}$$

$$\text{经过 } u \text{ 的最长路径} = \text{最深} + \text{次深}$$

**图解**：

```
        1
       / \
      2   3
     / \   \
    4   5   6

depth[4]=0  depth[5]=0  depth[6]=0
depth[2]: 子节点4,5 → 最深=1, 次深=1 → 经过2的最长=1+1=2, depth[2]=1
depth[3]: 子节点6 → 最深=1, 次深=0 → 经过3的最长=1, depth[3]=1
depth[1]: 子节点2,3 → 最深=2, 次深=2 → 经过1的最长=2+2=4, depth[1]=2

直径 = 4（路径 4-2-1-3-6 或 5-2-1-3-6）
```

**对比 BFS 解法**：

| 维度 | DP 解法 | BFS 解法（两遍 BFS） |
|------|---------|-------------------|
| 核心思想 | 枚举路径最高点，维护最深次深 | 从任意点 BFS 找最远点 u，再从 u BFS 找最远点 v |
| 时间复杂度 | O(n) | O(n) |
| **适用边权** | 任意权值（正/负均可） | **仅非负权值** |
| 能否顺便求每点最远距离 | ✅ 可得每个点的最深下行 | ❌ 只得直径两端 |
| 是否需要建树（有父子关系） | 需要 | 不需要（无向图即可） |
| 代码量 | 略长 | 较短 |

!!! warning "BFS解法的陷阱"
    BFS 两遍法**只适用于边权非负**的树。若有负权边，从任意点出发的最远点不一定在直径上。此时必须用 DP 解法。

### 45.4 树形背包（选课）

**问题**：n 门课组成一棵树（有先修关系），选 m 门课使总学分最大。选一门课必须先选它的先修课。

**为什么是"分组背包"？** 每个子树 v 看作一个"物品组"：你可以给 v 的子树分配 k 个名额（k=0 表示不选 v，k≥1 表示选 v 及其子树中的 k 门课）。每组内不同 k 值互斥——你只能选一个 k。这正是分组背包的定义。

**状态设计**：

- `f[u][j]`：子树 u 中，**u 必选**，共选 j 门课的最大学分

**转移**（分组背包）：

初始化 $f[u][1] = \text{val}[u]$（选 u 自己，占 1 个名额）。对 u 的每个子节点 v，先 `dfs(v)` 算子树，再倒序枚举 $j$（保证每组只选一次），枚举 $k$ 给 v 分配名额：

$$f[u][j] = \max(f[u][j],\ f[u][j-k] + f[v][k]), \quad 0 \leq k \leq \text{sz}[v]$$

!!! warning "循环顺序是核心"
    - **j 必须倒序**（从大到小）：保证处理子节点 v 时，`f[u][j-k]` 用的是"还没考虑 v"的旧值，避免 v 被重复选取。
    - **k 必须正序**：k 是给 v 分配的名额数，遍历所有可能。
    - 这和一维 0/1 背包的"倒序防重复"是同一个道理。

**复杂度分析**：表面看是三重循环，但利用子树大小约束后，均摊复杂度为 **O(nm)**（每对节点只在它们的 LCA 处被合并一次，总合并次数为 O(n²)，乘以 m 得 O(nm)）。

## 代码实现

下面给出树形 DP 的三个核心模板的完整代码。

### 模板一：树上最大独立集

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 6005;
int val[MAXN];
vector<int> g[MAXN];
int f[MAXN][2];            // f[u][0]不选u, f[u][1]选u
bool hasParent[MAXN];

void dfs(int u) {
    f[u][0] = 0;           // 不选 u，初始为 0
    f[u][1] = val[u];      // 选 u，至少有 u 的权值
    for (int v : g[u]) {
        dfs(v);            // 先递归子树
        f[u][0] += max(f[v][0], f[v][1]);  // u不选，子节点自由
        f[u][1] += f[v][0];                // u选了，子节点都不能选
    }
}

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) scanf("%d", &val[i]);
    for (int i = 1; i < n; i++) {
        int u, v;          // u 的直接上司是 v
        scanf("%d %d", &u, &v);
        g[v].push_back(u); // v -> u，建父到子边
        hasParent[u] = true;
    }
    int root = 1;          // 找根节点（没有父节点）
    while (hasParent[root]) root++;
    dfs(root);
    printf("%d\n", max(f[root][0], f[root][1]));
    return 0;
}
```

### 模板二：树的直径（DP解法）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
struct Edge { int to, w, nxt; } e[MAXN * 2];
int head[MAXN], cnt = 0;
int diameter = 0;          // 全局答案

void addEdge(int u, int v, int w) {
    e[++cnt] = {v, w, head[u]};
    head[u] = cnt;
}

// 返回从 u 向下的最长路径长度
int dfs(int u, int fa) {
    int max1 = 0, max2 = 0;  // 最深、次深下行路径
    for (int i = head[u]; i; i = e[i].nxt) {
        int v = e[i].to, w = e[i].w;
        if (v == fa) continue;       // 不走回头路
        int d = dfs(v, u) + w;       // 子节点下行 + 当前边权
        if (d >= max1) {             // 更新最深和次深
            max2 = max1;
            max1 = d;
        } else if (d > max2) {
            max2 = d;
        }
    }
    diameter = max(diameter, max1 + max2);  // 经过 u 的最长路径
    return max1;                            // 返回最深下行
}

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 1; i < n; i++) {
        int u, v, w;
        scanf("%d %d %d", &u, &v, &w);
        addEdge(u, v, w);
        addEdge(v, u, w);
    }
    dfs(1, 0);
    printf("%d\n", diameter);
    return 0;
}
```

### 模板三：树形背包（选课）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 305;
int val[MAXN];
vector<int> g[MAXN];
int f[MAXN][MAXN];   // f[u][j]: 子树u选j门课的最大学分（u必选）
int sz[MAXN];        // sz[u]: 子树u的最大可选课数

void dfs(int u) {
    f[u][1] = val[u];       // 必选 u，占 1 个名额
    sz[u] = 1;
    for (int v : g[u]) {
        dfs(v);
        // 分组背包：j 倒序，k 正序
        for (int j = sz[u] + sz[v]; j >= 1; j--) {
            for (int k = 0; k <= sz[v] && k <= j - 1; k++) {
                // k=0 表示不选v；k>=1 表示选v及其子树k门课
                // j-k-1>=0 保证 u 至少保留 1 个名额（u自己）
                f[u][j] = max(f[u][j], f[u][j - k] + f[v][k]);
            }
        }
        sz[u] += sz[v];
    }
}

int main() {
    int n, m;
    scanf("%d %d", &n, &m);
    val[0] = 0;             // 虚拟根 0，学分为 0
    for (int i = 1; i <= n; i++) {
        int s;
        scanf("%d %d", &s, &val[i]);
        g[s].push_back(i);  // s 是先修课
    }
    dfs(0);                  // 从虚拟根开始
    printf("%d\n", f[0][m + 1]);  // 虚拟根占 1 名额，实选 m 门
    return 0;
}
```

!!! tip "虚拟根技巧"
    当题目是**森林**（多棵树）时，建一个权值为 0 的虚拟根 0，把所有树根挂到 0 下面，就能统一处理。P2014 选课中，先修课为 0 的课程直接挂在虚拟根下，最后查 `f[0][m+1]` 即可（虚拟根本身占 1 个名额但学分为 0）。

## ⚠️ 常见误区

### 误区1：DFS递归深度过大导致栈溢出

!!! warning "问题"
    当树退化为链（如 n=10⁵ 的链表），DFS 递归深度达 10⁵ 层，默认栈空间（Windows 约 1MB）会**栈溢出 RE**。

    **修复方法**：
    1. **开大栈**：编译时加 `-Wl,--stack=268435456`（256MB），或 `#pragma comment(linker, "/STACK:256000000")`
    2. **改迭代**：用手写栈模拟 DFS，记录访问顺序，再逆序处理
    3. **BFS拓扑序**：先 BFS 求出节点访问顺序，按逆序处理（等价于后序）

    ```cpp
    // 方法3：BFS求逆序，避免递归
    int order[MAXN], idx = 0;
    void bfs(int root) {
        queue<int> q; q.push(root);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            order[idx++] = u;        // BFS顺序
            for (int v : g[u]) q.push(v);
        }
        // 逆序处理等价于后序DFS（先处理子再处理父）
        for (int i = idx - 1; i >= 0; i--) {
            int u = order[i];
            // 在这里做状态转移：此时所有子节点已处理完毕
        }
    }
    ```

### 误区2：树形背包循环顺序写反

!!! warning "问题"
    树形背包中，j 循环若写成**正序**（从小到大），会导致同一个子节点被重复选取。

    ```cpp
    // ❌ 错误：j 正序，f[u][j-k] 可能已包含 v 的贡献
    for (int j = 1; j <= m; j++)
        for (int k = 0; k <= sz[v]; k++)
            f[u][j] = max(f[u][j], f[u][j-k] + f[v][k]);

    // ✅ 正确：j 倒序，保证 f[u][j-k] 是"未考虑v"的旧值
    for (int j = m; j >= 1; j--)
        for (int k = 0; k <= sz[v] && k <= j - 1; k++)
            f[u][j] = max(f[u][j], f[u][j-k] + f[v][k]);
    ```

### 误区3：忘记找根节点 / 建边方向搞反

!!! warning "问题"
    树形 DP 需要有明确的父子关系（从根向叶子递归）。但题目常给的是无向边 (u, v)，需要：
    1. 记录 `hasParent[]` 找根（没有父节点的节点）
    2. DFS 时传 `fa` 参数防止"走回头路"

    ```cpp
    // 无向树建图后，DFS 必须传父节点
    void dfs(int u, int fa) {
        for (int v : g[u]) {
            if (v == fa) continue;  // 关键！不走回头路
            dfs(v, u);
            // 状态转移
        }
    }
    ```

### 误区4：状态初始化遗漏

!!! warning "问题"
    - 最大独立集：忘记 `f[u][0] = 0` 或 `f[u][1] = val[u]`，导致转移用到脏数据
    - 树形背包：忘记 `f[u][1] = val[u]`（u 必选的基础状态），导致全为 0
    - 全局数组默认全 0，但涉及"必选"约束时，需要显式初始化关键状态

### 误区5：树的直径误用BFS处理负权

!!! warning "问题"
    BFS 两遍法**只适用于非负权值**。若有负权边，第一遍 BFS 找到的"最远点"可能不在直径上。

    **修复**：有负权时改用 DP 解法（维护最深次深），DP 解法对任意权值都正确。

## 典型例题

### 例题一：[P1352] 没有上司的舞会

**题意**：某公司有 n 名员工（1≤n≤6000），每人有快乐值（-128~127）。舞会不能同时邀请一个人和他的直接上司。求邀请方案的最大快乐值之和。

**输入**：第一行 n；第二行 n 个快乐值；接下来 n-1 行每行 u, v 表示 u 的直接上司是 v。

**分析**：典型的树上最大独立集。建树后，`f[u][0]` 表示不邀请 u，`f[u][1]` 表示邀请 u。

- `f[u][0] = Σ max(f[v][0], f[v][1])`
- `f[u][1] = happy[u] + Σ f[v][0]`

**代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 6005;
int happy[MAXN];
vector<int> g[MAXN];
int f[MAXN][2];
bool hasParent[MAXN];

void dfs(int u) {
    f[u][0] = 0;
    f[u][1] = happy[u];
    for (int v : g[u]) {
        dfs(v);
        f[u][0] += max(f[v][0], f[v][1]);
        f[u][1] += f[v][0];
    }
}

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) scanf("%d", &happy[i]);
    for (int i = 1; i < n; i++) {
        int u, v;
        scanf("%d %d", &u, &v);
        g[v].push_back(u);      // v 是上司，u 是下属
        hasParent[u] = true;
    }
    int root = 1;
    while (hasParent[root]) root++;
    dfs(root);
    printf("%d\n", max(f[root][0], f[root][1]));
    return 0;
}
```

**复杂度**：时间 O(n)，空间 O(n)。

### 例题二：[P2014] 选课

**题意**：n 门课（1≤n≤300），每门有学分（≤20）。每门课最多一门先修课（0 表示无）。选 m（1≤m≤300）门课使总学分最大，选一门课必须先选其先修课。

**分析**：经典树形背包。建虚拟根 0，把先修课为 0 的课程挂到 0 下。`f[u][j]` 表示子树 u 中选 j 门课（u 必选）的最大学分。

**转移**（分组背包）：

```
f[u][1] = val[u]
for v in children(u):
    for j 倒序:
        for k = 0 to sz[v]:
            f[u][j] = max(f[u][j], f[u][j-k] + f[v][k])
```

**代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 305;
int val[MAXN];
vector<int> g[MAXN];
int f[MAXN][MAXN];
int sz[MAXN];

void dfs(int u) {
    f[u][1] = val[u];
    sz[u] = 1;
    for (int v : g[u]) {
        dfs(v);
        for (int j = sz[u] + sz[v]; j >= 1; j--) {
            for (int k = 0; k <= sz[v] && k <= j - 1; k++) {
                f[u][j] = max(f[u][j], f[u][j - k] + f[v][k]);
            }
        }
        sz[u] += sz[v];
    }
}

int main() {
    int n, m;
    scanf("%d %d", &n, &m);
    val[0] = 0;
    for (int i = 1; i <= n; i++) {
        int s;
        scanf("%d %d", &s, &val[i]);
        g[s].push_back(i);
    }
    dfs(0);
    printf("%d\n", f[0][m + 1]);
    return 0;
}
```

**复杂度**：时间 O(nm)，空间 O(nm)。

### 例题三：[P2015] 二叉苹果树

**题意**：一棵二叉树（1≤n≤100），每条边有苹果数（≤200）。保留 Q（1≤Q≤n）条边，使剩余苹果数最大。根节点 1 必须保留。

**分析**：树形背包变体。`f[u][j]` 表示子树 u 保留 j 条边的最大苹果数。对每个子节点 v（边权 w）：

```
f[u][j] = max(f[u][j], f[u][j-k-1] + f[v][k] + w)
```

其中 k 是分给 v 子树的边数，1 是 u-v 这条边本身。

**代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 105;
struct Edge { int to, w, nxt; } e[MAXN * 2];
int head[MAXN], cnt = 0;
int f[MAXN][MAXN];

void addEdge(int u, int v, int w) {
    e[++cnt] = {v, w, head[u]};
    head[u] = cnt;
}

void dfs(int u, int fa, int q) {
    for (int i = head[u]; i; i = e[i].nxt) {
        int v = e[i].to, w = e[i].w;
        if (v == fa) continue;
        dfs(v, u, q);
        for (int j = q; j >= 1; j--) {       // 倒序
            for (int k = 0; k < j; k++) {     // 给 v 分 k 条边，u-v 占 1 条
                f[u][j] = max(f[u][j], f[u][j - k - 1] + f[v][k] + w);
            }
        }
    }
}

int main() {
    int n, q;
    scanf("%d %d", &n, &q);
    for (int i = 1; i < n; i++) {
        int u, v, w;
        scanf("%d %d %d", &u, &v, &w);
        addEdge(u, v, w);
        addEdge(v, u, w);
    }
    dfs(1, 0, q);
    printf("%d\n", f[1][q]);
    return 0;
}
```

**复杂度**：时间 O(nq²)，空间 O(nq)。

## 📖 本章总结

### 思维导图

- 树形 DP
  - 核心思想
    - 后序 DFS：先递归儿子，再更新父亲
    - 父子边转移：每个节点只与直接子节点交换信息
  - 经典模型
    - 最大独立集：`f[u][0/1]`，选/不选两态模型
    - 树的直径：最深下行 + 次深下行，DP 解法适用任意边权
    - 树形背包：分组背包在树上的应用，j 倒序 k 正序
      - BFS 解法：仅适用于非负边权
  - 常见陷阱
    - 递归过深：链式退化导致栈溢出 RE，需开大栈或改迭代
    - 背包循环：j 正序导致同一子节点被重复选取

### 核心口诀

| 口诀 | 含义 |
|------|------|
| **先递归儿子，再更新父亲** | 树形 DP 的核心框架——后序 DFS |
| **选或不选，两态足够** | 最大独立集只需 f[u][0] 和 f[u][1] |
| **最深次深，相加得直径** | 树的直径 = max(最深下行 + 次深下行) |
| **子树一组，j 倒 k 正** | 树形背包：每个子树是一组，j 倒序 k 正序 |
| **链式退化，栈要开大** | n 大时小心递归深度，开大栈或改迭代 |

### 速查表

| 模型 | 状态设计 | 转移方程 | 复杂度 | 典型题目 |
|------|---------|---------|--------|---------|
| 最大独立集 | f[u][0/1] | f[u][0]=Σmax(f[v][0],f[v][1]); f[u][1]=val[u]+Σf[v][0] | O(n) | P1352 |
