!!! info "本章内容"

    - 时间复杂度 $O(\log n)$ 的原理

    - 差分 + 树状数组：实现区间修改 + 单点查询
    - 经典应用：逆序对计数（离散化 + 树状数组）

## 💡 生活类比

!!! tip "生活类比：楼层值班表"
    想象一栋 8 层的大楼，每层都有一个**值班员**，但不同值班员负责的楼层范围不同：

    ```
    楼层:    1    2    3    4    5    6    7    8
    值班员:  c1   c2   c3   c4   c5   c6   c7   c8
    负责范围:
    c1 → [1]          (管 1 层)
    c2 → [1,2]        (管 2 层)
    c3 → [3]          (管 1 层)
    c4 → [1,2,3,4]    (管 4 层)
    c5 → [5]          (管 1 层)
    c6 → [5,6]        (管 2 层)
    c7 → [7]          (管 1 层)
    c8 → [1,2,3,4,5,6,7,8] (管 8 层)
    ```

    - **查询"第 7 层及以下总人数"**：找值班员 c7（管第 7 层）→ c6（管 5~6 层）→ c4（管 1~4 层），只要问 3 个值班员就够了！
    - **更新"第 3 层来了 5 个人"**：只需通知 c3（管第 3 层）→ c4（管 1~4 层）→ c8（管 1~8 层），也只要更新 3 个值班员！

    关键规律：**编号 $i$ 的值班员恰好管理 $\text{lowbit}(i)$ 层**。楼层越高，管的范围越大——这就是树状数组。

## 第一节 lowbit 运算回顾

### 1.1 什么是 lowbit

`lowbit(x)` 表示 $x$ 的二进制表示中**最低位的 1** 所对应的值。

```
x = 12 = (1100)₂
            ↑ 最低位的 1 在第 2 位（从 0 开始），值为 2² = 4
lowbit(12) = 4 = (100)₂

x = 10 = (1010)₂
           ↑ 最低位的 1 在第 1 位，值为 2¹ = 2
lowbit(10) = 2 = (10)₂

x = 7 = (111)₂
          ↑ 最低位的 1 在第 0 位，值为 2⁰ = 1
lowbit(7) = 1 = (1)₂
```

### 1.2 用位运算求 lowbit

!!! info "核心公式"
    $$\text{lowbit}(x) = x\ \&\ (-x)$$

    这利用了补码的特性。在计算机中，负数用**补码**表示，$-x = \sim x + 1$（按位取反再加一）。

**推导过程**（以 $x = 12$ 为例）：

```
x  = 0000...0000 1100   （12 的原码）
~x = 1111...1111 0011   （按位取反）
-x = 1111...1111 0100   （取反加一，即补码）

x & -x:
   0000...0000 1100
&  1111...1111 0100
=  0000...0000 0100  = 4  ✓（最低位的 1 被保留，其余全为 0）
```

**原理**：取反加一时，最低位的 1 右边的 0 全变成 1，加一后进位回来，恰好让最低位的 1 保持为 1，而更高位全部取反。再与原数做按位与，高位全变 0，只剩最低位的 1。

```cpp
#include <bits/stdc++.h>
using namespace std;

int lowbit(int x) { return x & -x; }

int main() {
    for (int i = 1; i <= 8; i++)
        printf("lowbit(%d) = %d\n", i, lowbit(i));
    return 0;
}
// 输入：无（演示 lowbit 运算）
// 输出：
// lowbit(1) = 1
// lowbit(2) = 2
// lowbit(3) = 1
// lowbit(4) = 4
// lowbit(5) = 1
// lowbit(6) = 2
// lowbit(7) = 1
// lowbit(8) = 8
```

**lowbit 值规律表**（$1 \sim 16$）：

| $i$ | 二进制 | lowbit | $i$ | 二进制 | lowbit |
|-----|--------|--------|-----|--------|--------|
| 1 | 0001 | 1 | 9 | 1001 | 1 |
| 2 | 0010 | 2 | 10 | 1010 | 2 |
| 3 | 0011 | 1 | 11 | 1011 | 1 |
| 4 | 0100 | 4 | 12 | 1100 | 4 |
| 5 | 0101 | 1 | 13 | 1101 | 1 |
| 6 | 0110 | 2 | 14 | 1110 | 2 |
| 7 | 0111 | 1 | 15 | 1111 | 1 |
| 8 | 1000 | 8 | 16 | 10000 | 16 |

## 第二节 树状数组的基本结构

### 2.1 核心定义

设原数组为 $a_1, a_2, \dots, a_n$，树状数组 $c$ 定义为：

$$c[i] = \sum_{k=i-\text{lowbit}(i)+1}^{i} a_k$$

即 $c[i]$ 存储 $a$ 数组中**从 $i - \text{lowbit}(i) + 1$ 到 $i$** 这一段的区间和，区间长度恰好为 $\text{lowbit}(i)$。

```
以 n = 8 为例，a[1]~a[8] 为原数组：

c[1] = a[1]                    （管辖区间 [1, 1]，长度 lowbit(1)=1）
c[2] = a[1] + a[2]             （管辖区间 [1, 2]，长度 lowbit(2)=2）
c[3] = a[3]                    （管辖区间 [3, 3]，长度 lowbit(3)=1）
c[4] = a[1]+a[2]+a[3]+a[4]    （管辖区间 [1, 4]，长度 lowbit(4)=4）
c[5] = a[5]                    （管辖区间 [5, 5]，长度 lowbit(5)=1）
c[6] = a[5] + a[6]            （管辖区间 [5, 6]，长度 lowbit(6)=2）
c[7] = a[7]                    （管辖区间 [7, 7]，长度 lowbit(7)=1）
c[8] = a[1]+...+a[8]          （管辖区间 [1, 8]，长度 lowbit(8)=8）
```

### 2.2 树形结构图

```
                    c[8]
                  /  |  \  \  \  \  \  \
               c[4]              c[6]  c[7]  (叶子)
              /  |  \           /  \
           c[2]  c[3]        c[5]   (叶子)
          /  |
       c[1] (叶子)

说明：c[i] 的"父亲"是 c[i + lowbit(i)]
      c[1]→c[2]→c[4]→c[8]  （1+1=2, 2+2=4, 4+4=8）
      c[3]→c[4]             （3+1=4）
      c[5]→c[6]→c[8]        （5+1=6, 6+2=8）
      c[7]→c[8]             （7+1=8）
```

!!! warning "重要性质"
    - **向上跳**（修改时）：$i \to i + \text{lowbit}(i)$，不断走向包含 $i$ 的父节点
    - **向下跳**（查询时）：$i \to i - \text{lowbit}(i)$，不断拆分前缀为若干 $c$ 的并集
    - $i + \text{lowbit}(i)$：把最低位的 1 进位（类似二进制加法）
    - $i - \text{lowbit}(i)$：把最低位的 1 清零

## 第三节 两大核心操作

### 3.1 单点更新 add(i, v)

将 $a[i]$ 加上 $v$，需要更新所有包含 $a[i]$ 的 $c[j]$。这些 $c[j]$ 的下标 $j$ 满足：从 $i$ 出发，不断执行 $j \to j + \text{lowbit}(j)$，直到 $j > n$。

```cpp
void add(int i, long long v) {
    for (; i <= n; i += lowbit(i))   // 向上跳：i + lowbit(i)
        c[i] += v;
}
// 输入：下标 i（1-based），增量 v
// 输出：无（原地更新树状数组 c）
```

**示例**：$n=8$，执行 `add(3, 5)`（给 $a[3]$ 加 5）：

```
i = 3 → 更新 c[3]    （3 + lowbit(3) = 3 + 1 = 4）
i = 4 → 更新 c[4]    （4 + lowbit(4) = 4 + 4 = 8）
i = 8 → 更新 c[8]    （8 + lowbit(8) = 8 + 8 = 16 > 8，停止）

共更新 3 个节点：c[3], c[4], c[8]
```

### 3.2 前缀查询 query(i)

查询 $a_1 + a_2 + \dots + a_i$。将前缀 $[1, i]$ 拆分为若干个 $c$ 的并集：从 $i$ 出发，不断执行 $j \to j - \text{lowbit}(j)$，直到 $j = 0$。

```cpp
long long query(int i) {
    long long s = 0;
    for (; i > 0; i -= lowbit(i))   // 向下跳：i - lowbit(i)
        s += c[i];
    return s;
}
// 输入：下标 i（1-based）
// 输出：前缀和 a[1] + a[2] + ... + a[i]
```

**示例**：$n=8$，执行 `query(7)`（查询 $a_1 + \dots + a_7$）：

```
i = 7 → 累加 c[7]    （7 管辖 [7,7]，7 - lowbit(7) = 7 - 1 = 6）
i = 6 → 累加 c[6]    （6 管辖 [5,6]，6 - lowbit(6) = 6 - 2 = 4）
i = 4 → 累加 c[4]    （4 管辖 [1,4]，4 - lowbit(4) = 4 - 4 = 0）
i = 0 → 停止

c[7] + c[6] + c[4] = a[7] + (a[5]+a[6]) + (a[1]+a[2]+a[3]+a[4]) = a[1]+...+a[7] ✓
```

### 3.3 完整模板演示

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100;
int n = 8;
int c[N];

int lowbit(int x) { return x & -x; }

void add(int i, int v) {
    for (; i <= n; i += lowbit(i))
        c[i] += v;
}

int query(int i) {
    int s = 0;
    for (; i > 0; i -= lowbit(i))
        s += c[i];
    return s;
}

int main() {
    // 建树：逐个单点更新
    int a[] = {0, 3, 1, 4, 1, 5, 9, 2, 6};  // a[1]~a[8]
    for (int i = 1; i <= 8; i++)
        add(i, a[i]);

    // 查询前缀和
    cout << "query(3) = " << query(3) << endl;  // a[1]+a[2]+a[3] = 3+1+4 = 8
    cout << "query(8) = " << query(8) << endl;  // 3+1+4+1+5+9+2+6 = 31

    // 单点修改：a[3] += 10
    add(3, 10);
    cout << "after add(3, 10): query(3) = " << query(3) << endl;  // 8+10 = 18

    return 0;
}
// 输入：无（演示树状数组基本操作）
// 输出：
// query(3) = 8
// query(8) = 31
// after add(3, 10): query(3) = 18
```

## 第四节 复杂度分析

### 4.1 为什么是 O(log n)

无论是 `add` 还是 `query`，循环每执行一次，$i$ 的二进制表示中最低位的 1 就会被"跳过"（`add` 是进位，`query` 是清零）。

一个数 $i$ 最多有 $\lfloor \log_2 n \rfloor + 1$ 个二进制位，因此循环最多执行 $O(\log n)$ 次。

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| `add(i, v)` 单点更新 | $O(\log n)$ | 沿 $i + \text{lowbit}(i)$ 向上跳 |
| `query(i)` 前缀查询 | $O(\log n)$ | 沿 $i - \text{lowbit}(i)$ 向下跳 |
| 建树（$n$ 次 `add`） | $O(n \log n)$ | 可优化到 $O(n)$，但竞赛中 $O(n \log n)$ 足够 |
| 空间 | $O(n)$ | 只需一个数组 $c$ |

!!! tip "为什么比朴素数组快？"
    - 朴素数组：单点修改 $O(1)$，但前缀查询 $O(n)$
    - 前缀和数组：前缀查询 $O(1)$，但单点修改 $O(n)$
    - **树状数组**：两者都是 $O(\log n)$，在"修改和查询交替进行"的场景下完胜！

## 第五节 区间求和

### 5.1 前缀和相减

利用前缀和思想，区间 $[l, r]$ 的和可以通过两个前缀查询相减得到：

$$\text{sum}(l, r) = \text{query}(r) - \text{query}(l - 1)$$

```cpp
long long rangeSum(int l, int r) {
    return query(r) - query(l - 1);
}
// 输入：区间左右端点 l, r（1-based）
// 输出：区间 [l, r] 的和
```

**推导**：

$$\text{query}(r) = a_1 + \dots + a_l + \dots + a_r$$
$$\text{query}(l-1) = a_1 + \dots + a_{l-1}$$
$$\text{query}(r) - \text{query}(l-1) = a_l + \dots + a_r = \text{sum}(l, r)$$

这与第 14 章的前缀和公式完全一致，树状数组的 `query` 本质就是"动态前缀和"。

## 第六节 差分 + 树状数组：区间修改 + 单点查询

### 6.1 问题转换

树状数组原生支持"单点修改 + 区间查询"。如果要支持"**区间修改 + 单点查询**"，需要借助差分思想。

回顾第 14 章：差分数组 $d[i] = a[i] - a[i-1]$，前缀和还原 $a[i] = \sum_{k=1}^{i} d[k]$。

- **区间 $[l, r]$ 加 $k$**：等价于 $d[l] += k,\ d[r+1] -= k$（两个单点修改）
- **查询 $a[x]$**：等价于求 $d$ 的前缀和 $\sum_{k=1}^{x} d[k]$（一次前缀查询）

于是把差分数组 $d$ 放进树状数组：

| 操作 | 原问题 | 转换后 | 树状数组操作 |
|------|--------|--------|-------------|
| 区间 $[l,r]$ 加 $k$ | 区间修改 | $d[l]\mathrel{+}=k,\ d[r+1]\mathrel{-}=k$ | `add(l, k)`, `add(r+1, -k)` |
| 查询 $a[x]$ | 单点查询 | $a[x] = \sum_{k=1}^x d[k]$ | `query(x)` |

```cpp
// 区间 [l, r] 加 k
void rangeAdd(int l, int r, long long k) {
    add(l, k);
    add(r + 1, -k);
}

// 查询 a[x] 的值
long long pointQuery(int x) {
    return query(x);
}
// 输入：rangeAdd 为区间 [l,r] 加 k；pointQuery 为查询位置 x
// 输出：rangeAdd 无返回值；pointQuery 返回 a[x] 的当前值
```

### 6.2 建树方式

读入初始数组 $a$ 后，用差分方式建树：

```cpp
long long prev = 0;
for (int i = 1; i <= n; i++) {
    long long a;
    scanf("%lld", &a);
    add(i, a - prev);   // d[i] = a[i] - a[i-1]
    prev = a;
}
// 输入：n 个数 a[1]~a[n]
// 输出：无（以差分方式建好树状数组）
```

## 第七节 逆序对计数

### 7.1 问题描述

给定数组 $a_1, a_2, \dots, a_n$，求其中**逆序对**的数量。逆序对是指满足 $i < j$ 且 $a_i > a_j$ 的数对 $(i, j)$。

### 7.2 树状数组解法

**核心思想**：从左到右扫描数组，每遇到 $a_j$ 时，查询"之前出现过且比 $a_j$ 大的数的个数"。

具体步骤：
1. **离散化**：如果 $a_i$ 的值域很大（如 $10^9$），先离散化到 $1 \sim n$ 的范围
2. 从左到右遍历，对每个 $a_j$：
   - 查询当前已插入的数中，值 $> a_j$ 的个数 = `j - 1 - query(a_j)`
   - 把 $a_j$ 插入树状数组：`add(a_j, 1)`

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 500005;
int n, c[N];

int lowbit(int x) { return x & -x; }
void add(int i, int v) { for (; i <= n; i += lowbit(i)) c[i] += v; }
int query(int i) { int s = 0; for (; i > 0; i -= lowbit(i)) s += c[i]; return s; }

int main() {
    scanf("%d", &n);
    vector<int> a(n);
    for (int i = 0; i < n; i++) scanf("%d", &a[i]);

    // 离散化
    vector<int> b = a;
    sort(b.begin(), b.end());
    b.erase(unique(b.begin(), b.end()), b.end());
    int m = b.size();
    for (int i = 0; i < n; i++)
        a[i] = lower_bound(b.begin(), b.end(), a[i]) - b.begin() + 1;

    long long ans = 0;
    for (int j = 0; j < n; j++) {
        // 查询已插入的数中，比 a[j] 大的个数
        ans += j - query(a[j]);
        add(a[j], 1);
    }
    printf("%lld\n", ans);
    return 0;
}
// 输入：
// 8
// 5 3 9 1 6 8 2 4
// 输出：16
```

**样例验证**：$a = [5, 3, 9, 1, 6, 8, 2, 4]$，逆序对共 16 个。

!!! tip "逆序对的多种解法"
    逆序对有三种经典解法：
    - **归并排序**：$O(n \log n)$，不需要离散化，最经典
    - **树状数组**：$O(n \log n)$，需要离散化，思路更直观
    - **线段树**：$O(n \log n)$，需要离散化，与树状数组思路相同

    CSP-S 中三者都可能出现，归并排序和树状数组最常用。

## 第八节 二维树状数组简介

### 8.1 从一维到二维

二维树状数组用于维护二维矩阵的前缀和，支持单点修改和子矩阵查询。

定义：

$$c[i][j] = \sum_{x=i-\text{lowbit}(i)+1}^{i} \sum_{y=j-\text{lowbit}(j)+1}^{j} a[x][y]$$

核心操作是一维的"嵌套"版本：

```cpp
void add(int x, int y, int v) {
    for (int i = x; i <= n; i += lowbit(i))
        for (int j = y; j <= m; j += lowbit(j))
            c[i][j] += v;
}

int query(int x, int y) {
    int s = 0;
    for (int i = x; i > 0; i -= lowbit(i))
        for (int j = y; j > 0; j -= lowbit(j))
            s += c[i][j];
    return s;
}

// 子矩阵 (x1,y1)~(x2,y2) 的和
int subMatrix(int x1, int y1, int x2, int y2) {
    return query(x2, y2) - query(x1 - 1, y2)
         - query(x2, y1 - 1) + query(x1 - 1, y1 - 1);
}
// 输入：add 为坐标 (x,y) 和增量 v；query 为坐标 (x,y)；subMatrix 为子矩阵四角
// 输出：add 无返回值；query 返回 (1,1)~(x,y) 子矩阵和；subMatrix 返回子矩阵和
```

复杂度：单点修改和查询都是 $O(\log n \cdot \log m)$。

## 第九节 树状数组与前缀和的对比

| 特性 | 前缀和（第14章） | 树状数组 |
|------|-----------------|---------|
| 单点修改 | $O(n)$（需重建） | $O(\log n)$ |
| 区间查询 | $O(1)$ | $O(\log n)$ |
| 区间修改 | 差分 $O(1)$ | 差分 + BIT $O(\log n)$ |
| 建树 | $O(n)$ | $O(n \log n)$ |
| 空间 | $O(n)$ | $O(n)$ |
| 代码复杂度 | 极简 | 简短 |
| 适用场景 | 修改少、查询多 | 修改和查询交替 |
| 功能扩展 | 有限 | 支持二维、逆序对等 |

!!! info "选择建议"
    - 如果**只查询不修改** → 前缀和（$O(1)$ 查询，代码最简）
    - 如果**单点修改 + 区间查询** → 树状数组（代码短，常数小）
    - 如果**区间修改 + 区间查询** → 线段树（树状数组需额外技巧，见下一章）
    - 如果**需要维护 max/min 等非可减信息** → 线段树（树状数组做前缀 max/min 较难）

## 常见误区

!!! danger "误区1：树状数组下标从 0 开始"
    **错误**：`add(0, v)` 或 `query(0)`
    **原因**：`lowbit(0) = 0`，会导致死循环（`i += 0` 永远不前进）。
    **正确**：树状数组下标**必须从 1 开始**，读入数据时也要从下标 1 开始存储。

!!! danger "误区2：忘记建树"
    **错误**：直接调用 `query`，结果全为 0。
    **原因**：树状数组 $c$ 初始全为 0，必须先通过 `add` 插入初始值。
    **正确**：读入 $a[i]$ 后执行 `add(i, a[i])`（或差分建树 `add(i, a[i]-a[i-1])`）。

!!! danger "误区3：区间求和用错端点"
    **错误**：`sum(l, r) = query(r) - query(l)`（少减了 $a[l-1]$）
    **正确**：`sum(l, r) = query(r) - query(l - 1)`。注意是 $l - 1$ 不是 $l$。

!!! danger "误区4：区间修改忘记差分转换"
    **错误**：直接对树状数组做区间修改，误以为 `add(l, k); add(r+1, -k)` 后 `rangeSum(l,r)` 就能返回正确结果。
    **原因**：差分 + 树状数组中，`query(x)` 返回的是 $a[x]$（单点值），不是前缀和。
    **正确**：区间修改 + 区间查询需要差分 + 两次树状数组（或改用线段树）。

!!! danger "误区5：数据溢出"
    **错误**：用 `int` 存累加和，结果溢出。
    **原因**：$n = 5 \times 10^5$，每个数可达 $2^{31}$，求和远超 `int` 范围。
    **正确**：树状数组 $c$ 和查询返回值用 `long long`。

!!! danger "误区6：数组开小"
    **错误**：数组只开到 $n$，区间修改时 `add(r+1, -k)` 越界。
    **正确**：数组大小至少开 $n + 2$（差分需要在 $r+1$ 处操作）。

## 典型例题

### 【P3374】树状数组 1（单点修改 + 区间查询）

**题目**：已知数列，支持两种操作：将第 $x$ 个数加上 $k$；查询区间 $[x, y]$ 的和。

**分析**：这是树状数组最基础的应用。`add` 做单点修改，`query(r) - query(l-1)` 做区间查询，两者都是 $O(\log n)$。

**样例验证**：

```
初始：a = [1, 5, 4, 2, 3]
1 1 3     → a[1] += 3 → a = [4, 5, 4, 2, 3]
2 2 5     → sum(2,5) = 5+4+2+3 = 14
1 3 -1    → a[3] += -1 → a = [4, 5, 3, 2, 3]
1 4 2     → a[4] += 2 → a = [4, 5, 3, 4, 3]
2 1 4     → sum(1,4) = 4+5+3+4 = 16
```

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 500005;
int n, m;
long long c[N];

int lowbit(int x) { return x & -x; }

void add(int i, long long v) {
    for (; i <= n; i += lowbit(i))
        c[i] += v;
}

long long query(int i) {
    long long s = 0;
    for (; i > 0; i -= lowbit(i))
        s += c[i];
    return s;
}

int main() {
    scanf("%d%d", &n, &m);
    for (int i = 1; i <= n; i++) {
        long long a;
        scanf("%lld", &a);
        add(i, a);
    }
    while (m--) {
        int op, x, y;
        scanf("%d%d%d", &op, &x, &y);
        if (op == 1) {
            add(x, y);
        } else {
            printf("%lld\n", query(y) - query(x - 1));
        }
    }
    return 0;
}
// 输入：
// 5 5
// 1 5 4 2 3
// 1 1 3
// 2 2 5
// 1 3 -1
// 1 4 2
// 2 1 4
// 输出：
// 14
// 16
```

### 【P3368】树状数组 2（区间修改 + 单点查询）

**题目**：已知数列，支持两种操作：将区间 $[x, y]$ 内每个数加上 $k$；查询第 $x$ 个数的值。

**分析**：用**差分 + 树状数组**。维护差分数组 $d$，区间 $[l,r]$ 加 $k$ 等价于 `add(l, k); add(r+1, -k)`，单点查询 $a[x]$ 等价于 `query(x)`（差分数组前缀和）。

**样例验证**：

```
初始：a = [1, 5, 4, 2, 3]
1 2 4 2   → 区间[2,4]加2 → a = [1, 7, 6, 4, 3]
2 3       → a[3] = 6
1 1 5 -1  → 区间[1,5]加-1 → a = [0, 6, 5, 3, 2]
1 3 5 7   → 区间[3,5]加7 → a = [0, 6, 12, 10, 9]
2 4       → a[4] = 10
```

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 500005;
int n, m;
long long c[N];

int lowbit(int x) { return x & -x; }

void add(int i, long long v) {
    for (; i <= n; i += lowbit(i))
        c[i] += v;
}

long long query(int i) {
    long long s = 0;
    for (; i > 0; i -= lowbit(i))
        s += c[i];
    return s;
}

int main() {
    scanf("%d%d", &n, &m);
    long long prev = 0;
    for (int i = 1; i <= n; i++) {
        long long a;
        scanf("%lld", &a);
        add(i, a - prev);     // 差分建树：d[i] = a[i] - a[i-1]
        prev = a;
    }
    while (m--) {
        int op;
        scanf("%d", &op);
        if (op == 1) {
            int x, y;
            long long k;
            scanf("%d%d%lld", &x, &y, &k);
            add(x, k);          // d[l] += k
            add(y + 1, -k);     // d[r+1] -= k
        } else {
            int x;
            scanf("%d", &x);
            printf("%lld\n", query(x));  // a[x] = d[1]+...+d[x]
        }
    }
    return 0;
}
// 输入：
// 5 5
// 1 5 4 2 3
// 1 2 4 2
// 2 3
// 1 1 5 -1
// 1 3 5 7
// 2 4
// 输出：
// 6
// 10
```

!!! tip "P3374 与 P3368 的对偶关系"
    - **P3374**（单点修改 + 区间查询）：直接存原值，`add` 修改、`query(r)-query(l-1)` 查询
    - **P3368**（区间修改 + 单点查询）：存差分值，`add(l,k); add(r+1,-k)` 修改、`query(x)` 查询

    两者正好是"修改"与"查询"的互换——这就是差分与前缀和互逆关系的体现。

## 📖 本章总结

### 核心要点回顾

- ✅ **lowbit**：`x & -x`，取二进制最低位的 1，利用补码（取反加一）实现
- ✅ **树状数组定义**：$c[i]$ 管辖区间 $[i - \text{lowbit}(i) + 1,\ i]$，长度为 $\text{lowbit}(i)$
- ✅ **单点更新 `add(i, v)`**：$i \to i + \text{lowbit}(i)$ 向上跳，$O(\log n)$
- ✅ **前缀查询 `query(i)`**：$i \to i - \text{lowbit}(i)$ 向下跳，$O(\log n)$
- ✅ **区间求和**：$\text{sum}(l,r) = \text{query}(r) - \text{query}(l-1)$
- ✅ **差分 + 树状数组**：区间修改 `add(l,k); add(r+1,-k)`，单点查询 `query(x)`
- ✅ **下标从 1 开始**，数组开 $n+2$，和用 `long long`

### 知识脉络

- **树状数组（前缀和的动态升级版）**
  - **基础：lowbit 运算**
    - `lowbit(x) = x & -x`（补码：取反加一）
    - 作用：确定每个 $c[i]$ 的管辖区间长度
  - **核心结构**
    - $c[i]$ 管辖 $[i-\text{lowbit}(i)+1,\ i]$
    - 修改沿 $i + \text{lowbit}(i)$ 向上跳
    - 查询沿 $i - \text{lowbit}(i)$ 向下跳
  - **两大操作（均 $O(\log n)$）**
    - `add(i, v)`：单点加，向上更新所有包含 $a[i]$ 的 $c[j]$
    - `query(i)`：前缀和 $a_1 + \dots + a_i$，向下拆分
  - **应用模式**
    - 单点修改 + 区间查询：直接存原值（P3374）
    - 区间修改 + 单点查询：差分建树（P3368）
    - 逆序对计数：离散化 + 逐个插入查询
  - **进阶**
    - 二维树状数组：嵌套双重循环，$O(\log^2 n)$
  - **与前缀和对比**
    - 前缀和：查询 $O(1)$、修改 $O(n)$，适合静态
    - 树状数组：查询修改均 $O(\log n)$，适合动态
