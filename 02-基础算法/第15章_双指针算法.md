`[CSP-S 进阶]` 双指针是优化暴力枚举的利器，CSP-S 中高频出现于区间、序列、字符串问题

## 💡 生活类比

!!! tip "两个人走路，三种走法"
    双指针就像**两个人在数组这条走廊上走路**，但走法不同：

    - **对撞指针**：一个人从走廊左端走，一个人从右端走，朝着彼此靠近，碰面就停——像**两个人从跑道两端相向而行找中间点**。
    - **快慢指针**：两个人同时从起点出发，一个走得快、一个走得慢，快的追上慢的就说明"有环"——像**龟兔赛跑**，兔子跑得快却在环形赛道上被乌龟"反超"。
    - **滑动窗口**：两个人像一扇**推拉窗框看风景**——窗框的两边（左右指针）只能向右滑，窗的宽度可以伸缩，但窗框永远不会向左退。你想看更全的风景就把窗推宽，风景"重复"了就把窗收窄。

## 核心概念

### 双指针的核心思想

!!! abstract "一句话核心"
    利用序列的**单调性**，让两个指针各自只朝一个方向移动，从而把"两重循环枚举"的 $O(n^2)$ 优化为 $O(n)$。

为什么能省掉一重循环？关键在于**单调性**——当某个指针前进一步时，另一个指针**不需要回头**，因为回头只会得到更差（或已经考虑过）的结果。这样一来，两个指针加起来最多移动 $2n$ 次，总复杂度 $O(n)$。

```
暴力双循环：              双指针优化：
for i in 0..n:            while 满足单调性:
    for j in 0..n:            移动一个指针（不回头）
        检查(i, j)            检查(left, right)
O(n²)                     O(n)
```

!!! warning "单调性是双指针的前提"
    并非所有问题都能用双指针！只有当**指针移动具有单调性**（即一个指针前进后，另一个指针不需要回退）时才能用。若问题本身没有单调性，强行套双指针会得到错误答案。

### 三大模型对比表

| 模型 | 指针方向 | 初始位置 | 指针速度 | 典型问题 | 时间复杂度 |
|------|---------|----------|---------|----------|-----------|
| **对撞指针** | ←→ 相向而行 | 两端 `left=0, right=n-1` | 同速（各走一步） | 有序数组两数之和、回文判定、盛水容器 | $O(n)$ |
| **快慢指针** | →→ 同向 | 同一起点 | 不同速（快 2 步 / 慢 1 步） | 有序数组去重、链表找中点、Floyd 判环 | $O(n)$ |
| **滑动窗口** | →→ 同向（不退） | `left=0, right=0` | 右扩左缩 | 最长不重复子串、最小覆盖子串、逛画展 | $O(n)$ |

!!! info "复杂度为什么都是 $O(n)$？"
    虽然代码里看到 `while` 套在 `for` 里，看似嵌套，但**两个指针都只朝一个方向移动**。对撞指针：`left` 与 `right` 各最多移动 $n$ 次；滑动窗口：`left` 和 `right` 都从 $0$ 走到 $n$，总移动 $\le 2n$；快慢指针：`fast` 最多走 $2n$ 步。所以**总移动次数与 $n$ 成正比**，是 $O(n)$ 而非 $O(n^2)$。

### 暴力 vs 双指针：以两数之和为例

**暴力解法**（$O(n^2)$）：双重循环枚举所有数对：

```cpp
// 暴力：枚举所有 (i, j)，i < j
for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++)
        if (a[i] + a[j] == target) { cout << i << " " << j; return 0; }
```

当 $n = 10^5$ 时，$n^2 = 10^{10}$，远超 1 秒时限（约 $10^8$ 次运算），必然超时。

**双指针解法**（$O(n)$）：利用有序性，`left`、`right` 各最多移动 $n$ 次：

```
暴力：检查 C(n,2) ≈ n²/2 个数对       双指针：left+right 共移动 ≤ 2n 次
n=10⁵ 时 ≈ 5×10⁹ 次（超时）            n=10⁵ 时 ≈ 2×10⁵ 次（秒过）
```

这就是双指针的价值：**用单调性把"枚举所有可能"变为"只走必要的一趟"**。

## 代码实现

### 模型一：快慢指针（链表判环）

**思想**：两个指针都从链表头出发，`slow` 每次走 1 步，`fast` 每次走 2 步。若有环，`fast` 终将追上 `slow`（Floyd 龟兔赛跑算法）；若无环，`fast` 会先到达链尾 `nullptr`。

**过程演示**（找中点，链表 `1→2→3→4→5→NULL`）：

```
第1步：slow=2, fast=3   (slow 走1步，fast 走2步)
第2步：slow=3, fast=5   (fast 到末尾，slow 在中点)
结果：中点 = slow = 3
```

**过程演示**（判环，链表 `1→2→3→4→2`，4 指回 2 形成环）：

```
第1步：slow=2, fast=3
第2步：slow=3, fast=2   (fast 转了一圈)
第3步：slow=4, fast=4   (相遇！有环)
```

```cpp
#include <bits/stdc++.h>
using namespace std;

struct ListNode {
    int val;
    ListNode *next;
};

// 判环：若 fast 能追上 slow 则有环
bool hasCycle(ListNode *head) {
    ListNode *slow = head, *fast = head;   // 必须同起点出发
    while (fast != nullptr && fast->next != nullptr) {
        slow = slow->next;                 // 慢指针 1 步
        fast = fast->next->next;           // 快指针 2 步
        if (slow == fast) return true;     // 相遇 = 有环
    }
    return false;                          // fast 到尾 = 无环
}

// 找中点：slow 走到链表中间
ListNode* findMiddle(ListNode *head) {
    ListNode *slow = head, *fast = head;
    while (fast != nullptr && fast->next != nullptr) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;                           // 中点
}
```

!!! tip "快慢指针的"读写分离""
    在数组去重场景中，`fast` 负责**读**（遍历所有元素），`slow` 负责**写**（标记有效位置）。这样无需额外数组，**原地**完成去重。

**应用：有序数组原地去重**——给定升序数组，原地删除重复元素，返回去重后长度：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    if (n == 0) { cout << 0; return 0; }
    int slow = 0;                          // 已写入区域的末尾
    for (int fast = 1; fast < n; fast++) {
        if (a[fast] != a[slow]) {          // 遇到新元素
            slow++;
            a[slow] = a[fast];             // 写入新区
        }
    }
    cout << slow + 1 << "\n";              // 长度 = 末尾下标 + 1
    for (int i = 0; i <= slow; i++) cout << a[i] << " ";
    return 0;
}
```

### 模型二：对撞指针（两数之和）

**问题**：给定**升序**数组 $a$ 和目标值 $target$，找两个数 $a[i] + a[j] = target$（$i \neq j$）。

**思路**：`left` 指小端，`right` 指大端。若 $a[l] + a[r]$ 偏小，则 `left++`（要变大）；若偏大，则 `right--`（要变小）。

**过程演示**（数组 `[1, 2, 3, 4, 5, 6, 7]`，target = 10）：

```
初始：  left=0(a[0]=1)  right=6(a[6]=7)  sum=8 < 10 → left++
第1步： left=1(a[1]=2)  right=6(a[6]=7)  sum=9 < 10 → left++
第2步： left=2(a[2]=3)  right=6(a[6]=7)  sum=10 == 10 → 找到！
结果：  位置 2 和 6
```

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, target;
    cin >> n >> target;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    int left = 0, right = n - 1;
    while (left < right) {                 // 严格小于，避免取到同一个
        int sum = a[left] + a[right];
        if (sum == target) {               // 找到答案
            cout << left << " " << right << "\n";
            return 0;
        } else if (sum < target) {
            left++;                        // 和太小，左指针右移
        } else {
            right--;                       // 和太大，右指针左移
        }
    }
    cout << "No solution\n";
    return 0;
}
```

!!! warning "为什么能保证找到解？"
    若 $a[l] + a[r] < target$，则 $a[l]$ 与**任何** $a[k]$（$k \le r$）相加都更小，所以 $a[l]$ 不可能是答案，**安全丢弃** $a[l]$（`left++`）。这就是"单调性"——双指针正确性的根本保证。注意：数组必须**有序**，否则单调性不成立。

**变体：回文判定**——判断字符串正读反读是否相同，是对撞指针的另一个经典应用：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;
    int left = 0, right = s.size() - 1;
    bool ok = true;
    while (left < right) {
        if (s[left] != s[right]) {         // 两端字符不一致
            ok = false;
            break;
        }
        left++;
        right--;
    }
    cout << (ok ? "Yes" : "No") << "\n";
    return 0;
}
```

### 模型三：滑动窗口（最长不重复子串）

**问题**：给定字符串 $s$，求**不含重复字符**的最长子串长度。

**思路**：`right` 扩展加入新字符；若新字符已在窗口内重复，则 `left` 右移直到窗口重新无重复。用数组 `cnt[256]` 记录每个字符出现次数。

**过程演示**（字符串 `s = "abcba"`）：

```
right=0 'a': 窗口[a]       无重复  left=0  ans=1
right=1 'b': 窗口[a,b]      无重复  left=0  ans=2
right=2 'c': 窗口[a,b,c]    无重复  left=0  ans=3
right=3 'b': 窗口[a,b,c,b]  b重复！收缩 left 直到无重复
              left++ → 窗口[b,c,b]  仍重复
              left++ → 窗口[c,b]     无重复  left=2  ans=3
right=4 'a': 窗口[c,b,a]    无重复  left=2  ans=3
结果：最长不重复子串长度 = 3
```

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;
    int n = s.size();
    int cnt[256] = {0};                    // 字符计数
    int left = 0, ans = 0;
    for (int right = 0; right < n; right++) {
        cnt[(unsigned char)s[right]]++;    // 右端进入窗口
        // 若有重复，左端右移直到无重复
        while (cnt[(unsigned char)s[right]] > 1) {
            cnt[(unsigned char)s[left]]--;
            left++;
        }
        ans = max(ans, right - left + 1); // 更新答案
    }
    cout << ans << "\n";
    return 0;
}
```

!!! tip "滑动窗口四步走"
    1. **右端进窗口**：`right` 扩展，更新 `cnt`、`kinds` 等状态。
    2. **判断合法性**：当窗口不满足条件（如有重复）时进入收缩。
    3. **左端出窗口**：`left` 右移，相应更新状态。
    4. **更新答案**：在合法时记录答案。

    这四步的顺序非常关键，错了会导致答案偏差。求**最长**在合法后更新；求**最短**在每次合法时尝试收缩后再更新。

**应用实例：洛谷 P1638 逛画展**——$n$ 幅画，$m$ 种画派，求包含全部 $m$ 种画派的**最短**连续区间。

这是"求最短"的滑动窗口：`right` 扩展加入新画派；当窗口已包含全部 $m$ 种时，尝试 `left` 右移**缩短**窗口（保持合法性以求最短）。用 `cnt[]` 记录每种画派数量，`kinds` 记录窗口内画派种类数。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXM = 2005;
int cnt[MAXM];                             // 每种画派在窗口内的数量

int main() {
    int n, m;
    cin >> n >> m;
    vector<int> a(n + 1);
    for (int i = 1; i <= n; i++) cin >> a[i];

    int left = 1, kinds = 0;
    int ansLen = n + 1, ansL = 1, ansR = n;
    for (int right = 1; right <= n; right++) {
        // 右端画进入窗口
        if (cnt[a[right]] == 0) kinds++;   // 新出现一种画派
        cnt[a[right]]++;

        // 窗口已包含全部 m 种画派 → 尝试收缩左端
        while (kinds == m) {
            if (right - left + 1 < ansLen) {  // 更短则更新答案
                ansLen = right - left + 1;
                ansL = left;
                ansR = right;
            }
            // 左端画离开窗口
            cnt[a[left]]--;
            if (cnt[a[left]] == 0) kinds--;   // 这种画派在窗口内没了
            left++;
        }
    }
    cout << ansL << " " << ansR << "\n";
    return 0;
}
```

!!! tip "注意 P1638 与最长不重复子串的区别"
    - **最长不重复子串**（求最长）：窗口**非法**时收缩 `left`，**合法**后更新答案。
    - **逛画展**（求最短）：窗口**合法**时收缩 `left`，每次合法都尝试更新答案。
    - 两者收缩时机恰好相反，务必分清"求最长"还是"求最短"。

## ⚠️ 常见误区

### 误区一：忽略单调性，所有问题都套双指针

**错误**：看到"两个数""区间"就无脑用双指针。

**真相**：双指针的前提是**单调性**——指针移动后，另一个指针不需要回头。若问题本身不满足单调性（如无序数组求两数之和），直接套对撞指针会**漏解**。必须先排序让序列有序，或改用哈希表。

```cpp
// 错误：无序数组直接对撞
// a[left]+a[right] < target 时 left++，但 a[left] 可能与中间某数配对！
// 正确：先 sort(a)，再对撞
```

### 误区二：滑动窗口忘记收缩左边界

**错误**：求"最短合法区间"时，只顾 `right` 扩展，忘记在合法时 `left` 右移尝试缩短。

```cpp
// 错误：只扩展不收缩，求的是"包含全部画派"的任意区间，不是最短
while (kinds == m) {
    // 忘记在收缩过程中更新 ans！
    cnt[a[left]]--;
    if (cnt[a[left]] == 0) kinds--;
    left++;
}
```

**修正**：求最短时，**每次合法都要尝试收缩**，并在收缩前更新答案：

```cpp
while (kinds == m) {
    ans = min(ans, right - left + 1);  // 先更新答案
    cnt[a[left]]--;                     // 再收缩
    if (cnt[a[left]] == 0) kinds--;
    left++;
}
```

### 误区三：快慢指针判环时起点不同

**错误**：让 `slow` 从 `head` 出发，`fast` 从 `head->next` 出发，导致**错过首次相遇**。

```cpp
// 错误：起点不同，可能在环中"擦肩而过"
ListNode *slow = head, *fast = head->next;
```

**修正**：`fast` 和 `slow` 必须从**同一节点**出发，才能保证相遇：

```cpp
ListNode *slow = head, *fast = head;    // 同起点
```

!!! warning "判环为什么 fast 一定能追上 slow？"
    若有环，fast 进入环后每步**拉近 1 步**距离，最终必与 slow 相遇。这是 Floyd 龟兔赛跑算法的核心。注意起点必须相同，否则可能错过相遇。

### 误区四：对撞指针循环条件写成 `left <= right`

**错误**：把循环条件写成 `while (left <= right)`，导致 `left == right` 时仍进入循环，此时 `a[left]` 与 `a[right]` 是**同一个元素**，两数之和退化为"一个数 ×2"，不符合"两个不同数"的要求。

```cpp
// 错误：left == right 时仍进入，把同一元素算了两次
while (left <= right) { ... }
// 正确：严格小于，保证两指针指向不同元素
while (left < right) { ... }
```

**修正**：用严格小于 `while (left < right)`，保证两指针指向不同元素。同理，二分查找中 `while (left <= right)` 是正确的（因为查找单个元素允许 `left == right`），但双指针求"两个不同元素"时必须用 `<`。两者切勿混淆。

## 典型例题：洛谷 P1102 A-B 数对

**题目**：给定 $n$ 个正整数和目标差 $C$，求满足 $A - B = C$ 的数对 $(A, B)$ 个数（$A$、$B$ 是数组中不同位置的数）。

**分析**：等价于找 $A = B + C$。**排序后用双指针**：对每个 $B = a[i]$，用两个指针 `l`、`r` 找到值恰好等于 $a[i] + C$ 的元素区间 $[l, r)$，区间长度即为以 $a[i]$ 为 $B$ 时的 $A$ 个数。由于数组有序，$a[i]$ 单调递增，目标值 $a[i]+C$ 也单调递增，`l`、`r` 只向右移动，总复杂度 $O(n \log n)$（排序） + $O(n)$（双指针）。

**样例追踪**（数组 `[1, 1, 2, 3, 3]`，$C = 1$，排序后不变）：

```
i=0, B=a[0]=1, target=2: l 找到 2(下标2), r 找到 3(下标3)  → 区间[2,3) 长度1  ans+=1
i=1, B=a[1]=1, target=2: l 仍在 2, r 仍在 3                  → 长度1          ans+=1
i=2, B=a[2]=2, target=3: l 找到 3(下标3), r 到末尾(下标5)     → 区间[3,5) 长度2  ans+=2
i=3, B=a[3]=3, target=4: l 到末尾, r 到末尾                   → 长度0          ans+=0
i=4, B=a[4]=3, target=4: 同上                                 → 长度0          ans+=0
结果：ans = 4
```

合法数对：$(A=2,B=1)_{i=0}$、$(A=2,B=1)_{i=1}$、$(A=3,B=2)_{i=2,j=3}$、$(A=3,B=2)_{i=2,j=4}$，共 4 对。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    long long C;
    cin >> n >> C;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    sort(a.begin(), a.end());             // 第一步：排序保证单调性

    long long ans = 0;
    int l = 0, r = 0;                     // [l, r) 为值 == a[i]+C 的区间
    for (int i = 0; i < n; i++) {         // 枚举 B = a[i]
        long long target = (long long)a[i] + C;
        while (l < n && (long long)a[l] < target) l++;  // 找下界
        while (r < n && (long long)a[r] <= target) r++; // 找上界
        ans += r - l;                     // 区间内都是合法的 A
        if (C == 0) ans--;                // C=0时排除自身配对
    }
    cout << ans << "\n";
    return 0;
}
```

!!! tip "为什么 l、r 不会回退？"
    因为 $a[i]$ 随 $i$ 递增（数组已排序），所以 $target = a[i] + C$ 也递增。`l` 只需在原位置基础上继续右移找到新的下界，`r` 同理。两个指针累计各最多移动 $n$ 次，所以双指针部分是 $O(n)$。

!!! info "本题的其他解法"
    - **哈希表**：用 `map` 统计每个数出现次数，对每个 $B$ 查询 $B+C$ 的次数，$O(n)$（不计 map 常数）。代码更短但常数较大。
    - **二分查找**：排序后对每个 $a[i]$ 用 `lower_bound` / `upper_bound` 找 $a[i]+C$ 的区间，$O(n \log n)$。
    - **双指针**：本解法，$O(n \log n)$，但常数小、思路清晰。

## 📚 本节练习

### 🟢 基础题（双指针模板，巩固思路）

**练习 1**：[P1638] 逛画展 - https://www.luogu.com.cn/problem/P1638
> $n$ 幅画，$m$ 种画派，求包含全部画派的最短连续区间。
**提示**：经典滑动窗口。`right` 扩展加入新画派，`cnt[]` 维护窗口内每种画派数量，`kinds` 计窗口内画派种类数。当 `kinds == m` 时尝试收缩 `left` 求最短。套用本章"滑动窗口四步走"模板。

**练习 2**：[P1147] 连续自然数和 - https://www.luogu.com.cn/problem/P1147
> 求所有连续正整数序列，使其和恰好等于 $M$（至少两个数）。
**提示**：尺取法（同向双指针）。维护窗口 $[left, right]$ 的元素和 `sum`，`sum < M` 则 `right++` 扩展，`sum > M` 则 `left++` 收缩，`sum == M` 则记录答案并继续移动。注意 $1 \sim M$ 范围足够，输出按左端点升序。

### 🟡 拓展题（CSP-S 经典，需思考）

**练习 3**：[P1102] A-B 数对 - https://www.luogu.com.cn/problem/P1102
> 给定 $n$ 个数和目标差 $C$，求满足 $A - B = C$ 的数对个数。
**提示**：等价于 $A = B + C$。**排序后用双指针**：对每个 $B$ 用 `l`、`r` 找值等于 $B+C$ 的区间。也可用 `map` 计数，但双指针是经典 $O(n \log n)$ 解法。详见本章典型例题完整代码。

**练习 4**：[P1886] 滑动窗口 - https://www.luogu.com.cn/problem/P1886
> 有一个大小为 $k$ 的窗口从数组左端滑到右端，求每个窗口内的最大值和最小值。
**提示**：滑动窗口的进阶——窗口大小固定，但要求**窗口内最值**。朴素做法每次扫窗口 $O(k)$ 共 $O(nk)$ 会超时。需用**单调队列**维护窗口内最大/最小值，每次 $O(1)$ 取队首，总 $O(n)$。这是滑动窗口 + 单调队列的标准组合，与第 35 章单调队列衔接。

### 🔴 CSP-S 进阶题（综合应用）

**练习 5**：[P3143] 钻石收藏家 - https://www.luogu.com.cn/problem/P3143
> $n$ 颗钻石大小为 $s_i$，要选一些放进**两个**展示柜，每个柜内钻石大小差不超过 $K$，求最多展示多少颗。
**提示**：**排序 + 双指针**求"大小差不超过 $K$ 的最长区间"。先用双指针对每个起点 $i$ 求以 $a[i]$ 为最小值时能延伸的最远右端 $r_i$（满足 $a[r_i] - a[i] \le K$），区间长度 $len_i = r_i - i + 1$。再用**前缀最大值** `pre[i]` 表示前 $i$ 个元素中能选的最大钻石数。答案为 $\max(pre[j] + suf[j+1])$，其中 $suf$ 是后缀最大值。关键是两段不重叠，用前后缀最大值拼接。

**练习 6**：[P1714] 切蛋糕 - https://www.luogu.com.cn/problem/P1714
> $n$ 块蛋糕有美味值（含负数），求长度**不超过** $m$ 的连续区间的最大美味值之和。
**提示**：前缀和 + **单调队列滑动窗口**。设前缀和 $S$，问题变为：对每个 $i$，在 $[i-m, i-1]$ 范围内找最小的 $S[j]$，则 $S[i] - S[j]$ 是以 $i$ 结尾的最大区间和。用**单调递增队列**维护窗口内 $S[j]$ 的最小值，每次 $O(1)$ 取队首。这是滑动窗口 + 单调队列的进阶组合，CSP-S 高频考点。

## 📖 本章总结

### 核心要点回顾

- ✅ **双指针核心**：利用单调性，让指针只朝一个方向移动，把 $O(n^2)$ 优化为 $O(n)$
- ✅ **对撞指针**：两端向中间逼近，解决有序数组两数之和、回文判定
- ✅ **快慢指针**：同向不同速，原地去重、链表找中点、Floyd 判环
- ✅ **滑动窗口**：右扩左缩，维护合法区间，解决不重复子串、最小覆盖
- ✅ 滑动窗口四步走：**右进 → 判合法 → 左出 → 更新答案**
- ✅ 双指针的前提是**单调性**，无单调性则需先排序或改用哈希

### 三大模型速查表

| 模式 | 指针方向 | 典型问题 | 时间 | 空间 |
|------|---------|----------|------|------|
| 对撞 | ←→ 相向 | 两数之和、回文、容器盛水 | $O(n)$ | $O(1)$ |
| 快慢 | →→ 同向 | 去重、找中点、判环 | $O(n)$ | $O(1)$ |
| 滑动窗口 | →→ 同向（不退） | 不重复子串、最小覆盖、逛画展 | $O(n)$ | $O(\Sigma)$ |

### 知识脉络

- **双指针算法（单调性优化 $O(n^2) \to O(n)$）**
  - **对撞指针**（`left ↔ right` 相向而行）
    - 典型问题：有序数组两数之和、回文判定、容器盛水
    - 关键：利用单调性保证解不丢失，`while (left < right)`
    - 复杂度：$O(n)$，空间 $O(1)$
  - **快慢指针**（`slow/fast` 同向不同速）
    - 典型问题：有序数组原地去重、链表找中点、Floyd 判环
    - 关键：读写分离（`slow` 写、`fast` 读），判环时同起点出发
    - 复杂度：$O(n)$，空间 $O(1)$
  - **滑动窗口**（`left, right` 同向不退）
    - 典型问题：最长不重复子串、最小覆盖子串、逛画展
    - 关键：四步走——右进 → 判合法 → 左出 → 更新答案
    - 求最长：非法时收缩，合法后更新
    - 求最短：合法时收缩，每次合法都更新
    - 复杂度：$O(n)$，空间 $O(\Sigma)$（$\Sigma$ 为字符集大小）
  - **洛谷经典题**
    - P1638 逛画展（滑动窗口求最短）
    - P1102 A-B 数对（排序 + 双指针）
    - P3143 钻石收藏家（排序 + 双指针 + 前后缀最大值）

### 复杂度对比

| 算法 | 时间 | 空间 | 适用条件 |
|------|------|------|---------|
| 暴力双循环 | $O(n^2)$ | $O(1)$ | 无限制 |
| 对撞指针 | $O(n)$ | $O(1)$ | 序列有序 |
| 快慢指针 | $O(n)$ | $O(1)$ | 链表/数组均可 |
| 滑动窗口 | $O(n)$ | $O(\Sigma)$ | 窗口合法性可维护 |

> $\Sigma$ 为字符集大小，常为 26（字母）或 256（ASCII）。
