# 第14章 前缀和与差分

`[CSP-S 进阶]` 前缀和与差分是一对"互逆"的预处理技巧，CSP-S 几乎每年必考

!!! info "本章内容"
    前缀和与差分是**最简单却最高频**的算法技巧。代码核心往往只有一两行，却能把 $O(n)$ 的查询降到 $O(1)$，把 $O(n)$ 的区间修改降到 $O(1)$。本章你将学习：

    - 一维前缀和：$O(1)$ 回答区间求和
    - 二维前缀和：容斥原理推导，$O(1)$ 回答子矩阵求和
    - 一维差分：$O(1)$ 完成区间批量修改
    - 二维差分：$O(1)$ 完成子矩阵批量修改
    - 经典应用：地毯铺设、最大子段和

!!! warning "本章特点"
    凡涉及"区间求和""区间加减""子矩阵操作"的问题，第一反应就该是前缀和或差分。CSP-S 中这两类技巧几乎每年必出。建议学完第6章数组和第10章时间复杂度后再学本章。本章也是后续学习树状数组、线段树的思维基础。

---

## 📌 学习目标

学完本章，你应当能够：

1. **准确默写**一维前缀和的预处理与查询公式（`s[i]=s[i-1]+a[i]`、`sum(l,r)=s[r]-s[l-1]`），并说清预处理 $O(n)$、查询 $O(1)$
2. **手推二维前缀和的容斥原理**，画出"加加减减"的矩阵推演图，正确写出预处理与查询的四项公式
3. **5 分钟内**写出一维差分的区间修改模板（`d[l]+=v, d[r+1]-=v`）和二维差分的四角操作（加减减加）
4. 理解**前缀和与差分互为逆运算**的关系，能根据题意选择合适技巧
5. 独立 AC 地毯（P3397）、语文成绩（P2367）等经典差分题

## 💡 生活类比

> **前缀和像"银行存折的累计余额"**：存折上不记每一笔进出，而是记"到某天为止累计存了多少"。想查"3 月 7 日到 3 月 15 日存了多少"？只需用 15 日的累计余额减去 2 月末的余额，一步搞定——**用减法代替加法**。

> **差分像"记账本只记每笔增减"**：不直接记当前余额，而是只记"今天比昨天多了多少"。要给第 3 天到第 7 天统一加 50 元？不必逐天改，只在第 3 天记"+50"、第 8 天记"-50"，最后从左到右扫一遍累加就还原了所有余额——**把区间操作转化为端点操作**。

一句话总结：**前缀和用减法代替加法（加速查询），差分用端点代替区间（加速修改）**，二者互为逆运算。

## 核心概念

### 一、一维前缀和

!!! abstract "问题引入：记账本的妙用"
    小明有一个**记账本**，每天记下当天的花费。30 天后想查"第 3 天到第 7 天一共花了多少钱"。

    ```
    天数:   1    2    3    4    5    6    7   ...
    花费:  20   15   30   10   25   40   35   ...
    ```

    **朴素做法**：每次查询都把第 3 到第 7 天的花费加一遍，$O(r-l+1)$。若有 $q$ 次查询，总时间 $O(q \cdot n)$，当 $n=10^5, q=10^5$ 时会 TLE。

    **目标**：预处理一次后，每次查询任意区间的和只需 $O(1)$。这就要请出「前缀和」——用减法代替加法。

设原数组为 $a_1, a_2, \dots, a_n$，定义**前缀和数组** $s$：

$$s_i = a_1 + a_2 + \dots + a_i = \sum_{k=1}^{i} a_k$$

规定 $s_0 = 0$（边界，方便处理）。预处理递推：

$$s_i = s_{i-1} + a_i$$

则区间 $[l, r]$ 的和为：

$$\text{sum}(l, r) = s_r - s_{l-1}$$

**推导**：$s_r = a_1 + \dots + a_l + \dots + a_r$，$s_{l-1} = a_1 + \dots + a_{l-1}$，相减正好留下 $a_l + \dots + a_r$。

```
原数组 a:  [20,  15,  30,  10,  25,  40,  35]
前缀和 s:  0   20   35   65   75  100  140  175
           ↑   ↑    ↑    ↑    ↑    ↑    ↑    ↑
          s0  s1   s2   s3   s4   s5   s6   s7

查询 [3,7] = s7 - s2 = 175 - 35 = 140 ✓
```

### 二、二维前缀和（容斥原理）

设原矩阵为 $a_{i,j}$，定义二维前缀和：

$$s_{i,j} = \sum_{x=1}^{i}\sum_{y=1}^{j} a_{x,y}$$

即从 $(1,1)$ 到 $(i,j)$ 这个子矩阵的元素之和。

**预处理递推（容斥原理）**：

$$s_{i,j} = s_{i-1,j} + s_{i,j-1} - s_{i-1,j-1} + a_{i,j}$$

**矩阵推演过程**（"加加减减"的来由）：

```
   构造 s[i][j]（从(1,1)到(i,j)的和）：

            ←── j-1 列 ──→ ← 1 列 →
         1  ┌──────────────┬────────┐
            │              │        │   ↑
            │   s[i-1][j-1]│s[i-1][j]   │
            │    (区域 A)  │(区域 B)│ i-1 行
            │              │        │   │
       i-1  ├──────────────┼────────┤   ↓
            │  s[i][j-1]   │ a[i][j]│
            │   (区域 C)   │(区域 D)│ 1 行
         i  └──────────────┴────────┘

   s[i-1][j] = A + B        （上方整块，到 i-1 行）
   s[i][j-1] = A + C        （左方整块，到 j-1 列）
   两者相加   = 2A + B + C   ← A 被算了两次！
   减去 s[i-1][j-1] = A     → A + B + C
   再加 a[i][j] = D          → A + B + C + D = s[i][j]  ✓

   口诀：加、加、减、加
```

**查询子矩阵 $(r_1, c_1)$ 到 $(r_2, c_2)$ 的和**：

$$\text{sum} = s_{r_2,c_2} - s_{r_1-1,c_2} - s_{r_2,c_1-1} + s_{r_1-1,c_1-1}$$

```
   查询子矩阵 Q = (r1,c1) ~ (r2,c2) 的和：

                 c1-1            c2
            1    +-----+--------------+
                 |     |              |   ↑
            r1-1 |  T  |      U       |   │ r1-1 行（上方整条）
                 +-----+--------------+   ↓
            r1   |     |┌────────────┐|
                 |  V  ││            ││   V = 左方下条
                 |     ││     Q      ││   Q = 查询区域
            r2   +-----+└────────────┘|

   s[r2][c2]      = T + U + V + Q   （整个大矩形）
   s[r1-1][c2]    = T + U           （上方整条）
   s[r2][c1-1]    = T + V           （左方整条）
   s[r1-1][c1-1]  = T               （左上角，被多减一次）

   ans = s[r2][c2] - s[r1-1][c2] - s[r2][c1-1] + s[r1-1][c1-1]
       = (T+U+V+Q) - (T+U) - (T+V) + T
       = Q  ✓

   口诀：减、减、加（左上角被多减，加回来）
```

### 三、差分数组

设原数组为 $a_1, a_2, \dots, a_n$，定义**差分数组** $d$：

$$d_i = a_i - a_{i-1} \quad (\text{规定 } a_0 = 0)$$

即 $d_i$ 表示 $a_i$ 相比 $a_{i-1}$ 的**变化量**。

**前缀和与差分互为逆运算**：

- 由 $a$ 求 $d$（差分）：$d_i = a_i - a_{i-1}$
- 由 $d$ 求 $a$（前缀和还原）：$a_i = d_1 + d_2 + \dots + d_i$

**区间修改**：要把 $[l, r]$ 的每个元素都加 $v$，只需：

$$d_l \mathrel{+}= v, \quad d_{r+1} \mathrel{-}= v$$

**原理**：$d_l$ 加 $v$ 后，还原时 $a_l, a_{l+1}, \dots, a_n$ 都会多 $v$；而 $d_{r+1}$ 减 $v$ 抵消，使 $a_{r+1}$ 及之后不变。正好只影响 $[l, r]$。

```
原数组 a:   [0,  0,  0,  0,  0]      （初始全 0）
差分数组 d: [0,  0,  0,  0,  0,  0]  （比原数组多一个位置）

操作：[2,4] 加 5
  d[2] += 5;  d[5] -= 5;
差分 d:    [0,  5,  0,  0,  -5, 0]

还原（前缀和）：
  a[1]=0, a[2]=5, a[3]=5, a[4]=5, a[5]=0   ✓ 只 [2,4] 被加了 5
```

**二维差分**：对子矩阵 $(r_1, c_1)$ 到 $(r_2, c_2)$ 整体加 $v$，只需改四个角：

$$d_{r_1,c_1}\mathrel{+}=v,\quad d_{r_2+1,c_1}\mathrel{-}=v,\quad d_{r_1,c_2+1}\mathrel{-}=v,\quad d_{r_2+1,c_2+1}\mathrel{+}=v$$

```
   子矩阵 (r1,c1)~(r2,c2) 整体加 v，四个角操作：

            c1            c2    c2+1
       r1   +-----v-------+------+
            |             |      |
            |   +v 扩散区 |      |
       r2   +-------------+------+
       r2+1 |    -v       |  +v  |
            +-------------+------+

   d[r1][c1]    += v   左上角 +v  （向右下扩散 +v）
   d[r2+1][c1]  -= v   左下角 -v  （抵消下方溢出）
   d[r1][c2+1]  -= v   右上角 -v  （抵消右方溢出）
   d[r2+1][c2+1]+= v   右下角 +v  （补回多减的部分）

   口诀：加、减、减、加（对角同号）
   还原 = 对 d 求二维前缀和（与二维前缀和公式完全一致）
```

### 四、操作总览（含时间复杂度）

| 技巧 | 预处理 | 查询/修改 | 还原 | 核心公式 |
|------|--------|----------|------|---------|
| 一维前缀和 | $O(n)$ | 查询 $O(1)$ | — | $s_r - s_{l-1}$ |
| 二维前缀和 | $O(nm)$ | 查询 $O(1)$ | — | $s_{r_2,c_2} - s_{r_1-1,c_2} - s_{r_2,c_1-1} + s_{r_1-1,c_1-1}$ |
| 一维差分 | 修改 $O(1)$ | — | $O(n)$ | $d_l\mathrel{+}=v,\ d_{r+1}\mathrel{-}=v$ |
| 二维差分 | 修改 $O(1)$ | — | $O(nm)$ | 四角：加减减加 |

!!! tip "何时用前缀和，何时用差分？"
    - 题目**只查询不修改** → 前缀和（预处理一次，多次 $O(1)$ 查询）
    - 题目**先批量修改再一次性输出** → 差分（每次修改 $O(1)$，最后统一还原）
    - 题目**修改与查询交替进行** → 朴素前缀和失效，需用树状数组/线段树（后续章节）

## 代码实现

### 一、一维前缀和（区间求和）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
long long a[MAXN], s[MAXN];      // a 原数组，s 前缀和数组

int main() {
    int n, q;
    cin >> n >> q;               // n 个数，q 次查询
    for (int i = 1; i <= n; i++) cin >> a[i];

    // 预处理前缀和，O(n)
    s[0] = 0;                    // 边界：s[0] = 0
    for (int i = 1; i <= n; i++) {
        s[i] = s[i - 1] + a[i];  // 递推
    }

    // 查询区间 [l, r] 的和，每次 O(1)
    while (q--) {
        int l, r;
        cin >> l >> r;
        cout << s[r] - s[l - 1] << "\n";   // 核心公式
    }
    return 0;
}
```

### 二、二维前缀和（子矩阵求和）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1005;
long long a[MAXN][MAXN], s[MAXN][MAXN];

int main() {
    int n, m, q;
    cin >> n >> m >> q;          // n 行 m 列，q 次查询
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            cin >> a[i][j];

    // 预处理二维前缀和，O(n*m)
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            s[i][j] = s[i - 1][j] + s[i][j - 1]
                    - s[i - 1][j - 1] + a[i][j];   // 容斥：加加减加
        }
    }

    // 查询子矩阵 (r1,c1)~(r2,c2) 的和，每次 O(1)
    while (q--) {
        int r1, c1, r2, c2;
        cin >> r1 >> c1 >> r2 >> c2;
        long long ans = s[r2][c2] - s[r1 - 1][c2]
                       - s[r2][c1 - 1] + s[r1 - 1][c1 - 1];
        cout << ans << "\n";
    }
    return 0;
}
```

### 三、一维差分（区间加减）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
long long d[MAXN];              // 差分数组（原数组甚至不用存）

int main() {
    int n, m;
    cin >> n >> m;              // n 个元素，m 次区间修改
    // 初始原数组全 0，差分数组也全 0，无需初始化

    while (m--) {
        int l, r;
        long long v;
        cin >> l >> r >> v;     // 区间 [l,r] 加 v
        d[l] += v;              // 左端点 +v
        d[r + 1] -= v;          // 右端点后一位 -v（抵消）
    }

    // 还原：对差分数组求前缀和得到最终数组，O(n)
    long long cur = 0;
    for (int i = 1; i <= n; i++) {
        cur += d[i];            // 累加差分值
        cout << cur << " \n"[i == n];
    }
    return 0;
}
```

### 四、二维差分（子矩阵批量修改）

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1005;
long long d[MAXN][MAXN];        // 二维差分数组

int main() {
    int n, m, q;
    cin >> n >> m >> q;         // n 行 m 列，q 次子矩阵修改
    // 初始全 0，差分数组也全 0，无需初始化

    while (q--) {
        int r1, c1, r2, c2;
        long long v;
        cin >> r1 >> c1 >> r2 >> c2 >> v;
        d[r1][c1] += v;            // 左上 +v
        d[r2 + 1][c1] -= v;        // 下方抵消
        d[r1][c2 + 1] -= v;        // 右方抵消
        d[r2 + 1][c2 + 1] += v;    // 右下角加回（容斥）
    }

    // 还原：对差分数组求二维前缀和，O(n*m)
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            int v = d[i][j];
            d[i][j] = d[i - 1][j] + d[i][j - 1]
                    - d[i - 1][j - 1] + v;   // 就地前缀和
            cout << d[i][j] << " \n"[j == m];
        }
    }
    return 0;
}
```

### 五、前缀和 + 维护极值（最大子段和）

**思路**：设 $s_i$ 为前缀和。以 $i$ 结尾的最大子段和为 $s_i - \min_{0\le k<i} s_k$。边读边维护"前缀和的最小值"，把"找最小 $s_k$"从 $O(n)$ 枚举优化为 $O(1)$，整体 $O(n)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    long long s = 0;             // 当前前缀和
    long long minS = 0;          // 前缀和的最小值（s[0]=0）
    long long ans = LLONG_MIN;   // 最终答案（初始化为极小值，可能全为负数）
    for (int i = 1; i <= n; i++) {
        long long x;
        cin >> x;
        s += x;                  // s[i] = s[i-1] + a[i]
        ans = max(ans, s - minS);   // 以 i 结尾的最大子段和
        minS = min(minS, s);     // 更新前缀和最小值
    }
    cout << ans << "\n";
    return 0;
}
```

!!! tip "前缀和 + 维护极值 = 优化枚举"
    最大子段和的本质是：枚举右端点 $i$，找一个左端点 $k$ 使 $s_i - s_k$ 最大，即 $s_k$ 最小。这种"前缀和 + 单调性/极值"的组合在 CSP-S 中非常常见，切蛋糕（P1714）就是其进阶版（用单调队列维护窗口内最小值）。

## ⚠️ 常见误区

!!! danger "误区一：前缀和数组下标从 0 还是 1？"
    前缀和**强烈建议下标从 1 开始**。这样 $s_r - s_{l-1}$ 在 $l=1$ 时变成 $s_r - s_0$，而 $s_0 = 0$ 正好是边界，**无需特判**。

    如果下标从 0 开始，$l=0$ 时 $l-1 = -1$ 会**越界**，需要额外判断，极易出错。差分同样建议从 1 开始，且数组多开 $2$ 个位置。

!!! danger "误区二：差分修改后忘记求前缀和还原"
    差分数组本身没有直观含义，**必须对它求一遍前缀和**才能得到最终的原数组。初学者常在所有修改做完后直接输出 `d[i]`，结果完全错误。

    ```cpp
    // ✗ 错误：直接输出差分数组
    for (int i = 1; i <= n; i++) cout << d[i];

    // ✓ 正确：先求前缀和再输出
    long long cur = 0;
    for (int i = 1; i <= n; i++) {
        cur += d[i];
        cout << cur;
    }
    ```
    记住：**差分是"记账"，前缀和是"结算"**，不结算的账本没有意义。

!!! danger "误区三：二维容斥符号搞错"
    二维前缀和预处理是 `+ + - +`（加、加、减、加），查询是 `- - +`（减、减、加）。二维差分修改是 `+ - - +`（加减减加）。这些符号**一旦写反，答案全错**，而且因为多算少算相互抵消，往往不会报错而是输出一个"看似合理"的错误值，调试极难。

    **应对策略**：理解容斥原理（重叠区域算两次要减回，多减的要加回），靠推导而非死记。每次写完用一个小数据手算验证。

!!! warning "误区四：差分数组开太小导致越界 RE"
    一维差分修改 $[l, r]$ 时会访问 `d[r+1]`，当 $r=n$ 时需要 `d[n+1]`；二维差分会访问 `d[r2+1][c2+1]`。所以：

    - 一维差分数组至少开到 `n + 2`
    - 二维差分数组至少开到 `(n+2) × (m+2)`

    这是差分题最常见的 RE 原因。

!!! warning "误区五：前缀和数组用 int 导致溢出"
    当 $n = 10^5$ 且每个 $a_i$ 达 $10^4$ 时，前缀和可能达到 $10^9$，逼近 `int` 上界（约 $2.1 \times 10^9$）。多个前缀和相加减（如二维容斥）更易溢出。**建议前缀和数组一律用 `long long`**，避免阴沟翻船。

!!! tip "误区六：二维差分还原时把"就地前缀和"写错"
    二维差分还原时，常对 `d` 数组**就地**做二维前缀和。注意递推公式中右边的 `d[i][j]` 是**原始差分值**，左边赋值后变成前缀和值：

    ```cpp
    d[i][j] = d[i-1][j] + d[i][j-1] - d[i-1][j-1] + d[i][j];
    //                                        ↑ 这里的 d[i][j] 是原值
    ```
    这一行能正确工作是因为 C++ 先算右边的表达式（此时 `d[i][j]` 还是原值），再赋给左边。理解后不会写错，但若误拆成两步就要注意顺序。

## 典型例题

### 【P3397】地毯（CSP-S 经典，二维差分）

**题目**：在 $n \times n$ 的网格上铺 $m$ 张矩形地毯。每张地毯覆盖 $(r_1, c_1)$ 到 $(r_2, c_2)$ 的矩形区域。铺完后输出每个格子被覆盖的次数。

**分析**：每张地毯就是一次"子矩阵加 1"操作，共 $m$ 次。朴素做法每次扫矩形 $O(n^2)$，总共 $O(m \cdot n^2)$，当 $n=m=1000$ 时达 $10^9$ 会 TLE。用二维差分，每次操作 $O(1)$，最后统一还原 $O(n^2)$，总共 $O(n^2 + m)$，轻松 AC。

**手算示例**：$n=3$，铺 1 张地毯 $(1,1)$ 到 $(2,2)$。

```
差分数组 d（初始全 0）：
  操作 d[1][1]+=1, d[3][1]-=1, d[1][3]-=1, d[3][3]+=1

  d:  1   0  -1          还原（二维前缀和）后：
      0   0   0              1   1   0
     -1   0   1              1   1   0
                              0   0   0   ✓ 只有 (1,1)~(2,2) 被覆盖
```

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1005;
int d[MAXN][MAXN];              // 差分数组，覆盖次数不会很大，int 足够

int main() {
    int n, m;
    cin >> n >> m;             // n×n 网格，m 张地毯

    while (m--) {
        int r1, c1, r2, c2;
        cin >> r1 >> c1 >> r2 >> c2;
        d[r1][c1] += 1;            // 左上 +1
        d[r2 + 1][c1] -= 1;        // 下方抵消
        d[r1][c2 + 1] -= 1;        // 右方抵消
        d[r2 + 1][c2 + 1] += 1;    // 右下角加回（容斥）
    }

    // 还原：对差分数组求二维前缀和，O(n^2)
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            d[i][j] = d[i - 1][j] + d[i][j - 1]
                    - d[i - 1][j - 1] + d[i][j];
            cout << d[i][j] << " \n"[j == n];
        }
    }
    return 0;
}
```

!!! tip "差分题的识别信号"
    凡题目形如"有 $m$ 次区间/子矩阵覆盖操作，最后统计每点被覆盖次数"，差分是首选。把每次覆盖拆成端点操作，最后前缀和还原，复杂度从 $O(m \cdot n^2)$ 降到 $O(n^2 + m)$。地毯、海盗分金、语文成绩都是这一模式。

**复杂度对比**：

| 做法 | 单次操作 | 还原 | 总复杂度（$m$ 次操作） |
|------|---------|------|----------------------|
| 朴素遍历 | $O(n^2)$ | — | $O(m \cdot n^2)$，$n=m=1000$ 时 $10^9$ TLE |
| 二维差分 | $O(1)$ | $O(n^2)$ | $O(n^2 + m)$，$n=m=1000$ 时约 $10^6$ 轻松 AC |

**关键点**：差分把"每次 $O(n^2)$ 的修改"换成"每次 $O(1)$ 的端点操作 + 一次 $O(n^2)$ 还原"，本质是把多次重复的扫矩形工作**延迟合并**到最后一次性完成。这正是差分思想的核心价值。

## 📚 本节练习

### 🟢 基础题（巩固模板）

**练习 1**：[P2367] 语文成绩 — https://www.luogu.com.cn/problem/P2367
> 给 $n$ 个学生的语文成绩，进行 $p$ 次"第 $x$ 到第 $y$ 名学生成绩加 $z$"的操作，最后求最低分。
**提示**：典型一维差分。每次操作 `d[x]+=z, d[y+1]-=z`，所有操作后求前缀和还原，扫描一遍取最小值。注意 $z$ 可能为负（减分）。复杂度 $O(n+p)$。
**避坑**：差分数组开到 `n+2`；还原时边累加边维护最小值，无需额外数组。

**练习 2**：[P1115] 最大子段和 — https://www.luogu.com.cn/problem/P1115
> 给定序列，找出一段连续子序列使其和最大。
**提示**：前缀和 + 维护最小前缀和。设 $s$ 为前缀和，以 $i$ 结尾的最大子段和为 $s_i - \min_{0\le k<i} s_k$。边读边算，维护 `minS`。核心：`ans = max(ans, s - minS)`，`minS = min(minS, s)`。注意答案初始化为极小值（可能全为负数）。复杂度 $O(n)$。

### 🟡 拓展题（CSP-S 经典，需思考）

**练习 3**：[P3406] 海盗分金（CSP-S 经典，差分应用） — https://www.luogu.com.cn/problem/P3406
> 海盗沿城市路径航行，每段经过次数不同，求最优总票价。
**提示**：相邻两个城市间是一段。从 $a$ 到 $b$（$a<b$）等价于区间 $[a, b-1]$ 每段经过次数 +1，用差分 $O(1)$ 处理。最后前缀和还原每段经过次数，对每段选最优票价方案。注意路径可能反向（$a>b$），取 `min/max` 处理。复杂度 $O(n+m)$。
**避坑**：差分数组大小按城市数开；票价的"单次票/多次票/通票"三选优要仔细比较。

**练习 4**：[P2280] [HNOI2003] 激光炸弹 — https://www.luogu.com.cn/problem/P2280
> 在 $n\times n$ 网格上有若干目标（带价值），用一枚边长为 $R$ 的正方形炸弹（边不算）炸掉最多价值。
**提示**：二维前缀和。先预处理目标价值的二维前缀和，再枚举炸弹左上角 $(i,j)$，炸掉区域为 $(i,j)$ 到 $(i+R-1, j+R-1)$，用 $O(1)$ 容斥查询。注意坐标可能稀疏，但值域不大直接开数组。复杂度 $O(n^2)$。
**避坑**：炸弹边长 $R$ 的区域是 $R\times R$（不含边界外），坐标范围和数组大小要对应；价值总和用 `long long`。

### 🔴 CSP-S 进阶题（综合应用）

**练习 5**：[P3397] 地毯 — https://www.luogu.com.cn/problem/P3397
> 在 $n\times n$ 网格上铺 $m$ 张矩形地毯，输出每格被覆盖次数。
**提示**：即本章典型例题，建议先自己写一遍再对照。每张地毯是子矩阵加 1，用二维差分四个角处理（加减减加），最后二维前缀和还原。
**避坑**：数组开 $(n+2)\times(n+2)$，防止 `d[r2+1][c2+1]` 越界；还原时注意就地前缀和的写法。

**练习 6**：[P1714] 切蛋糕 — https://www.luogu.com.cn/problem/P1714
> $n$ 块蛋糕有美味值（含负数），求长度**不超过** $m$ 的连续区间的最大美味值之和。
**提示**：前缀和 + 单调队列。设前缀和 $S$，问题变为：对每个 $i$，在 $[i-m, i-1]$ 范围内找最小的 $S[j]$，则 $S[i]-S[j]$ 是以 $i$ 结尾、长度 $\le m$ 的最大区间和。用**单调递增队列**维护窗口内 $S[j]$ 的最小值，每次 $O(1)$ 取队首。这是前缀和 + 单调队列的进阶组合，CSP-S 高频考点。复杂度 $O(n)$。
**避坑**：是"长度不超过 $m$"而非"恰好 $m$"，单调队列窗口大小为 $m$；前缀和下标从 0 开始时 $S[0]=0$ 要入队。

## 📖 本章总结

### 核心要点回顾

- ✅ **一维前缀和**：$s_i = s_{i-1} + a_i$，区间求和 $s_r - s_{l-1}$，预处理 $O(n)$ 查询 $O(1)$
- ✅ **二维前缀和**：容斥递推 $s_{i,j} = s_{i-1,j} + s_{i,j-1} - s_{i-1,j-1} + a_{i,j}$（加加减加），子矩阵求和 $O(1)$
- ✅ **一维差分**：区间加 $v$ 只需 $d_l\mathrel{+}=v,\ d_{r+1}\mathrel{-}=v$，修改 $O(1)$ 还原 $O(n)$
- ✅ **二维差分**：子矩阵加 $v$ 只需改四个角（加减减加），还原用二维前缀和
- ✅ **前缀和与差分互为逆运算**：差分→前缀和还原，前缀和→差分还原
- ✅ **数组下标从 1 开始**，差分数组多开 $2$ 个位置防越界，前缀和数组用 `long long` 防溢出

### 知识脉络

- **前缀和与差分（互为逆运算）**
  - **前缀和（用减法加速查询）**
    - 一维前缀和：`s[i] = s[i-1] + a[i]`，查询 `sum(l,r) = s[r] - s[l-1]`，$O(1)$
    - 二维前缀和：容斥递推（加加减加），子矩阵求和 $O(1)$
  - **差分（用端点加速修改）**
    - 一维差分：`d[l] += v, d[r+1] -= v`，修改 $O(1)$，还原 $O(n)$
    - 二维差分：四角操作（加减减加），还原用二维前缀和
  - **经典应用（前缀和 + 极值）**
    - 最大子段和（P1115）：`ans = max(ans, s - minS)`
    - 切蛋糕（P1714）：前缀和 + 单调队列维护窗口内最小值
  - **核心公式对照**
    - 二维前缀和预处理：加、加、减、加
    - 二维前缀和查询：减、减、加
    - 二维差分修改：加、减、减、加（对角同号）
    - 以上都用容斥原理推导
