# 第44章 区间DP

> 前面的 DP 多在"下标序列"上做，状态沿 i → i+1 推进。但有一类问题需要把"一段连续区间"整体合并成一个结果，合并时只能选相邻元素——这时状态的阶段不再是下标，而是"区间长度"。这就是区间 DP，它用 `f[i][j]` 表示区间 `[i,j]` 上的最优解，通过枚举分割点 k 把大区间拆成两个子区间。区间 DP 是 CSP-S 的高频考点，掌握它就能解决石子合并、能量项链、矩阵链乘等经典问题。

!!! info "本章内容"
    - 区间 DP 的核心思想：状态 `f[i][j]` 表示区间 `[i,j]` 的最优解
    - 通用框架：枚举区间长度 → 枚举左端点 → 枚举分割点 k
    - 经典模板：石子合并（P1775）与二维填表过程演示
    - 环形区间 DP：断环成链技巧，能量项链（P1063）与环形石子合并（P1880）
    - 记忆化搜索写法 vs 递推写法的对比
    - 常见误区：边界初始化、前缀和优化、环形处理

## 💡 生活类比

打个比方：操场上站着 4 个人排队，每个人手里举着一个数字。现在要让他们两两合并"抱团"，规则是**每次只能合并相邻的两人**，合并后的新团体数字 = 两人数字之和，合并代价 = 这个和。目标是把所有人合并成一个团体，使总代价最小。

比如数字 `[4, 5, 9, 4]`：

- 先合并 4 和 5（代价 9）→ `[9, 9, 4]`
- 再合并 9 和 4（代价 13）→ `[9, 13]`
- 最后合并 9 和 13（代价 22）→ `[22]`
- 总代价 = 9 + 13 + 22 = 44

但也可以先合并 5 和 9（代价 14）→ `[4, 14, 4]`，再合并 14 和 4（代价 18）→ `[4, 18]`，最后合并（代价 22），总代价 = 54。显然不如上面的方案优。

**关键洞察**：最后一次合并，一定是把 `[i,k]` 和 `[k+1,j]` 两段合成一段，代价固定为区间总和。所以总代价 = 左段最优 + 右段最优 + 区间总和。这就是区间 DP 的最优子结构。

## 第1节 区间DP的核心思想

### 44.1 什么是区间DP

普通 DP 在序列上做，状态沿"下标 i → i+1"推进。区间 DP 的状态是**一个二元组 `(i, j)`**，表示连续区间 `[i, j]` 上的最优解。阶段不再是下标，而是**区间长度**——先算所有长度为 1 的区间，再算长度为 2 的，依此类推，直到算出长度为 n 的整个区间。

为什么长度是天然的阶段？因为大区间 `[i,j]` 的最优解，一定由更小的子区间 `[i,k]` 和 `[k+1,j]` 组合而成。**先解决小问题，才能解决大问题**——这正是 DP 的最优子结构。

| 特征 | 普通 DP | 区间 DP |
|------|---------|---------|
| 状态 | `f[i]`（一维下标） | `f[i][j]`（区间两端） |
| 阶段 | 下标 i 从小到大 | 区间长度 len 从小到大 |
| 转移 | 从 `f[i-1]` 等转移 | 枚举分割点 k，由两个子区间合并 |
| 典型问题 | 背包、LIS、LCS | 石子合并、矩阵链乘 |

!!! info "区间DP的三要素"
    - **阶段**：区间长度 len（从 2 到 n）
    - **状态**：`f[i][j]`，区间 `[i,j]` 上的最优解（最小/最大代价）
    - **转移**：`f[i][j] = min/max(f[i][j], f[i][k] + f[k+1][j] + 合并代价)`，其中 `k ∈ [i, j)`

### 44.2 最优子结构

区间 DP 成立的前提是**最优子结构**：大区间 `[i,j]` 的最优解，一定能由其子区间 `[i,k]` 和 `[k+1,j]` 的最优解组合得到。

以石子合并为例：最后一步一定是在某个分割点 k 处，把 `[i,k]` 合并成的一堆和 `[k+1,j]` 合并成的一堆进行合并。这一步的代价 = 区间 `[i,j]` 的石子总和（固定值）。所以：

$$f[i][j] = \min_{k=i}^{j-1} \{ f[i][k] + f[k+1][j] + sum(i,j) \}$$

无论最后一步在哪个 k 处分割，`sum(i,j)` 都一样。所以要最小化 `f[i][j]`，只需最小化 `f[i][k] + f[k+1][j]`——而这正是两个子问题的最优解。

## 第2节 通用框架

### 44.3 三重循环模板

区间 DP 的通用框架只有四步，记住口诀"**长度、左端、分割点**"：

```
for len = 2 to n:              // ① 枚举区间长度（阶段）
    for i = 1 to n - len + 1:  // ② 枚举左端点
        j = i + len - 1        //    计算右端点
        for k = i to j - 1:    // ③ 枚举分割点
            f[i][j] = min(f[i][j], f[i][k] + f[k+1][j] + cost(i,j))
```

**为什么 len 从 2 开始？** 因为长度为 1 的区间 `[i,i]` 是单个元素，无需合并，`f[i][i] = 0` 是边界。长度为 2 时才开始有合并操作。

**为什么外层是 len 而不是 i？** 因为 `f[i][j]` 依赖 `f[i][k]` 和 `f[k+1][j]`，这两个子区间长度都小于 `j-i+1`。按长度递增计算，能保证转移时子问题已求解。

### 44.4 前缀和优化

合并代价 `cost(i,j)` 通常是区间 `[i,j]` 的元素之和。如果每次用循环求和，时间复杂度会退化到 $O(n^4)$。用**前缀和**可以降到 $O(1)$：

```
s[i] = a[1] + a[2] + ... + a[i]        // 预处理前缀和
sum(i, j) = s[j] - s[i-1]              // O(1) 查询区间和
```

| 做法 | 求区间和 | 总复杂度 |
|------|---------|---------|
| 每次循环累加 | O(n) | $O(n^4)$ |
| 前缀和预处理 | O(1) | $O(n^3)$ |

!!! tip "前缀和是区间DP的标配"
    凡是合并代价涉及"区间元素之和"的区间 DP，一定要用前缀和。这是把 $O(n^4)$ 优化到 $O(n^3)$ 的关键一步，面试和比赛中都不可遗漏。

## 第3节 石子合并与填表演示

### 44.5 问题引入（P1775）

**问题**：n 堆石子排成一排（n≤100），每次只能合并**相邻**的两堆，合并代价 = 两堆石子质量之和。求把 n 堆合并成一堆的最小总代价。

**状态设计**：`f[i][j]` = 把区间 `[i,j]` 的石子合并成一堆的最小代价。

**转移方程**：

$$f[i][j] = \min_{k=i}^{j-1} \{ f[i][k] + f[k+1][j] + s[j] - s[i-1] \}$$

**边界**：`f[i][i] = 0`（单堆无需合并）。

### 44.6 手动填表演示

以 4 堆石子 `[4, 5, 9, 4]` 为例。前缀和：`s = [0, 4, 9, 18, 22]`。

**第1步：填长度为 1 的区间（边界）**

| `f[i][j]` | j=1 | j=2 | j=3 | j=4 |
|-----------|-----|-----|-----|-----|
| **i=1** | 0 | | | |
| **i=2** | | 0 | | |
| **i=3** | | | 0 | |
| **i=4** | | | | 0 |

**第2步：填长度为 2 的区间**

- `f[1][2]`：k=1，`f[1][1]+f[2][2]+(s[2]-s[0]) = 0+0+9 = 9`
- `f[2][3]`：k=2，`f[2][2]+f[3][3]+(s[3]-s[1]) = 0+0+14 = 14`
- `f[3][4]`：k=3，`f[3][3]+f[4][4]+(s[4]-s[2]) = 0+0+13 = 13`

| `f[i][j]` | j=1 | j=2 | j=3 | j=4 |
|-----------|-----|-----|-----|-----|
| **i=1** | 0 | **9** | | |
| **i=2** | | 0 | **14** | |
| **i=3** | | | 0 | **13** |
| **i=4** | | | | 0 |

**第3步：填长度为 3 的区间**

- `f[1][3]`：sum = s[3]-s[0] = 18
  - k=1：`f[1][1]+f[2][3]+18 = 0+14+18 = 32`
  - k=2：`f[1][2]+f[3][3]+18 = 9+0+18 = 27`
  - 最小值 = **27**
- `f[2][4]`：sum = s[4]-s[1] = 18
  - k=2：`f[2][2]+f[3][4]+18 = 0+13+18 = 31`
  - k=3：`f[2][3]+f[4][4]+18 = 14+0+18 = 32`
  - 最小值 = **31**

| `f[i][j]` | j=1 | j=2 | j=3 | j=4 |
|-----------|-----|-----|-----|-----|
| **i=1** | 0 | 9 | **27** | |
| **i=2** | | 0 | 14 | **31** |
| **i=3** | | | 0 | 13 |
| **i=4** | | | | 0 |

**第4步：填长度为 4 的区间**

- `f[1][4]`：sum = s[4]-s[0] = 22
  - k=1：`f[1][1]+f[2][4]+22 = 0+31+22 = 53`
  - k=2：`f[1][2]+f[3][4]+22 = 9+13+22 = 44` ← 最优
  - k=3：`f[1][3]+f[4][4]+22 = 27+0+22 = 49`
  - 最小值 = **44**

| `f[i][j]` | j=1 | j=2 | j=3 | j=4 |
|-----------|-----|-----|-----|-----|
| **i=1** | 0 | 9 | 27 | **44** |
| **i=2** | | 0 | 14 | 31 |
| **i=3** | | | 0 | 13 |
| **i=4** | | | | 0 |

**答案**：`f[1][4] = 44`。最优方案是先合并 `[1,2]`（代价 9），再合并 `[3,4]`（代价 13），最后合并两段（代价 22），总代价 44。

!!! tip "填表顺序的直觉"
    从主对角线（长度1）开始，逐条对角线向右上角推进。每次填一个格时，它左边和下方的格子（更短的子区间）都已填好——这就是"按长度递增"的妙处。

### 44.7 AC代码（P1775 递推写法）

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 105;
int n, a[MAXN], s[MAXN];      // s 为前缀和
int f[MAXN][MAXN];            // f[i][j] 区间[i,j]最小合并代价
int main() {
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
        s[i] = s[i - 1] + a[i];          // 预处理前缀和
    }
    memset(f, 0x3f, sizeof(f));          // 初始化为极大值
    for (int i = 1; i <= n; i++) f[i][i] = 0;  // 边界：单堆代价为0
    for (int len = 2; len <= n; len++) {        // 枚举区间长度
        for (int i = 1; i + len - 1 <= n; i++) { // 枚举左端点
            int j = i + len - 1;                  // 右端点
            for (int k = i; k < j; k++) {         // 枚举分割点
                int cost = s[j] - s[i - 1];       // 区间和（前缀和O(1)）
                f[i][j] = min(f[i][j], f[i][k] + f[k + 1][j] + cost);
            }
        }
    }
    printf("%d\n", f[1][n]);
    return 0;
}
```

**复杂度**：时间 $O(n^3)$，空间 $O(n^2)$。

## 第4节 能量项链与矩阵链乘

### 44.8 问题引入（P1063）

**问题**：n 颗珠子组成环形项链，每颗珠子 i 有头标记 `a[i]` 和尾标记 `a[i+1]`（环形，`a[n+1]=a[1]`）。合并相邻两颗珠子 `(i..j)` 和 `(j+1..k)` 时释放能量 = `a[i] * a[j+1] * a[k]`。求合并成一串时释放的最大总能量。

这是经典的**矩阵链乘**模型：每颗珠子相当于一个矩阵 `a[i] × a[i+1]`，合并两段相当于做矩阵乘法，代价 = 行×列×公共维。

### 44.9 状态设计

- `f[i][j]` = 合并区间 `[i,j]` 的珠子成一串的最大能量
- 合并后，这一串的"头"仍是 `a[i]`，"尾"仍是 `a[j+1]`

**转移**：枚举最后一步在 k 处分割，合并左段 `[i,k]` 和右段 `[k+1,j]`：

$$f[i][j] = \max_{k=i}^{j-1} \{ f[i][k] + f[k+1][j] + a[i] \cdot a[k+1] \cdot a[j+1] \}$$

**关键理解**：`a[i]` 是左段合并后的头，`a[k+1]` 是右段合并后的头（也是左右段的"交界"标记），`a[j+1]` 是右段合并后的尾。三者相乘正是这次合并释放的能量。

!!! info "与石子合并的区别"
    - 石子合并：合并代价 = 区间元素和（用前缀和算）
    - 能量项链：合并代价 = 三个标记的乘积（与边界有关，不需要前缀和）
    
    两者的框架完全一样，只是"合并代价"的计算方式不同。

### 44.10 环形处理：断环成链

项链是环形，但区间 DP 只能处理线性序列。解决办法是**断环成链**：

1. 把数组复制一份接在后面：`a[i+n] = a[i]`（i=1..n），数组长变为 2n
2. 在长度为 2n 的链上做区间 DP
3. 答案 = 所有长度为 n 的区间的最优值：`ans = max(f[i][i+n-1])`，i=1..n

**为什么这样做对？** 环上任意一个长度为 n 的连续段，都对应链上某个长度为 n 的区间。把数组翻倍后，所有可能的"断点"都被覆盖了——相当于枚举了环上所有可能的起始位置。

```
原环（n=4）：  [1] - [2] - [3] - [4] - (回到[1])

断环成链（复制一份）：
  位置: 1   2   3   4   5   6   7   8
  数值: a1  a2  a3  a4  a1  a2  a3  a4
  
所有长度为4的区间：
  [1,4] [2,5] [3,6] [4,7]  ← 覆盖了环上4种断点
```

### 44.11 AC代码（P1063）

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 210;         // 开2n大小
int n, a[MAXN];
int f[MAXN][MAXN];
int main() {
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
        a[i + n] = a[i];      // 断环成链：复制一份
    }
    // 注意：a[j+1] 需要访问到 2n+1 位置，由于复制后 a[n+1]=a[1]
    // 当 j=2n 时需要 a[2n+1]，这里数组要够大或用取模
    for (int len = 2; len <= n; len++) {          // 枚举区间长度
        for (int i = 1; i + len - 1 <= 2 * n; i++) { // 枚举左端点
            int j = i + len - 1;                    // 右端点
            for (int k = i; k < j; k++) {           // 枚举分割点
                // a[i]*a[k+1]*a[j+1]：这次合并释放的能量
                f[i][j] = max(f[i][j], f[i][k] + f[k + 1][j]
                              + a[i] * a[k + 1] * a[j + 1]);
            }
        }
    }
    int ans = 0;
    for (int i = 1; i <= n; i++)    // 在所有长度为n的区间中取最大值
        ans = max(ans, f[i][i + n - 1]);
    printf("%d\n", ans);
    return 0;
}
```

**复杂度**：时间 $O(n^3)$，空间 $O(n^2)$。

!!! warning "数组大小注意"
    断环成链后数组长度为 2n，而转移中 `a[j+1]` 当 j=2n 时需要访问 `a[2n+1]`。实际中 `a[2n+1]` 不会越界（数组开到 2n+5），且其值不影响长度为 n 的区间答案。但为安全起见，数组开 `MAXN = 2*n + 5`。

## 第5节 环形区间DP详解

### 44.12 环形 vs 线性

| 对比项 | 线性区间 DP | 环形区间 DP |
|--------|------------|------------|
| 数据结构 | 一排序列 | 首尾相连的环 |
| 断点 | 固定（首尾不合并） | 任意位置都可断开 |
| 处理方法 | 直接做 | 断环成链，数组翻倍 |
| 数组大小 | n | 2n |
| 答案位置 | `f[1][n]` | `max(f[i][i+n-1])`，i=1..n |

### 44.13 断环成链的通用步骤

```
原数组：a[1], a[2], ..., a[n]
翻倍后：a[1], a[2], ..., a[n], a[1], a[2], ..., a[n]
         ↑                      ↑
        位置1                   位置n+1

在长度2n的链上做区间DP
答案 = 所有可能的"长度为n的区间"中的最优值
     = optimize(f[i][i+n-1]), i = 1, 2, ..., n
```

**核心原理**：环上没有固定的"起点"，但只要枚举所有可能的起点（共 n 种），就覆盖了环上所有长度为 n 的连续段。翻倍数组后，每种起点对应链上一个长度为 n 的区间，一次 DP 即可全部算出。

### 44.14 环形石子合并（P1880）

P1880 是 P1775 的环形版：n 堆石子围成一圈，求合并成一堆的最小代价和最大代价。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 210;
int n, a[MAXN], s[MAXN];
int fmin[MAXN][MAXN], fmax[MAXN][MAXN];
int main() {
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
        a[i + n] = a[i];               // 断环成链
    }
    for (int i = 1; i <= 2 * n; i++)
        s[i] = s[i - 1] + a[i];        // 前缀和
    memset(fmin, 0x3f, sizeof(fmin));
    for (int i = 1; i <= 2 * n; i++)
        fmin[i][i] = fmax[i][i] = 0;   // 边界：单堆代价0
    for (int len = 2; len <= n; len++) {
        for (int i = 1; i + len - 1 <= 2 * n; i++) {
            int j = i + len - 1;
            for (int k = i; k < j; k++) {
                int cost = s[j] - s[i - 1];
                fmin[i][j] = min(fmin[i][j], fmin[i][k] + fmin[k + 1][j] + cost);
                fmax[i][j] = max(fmax[i][j], fmax[i][k] + fmax[k + 1][j] + cost);
            }
        }
    }
    int ansmin = INT_MAX, ansmax = 0;
    for (int i = 1; i <= n; i++) {     // 所有长度n的区间取最优
        ansmin = min(ansmin, fmin[i][i + n - 1]);
        ansmax = max(ansmax, fmax[i][i + n - 1]);
    }
    printf("%d\n%d\n", ansmin, ansmax);
    return 0;
}
```

!!! tip "同时求最小和最大"
    P1880 要求同时输出最小和最大代价，只需维护两个 DP 数组 `fmin` 和 `fmax`，在一次三重循环中同时更新即可，无需跑两遍。

## 第6节 记忆化搜索 vs 递推

### 44.15 两种写法对比

区间 DP 有两种实现方式：

| 对比项 | 递推写法 | 记忆化搜索 |
|--------|---------|-----------|
| 方向 | 自底向上（先小后大） | 自顶向下（先大后小） |
| 阶段 | 按区间长度 len 递增 | 递归自然处理 |
| 直觉 | 需要想清楚循环顺序 | 更接近状态定义 |
| 效率 | 略快（无递归开销） | 略慢（函数调用） |
| 边界 | 显式初始化 | 在递归中判断 |
| 适用 | 标准区间DP | 状态依赖复杂时 |

### 44.16 记忆化搜索写法（P1775）

记忆化搜索自顶向下：从 `f[1][n]` 出发，递归求解子问题，用 `vis` 数组避免重复计算。

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 105;
int n, a[MAXN], s[MAXN];
int f[MAXN][MAXN];           // 记忆化数组
bool vis[MAXN][MAXN];        // 标记是否已计算
int solve(int i, int j) {
    if (i == j) return 0;            // 边界：单堆无需合并
    if (vis[i][j]) return f[i][j];   // 已计算，直接返回
    vis[i][j] = true;
    f[i][j] = INT_MAX;
    for (int k = i; k < j; k++) {    // 枚举分割点
        int cost = s[j] - s[i - 1];
        f[i][j] = min(f[i][j], solve(i, k) + solve(k + 1, j) + cost);
    }
    return f[i][j];
}
int main() {
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
        s[i] = s[i - 1] + a[i];
    }
    printf("%d\n", solve(1, n));
    return 0;
}
```

### 44.17 两种写法的选择建议

!!! tip "何时用记忆化搜索？"
    - **状态依赖关系复杂**时：有些区间DP的子问题不是简单的"更短区间"，递推难写
    - **只需要少量状态**时：如果很多 `f[i][j]` 根本用不到，记忆化只算有用的
    - **调试方便**时：记忆化可以打印调用过程，便于理解

    **何时用递推？**
    - **标准区间DP模板题**：循环顺序清晰，效率高
    - **n 较大**（>500）时：递归有栈溢出风险
    - **比赛追求速度**时：递推通常更快

## 第7节 常见误区

### 误区1：忘记边界初始化 f[i][i]=0

!!! warning "问题"
    区间 DP 的边界是 `f[i][i] = 0`（单点无需合并）。如果忘记初始化，`f` 数组中的随机值会导致转移结果错误。

    ```cpp
    // ❌ 错误：忘记初始化边界
    memset(f, 0x3f, sizeof(f));
    for (int len = 2; len <= n; len++)  // f[i][i] 还是极大值！

    // ✅ 正确：显式初始化
    memset(f, 0x3f, sizeof(f));
    for (int i = 1; i <= n; i++) f[i][i] = 0;  // 单点代价为0
    ```

### 误区2：忘记前缀和导致 O(n⁴)

!!! warning "问题"
    如果每次转移都用循环求区间和 `sum(i,j)`，三重循环内还套一层求和，总复杂度变成 $O(n^4)$，n=100 时就会 TLE。

    ```cpp
    // ❌ 错误：每次循环求和，O(n⁴)
    for (int k = i; k < j; k++) {
        int sum = 0;
        for (int t = i; t <= j; t++) sum += a[t];  // 别这么做！
        f[i][j] = min(f[i][j], f[i][k] + f[k+1][j] + sum);
    }

    // ✅ 正确：前缀和预处理，O(1) 查询
    for (int i = 1; i <= n; i++) s[i] = s[i-1] + a[i];
    for (int k = i; k < j; k++) {
        int cost = s[j] - s[i-1];  // O(1)
        f[i][j] = min(f[i][j], f[i][k] + f[k+1][j] + cost);
    }
    ```

### 误区3：环形问题没断环成链

!!! warning "问题"
    环形区间 DP 如果直接当线性做（只算 `f[1][n]`），会漏掉"首尾合并"的情况。比如 4 堆石子围成一圈，`[1,4]` 和 `[4,1]` 是两种不同的合并方式，但线性 DP 只考虑了前者。

    ```cpp
    // ❌ 错误：环形问题当线性做
    // 只算了 f[1][n]，漏掉了首尾相连的合并
    printf("%d\n", f[1][n]);

    // ✅ 正确：断环成链，枚举所有长度n的区间
    for (int i = 1; i <= n; i++) a[i+n] = a[i];  // 复制一份
    // ... 在 2n 长度上做DP ...
    int ans = 0;
    for (int i = 1; i <= n; i++) ans = max(ans, f[i][i+n-1]);
    ```

### 误区4：区间长度从1开始

!!! warning "问题"
    len 从 1 开始会导致单点区间参与合并计算。长度为 1 的区间 `[i,i]` 是边界，不应该进入分割循环——因为 `k` 从 `i` 到 `j-1 = i-1`，循环根本不执行，但会浪费时间，更严重的是若逻辑有误可能产生错误状态。

    ```cpp
    // ❌ 错误（至少是多余）：len从1开始
    for (int len = 1; len <= n; len++)  // len=1时k循环不执行，白跑

    // ✅ 正确：len从2开始，len=1是边界已初始化
    for (int len = 2; len <= n; len++)
    ```

### 误区5：分割点范围错误

!!! warning "问题"
    分割点 k 的范围是 `[i, j-1]`（即 `k < j`）。如果写成 `k <= j`，会越界访问 `f[j+1][j]`（非法区间）；如果写成 `k < j-1`，会漏掉最后一种分割。

    ```cpp
    // ❌ 错误：k <= j 会越界
    for (int k = i; k <= j; k++)  // k=j时 f[k+1][j]=f[j+1][j] 非法

    // ✅ 正确：k < j，即 k ∈ [i, j-1]
    for (int k = i; k < j; k++)
    ```

## 第8节 配套习题精讲

### 例题一：[P1775] 石子合并（弱化版）

**题意**：n 堆石子排成一排（n≤100），每次合并相邻两堆，代价为两堆质量之和。求最小总代价。

**思路**：线性区间 DP 模板题。`f[i][j]` 表示合并区间 `[i,j]` 的最小代价，枚举分割点 k，用前缀和求区间和。详见 44.5-44.7 节。

**AC代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 105;
int n, a[MAXN], s[MAXN];
int f[MAXN][MAXN];
int main() {
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
        s[i] = s[i - 1] + a[i];
    }
    memset(f, 0x3f, sizeof(f));
    for (int i = 1; i <= n; i++) f[i][i] = 0;
    for (int len = 2; len <= n; len++) {
        for (int i = 1; i + len - 1 <= n; i++) {
            int j = i + len - 1;
            for (int k = i; k < j; k++) {
                f[i][j] = min(f[i][j], f[i][k] + f[k + 1][j] + s[j] - s[i - 1]);
            }
        }
    }
    printf("%d\n", f[1][n]);
    return 0;
}
```

**复杂度**：时间 $O(n^3)$，空间 $O(n^2)$。

### 例题二：[P1063] [NOIP2006] 能量项链

**题意**：n 颗珠子组成环形项链（n≤100），珠子 i 的头标记为 `a[i]`，尾标记为 `a[i+1]`（环形）。合并相邻两段释放能量 = `头×交界×尾`。求最大总能量。

**思路**：环形区间 DP + 矩阵链乘模型。断环成链（数组翻倍），`f[i][j]` 表示合并 `[i,j]` 的最大能量，转移时枚举分割点 k，能量 = `a[i]*a[k+1]*a[j+1]`。详见 44.8-44.11 节。

**AC代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 210;
int n, a[MAXN];
int f[MAXN][MAXN];
int main() {
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
        a[i + n] = a[i];           // 断环成链
    }
    for (int len = 2; len <= n; len++) {
        for (int i = 1; i + len - 1 <= 2 * n; i++) {
            int j = i + len - 1;
            for (int k = i; k < j; k++) {
                f[i][j] = max(f[i][j], f[i][k] + f[k + 1][j]
                              + a[i] * a[k + 1] * a[j + 1]);
            }
        }
    }
    int ans = 0;
    for (int i = 1; i <= n; i++)
        ans = max(ans, f[i][i + n - 1]);
    printf("%d\n", ans);
    return 0;
}
```

**复杂度**：时间 $O(n^3)$，空间 $O(n^2)$。

### 例题三：[P1880] [NOI1995] 石子合并（环形版）

**题意**：n 堆石子围成一圈（n≤100），每次合并相邻两堆，代价为两堆质量之和。求最小总代价和最大总代价。

**思路**：环形区间 DP。断环成链后在 2n 长度上做 DP，同时维护 `fmin` 和 `fmax` 两个数组。答案在所有长度为 n 的区间中取最优。详见 44.14 节。

**AC代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 210;
int n, a[MAXN], s[MAXN];
int fmin[MAXN][MAXN], fmax[MAXN][MAXN];
int main() {
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
        a[i + n] = a[i];           // 断环成链
    }
    for (int i = 1; i <= 2 * n; i++)
        s[i] = s[i - 1] + a[i];
    memset(fmin, 0x3f, sizeof(fmin));
    for (int i = 1; i <= 2 * n; i++)
        fmin[i][i] = fmax[i][i] = 0;
    for (int len = 2; len <= n; len++) {
        for (int i = 1; i + len - 1 <= 2 * n; i++) {
            int j = i + len - 1;
            for (int k = i; k < j; k++) {
                int cost = s[j] - s[i - 1];
                fmin[i][j] = min(fmin[i][j], fmin[i][k] + fmin[k + 1][j] + cost);
                fmax[i][j] = max(fmax[i][j], fmax[i][k] + fmax[k + 1][j] + cost);
            }
        }
    }
    int ansmin = INT_MAX, ansmax = 0;
    for (int i = 1; i <= n; i++) {
        ansmin = min(ansmin, fmin[i][i + n - 1]);
        ansmax = max(ansmax, fmax[i][i + n - 1]);
    }
    printf("%d\n%d\n", ansmin, ansmax);
    return 0;
}
```

**复杂度**：时间 $O(n^3)$，空间 $O(n^2)$。

## 📖 本章总结

### 思维导图

- 区间 DP
  - 核心框架
    - 长度阶段：len 递增（从 2 到 n）
    - 枚举分割点：k ∈ [i, j)，将大区间拆为两个子区间
    - 前缀和优化：O(1) 查询区间和，总复杂度 O(n³)
  - 经典模型
    - 石子合并：`f[i][j] = min(f[i][k] + f[k+1][j] + s[j]-s[i-1])`
    - 能量项链 / 矩阵链乘：合并代价 = `a[i] × a[k+1] × a[j+1]`
  - 环形处理
    - 断环成链：数组翻倍至 2n
    - 答案取优：在所有长度为 n 的区间中取最优值

### 核心口诀

| 口诀 | 含义 |
|------|------|
| **长度、左端、分割点** | 三重循环的顺序：先枚举区间长度，再左端点，最后分割点 |
| **单点为零，长二开始** | 边界 `f[i][i]=0`，区间长度从 2 开始转移 |
| **前缀和省一层** | 用前缀和把区间和查询从 O(n) 降到 O(1)，总复杂度 $O(n^3)$ |
| **环形断链，翻倍取优** | 环形问题复制数组成 2n，答案在所有长度 n 的区间中取最优 |
| **递推更快，记忆化更直** | 递推效率高，记忆化搜索更直观，按场景选择 |

### 速查表

| 模型 | 状态设计 | 转移方程 | 复杂度 | 典型题目 |
