## 💡 生活类比

!!! tip "类比一：弹夹装弹"
    想象一把手枪的弹夹：你**最后压入**的那颗子弹，会**最先被射出**。第一颗装进去的子弹，反而要等到最后才发射。这就是栈——**后进先出**（LIFO, Last In First Out）。

```
装弹顺序：1 → 2 → 3 → 4（4 最后装入，在最上面）
弹夹：        射击顺序：4 → 3 → 2 → 1（4 最先射出）
┌───┐
│ 4 │ ← 栈顶（最后装入，最先射出）
├───┤
│ 3 │
├───┤
│ 2 │
├───┤
│ 1 │ ← 栈底（最先装入，最后射出）
└───┘
```

!!! tip "类比二：洗碗碟堆放"
    洗碗时，你把洗干净的碗**一只一只往上叠**；吃饭时，从**最上面那只**开始拿。底下那只碗要等上面全部拿走才能取到。叠碗 = push，取碗 = pop，你只能操作「最顶端」。

这两个类比的共同点：**只在一端（顶端）进行插入和删除**。这就是栈的本质约束。

## 核心概念

### 3.1 栈的定义

「栈 stack」是一种**受限的线性表**：只允许在**同一端**（称为栈顶 top）进行插入和删除操作。这一限制带来了 **LIFO（后进先出）** 的特性。

- **入栈 push**：将元素压入栈顶。
- **出栈 pop**：将栈顶元素删除。
- **取栈顶 top**：查看（但不删除）栈顶元素。
- **判空 empty**：检查栈中是否还有元素。
- **大小 size**：返回栈中元素个数。

### 3.2 核心操作一览（含时间复杂度）

| 操作 | 含义 | 时间复杂度 | 备注 |
|------|------|:----------:|------|
| `push(x)` | 将 x 压入栈顶 | $O(1)$ | 栈满时数组版需检查 |
| `pop()` | 删除栈顶元素 | $O(1)$ | 空栈 pop 是未定义行为 |
| `top()` / `getTop()` | 取栈顶元素（不删除） | $O(1)$ | 空栈 top 是未定义行为 |
| `empty()` | 判空 | $O(1)$ | 返回 bool |
| `size()` | 返回元素个数 | $O(1)$ | — |

!!! info "关键约束"
    栈**不支持**随机访问 `stk[i]`，也不支持在中间插入/删除。所有操作只能在**栈顶**进行。这个限制看似"残废"，但正是它让递归、回溯、表达式求值等问题迎刃而解。

### 3.3 ASCII 示意图

```
        栈的运行过程（依次 push 10, 20, 30，再 pop 一次）

push(10):        push(20):        push(30):        pop():
                                                       ↓ 弹出 30
┌────┐           ┌────┐           ┌────┐           ┌────┐
│ 10 │ ← top=1   │ 20 │ ← top=2   │ 30 │ ← top=3   │ 20 │ ← top=2
└────┘           ├────┤           ├────┤           ├────┤
                 │ 10 │           │ 20 │           │ 10 │
                 └────┘           ├────┤           └────┘
                                  │ 10 │
                                  └────┘

注意：本模板中 top 始终指向「栈顶元素的下标」，top=0 表示空栈。
```

### 3.4 栈的应用场景速览

!!! info "为什么这个'受限'结构如此重要"
    栈的 LIFO 特性天然契合"**有去有回、最后处理的最先撤回**"的场景。在 CSP-S 中，栈是以下问题的底层支撑：

| 应用场景 | 栈的作用 | 出现章节 |
|---------|---------|:--------:|
| 括号匹配 | 左括号入栈，遇右括号弹栈配对 | 本章 |
| 表达式求值（前/中/后缀） | 操作数/运算符入栈，按优先级计算 | 本章练习 |
| 函数调用 / 递归 | 系统用"调用栈"保存返回地址和局部变量 | 第 8 章 |
| DFS 深度优先搜索 | 用栈模拟递归，避免栈溢出 | 第 27 章 |
| 回溯算法 | 选择入栈、失败弹栈、回退到上一步 | 第 27 章 |
| 单调栈 | 维护单调性，求"下一个更大/更小" | 本章进阶 |
| 浏览器后退 / 撤销操作 | 历史页面/操作入栈，后退即弹栈 | — |

**核心直觉**：只要问题中存在"**最近相关性**"——即最新产生的数据需要最先被处理——就该想到栈。

## 数组模拟实现 ⭐

### 4.1 存储结构说明

数组模拟栈的核心思想：用一个**全局数组** `stk[]` 存元素，用一个**整型变量** `top` 记录栈顶位置。

!!! info "top 的含义（本模板约定）"
    本书中 `top` 是**栈顶元素的下标**（而非"下一个空位"）：
    - `top = 0`：空栈
    - `top = 1`：栈中 1 个元素，存于 `stk[1]`
    - `top = n`：栈中 n 个元素，栈顶是 `stk[n]`
    - `stk[0]` **不使用**，这样 `top` 的值恰好等于元素个数

    入栈时用 `++top`（先加再赋值），保证元素从 `stk[1]` 开始存。

### 4.2 完整代码模板

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100010;          // 栈的最大容量，按题目数据范围调整
int stk[N], top = 0;           // stk[1..top] 存元素，top=0 表示空栈

// 初始化（清空栈）
void init() {
    top = 0;                   // top 归零即清空，旧数据无需抹除
}

// 入栈：将 x 压入栈顶
void push(int x) {
    stk[++top] = x;            // top 先自增，再把 x 放到新栈顶位置
}                              // 注意：生产代码应检查 top < N 防越界

// 出栈：删除栈顶元素
void pop() {
    if (top > 0) top--;        // 边界检查：空栈时不操作，避免 top 变成负数
}

// 取栈顶元素（不删除）
int getTop() {
    if (top == 0) return -1;   // 边界检查：空栈返回哨兵值 -1
    return stk[top];           // 返回栈顶元素
}

// 判空
bool empty() {
    return top == 0;           // top 为 0 即空栈
}

// 返回元素个数
int size() {
    return top;                // top 的值恰好等于元素个数
}

int main() {
    init();                    // 初始化
    push(10);                  // 栈：[10]，top=1
    push(20);                  // 栈：[10, 20]，top=2
    push(30);                  // 栈：[10, 20, 30]，top=3

    cout << getTop() << endl;  // 输出 30（取栈顶）
    cout << size()   << endl;  // 输出 3

    pop();                     // 栈：[10, 20]，top=2
    cout << getTop() << endl;  // 输出 20

    pop(); pop();              // 清空栈
    cout << (empty() ? "空" : "非空") << endl;  // 输出 空
    cout << getTop() << endl;  // 输出 -1（空栈哨兵值）

    return 0;
}
```

### 4.3 实现要点

!!! tip "三个必须记住的细节"
    1. **`++top` 而非 `top++`**：先用后加会导致 `stk[0]` 被占用，与"top=元素个数"的约定冲突。
    2. **`pop` 前必须判 `top > 0`**：否则 `top` 变成 -1，后续 `stk[++top]` 会越界写到 `stk[0]`，埋下隐患。
    3. **`getTop` 空栈要返回哨兵值**：直接 `return stk[top]` 在空栈时会返回 `stk[0]`（垃圾值），调试时极难发现。

!!! warning "数组大小 N 的选择"
    `N` 必须**大于**题目可能入栈的最大元素数。常见取值 `100010`（10 万级）、`1000010`（百万级）。若不确定，宁可开大，但别超过内存限制（一般 256MB 可容纳约 $6 \times 10^7$ 个 int）。

| 操作 | 时间复杂度 | 空间复杂度 |
|------|:----------:|:----------:|
| init | $O(1)$ | $O(N)$（预分配） |
| push | $O(1)$ | — |
| pop | $O(1)$ | — |
| getTop | $O(1)$ | — |
| empty / size | $O(1)$ | — |

### 4.4 调试技巧：如何打印栈内容

数组模拟栈的一大优势是**可直接遍历调试**。比赛时若怀疑栈状态异常，加一行即可排查：

```cpp
// 调试：从栈顶到栈底打印所有元素
void debug() {
    cerr << "栈(top→底): ";
    for (int i = top; i >= 1; i--) {
        cerr << stk[i] << " ";
    }
    cerr << "  [size=" << top << "]" << endl;
}
```

!!! tip "STL 栈如何调试？"
    STL `stack` 不支持遍历，调试时只能**先把元素全部 pop 到临时数组**，看完再 push 回去——非常麻烦。这也是为什么单调栈等需要观察栈状态的题目，老手更偏爱数组模拟。

```cpp
// STL 栈的笨调试法（慎用，会破坏栈）
void debugSTL(stack<int> stk) {     // 注意：传值拷贝，不破坏原栈
    cerr << "栈(top→底): ";
    while (!stk.empty()) {
        cerr << stk.top() << " ";
        stk.pop();
    }
    cerr << endl;
}
```

## STL 实现 ⭐

### 5.1 头文件与声明

```cpp
#include <bits/stdc++.h>
using namespace std;

stack<int> stk;                // 声明一个存放 int 的栈
// stack<string> strs;         // 也可以存放 string、结构体等
```

### 5.2 完整代码示例

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    stack<int> stk;            // 声明栈（默认空栈，无需 init）

    stk.push(10);              // 入栈：栈 [10]
    stk.push(20);              // 入栈：栈 [10, 20]
    stk.push(30);              // 入栈：栈 [10, 20, 30]

    cout << stk.top()  << endl;  // 输出 30（取栈顶，不删除）
    cout << stk.size() << endl;  // 输出 3

    stk.pop();                 // 出栈：栈 [10, 20]
    cout << stk.top()  << endl;  // 输出 20

    stk.pop(); stk.pop();      // 清空栈
    cout << (stk.empty() ? "空" : "非空") << endl;  // 输出 空

    return 0;
}
```

### 5.3 成员函数速查表

| 成员函数 | 功能 | 时间复杂度 | 空栈行为 |
|---------|------|:----------:|----------|
| `stk.push(x)` | 将 x 压入栈顶 | $O(1)$ | 正常 |
| `stk.pop()` | 删除栈顶元素（**不返回值**） | $O(1)$ | 未定义行为 |
| `stk.top()` | 返回栈顶元素的引用（不删除） | $O(1)$ | 未定义行为 |
| `stk.empty()` | 判空，返回 bool | $O(1)$ | 返回 true |
| `stk.size()` | 返回元素个数 | $O(1)$ | 返回 0 |
| `stk.emplace(x)` | 原地构造并入栈（C++11） | $O(1)$ | 正常 |
| `swap(stk1, stk2)` | 交换两个栈的内容 | $O(1)$ | — |

!!! warning "STL pop 的两个坑"
    1. **`pop()` 不返回值**：想取出栈顶再删除，必须先 `top()` 再 `pop()`：
       ```cpp
       int x = stk.top();   // 先取
       stk.pop();           // 再删
       ```
    2. **空栈 `top()`/`pop()` 是未定义行为**：可能崩溃、可能返回垃圾值，**务必先 `empty()` 判断**。

## 双轨对比总结

### 6.1 两种实现全方位对比

| 维度 | 数组模拟 | STL stack |
|------|---------|-----------|
| **代码量** | 较多（需手写 5 个函数） | 极少（直接调用） |
| **运行速度** | ⚡ 最快（无封装开销） | 略慢（有封装，但常数极小） |
| **内存** | 固定预分配 `N` 个 int | 动态分配，按需增长 |
| **越界保护** | ❌ 无，需手动检查 | ✅ 空栈操作会触发未定义行为但易调试 |
| **可调试性** | ✅ 可直接 `cout << stk[i]` 查看所有元素 | ❌ 无法遍历，只能 `top()` 一个个 pop 出来看 |
| **适用场景** | 高频调用、需要随机访问栈内元素、单调栈 | 快速实现、对常数不敏感的题目 |

### 6.2 赛场选择建议

!!! tip "NOI 金牌教练的考场策略"
    - **简单题、追求编码速度** → 用 STL，节省 2-3 分钟编码时间。
    - **需要遍历栈内元素**（如单调栈、对顶栈） → 用数组模拟，可直接 `for (int i = 1; i <= top; i++)` 访问。
    - **TLE 卡常数** → 用数组模拟，省去函数调用开销。
    - **不确定时** → 默认数组模拟，它在 CSP-S 中**永远不会出错**，且调试更方便。

## ⚠️ 常见误区

### 误区一：栈空时 pop / top 未判空

```cpp
// ❌ 错误写法
void pop() { top--; }                    // 空栈时 top 变 -1，后续越界
int getTop() { return stk[top]; }        // 空栈返回 stk[0] 垃圾值

// ✅ 正确写法
void pop() { if (top > 0) top--; }       // 空栈不操作
int getTop() { if (top == 0) return -1; return stk[top]; }
```

**后果**：数组模拟中 `top` 变负数后，下次 `push` 的 `++top` 会写到 `stk[0]`，逻辑全乱；STL 中则直接未定义行为，可能 RE。

### 误区二：STL `pop()` 误以为返回栈顶值

```cpp
// ❌ 错误写法（初学者最常犯）
stack<int> stk;
stk.push(10);
int x = stk.pop();           // 编译错误！pop 返回 void

// ✅ 正确写法
int x = stk.top();           // 先取值
stk.pop();                   // 再删除
```

**原因**：STL 设计哲学是"操作与查询分离"，`pop` 只负责删除，`top` 只负责查询。这是与 Java `Stack.pop()` 的重大区别。

### 误区三：`top` 指针含义混淆（++top vs top++）

```cpp
// 写法 A（本书采用）：top 指向栈顶元素，stk[1..top] 有效
void push(int x) { stk[++top] = x; }     // 先加，x 放到新位置
// 此时 top == 元素个数，空栈 top=0

// 写法 B（另一种约定）：top 指向下一个空位，stk[0..top-1] 有效
void push(int x) { stk[top++] = x; }     // 先存，top 后加
// 此时 top == 元素个数，空栈 top=0

// ❌ 致命错误：两种约定混用
void push(int x) { stk[++top] = x; }     // 用了写法 A
int getTop() { return stk[top - 1]; }    // 却用了写法 B 的逻辑 → 取错元素
```

**教训**：选定一种约定就**贯彻始终**。本书统一用**写法 A**（`++top`），因为它更直观——`top` 既是下标又是元素个数。

### 误区四：数组开太小导致越界 RE

```cpp
// ❌ 题目说 n ≤ 10^6，却只开了 100010
const int N = 100010;         // 容量只有 10 万，放不下 100 万元素
int stk[N], top = 0;
// 当 push 超过 10 万次时，stk[++top] 越界 → RE 或 WA

// ✅ 根据数据范围开足
const int N = 1000010;        // 留 10 的余量，开到 100 万 + 10
```

**教训**：数组容量 `N` 要**严格大于**最大入栈次数。经验值：题目说 $n \le 10^5$ 就开 `100010`，$n \le 10^6$ 就开 `1000010`，末尾留 10 个位置防 off-by-one。

!!! info "延伸：栈与递归的内在联系"
    你写的每一个递归函数，系统都会用**调用栈**（call stack）来管理：每层递归的参数、局部变量、返回地址都"压栈"，返回时"弹栈"。所以：
    - **递归深度 = 栈的最大深度**。
    - 递归太深（如 $10^6$ 层）会**栈溢出**（Stack Overflow），此时需改用**显式栈**的非递归写法。
    - 理解了栈，你才能真正理解第 27 章 DFS 进阶的非递归实现。

## 典型例题（双版本）

### 例题：括号匹配

**题意**：给定一个只含 `(` `)` 的字符串，判断括号是否匹配。如 `(()())` 匹配，`())(` 不匹配。

**思路**：遇到 `(` 入栈，遇到 `)` 时若栈非空则出栈，否则不匹配。最后栈空即匹配。

#### 版本一：数组模拟

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1000010;
char stk[N];                  // 栈存字符
int top = 0;

void push(char c) { stk[++top] = c; }
void pop() { if (top > 0) top--; }
char getTop() { return top == 0 ? '\0' : stk[top]; }
bool empty() { return top == 0; }

int main() {
    string s;
    cin >> s;

    bool ok = true;
    for (int i = 0; i < s.size() && ok; i++) {
        if (s[i] == '(') {
            push(s[i]);                 // 左括号入栈
        } else {                        // 遇到右括号
            if (empty()) {              // 栈空说明右括号多余
                ok = false;
            } else {
                pop();                  // 配对成功，弹出左括号
            }
        }
    }
    // 循环结束后栈非空，说明左括号多余
    if (ok && !empty()) ok = false;

    cout << (ok ? "YES" : "NO") << endl;
    return 0;
}
```

#### 版本二：STL 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;

    stack<char> stk;
    bool ok = true;
    for (int i = 0; i < s.size() && ok; i++) {
        if (s[i] == '(') {
            stk.push(s[i]);             // 左括号入栈
        } else {                        // 遇到右括号
            if (stk.empty()) {          // 栈空说明右括号多余
                ok = false;
            } else {
                stk.pop();              // 配对成功，弹出左括号
            }
        }
    }
    if (ok && !stk.empty()) ok = false; // 左括号多余

    cout << (ok ? "YES" : "NO") << endl;
    return 0;
}
```

!!! info "双版本对比"
    两个版本逻辑完全一致，差别仅在 API 名称（`push` vs `stk.push`）。本题数据规模小，两种实现均 AC。若扩展到多类型括号 `()[]{}`，只需入栈时存左括号、出栈时检查类型是否匹配即可。

#### 运行追踪：以 `(()())` 为例

```
输入：s = "(()())"

i=0, s[0]='('  → 入栈     栈: [ ( ]        top=1
i=1, s[1]='('  → 入栈     栈: [ (, ( ]     top=2
i=2, s[2]=')'  → 栈非空，弹栈  栈: [ ( ]    top=1   ✓ 配对
i=3, s[3]='('  → 入栈     栈: [ (, ( ]     top=2
i=4, s[4]=')'  → 栈非空，弹栈  栈: [ ( ]    top=1   ✓ 配对
i=5, s[5]=')'  → 栈非空，弹栈  栈: [ ]      top=0   ✓ 配对

循环结束，栈空 → 输出 YES
```

!!! warning "两种失败情形要分清"
    - **右括号多余**：扫描中途遇 `)` 时栈已空 → 立即判 `NO`（如 `())`）。
    - **左括号多余**：扫描结束栈仍非空 → 结束后判 `NO`（如 `(()`）。
    两个判断**缺一不可**，初学者常漏掉第二个。

## 【进阶】单调栈（S 组核心）

### 9.1 什么是单调栈

「单调栈 monotonic stack」是指栈内元素**保持单调递增（或递减）**的栈。它在解决"寻找下一个更大/更小元素"类问题时，能把朴素 $O(n^2)$ 优化到 $O(n)$。

!!! tip "生活类比"
    站成一排的人，每个人向右看，只能看到**第一个比自己高**的人（中间比自己矮的都被挡住了）。单调栈就是模拟这个"被挡住"的过程。

**核心思想**：入栈前，把栈顶所有"破坏单调性"的元素弹出，弹出的同时记录答案。

### 9.2 经典问题：下一个更大元素

**题意**：给定数组 `a[1..n]`，对每个 `a[i]`，求它右边第一个比 `a[i]` 大的元素的下标，没有则输出 0。（即洛谷 P5788）

**朴素思路** $O(n^2)$：对每个 i，向右扫描找第一个大于 a[i] 的。

**单调栈思路** $O(n)$：维护一个**下标栈**，栈内对应的 a 值**单调递减**。从右往左扫，每次把栈顶"小于等于 a[i]"的下标弹出，栈顶就是答案。

#### 版本一：数组模拟单调栈

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 3000010;
int a[N];                     // 原数组
int stk[N], top = 0;          // 栈存下标
int ans[N];                   // ans[i] = i 右边第一个比 a[i] 大的下标

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) scanf("%d", &a[i]);

    // 从右往左扫，维护"下标对应 a 值单调递减"的栈
    for (int i = n; i >= 1; i--) {
        // 弹出栈顶所有 a 值 <= a[i] 的下标（它们不可能是答案）
        while (top > 0 && a[stk[top]] <= a[i]) {
            top--;                        // 栈顶不满足单调性，弹出
        }
        // 此时栈顶就是 i 右边第一个比 a[i] 大的下标（栈空则为 0）
        ans[i] = (top > 0) ? stk[top] : 0;
        // 把 i 入栈，保持单调递减
        stk[++top] = i;
    }

    for (int i = 1; i <= n; i++) printf("%d ", ans[i]);
    return 0;
}
```

!!! tip "数组模拟单调栈的关键"
    栈里存的是**下标**而非值本身，这样弹出时既能比较 `a[stk[top]]`，又能直接把 `stk[top]` 作为答案下标。这是单调栈题目的通用技巧。

#### 版本二：STL 实现单调栈

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 3000010;
int a[N], ans[N];

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) scanf("%d", &a[i]);

    stack<int> stk;            // 栈存下标
    for (int i = n; i >= 1; i--) {
        // 弹出栈顶所有 a 值 <= a[i] 的下标
        while (!stk.empty() && a[stk.top()] <= a[i]) {
            stk.pop();
        }
        ans[i] = stk.empty() ? 0 : stk.top();
        stk.push(i);
    }

    for (int i = 1; i <= n; i++) printf("%d ", ans[i]);
    return 0;
}
```

### 9.3 手动推演示例（务必跟着走一遍）

!!! tip "金牌教练的忠告"
    单调栈的代码只有 5 行，但**不理解原理就记不住**。请用下面的例子，拿纸笔手动模拟一遍栈的变化，这是内化单调栈的最快路径。

**输入**：`a = [_, 3, 1, 4, 2, 5]`（下标 1~5，`_` 表示下标 0 不用）

我们要对每个 `a[i]` 求它**右边第一个更大**元素的下标。从右往左扫描，维护一个「下标对应的 a 值单调递减」的栈。

```
初始：栈空，top=0

i=5, a[5]=5：
  while 栈非空且 a[栈顶] <= 5？栈空，不弹
  ans[5] = 栈空 ? 0 → ans[5]=0          （5 右边没有更大的）
  入栈：stk=[5]，栈内 a 值：[5]

i=4, a[4]=2：
  while a[栈顶]=a[5]=5 <= 2？否，不弹
  ans[4] = 栈顶 = 5                      （2 右边第一个更大是 a[5]=5）
  入栈：stk=[5,4]，栈内 a 值：[5, 2]      （单调递减 ✓）

i=3, a[3]=4：
  while a[栈顶]=a[4]=2 <= 4？是，弹 4     stk=[5]
  while a[栈顶]=a[5]=5 <= 4？否，停
  ans[3] = 栈顶 = 5                      （4 右边第一个更大是 a[5]=5）
  入栈：stk=[5,3]，栈内 a 值：[5, 4]      （单调递减 ✓）

i=2, a[2]=1：
  while a[栈顶]=a[3]=4 <= 1？否，不弹
  ans[2] = 栈顶 = 3                      （1 右边第一个更大是 a[3]=4）
  入栈：stk=[5,3,2]，栈内 a 值：[5,4,1]   （单调递减 ✓）

i=1, a[1]=3：
  while a[栈顶]=a[2]=1 <= 3？是，弹 2     stk=[5,3]
  while a[栈顶]=a[3]=4 <= 3？否，停
  ans[1] = 栈顶 = 3                      （3 右边第一个更大是 a[3]=4）
  入栈：stk=[5,3,1]，栈内 a 值：[5,4,3]   （单调递减 ✓）

最终答案：ans = [_, 3, 3, 5, 5, 0]
         即 a[1]→a[3], a[2]→a[3], a[3]→a[5], a[4]→a[5], a[5]→无
```

!!! info "推演中观察到的规律"
    - 栈内下标对应的 a 值**始终单调递减**（从栈底到栈顶递减）。
    - 每次弹出的元素，其答案**正是当前 i**（因为 i 是它右边第一个比它大的）——这就是"弹栈时记录答案"的另一种写法。
    - 栈空表示当前元素右边没有更大的，答案记 0。

### 9.4 单调栈复杂度分析

!!! info "为什么是 $O(n)$？"
    虽然有嵌套循环（for 里有 while），但**每个元素至多入栈一次、出栈一次**，所以 while 总执行次数不超过 n 次。摊还分析后总时间 $O(n)$。

| 维度 | 朴素 | 单调栈 |
|------|:----:|:------:|
| 时间复杂度 | $O(n^2)$ | $O(n)$ |
| 空间复杂度 | $O(1)$ | $O(n)$ |

### 9.5 单调栈变体速查

| 需求 | 单调性 | 扫描方向 | 弹出条件 |
|------|:------:|:--------:|----------|
| 右边第一个更大 | 递减 | 从右往左 | `a[stk[top]] <= a[i]` |
| 右边第一个更小 | 递增 | 从右往左 | `a[stk[top]] >= a[i]` |
| 左边第一个更大 | 递减 | 从左往右 | `a[stk[top]] <= a[i]` |
| 左边第一个更小 | 递增 | 从左往右 | `a[stk[top]] >= a[i]` |
