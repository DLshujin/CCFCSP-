## 💡 生活类比

!!! tip "类比一：公司层级晋升"
    把堆想象成一家**等级森严的公司**：老板（根节点）永远是**能力最强/业绩最高**的那个人（大根堆）。一旦老板退休，就要从副总（左右儿子）中选出最强的接任，然后空出的副总位置由部门经理顶上……层层「下沉」补位，直到最底层。新员工入职则从最底层干起，若业绩碾压上级就**「上浮」晋升**，直到找到合适的位置。

```
              老板（最大值）           ← 根节点 = 堆顶
             /    \
         副总A    副总B               ← 每个父节点都 ≥ 子节点
        /  \      /  \
      经理  经理 经理  经理            ← 完全二叉树，从左到右排满
```

!!! tip "类比二：医院急诊分诊"
    急诊科按**病情严重程度**而非**到达顺序**叫号：危重病人优先救治。这就是「优先队列」——每次取出的不是最早入队的，而是**优先级最高**的。堆正是优先队列最高效的实现：入队 $O(\log n)$，取最优先者 $O(1)$、弹出 $O(\log n)$。

这两个类比的共同点：**父节点始终 ≥（或 ≤）子节点**，且**根节点永远是极值**。这就是堆的核心约束。

## 核心概念

### 22.1 堆的定义

「堆 Heap」是一棵**完全二叉树**，满足**堆序性**：

- **大根堆（Max-Heap）**：每个节点的值 **≥** 其左右子节点的值。根节点是**最大值**。
- **小根堆（Min-Heap）**：每个节点的值 **≤** 其左右子节点的值。根节点是**最小值**。

!!! info "完全二叉树的关键性质"
    完全二叉树是指：除最后一层外，每一层都被完全填充；且最后一层的节点从**左到右**连续排列。这一性质使得堆可以用**数组**高效存储，无需指针。

    设节点编号为 `u`（从 1 开始），则：
    - **父节点**：`u / 2`（整数除法）
    - **左儿子**：`u * 2`
    - **右儿子**：`u * 2 + 1`
    - **根节点**：`u = 1`

    数组下标从 **1** 开始是堆的惯例，可让父子关系公式最简洁。

### 22.2 核心操作一览（含时间复杂度）

| 操作 | 含义 | 时间复杂度 | 备注 |
|------|------|:----------:|------|
| `push(x)` | 插入元素 x（加到末尾后 `up`） | $O(\log n)$ | 堆大小 +1 |
| `pop()` | 删除堆顶（末尾覆盖后 `down`） | $O(\log n)$ | **必须先判空** |
| `top()` | 取堆顶（不删除） | $O(1)$ | 堆空时未定义 |
| `up(u)` | 节点 u 向上调整 | $O(\log n)$ | 与父节点比较 |
| `down(u)` | 节点 u 向下调整 | $O(\log n)$ | 与较小/较大儿子比较 |
| 建堆 | 从无序数组构造堆 | $O(n)$ | 从 `n/2` 到 1 依次 `down` |

!!! info "关键约束"
    堆**只保证堆顶是极值**，不保证整体有序。若想得到有序序列，需反复 `pop`——这就是堆排序的原理。

                /    \
              70      80       ← h[2], h[3]
             /  \    /  \

## 数组模拟堆：手写模板

### 22.4 `down` 操作（下沉）

**场景**：当节点 u 的值**变大**（在大根堆中）或其子节点更优时，需要将 u 向下调整，恢复堆序性。

**思路**（以大根堆为例）：找出 u 与其左右儿子中**最大**的那个；若最大者不是 u，则交换，并继续下沉。

```cpp
// 大根堆的 down 操作
// h: 堆数组（下标从 1 开始），sz: 堆中元素个数
void down(int h[], int sz, int u) {
    int t = u;                          // t 记录「当前最大值」的下标
    int l = u * 2, r = u * 2 + 1;       // 左右儿子
    if (l <= sz && h[l] > h[t]) t = l;  // 左儿子更大
    if (r <= sz && h[r] > h[t]) t = r;  // 右儿子更大
    if (t != u) {                       // 需要下沉
        swap(h[t], h[u]);
        down(h, sz, t);                 // 递归继续下沉
    }
}
```

!!! warning "边界条件：`l <= sz` 不能漏！"
    `down` 时必须检查 `l <= sz` 和 `r <= sz`，否则会访问越界。这是**最常见的丢分点**，下文「常见误区」会详细分析。

### 22.5 `up` 操作（上浮）

**场景**：当节点 u 的值**变小**（在大根堆中）或新节点插入末尾时，需要将 u 向上调整。

**思路**（大根堆）：只要 u 比父节点大，就与父节点交换，继续上浮。

```cpp
// 大根堆的 up 操作
void up(int h[], int u) {
    while (u / 2 >= 1 && h[u] > h[u / 2]) {  // 有父节点且比父节点大
        swap(h[u], h[u / 2]);
        u /= 2;                              // 上移到父节点位置
    }
}
```

### 22.6 `push` / `pop` / `top` 完整实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1000010;
int h[N];      // 堆数组（下标从 1 开始）
int sz;        // 堆中元素个数

// 大根堆下沉
void down(int u) {
    int t = u;
    int l = u * 2, r = u * 2 + 1;
    if (l <= sz && h[l] > h[t]) t = l;
    if (r <= sz && h[r] > h[t]) t = r;
    if (t != u) {
        swap(h[t], h[u]);
        down(t);
    }
}

// 大根堆上浮
void up(int u) {
    while (u / 2 >= 1 && h[u] > h[u / 2]) {
        swap(h[u], h[u / 2]);
        u /= 2;
    }
}

// 插入：加到末尾，然后 up
void push(int x) {
    h[++sz] = x;   // 注意是 ++sz，先把 sz+1 再赋值
    up(sz);
}

// 删除堆顶：用末尾覆盖堆顶，sz--，再 down(1)
void pop() {
    if (sz == 0) return;       // 空堆保护，避免 sz-- 变为 -1
    h[1] = h[sz--]; // 末尾元素顶替堆顶
    down(1);
}

// 取堆顶
int top() {
    if (sz == 0) return -1;    // 空堆返回哨兵值 -1（调用方应先判 empty）
    return h[1];
}

// 判空
bool empty() {
    return sz == 0;
}

int main() {
    int n; scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        int op, x; scanf("%d", &op);
        if (op == 1) { scanf("%d", &x); push(x); }
        else if (op == 2) printf("%d\n", top());
        else pop();
    }
    return 0;
}
```

!!! tip "删除堆顶的「末尾覆盖」技巧"
    为什么不直接删堆顶？因为直接删会留下两个孤儿子树，难以合并。正确做法是：用**最后一个元素**覆盖堆顶，`sz--`，再对根做一次 `down`。这样保持完全二叉树形态，调整只需 $O(\log n)$。

### 22.7 $O(n)$ 建堆

**场景**：已有 $n$ 个无序元素，想要构造一个堆。

**朴素做法**：逐个 `push`，复杂度 $O(n \log n)$。

**高效做法**：从下标 `n/2` 倒序到 `1`，依次执行 `down`。复杂度 **$O(n)$**。

```cpp
void build(int n) {
    sz = n;
    for (int i = n / 2; i >= 1; i--) {  // 从最后一个非叶子节点开始
        down(i);
    }
}
```

!!! info "为何 $O(n)$？"
    `down` 的执行次数与节点所在层有关：叶子节点（约 $n/2$ 个）不需要 `down`；倒数第二层（$n/4$ 个）最多下沉 1 层；倒数第三层（$n/8$ 个）最多下沉 2 层……

    总调整次数 $\le \dfrac{n}{4}\cdot 1 + \dfrac{n}{8}\cdot 2 + \dfrac{n}{16}\cdot 3 + \cdots = O(n)$。

    而逐个 `push` 是「自底向上 up」，每次都可能上浮到根，总复杂度 $O(n \log n)$。

    **记忆口诀**：`down` 建堆从 `n/2` 倒着来，复杂度 $O(n)$。

## STL priority_queue：速查与用法

### 22.8 头文件与定义

```cpp
#include <queue>          // priority_queue 在 <queue> 中
using namespace std;

priority_queue<int> pq;                              // 默认大根堆
priority_queue<int, vector<int>, greater<int>> pq2;  // 小根堆
priority_queue<int, vector<int>, less<int>> pq3;     // 大根堆（显式写法）
```

!!! warning "小根堆写法必须背熟"
    `priority_queue<int, vector<int>, greater<int>>` 是 CSP 考场高频写法。三个尖括号之间**不能有空格**（C++11 之前），但现在编译器已支持 `>>`。务必记住：**`greater` = 小根堆**，`less` = 大根堆。这与直觉相反，容易记混。

### 22.9 核心成员函数速查表

| 成员函数 | 含义 | 时间复杂度 | 备注 |
|----------|------|:----------:|------|
| `push(x)` | 插入元素 x | $O(\log n)$ | 自动调整堆 |
| `pop()` | 删除堆顶 | $O(\log n)$ | **无返回值**，且必须判空 |
| `top()` | 取堆顶（不删除） | $O(1)$ | 仅访问，不弹出 |
| `empty()` | 判空 | $O(1)$ | 返回 bool |
| `size()` | 元素个数 | $O(1)$ | — |
| `emplace(args...)` | 原地构造并插入 | $O(\log n)$ | C++11，避免临时对象 |

!!! warning "`priority_queue` 没有 `clear()`！"
    若需清空，只能循环 `while (!pq.empty()) pq.pop();`，或重新赋值 `pq = priority_queue<int>();`。

### 22.10 STL 完整示例：大根堆 + 小根堆

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 大根堆（默认）
    priority_queue<int> maxH;
    maxH.push(3); maxH.push(1); maxH.push(4); maxH.push(1); maxH.push(5);
    printf("大根堆堆顶: %d\n", maxH.top());   // 5
    maxH.pop();
    printf("弹出后堆顶: %d\n", maxH.top());   // 4

    // 小根堆
    priority_queue<int, vector<int>, greater<int>> minH;
    minH.push(3); minH.push(1); minH.push(4); minH.push(1); minH.push(5);
    printf("小根堆堆顶: %d\n", minH.top());   // 1
    minH.pop();
    printf("弹出后堆顶: %d\n", minH.top());   // 1

    // 降序输出（用大根堆做堆排序）
    while (!maxH.empty()) {
        printf("%d ", maxH.top());
        maxH.pop();
    }
    // 输出: 4 3 1 1
    return 0;
}
```

### 22.11 自定义比较器：结构体入堆

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int w, id;
    // 重载 < ：注意 priority_queue 是「大根堆按 <」，故要让「小的优先出」需反向
    bool operator < (const Node &o) const {
        return w > o.w;   // w 小的优先级高（先出堆）→ 小根堆
    }
};

int main() {
    priority_queue<Node> pq;
    pq.push({3, 1}); pq.push({1, 2}); pq.push({2, 3});
    while (!pq.empty()) {
        printf("id=%d w=%d\n", pq.top().id, pq.top().w);
        pq.pop();
    }
    // 输出顺序：id=2(w=1) → id=3(w=2) → id=1(w=3)
    return 0;
}
```

!!! tip "自定义比较器的「反向法则」"
    `priority_queue` 默认用 `less`（即 `<`），结果是**大根堆**。所以若想让「w 小的先出堆」，就要让 `w` 小的 Node 在 `<` 比较中表现为「更大」，即写 `return w > o.w;`。这与 `sort` 的比较器方向**相反**，是常见坑点。

## 双轨对比：手写堆 vs priority_queue

### 22.12 逐项对比表

| 维度 | 手写数组堆 | STL priority_queue |
|------|-----------|-------------------|
| **代码量** | 较长（`down/up/push/pop` 全写） | 极短（一行定义） |
| **编码速度** | 慢（5~10 分钟） | 快（1 分钟） |
| **常数性能** | 小（数组连续访问，缓存友好） | 较大（底层用 vector，仍有常数） |
| **调试难度** | 高（边界条件多） | 低（STL 保证正确） |
| **支持任意位置删除** | ✅ 可扩展（用「懒惰删除」或映射） | ❌ 不直接支持 |
| **支持修改堆中元素** | ✅ 修改后 `up`/`down` 一次 | ❌ 需先删后插，但删不了 |
| **支持随机访问** | ✅ `h[i]` 直接访问 | ❌ 只能访问 `top` |
| **灵活性** | 高（可改造为对顶堆、双堆等） | 低（黑盒） |

### 22.13 赛场选型策略

!!! tip "何时选手写堆？"
    1. 题目需要**修改堆中元素**或**删除任意元素**（如 Dijkstra 优化中可能要 decrease-key）。
    2. 题目需要**同时维护元素位置**（如 P1090 合并果子可手写，但 STL 也够用）。
    3. **常数卡得很死**（$n = 10^6$，且时限 0.5s），手写堆常数约为 STL 的 1/3。
    4. 题目明确要求「实现堆」（如模板题 P3378）。

!!! tip "何时选 STL priority_queue？"
    1. **时间紧迫**，优先保编码速度与正确性。
    2. 只需 `push/pop/top` 三件套，无需修改元素。
    3. **对顶堆**等结构中，用两个 `priority_queue` 配合即可（如 P1168 中位数）。
    4. Dijkstra、Prim 等图论算法的标配实现。

!!! warning "CSP-S 实战建议"
    **默认用 STL**，节省时间、减少 bug。只有当题目明确要求「手写」或「需要修改堆中元素」时才上手写堆。但**手写堆模板必须会默写**——它是面试与高难度题的必备技能。

## 常见误区

### 误区一：`down` 边界条件写错（`u*2 <= sz` 漏掉）

```cpp
// ❌ 错误写法：没有检查儿子下标是否越界
void down(int u) {
    int t = u;
    if (h[u*2] > h[t]) t = u*2;       // u*2 可能 > sz，越界！
    if (h[u*2+1] > h[t]) t = u*2+1;   // 同上
    if (t != u) { swap(h[t], h[u]); down(t); }
}

// ✅ 正确写法：先判 l <= sz
void down(int u) {
    int t = u, l = u*2, r = u*2+1;
    if (l <= sz && h[l] > h[t]) t = l;
    if (r <= sz && h[r] > h[t]) t = r;
    if (t != u) { swap(h[t], h[u]); down(t); }
}
```

**后果**：访问 `h[sz+1]`、`h[sz+2]` 等越界内存，轻则答案错误，重则 RE。

### 误区二：`push` 时 `sz++` 与 `++sz` 搞混

```cpp
// ❌ 错误：sz 先加 1 再用，但若 h 数组从 0 开始则错位
h[sz++] = x;   // 若 sz 初值为 0，则写在 h[0]，与「下标从 1 开始」矛盾

// ✅ 正确：先 ++sz 再赋值，保证写到 h[1], h[2], ...
h[++sz] = x;
```

### 误区三：`pop` 直接删堆顶，破坏完全二叉树

```cpp
// ❌ 错误：直接把堆顶「挖空」，左右子树失联
void pop() { sz--; down(1); }   // h[1] 没有被末尾覆盖，down 会用旧值

// ✅ 正确：末尾覆盖堆顶，再 down
void pop() { h[1] = h[sz--]; down(1); }
```

### 误区四：建堆从 1 到 n 顺序 `down`

```cpp
// ❌ 低效且逻辑错误：从 1 到 n 顺序 down 不能保证子树已有序
for (int i = 1; i <= n; i++) down(i);   // 复杂度退化

// ✅ 正确：从 n/2 倒序 down（叶子节点无需调整）
for (int i = n/2; i >= 1; i--) down(i);  // O(n)
```

### 误区五：大根堆/小根堆 `down` 比较方向写反

```cpp
// 大根堆：找「最大」的儿子与父比较
if (l <= sz && h[l] > h[t]) t = l;   // > ：大根堆

// 小根堆：找「最小」的儿子与父比较
if (l <= sz && h[l] < h[t]) t = l;   // < ：小根堆
```

!!! warning "改大小根堆只需改两个符号"
    把大根堆改成小根堆，只需把 `down` 中的 `>` 改成 `<`，把 `up` 中的 `>` 改成 `<`。**不要改错地方**。

### 误区六：`priority_queue` 的 `pop()` 返回值误用

```cpp
// ❌ 错误：pop() 返回 void，不能这样取值
int x = pq.pop();   // 编译错误

// ✅ 正确：先 top() 再 pop()
int x = pq.top();
pq.pop();
```

## 典型例题

### 22.14 应用一：堆排序

**思路**：先 $O(n)$ 建大根堆，再反复「交换堆顶与末尾、`sz--`、`down(1)」。最终数组**升序**排列。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100010;
int h[N], n;

void down(int u, int sz) {
    int t = u, l = u*2, r = u*2+1;
    if (l <= sz && h[l] > h[t]) t = l;
    if (r <= sz && h[r] > h[t]) t = r;
    if (t != u) { swap(h[t], h[u]); down(t, sz); }
}

void heap_sort() {
    // 1. O(n) 建大根堆
    for (int i = n/2; i >= 1; i--) down(i, n);
    // 2. 反复取堆顶放末尾
    for (int i = n; i > 1; i--) {
        swap(h[1], h[i]);     // 最大值归位
        down(1, i-1);         // 对剩余部分 down
    }
}

int main() {
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) scanf("%d", &h[i]);
    heap_sort();
    for (int i = 1; i <= n; i++) printf("%d ", h[i]);
    return 0;
}
```

| 性质 | 堆排序 |
|------|--------|
| 时间复杂度 | $O(n \log n)$（最坏、平均、最好均为） |
| 空间复杂度 | $O(1)$（原地排序） |
| 稳定性 | **不稳定** |
| 特点 | 适合 top K 问题，但缓存不友好 |

### 22.15 应用二：Top K 问题

**问题**：在 $n$ 个数中找出**最大**的 $k$ 个数（或最小的 $k$ 个数）。

**策略一（求最大 k 个，用小根堆，大小为 k）**：维护一个大小为 $k$ 的小根堆，新元素若大于堆顶则替换。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, k; scanf("%d %d", &n, &k);
    priority_queue<int, vector<int>, greater<int>> pq;  // 小根堆
    for (int i = 0; i < n; i++) {
        int x; scanf("%d", &x);
        if (pq.size() < k) pq.push(x);
        else if (x > pq.top()) { pq.pop(); pq.push(x); }
    }
    // 堆中即为最大的 k 个数
    while (!pq.empty()) { printf("%d ", pq.top()); pq.pop(); }
    return 0;
}
```

!!! info "为何求「最大 k 个」要用「小根堆」？"
    小根堆的堆顶是**当前 k 个数中的最小值**，正好作为「门槛」：新来的数若比门槛大，就挤掉门槛入堆。最终堆里留下的就是全局最大的 k 个。复杂度 $O(n \log k)$，当 $k \ll n$ 时远优于排序的 $O(n \log n)$。

### 22.16 应用三：对顶堆求动态中位数（P1168 核心）

**思路**：用**大根堆**装「较小的一半」，**小根堆**装「较大的一半」，并保持两堆规模平衡。中位数即大根堆堆顶。

```cpp
#include <bits/stdc++.h>
using namespace std;

priority_queue<int> big;                                  // 大根堆：较小的一半
priority_queue<int, vector<int>, greater<int>> small;     // 小根堆：较大的一半

void insert(int x) {
    if (big.empty() || x <= big.top()) big.push(x);
    else small.push(x);
    // 平衡：大根堆大小 ∈ [小根堆, 小根堆+1]
    while (big.size() > small.size() + 1) { small.push(big.top()); big.pop(); }
    while (small.size() > big.size())     { big.push(small.top()); small.pop(); }
}

int median() { return big.top(); }

int main() {
    int n; scanf("%d", &n);
    for (int i = 1; i <= n; i++) {
        int x; scanf("%d", &x); insert(x);
        if (i & 1) printf("%d\n", median());  // 奇数次输出中位数
    }
    return 0;
}
```

## 📚 本节练习

### 习题一：[P3378] 堆模板（小根堆）

**题意**：支持三种操作：`1 x` 插入 x；`2` 输出最小值；`3` 删除最小值。

**解法**：直接套手写小根堆模板，`down/up` 比较符号取 `<`。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 1000010;
int h[N], sz;

void down(int u) {
    int t = u, l = u*2, r = u*2+1;
    if (l <= sz && h[l] < h[t]) t = l;   // 小根堆用 <
    if (r <= sz && h[r] < h[t]) t = r;
    if (t != u) { swap(h[t], h[u]); down(t); }
}

void up(int u) {
    while (u/2 >= 1 && h[u] < h[u/2]) {  // 小根堆用 <
        swap(h[u], h[u/2]); u /= 2;
    }
}

int main() {
    int n; scanf("%d", &n);
    while (n--) {
        int op, x; scanf("%d", &op);
        if (op == 1) { scanf("%d", &x); h[++sz] = x; up(sz); }
        else if (op == 2) printf("%d\n", h[1]);
        else { h[1] = h[sz--]; down(1); }
    }
    return 0;
}
```

**复杂度**：$O(n \log n)$，可过。

### 习题二：[P1168] 中位数

**题意**：依次读入 $n$ 个数，每当读入**奇数个**数时输出当前中位数。

**解法**：对顶堆，详见 22.16 节。注意本题是**离线/在线**皆可，对顶堆天然支持在线。

**关键点**：
- 大根堆装较小的一半，堆顶是中位数候选。
- 每次插入后**立即平衡**两堆大小。
- 大根堆大小允许比小根堆多 1（用于奇数个时取中位数）。

### 习题三：[P1090] 合并果子

**题意**：有 $n$ 堆果子，每次合并任意两堆，代价为两堆重量之和。求把所有果子合成一堆的最小总代价。

**贪心策略**：每次选**最小的两堆**合并。用小根堆维护。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n; scanf("%d", &n);
    priority_queue<int, vector<int>, greater<int>> pq;  // 小根堆
    for (int i = 0; i < n; i++) {
        int x; scanf("%d", &x); pq.push(x);
    }
    long long ans = 0;
    while (pq.size() > 1) {
        int a = pq.top(); pq.pop();
        int b = pq.top(); pq.pop();
        ans += a + b;
        pq.push(a + b);   // 合并后的堆重新入队
    }
    printf("%lld\n", ans);
    return 0;
}
```

**复杂度**：$O(n \log n)$。

**正确性直觉**：每次合并最小两堆，类似哈夫曼树构造——**频率低的先合并**，总代价最小。这是贪心经典题，务必理解。

!!! warning "为何不能每次合并最大的两堆？"
    合并代价会**累加到后续每次合并中**。把大堆留到最后合并，能减少它被反复累加的次数，从而最小化总代价。这正是「小的先合并」的贪心依据。

## 本章总结

### 核心知识图谱

```
                              堆 Heap
                                │
          ┌─────────────────────┼─────────────────────┐
          ▼                     ▼                     ▼
       定义性质              核心操作               典型应用
   ┌────────────┐      ┌──────────────┐      ┌──────────────┐
   │ 完全二叉树 │      │ up   O(log n)│      │ 堆排序       │
   │ 大/小根堆  │      │ down O(log n)│      │ Top K        │
   │ 数组存储   │      │ build O(n)   │      │ 对顶堆中位数 │
   │ u*2/u*2+1  │      │ push/pop/top│      │ 合并果子     │
   └────────────┘      └──────────────┘      └──────────────┘
                                │
                    ┌───────────┴───────────┐
                    ▼                       ▼
              手写数组堆            STL priority_queue
           （灵活、常数小）        （快速、不易错）
```

### 必背速查

| 知识点 | 关键内容 |
|--------|---------|
| 父子关系 | 父 = `u/2`，左 = `u*2`，右 = `u*2+1`，下标从 1 开始 |
| 大根堆 `down` | 找最大儿子，`h[l] > h[t]` |
| 小根堆 `down` | 找最小儿子，`h[l] < h[t]` |
| `push` | `h[++sz]=x; up(sz);` |
| `pop` | `h[1]=h[sz--]; down(1);` |
| 建堆 | `for(i=n/2;i>=1;i--) down(i);` $O(n)$ |
| STL 大根堆 | `priority_queue<int> pq;` |
| STL 小根堆 | `priority_queue<int, vector<int>, greater<int>> pq;` |
| Top K（求最大 k 个） | 维护大小为 k 的**小根堆** |
| 对顶堆中位数 | 大根堆装小半，小根堆装大半 |

### 易错点清单

1. ❌ `down` 时漏写 `l <= sz`、`r <= sz` → 越界 RE
2. ❌ `push` 时 `h[sz++]` 与 `h[++sz]` 混淆 → 下标错位
3. ❌ `pop` 时未用末尾覆盖堆顶 → 完全二叉树破坏
4. ❌ 建堆时顺序 `for(i=1;i<=n;i++)` → 退化到 $O(n \log n)$ 且逻辑错
5. ❌ `priority_queue` 的 `pop()` 当成有返回值 → 编译错误
6. ❌ 自定义比较器方向与 `sort` 混淆 → 堆序反向
7. ❌ 大小根堆转换时只改 `down` 忘改 `up` → 堆序错乱
