## 💡 生活类比

打个比方，CSP-S 初赛就像考**驾照科目一**：你不一定要能把车开得多溜，但你必须**认得路标、懂得交规、看得懂仪表盘**。

- 计算机基础知识 = 认路标：你得知道 CPU 长什么样、内存和外存有什么区别、网络是怎么把数据送出去的。
- 进制转换和编码 = 看仪表盘：二进制是机器的"母语"，补码是机器处理负数的方式，你得能看懂。
- 程序阅读题 = 模拟驾驶：给你一段"路况"（代码），你要在脑子里"开一遍"，准确说出走到了哪里。
- 程序完善题 = 填空驾驶：路标被遮住了一块，你得根据前后路况推断遮住的内容。

而模拟卷，就是考前的"全真模拟驾驶"——做一遍，才知道自己哪里还薄弱。

## 核心概念

### 49.1 计算机基础知识

#### 49.1.1 计算机发展史

计算机的发展以**电子元器件**的更新为标志，分为四代：

| 代次 | 年代 | 元器件 | 代表机型 | 特点 |
|------|------|--------|----------|------|
| 第一代 | 1946–1957 | 电子管 | ENIAC | 体积大、耗电高 |
| 第二代 | 1958–1964 | 晶体管 | IBM 7094 | 体积缩小、可靠性提高 |
| 第三代 | 1965–1970 | 集成电路 | IBM 360 | 小型化、通用化 |
| 第四代 | 1971–至今 | 大规模/超大规模集成电路 | 微型机、PC | 个人计算机普及 |

!!! info "ENIAC 与 EDVAC"
    - **ENIAC**（1946）：世界上第一台通用电子计算机，但采用外插式程序，每次换程序要重新接线。
    - **EDVAC**（1952）：第一台**存储程序**计算机，基于冯诺依曼体系，程序和数据同存于内存。

#### 49.1.2 冯诺依曼体系结构

1945 年，美籍匈牙利数学家**冯诺依曼**（John von Neumann）提出"存储程序"思想，奠定了现代计算机的体系结构。

冯诺依曼体系的**五大部件**：

```
        ┌──────────────────────────────────┐
        │            计算机系统              │
        └──────────────┬───────────────────┘
                       │
        ┌──────────────┼──────────────────┐
        ▼              ▼                  ▼
    ┌────────┐    ┌────────┐        ┌────────┐
    │  运算器  │◄──►│  控制器  │◄──────►│ 存储器  │
    │  (ALU)  │    │  (CU)   │        │(内存)  │
    └────────┘    └────┬───┘        └────────┘
                         │                   ▲
                         ▼                   │
                   ┌─────────┐         ┌─────────┐
                   │  输入设备 │         │ 输出设备  │
                   └─────────┘         └─────────┘
```

- **运算器（ALU）**：执行算术和逻辑运算。
- **控制器（CU）**：取指令、译码、控制各部件协调工作。运算器 + 控制器 = **CPU**。
- **存储器**：存放程序和数据。
- **输入设备**：键盘、鼠标等。
- **输出设备**：显示器、打印机等。

!!! tip "核心思想：存储程序"
    程序和数据**同等对待**，都以二进制形式存于内存，机器按地址顺序取指执行。这是冯诺依曼体系最关键的贡献。

#### 49.1.3 CPU 与存储层次

**CPU 的组成**：
- 运算器（ALU）：算术逻辑单元
- 控制器（CU）：控制单元
- 寄存器（Register）：通用寄存器、程序计数器（PC）、指令寄存器（IR）等
- 高速缓存（Cache）：L1 / L2 / L3

**存储层次结构**（速度递减、容量递增、单位价格递减）：

```
寄存器 → Cache(L1→L2→L3) → 内存(RAM) → 固态硬盘(SSD) → 机械硬盘(HDD) → 外部存储
  快 ←─────────────────────────────────────────────────────────────→ 慢
  小 ←─────────────────────────────────────────────────────────────→ 大
```

!!! warning "易混淆：内存 vs 外存"
    - **内存（主存，RAM）**：断电丢失数据，CPU 可直接访问，速度快但容量小。
    - **外存（辅存，硬盘/U盘）**：断电不丢失，CPU 不能直接访问（需先调入内存），容量大但慢。

#### 49.1.7 位、字节、字与存储容量

**基本单位**：

| 单位 | 英文 | 含义 | 关系 |
|------|------|------|------|
| 位 | bit（缩写 b） | 最小单位，0 或 1 | — |
| 字节 | Byte（缩写 B） | 最基本存储单位 | 1 B = 8 bit |
| 字 | Word | CPU 一次处理的二进制位数 | 通常 2/4/8 字节 |

!!! info "位 vs 字节"
    - **位（bit）**：计算机中最小的数据单位，只有 0 和 1 两种状态。
    - **字节（Byte）**：最基本的存储单位，1 Byte = 8 bit。一个 ASCII 字符占 1 字节，一个汉字（UTF-8）占 3 字节。
    - **字（Word）**：CPU 一次能处理的二进制位数称为"字长"。32 位系统的字长为 4 字节，64 位系统为 8 字节。

**存储单位换算**（相邻单位进率为 $1024 = 2^{10}$）：

| 单位 | 缩写 | 换算关系 |
|------|------|----------|
| 字节 | B | $1 \text{ B} = 8 \text{ bit}$ |
| 千字节 | KB | $1 \text{ KB} = 1024 \text{ B}$ |
| 兆字节 | MB | $1 \text{ MB} = 1024 \text{ KB}$ |
| 吉字节 | GB | $1 \text{ GB} = 1024 \text{ MB}$ |
| 太字节 | TB | $1 \text{ TB} = 1024 \text{ GB}$ |
| 拍字节 | PB | $1 \text{ PB} = 1024 \text{ TB}$ |

!!! warning "易混淆：KB vs kb"
    - **KB**（大写 K，大写 B）= 千字节 = 1024 字节
    - **kb**（小写 k，小写 b）= 千比特 = 1000 比特（网络带宽常用）
    - 网速"100 Mbps"指 100 兆比特/秒，实际下载速度约 $100 \div 8 = 12.5$ MB/s

**存储容量计算例题**：

> **例题**：一个 1024×768 像素的 24 位真彩色图像，需要多少存储空间？

**分析**：
- 每个像素占 24 bit = 3 Byte
- 总像素数 = 1024 × 768 = 786432
- 总字节数 = 786432 × 3 = 2359296 B
- 换算：2359296 ÷ 1024 = 2304 KB ÷ 1024 ≈ 2.25 MB

**答案**：约 2.25 MB。

### 49.2 进制转换

#### 49.2.1 常用进制对照

| 进制 | 基数 | 数字符号 | 典型用途 |
|------|------|----------|----------|
| 二进制 | 2 | 0, 1 | 计算机内部 |
| 八进制 | 8 | 0–7 | 文件权限 |
| 十进制 | 10 | 0–9 | 日常 |
| 十六进制 | 16 | 0–9, A–F | 内存地址、颜色值 |

**对照表**（前 16 个数）：

| 十进制 | 二进制 | 八进制 | 十六进制 |
|--------|--------|--------|----------|
| 0 | 0000 | 0 | 0 |
| 5 | 0101 | 5 | 5 |
| 10 | 1010 | 12 | A |
| 15 | 1111 | 17 | F |
| 16 | 10000 | 20 | 10 |
| 255 | 11111111 | 377 | FF |

#### 49.2.2 转换方法

**① 任意进制 → 十进制：按权展开**

$$N = \sum d_i \times r^i$$

例：二进制 `1011` → 十进制：
$$1\times2^3 + 0\times2^2 + 1\times2^1 + 1\times2^0 = 8+0+2+1 = 11$$

十六进制 `2F` → 十进制：
$$2\times16^1 + 15\times16^0 = 32+15 = 47$$

**② 十进制 → 任意进制：除基取余，逆序排列**

例：十进制 25 → 二进制：

```
25 ÷ 2 = 12 ... 1
12 ÷ 2 = 6  ... 0
 6 ÷ 2 = 3  ... 0
 3 ÷ 2 = 1  ... 1
 1 ÷ 2 = 0  ... 1
```

从下往上读：`11001`。

**③ 二进制 ↔ 八进制：每 3 位一组**（不足补 0）

`101011` → `101 011` → `5 3` → 八进制 `53`

**④ 二进制 ↔ 十六进制：每 4 位一组**（不足补 0）

`101011` → `0010 1011` → `2 B` → 十六进制 `2B`

!!! warning "小数部分转换"
    小数部分用"乘基取整，顺序排列"。如 0.375 → 二进制：0.375×2=0.75→0，0.75×2=1.5→1，0.5×2=1.0→1，所以 0.375 = `0.011`。注意：并非所有十进制小数都能精确表示为二进制（如 0.1）。

### 49.3 数据编码

#### 49.3.1 ASCII 码

**ASCII**（American Standard Code for Information Interchange）使用 7 位二进制表示 128 个字符。需记住的关键码值：

| 字符 | ASCII 值 | 记忆口诀 |
|------|----------|----------|
| `'0'` | 48 | 数字 0 起于 48 |
| `'A'` | 65 | 大写 A 起于 65 |
| `'a'` | 97 | 小写 a 起于 97 |
| 空格 | 32 | 空格是 32 |

**关键规律**：
- `'0'`–`'9'` 连续（48–57）
- `'A'`–`'Z'` 连续（65–90）
- `'a'`–`'z'` 连续（97–122）
- 大小写字母差 **32**：`'A' + 32 = 'a'`，即大小写转换只改第 6 位（bit5）

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    char c = 'A';
    cout << (char)(c + 32) << endl;  // 输出 'a'：大写转小写
    cout << (char)(c | 32) << endl;  // 输出 'a'：位运算方式
    return 0;
}
```

#### 49.3.2 原码、反码、补码

以 **8 位有符号整数**为例，最高位为**符号位**（0 正 1 负）：

| 编码 | 正数（以 +5 为例） | 负数（以 -5 为例） |
|------|------------------|------------------|
| 原码 | `0000 0101` | `1000 0101` |
| 反码 | `0000 0101`（同原码） | `1111 1010`（符号位不变，其余取反） |
| 补码 | `0000 0101`（同原码） | `1111 1011`（反码 +1） |

**规律**：
- 正数：原码 = 反码 = 补码
- 负数：反码 = 原码符号位不变其余取反；补码 = 反码 + 1

!!! info "为什么要用补码？"
    用补码的核心理由是**统一加减法**：用补码表示后，`a - b` 可转化为 `a + (-b)`，CPU 只需一个加法器即可完成加减运算，无需单独设计减法电路。此外，补码还解决了原码中 `+0` 和 `-0` 两个零的问题，并使表示范围对称地多出一个最小负数。

**8 位补码的表示范围**：

| 范围 | 二进制 | 说明 |
|------|--------|------|
| +127 | `0111 1111` | 最大正数 |
| +1 | `0000 0001` | |
| 0 | `0000 0000` | 唯一的零 |
| -1 | `1111 1111` | |
| -128 | `1000 0000` | 最小负数（无对应原码） |

范围：`[-128, +127]`，共 256 个数。

!!! warning "易错：-128 的特殊性"
    `-128` 的补码是 `1000 0000`，它**没有对应的原码和反码**（8 位原码无法表示 -128）。这是因为补码比原码多表示一个最小负数。

**快速求负数补码的技巧**：取绝对值的二进制，**按位取反后加 1**。

例：求 -5 的 8 位补码。
1. +5 = `0000 0101`
2. 取反 = `1111 1010`
3. 加 1 = `1111 1011`

### 49.4 网络基础

#### 49.4.1 OSI 七层模型

OSI（Open Systems Interconnection）参考模型由 ISO 提出，将网络通信分为七层：

| 层号 | 层名 | 英文 | 典型设备/协议 |
|------|------|------|--------------|
| 7 | 应用层 | Application | HTTP, FTP, DNS |
| 6 | 表示层 | Presentation | 加密、压缩 |
| 5 | 会话层 | Session | 建立/管理会话 |
| 4 | 传输层 | Transport | TCP, UDP |
| 3 | 网络层 | Network | IP, 路由器 |
| 2 | 数据链路层 | Data Link | 交换机、MAC |
| 1 | 物理层 | Physical | 网线、集线器 |

**记忆口诀**（从下往上）：**物 / 数 / 网 / 传 / 会 / 表 / 应**

#### 49.4.2 TCP/IP 协议栈

TCP/IP 是实际使用的协议栈，分为四层：

| TCP/IP 层 | 对应 OSI 层 | 典型协议 |
|-----------|-------------|----------|
| 应用层 | 应用、表示、会话 | HTTP, FTP, SMTP, DNS |
| 传输层 | 传输 | TCP, UDP |
| 网际层 | 网络 | IP, ICMP |
| 网络接口层 | 数据链路、物理 | Ethernet, Wi-Fi |

**TCP vs UDP**：

| 特性 | TCP | UDP |
|------|-----|-----|
| 连接 | 面向连接（三次握手） | 无连接 |
| 可靠性 | 可靠（确认重传） | 不可靠 |
| 顺序 | 有序到达 | 可能乱序 |
| 速度 | 较慢 | 较快 |
| 应用 | 网页、邮件、文件传输 | 视频直播、DNS 查询 |

#### 49.4.3 IP 地址分类

IPv4 地址为 32 位，分为 A/B/C/D/E 五类：

| 类别 | 首位范围 | 网络号位数 | 默认子网掩码 | 适用规模 |
|------|----------|-----------|-------------|----------|
| A | 1–126 | 8 位 | 255.0.0.0 | 大型网络 |
| B | 128–191 | 16 位 | 255.255.0.0 | 中型网络 |
| C | 192–223 | 24 位 | 255.255.255.0 | 小型网络 |
| D | 224–239 | — | — | 组播 |
| E | 240–255 | — | — | 保留 |

!!! tip "特殊地址"
    - `127.0.0.1`：环回地址（localhost），用于本机测试
    - `10.x.x.x`、`172.16–31.x.x`、`192.168.x.x`：私有地址
    - `255.255.255.255`：广播地址

#### 49.4.5 Internet 与万维网

**Internet 的起源**：

**Internet（因特网）** 起源于 1969 年美国的 **ARPANET**（阿帕网），由美国国防部高级研究计划局（ARPA）资助建立，最初用于军事和学术研究。1983 年 TCP/IP 协议成为标准，1990 年代万维网的出现使 Internet 迅速普及。

| 时间 | 事件 |
|------|------|
| 1969 | ARPANET 建成，Internet 的雏形 |
| 1983 | TCP/IP 成为 ARPANET 标准协议 |
| 1989 | Tim Berners-Lee 提出万维网（WWW）构想 |
| 1991 | 第一个网站上线 |
| 1995 | 商业化 Internet 全面开放 |

!!! warning "易混淆：Internet ≠ WWW"
    - **Internet（因特网）**：全球互联的计算机网络基础设施，是"网络之网络"。
    - **WWW（World Wide Web，万维网）**：运行在 Internet 之上的**信息服务系统**，由网页、网站、超链接组成，使用 HTTP 协议传输。

    简言之：Internet 是"公路"，WWW 是"跑在公路上的货车"。Internet 上还有电子邮件（SMTP）、文件传输（FTP）、即时通讯等多种服务，WWW 只是其中之一。

**URL、域名与 DNS**：

**URL（统一资源定位符）**：网页的"地址"，格式为：

```
协议://域名:端口/路径/文件名
```

例：`https://www.luogu.com.cn/problem/P1001`

| 组成 | 示例 | 说明 |
|------|------|------|
| 协议 | `https` | 访问方式 |
| 域名 | `www.luogu.com.cn` | 服务器地址 |
| 端口 | `443`（HTTPS 默认，可省略）| 服务端口 |
| 路径 | `/problem/P1001` | 资源路径 |

**域名（Domain Name）**：IP 地址的"别名"，便于记忆。域名从右到左层级递增：`.cn`（国家顶级域）→ `.com`（二级域）→ `.luogu`（三级域）→ `www`（主机名）。

**DNS（Domain Name System，域名系统）**：将域名翻译为 IP 地址的"电话簿"。当你在浏览器输入域名时，DNS 服务器负责查找对应的 IP 地址。

```
用户输入域名 → DNS 查询 → 返回 IP 地址 → 浏览器访问该 IP
```

**HTTP / HTTPS 协议**：

| 协议 | 全称 | 端口 | 特点 |
|------|------|------|------|
| HTTP | 超文本传输协议 | 80 | 明文传输，数据不加密 |
| HTTPS | 安全超文本传输协议 | 443 | 在 HTTP 基础上加入 SSL/TLS 加密 |

!!! info "HTTPS = HTTP + SSL/TLS"
    HTTPS 并非新协议，而是在 HTTP 与 TCP 之间加入了一层 SSL/TLS 加密。它保证数据在传输过程中不被窃听或篡改，是现代网站的主流选择。

### 49.5 操作系统基础

#### 49.5.1 进程管理

**进程**是程序在计算机上的一次执行活动，是**资源分配的最小单位**；**线程**是 CPU 调度的最小单位。

进程的三种基本状态：

```
        ┌──────────┐
        │   就绪    │◄────────┐
        └────┬─────┘         │
             │ 调度           │ 时间片到
             ▼               │
        ┌──────────┐         │
        │   运行    │─────────┘
        └────┬─────┘
             │ 等待资源
             ▼
        ┌──────────┐
        │   阻塞    │──资源就绪──► 就绪
        └──────────┘
```

#### 49.5.2 存储管理

- **虚拟内存**：将外存的一部分当作内存使用，使程序可使用比物理内存更大的地址空间。
- **页面置换算法**：FIFO（先进先出）、LRU（最近最久未使用）、LFU（最不常用）。
- **内存分配方式**：连续分配、分页、分段、段页式。

#### 49.5.3 文件系统

- **NTFS**：Windows 主流，支持权限和大文件
- **ext4**：Linux 主流
- **exFAT**：U 盘常用，跨平台

## 代码实现

### 进制转换工具

```cpp
#include <bits/stdc++.h>
using namespace std;

// 十进制转任意进制（支持 2~16）
string decToBase(int n, int base) {
    if (n == 0) return "0";
    string s = "", digits = "0123456789ABCDEF";
    bool neg = n < 0;
    if (neg) n = -n;
    while (n > 0) {
        s = digits[n % base] + s;  // 余数对应的字符前置
        n /= base;
    }
    return neg ? "-" + s : s;
}

// 任意进制转十进制
int baseToDec(string s, int base) {
    int res = 0;
    for (char c : s) {
        int d = isdigit(c) ? c - '0' : toupper(c) - 'A' + 10;
        res = res * base + d;       // 按权累加
    }
    return res;
}

int main() {
    cout << decToBase(25, 2) << endl;       // 11001
    cout << decToBase(255, 16) << endl;     // FF
    cout << baseToDec("1011", 2) << endl;   // 11
    cout << baseToDec("2F", 16) << endl;    // 47
    return 0;
}
```

## ⚠️ 常见误区

### 误区 1：混淆"内存"与"外存"

**错误理解**：硬盘也是内存的一部分。

**正确理解**：内存（RAM）是 CPU 可直接访问的易失性存储；外存（硬盘、U 盘）是非易失性存储，CPU 必须先将数据从外存调入内存才能处理。寄存器和 Cache 属于 CPU 内部或附近的存储，比内存更快。

### 误区 2：原码、反码、补码不分

**错误理解**：负数的原码就是补码。

**正确理解**：正数三者相同；负数反码 = 原码取反（符号位不变），补码 = 反码 + 1。机器内部存储和运算用的是**补码**，不是原码。`-1` 的 8 位补码是 `11111111`，不是 `10000001`。

### 误区 3：大小写 ASCII 码差 1

**错误理解**：`'A'` 的 ASCII 是 65，`'a'` 是 66。

**正确理解**：`'A'`=65，`'a'`=97，差 **32**。记忆法：26 个大写字母（65–90）后面还隔着 6 个特殊字符（`[ \ ] ^ _ \``），小写才从 97 开始。

### 误区 4：OSI 七层顺序记反

**错误理解**：应用层在最底层。

**正确理解**：从下到上是**物理 → 数据链路 → 网络 → 传输 → 会话 → 表示 → 应用**。口诀"物数网传会表应"。传输层（TCP/UDP）在第 4 层，网络层（IP）在第 3 层。

### 误区 5：阅读程序时不模拟就猜

**错误理解**：看一眼代码觉得"应该输出 X"。

**正确理解**：阅读程序题必须**逐行手动模拟**，尤其注意循环边界、整数除法、运算符优先级。很多题目的陷阱就藏在 `i < n` 还是 `i <= n`、`/` 还是 `%` 这种细节里。

## 典型例题

### 例题 1：进制转换综合

**题目**：将十进制数 `200` 分别转换为二进制、八进制、十六进制；并将十六进制 `AB` 转换为十进制。

**分析**：

- 200 ÷ 2 = 100...0 → 100÷2=50...0 → 50÷2=25...0 → 25÷2=12...1 → 12÷2=6...0 → 6÷2=3...0 → 3÷2=1...1 → 1÷2=0...1
  逆序：`11001000`
- 200 ÷ 8 = 25...0 → 25÷8=3...1 → 3÷8=0...3 → 逆序：`310`
- 200 ÷ 16 = 12...8 → 12÷16=0...12(C) → 逆序：`C8`
- `AB` = 10×16 + 11 = 160 + 11 = `171`

**答案**：二进制 `11001000`，八进制 `310`，十六进制 `C8`；十六进制 `AB` = 十进制 `171`。

### 例题 2：补码计算

**题目**：8 位补码 `11110011` 表示的十进制数是多少？

**分析**：最高位为 1，是负数。求其绝对值：
- 补码 `11110011` → 减 1 得反码 `11110010` → 取反得原码 `00001101` = 13
- 所以原数为 `-13`

或者用"取反加 1"法：补码按位取反得 `00001100`，加 1 得 `00001101` = 13，所以原数为 `-13`。

**答案**：`-13`。

### 例题 3：阅读程序写输出

```cpp
#include <bits/stdc++.h>
using namespace std;
int main() {
    int a[6] = {0, 1, 2, 3, 4, 5};
    int s = 0;
    for (int i = 1; i <= 5; i++) {
        if (a[i] % 2 == 0) s += a[i];
        else s -= a[i];
    }
    cout << s << endl;
    return 0;
}
```

**分析**：
- i=1: a[1]=1, 奇数, s = 0 - 1 = -1
- i=2: a[2]=2, 偶数, s = -1 + 2 = 1
- i=3: a[3]=3, 奇数, s = 1 - 3 = -2
- i=4: a[4]=4, 偶数, s = -2 + 4 = 2
- i=5: a[5]=5, 奇数, s = 2 - 5 = -3

**答案**：`-3`

### 三、完善程序（15 分）

**以下程序统计数字 d 在 1 到 n 的所有整数中出现的总次数。请选择正确的选项填空。**

```cpp
#include <bits/stdc++.h>
using namespace std;

// 统计数字 d 在 1~n 所有数中出现的总次数
long long countDigit(long long n, int d) {
    long long cnt = 0;
    for (long long i = 1; i <= n; i *= 10) {
        long long high = n / (i * 10);   // 当前位的高位部分
        long long cur  = (n / i) % 10;   // 当前位的数字
        long long low  = n % i;          // 当前位的低位部分

        if (___①___) {
            cnt += (high + 1) * i;
        } else if (cur == d) {
            cnt += ___②___;
        } else {
            cnt += ___③___;
        }
    }
    return cnt;
}

int main() {
    long long n;
    int d;
    cin >> n >> d;
    cout << countDigit(n, d) << endl;
    return 0;
}
```

**选项：**

- ① A. `cur > d`　B. `cur < d`　C. `cur >= d`　D. `cur != d`
- ② A. `high * i`　B. `high * i + low`　C. `high * i + low + 1`　D. `(high + 1) * i`
- ③ A. `high * i`　B. `(high + 1) * i`　C. `high * i + low`　D. `high * i + 1`

### 二、阅读程序答案

**输出：`525`**

**解析**：

函数 `f` 的功能是**将整数 n 的各位数字逆转**（如 123 → 321）。

逐步模拟循环：

| 轮次 i | x（运算前） | f(x)（逆序） | x = f(x) + i |
|--------|------------|-------------|-------------|
| 1 | 123 | 321 | 322 |
| 2 | 322 | 223 | 225 |
| 3 | 225 | 522 | 525 |

- i=1: f(123)=321, x=321+1=322
- i=2: f(322)=223, x=223+2=225
- i=3: f(225)=522, x=522+3=525

最终输出 `525`。

!!! tip "解题方法论：程序阅读三步法"
    1. **通读**：先不纠结细节，整体读一遍，判断函数功能（本题 `f` 是逆序数字）。
    2. **模拟**：对关键变量逐行手算，画表格记录每轮变化。
    3. **边界**：检查循环次数（i=1,2,3 共 3 次）、终止条件、初始值是否理解正确。

### 三、完善程序答案

- ① **A** (`cur > d`)
- ② **C** (`high * i + low + 1`)
- ③ **A** (`high * i`)

**解析**：

本题是经典的**数位统计**算法，逐位考察数字 d 在每一位上出现的次数：

- **当 `cur > d`**：当前位可以取到 d，且高位从 0 到 high 都可（共 high+1 种），低位任意（i 种）。总数 = `(high+1) * i`。故选 A。
- **当 `cur == d`**：当前位取 d 时，高位只能取 0 到 high（high+1 种中 high 种完整，最后一种不完整）。完整部分 `high * i`，不完整部分低位可取 0 到 low（共 low+1 个）。总数 = `high * i + low + 1`。故选 C。
- **当 `cur < d`**：当前位取不到 d 的最高情形，只能由更小的高位提供，共 high 种完整轮次。总数 = `high * i`。故选 A。

**验证**：n=12, d=1，期望结果 5（数字 1 在 1,10,11,12 中出现：1→1, 10→1, 11→2, 12→1，共 5 次）。

- i=1: high=1, cur=2, low=0。cur(2)>d(1)：cnt += (1+1)*1 = 2
- i=10: high=0, cur=1, low=2。cur==d：cnt += 0*10+2+1 = 3
- i=100: high=0, cur=0<d：cnt += 0

总 cnt = 2+3 = **5**，与期望一致。

!!! tip "解题方法论：完善程序三步法"
    1. **理解算法**：先读题意和注释，明确程序整体功能（本题：统计某数字出现次数）。
    2. **分析空格前后**：看空格前定义了哪些变量、空格后如何使用结果，推断空格应填什么。
    3. **代入验证**：用小样例手工跑一遍填空后的程序，检查结果是否合理。

## 📖 本章总结

### 一、核心要点回顾

- ✅ **计算机发展四代**：电子管 → 晶体管 → 集成电路 → 大规模集成电路。
- ✅ **冯诺依曼体系**：运算器 + 控制器 + 存储器 + 输入 + 输出，核心是"存储程序"。
- ✅ **CPU = 运算器 + 控制器**（+ 寄存器 + Cache），内存是 CPU 直接访问的易失性存储。
- ✅ **图灵奖**：首位 Perlis（1966），首位华人姚期智（2000）。
- ✅ **操作系统五大功能**：进程管理、内存管理、文件管理、设备管理、作业管理；常见 OS：Windows/Linux/macOS/Android/iOS。
- ✅ **存储单位**：1 B = 8 bit；1 KB = 1024 B；1 MB = 1024 KB；进率 1024。
- ✅ **进制转换**：任意→十进制按权展开；十进制→任意除基取余；二↔八每 3 位一组；二↔十六每 4 位一组。
- ✅ **补码**：正数三码相同；负数补码 = 反码 + 1 = 绝对值取反加 1。用补码可统一加减法。
- ✅ **ASCII**：`'0'`=48, `'A'`=65, `'a'`=97，大小写差 32。
- ✅ **OSI 七层**：物数网传会表应；TCP/IP 四层：应用、传输、网际、网络接口。
- ✅ **IP 分类**：A(1–126)/B(128–191)/C(192–223)；常见端口 HTTP 80、HTTPS 443、FTP 21、DNS 53。
- ✅ **Internet**：起源于 ARPANET（1969）；WWW ≠ Internet；DNS 将域名解析为 IP 地址。
- ✅ **Linux 命令**：ls/cd/mkdir/rm/cp/mv/cat/chmod；rm 不可恢复，chmod 755 = rwxr-xr-x。
- ✅ **g++ 编译**：`g++ -o sol sol.cpp -O2 -std=c++14 -Wall`；CSP 用 NOI Linux + C++14。
- ✅ **NOI 历史**：创办于 1984 年；CSP-J（入门）/CSP-S（提高）；体系：CSP-J→CSP-S→NOIP→NOI→IOI。
- ✅ **进程**是资源分配最小单位，**线程**是 CPU 调度最小单位。
- ✅ **程序阅读三步法**：通读功能 → 手动模拟 → 检查边界。
- ✅ **程序完善三步法**：理解算法 → 分析空格前后 → 代入验证。
