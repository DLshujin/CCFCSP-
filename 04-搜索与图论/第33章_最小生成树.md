# 第33章 最小生成树

> 前一章我们学会了求任意两点间的最短路径，本章转向另一个核心图论问题：在连通图中找一棵**包含所有顶点、边权和最小**的树。这就是最小生成树（MST），Kruskal 和 Prim 两大算法分别从"边"和"点"出发，配合并查集或优先队列，高效解决修路、布线、网络连通等实际场景。

---

## 📌 学习目标

学完本章后，你应当能够：

1. **准确说出**生成树与最小生成树的定义，理解"n 个点的生成树恰好有 n-1 条边"
2. **默写**Kruskal 算法完整代码（结构体排序 + 并查集 + 主循环），并解释贪心正确性
3. **默写**Prim 算法（朴素版 O(n²) 和堆优化版 O(m log n)），并区分 `dis[v] = w` 与 Dijkstra 的 `dis[v] = dis[u] + w`
4. **根据图的性质**选择合适算法：稀疏图用 Kruskal，稠密图用 Prim 朴素版
5. **运用**"虚拟源点"技巧（P1194）和"MST + 删边"套路（P1991）解决建模题
6. **避开**常见误区：Kruskal 忘排序、并查集未初始化、Prim 的 dis 含义混淆、忘判连通性

## 💡 生活类比

### 类比一：村长修路

假设你是村长，手底下有 6 个村子需要修公路互相连通。任意两个村子之间修路的成本不同（有的村子之间隔着山，有的隔着河）。你不需要每两个村子都直接连通——只要任意两个村子之间能通过其他村子中转到达即可。**问：最少花多少钱，才能让所有村子都连通？**

```
      2
  A ------- B
  | \     / |
  |  \5  /  |
 3|   \ /   |6
  |   / \   |
  |  /1  \4 |
  | /     \ |
  C ------- D
      7

  想象成 4 个村子，边上数字是修路成本。
  要连通 4 个村子，最少需要 3 条路。
```

### 类比二：两种策略

- **Kruskal（省钱优先）**：村长把所有"可修的路"按造价从低到高列出来，从最便宜的开始挑，只要这条路两端还没连通，就修；如果两端已经连通了（修了反而绕圈），就跳过。
- **Prim（占地优先）**：村长先选一个村子作为"根据地"，然后每次从根据地往外延伸一条最便宜的路，把新的村子纳入根据地范围，直到所有村子都被纳入。

!!! tip "一句话记忆"
    Kruskal 像"从便宜到贵挑路，不连通的就连上"；Prim 像"从根据地往外扩张，每次加最近的村子"。

## 33.1 什么是生成树

### 33.1.1 生成树的定义

在一个**无向连通图** G=(V,E) 中：

- **生成树**：一个包含 G 中**所有顶点**的**连通子图**，且**没有环**（即它是一棵树）。
- **最小生成树（Minimum Spanning Tree, MST）**：所有生成树中，**边权之和最小**的那棵。

!!! info "关键性质"
    - n 个顶点的生成树恰好有 **n−1 条边**。
    - 生成树是连通的且无环。
    - 最小生成树可能不唯一（当有边权相同的边时），但**总权值唯一**。

| 性质       | 说明                       |
| -------- | ------------------------ |
| 顶点数      | n 个                      |
| 边数       | n−1 条                    |
| 是否连通     | 是                        |
| 是否有环     | 否                        |
| 总权值是否唯一  | 是                        |
| 树形态是否唯一  | 不一定（边权相同时可能有多解）          |

## 33.2 Kruskal 算法

### 33.2.1 思想：贪心 + 并查集

Kruskal 的思路非常直观：**把所有边按权值从小到大排序，逐条尝试加入生成树；如果加入后不形成环，就保留；否则跳过。**

判断"两端是否已连通"——这正是**并查集**（见第23章）的拿手好戏。

### 33.2.2 算法步骤

1. 把图中所有边按权值**从小到大排序**。
2. 初始化并查集，每个顶点自成一个集合。
3. 依次扫描每条边 (u, v, w)：
   - 若 u 和 v **不在同一集合**（即 find(u) ≠ find(v)），则把这条边加入 MST，并合并它们的集合。
   - 否则跳过（会形成环）。
4. 当已选满 n−1 条边时停止。

### 33.2.3 ASCII 示意图

```
原始图（4点6边）:
      2
  A-------B
  |\     /|
 3| \5  / |6
  |  \ /  |
  |   X   |
  |  / \  |
  | /1  \4|
  |/     \|
  C-------D
      7

排序后的边: (C,D,1), (A,B,2), (A,C,3), (B,D,4), (A,D,5), (C,D',7)

选边过程:
  Step1: (C,D,1)  C,D不同集合 -> 选!  merge(C,D)
  Step2: (A,B,2)  A,B不同集合 -> 选!  merge(A,B)
  Step3: (A,C,3)  A,C不同集合 -> 选!  merge(A,C)  (已选满3条, 结束)

MST总权值 = 1+2+3 = 6
```

### 33.2.4 完整实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 5005;
const int MAXM = 200005;

struct Edge {
    int u, v, w;
    bool operator < (const Edge &o) const {
        return w < o.w;  // 按边权升序
    }
} e[MAXM];

int fa[MAXN];
int n, m;

// 并查集查找（路径压缩），详见第23章
int find(int x) {
    return fa[x] == x ? x : fa[x] = find(fa[x]);
}

// 合并两个集合
bool merge(int x, int y) {
    int fx = find(x), fy = find(y);
    if (fx == fy) return false;  // 已在同一集合，合并失败
    fa[fx] = fy;
    return true;
}

int main() {
    scanf("%d %d", &n, &m);
    for (int i = 1; i <= m; i++)
        scanf("%d %d %d", &e[i].u, &e[i].v, &e[i].w);

    sort(e + 1, e + m + 1);

    // 初始化并查集
    for (int i = 1; i <= n; i++) fa[i] = i;

    int cnt = 0;       // 已选边数
    long long ans = 0; // 总权值
    for (int i = 1; i <= m && cnt < n - 1; i++) {
        if (merge(e[i].u, e[i].v)) {
            ans += e[i].w;
            cnt++;
        }
    }

    if (cnt < n - 1)
        printf("orz\n");  // 图不连通，无法生成MST
    else
        printf("%lld\n", ans);
    return 0;
}
```

!!! tip "代码细节"
    - `fa[x] == x ? x : fa[x] = find(fa[x])` 是路径压缩的一行写法，简洁高效。
    - 用 `cnt` 计数已选边数，选满 n−1 条即可提前终止。
    - 若循环结束后 `cnt < n−1`，说明图本身不连通，**不存在生成树**。洛谷模板题要求输出 `orz`。

### 33.2.5 复杂度分析

| 步骤       | 复杂度           |
| -------- | ------------- |
| 边排序      | O(m log m)    |
| 并查集操作    | 近似 O(m α(n))  |
| **总计**   | **O(m log m)** |

由于 m ≤ n²，所以 O(m log m) = O(m log n²) = O(m log n)。Kruskal 的瓶颈在**排序**。

## 33.3 Prim 算法

### 33.3.1 思想：从一个点向外扩展

Prim 的思路和 Dijkstra 很像：**从任意一个起点开始，每次把"连接已选点集和未选点集"中权值最小的那条边加入 MST，并把对应顶点纳入已选点集。**

### 33.3.2 算法步骤

1. 任选一个起点 s，把它加入 MST。
2. 维护数组 `dis[i]`：表示顶点 i 到**当前已选点集**的最短边权。
3. 每次在未选点中挑出 `dis` 最小的顶点 u，把它加入 MST，累加 `dis[u]` 到答案。
4. 用 u 更新它的邻居：对所有 (u, v, w)，若 v 未选且 w < dis[v]，则 `dis[v] = w`。
5. 重复直到所有点都加入。

### 33.3.3 ASCII 示意图

```
初始: 选A, 已选={A}
  dis: A=0, B=2, C=3, D=inf

Step1: 选dis最小的B(=2), 已选={A,B}, ans=2
  用B更新: D=min(inf,4)=4
  dis: B=2, C=3, D=4

Step2: 选dis最小的C(=3), 已选={A,B,C}, ans=2+3=5
  用C更新: D=min(4,1)=1
  dis: D=1

Step3: 选dis最小的D(=1), 已选={A,B,C,D}, ans=5+1=6
  选满4个点, 结束

MST总权值 = 2+3+1 = 6  (与Kruskal一致!)
```

### 33.3.4 朴素实现 O(n²)

适合**稠密图**（边数接近 n²）。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 5005;
const int INF = 0x3f3f3f3f;

int g[MAXN][MAXN];   // 邻接矩阵
int dis[MAXN];       // 到已选点集的最短边权
bool vis[MAXN];      // 是否已选入MST
int n, m;

int main() {
    scanf("%d %d", &n, &m);
    memset(g, 0x3f, sizeof(g));
    for (int i = 1; i <= m; i++) {
        int u, v, w;
        scanf("%d %d %d", &u, &v, &w);
        g[u][v] = min(g[u][v], w);  // 处理重边
        g[v][u] = min(g[v][u], w);
    }

    memset(dis, 0x3f, sizeof(dis));
    dis[1] = 0;  // 从1号点开始

    long long ans = 0;
    int cnt = 0;
    for (int i = 1; i <= n; i++) {
        // 找dis最小的未选点
        int u = -1, mind = INF;
        for (int j = 1; j <= n; j++)
            if (!vis[j] && dis[j] < mind) {
                mind = dis[j];
                u = j;
            }
        if (u == -1) break;       // 图不连通
        vis[u] = true;
        ans += dis[u];
        cnt++;
        // 用u更新邻居
        for (int v = 1; v <= n; v++)
            if (!vis[v] && g[u][v] < dis[v])
                dis[v] = g[u][v];
    }

    if (cnt < n) printf("orz\n");
    else printf("%lld\n", ans);
    return 0;
}
```

!!! warning "常见误区：dis 初始化"
    - Prim 的 `dis` 数组初始化为 **INF**，但**起点必须置 0**（否则起点选不进来）。
    - `dis[i]` 在 Prim 中表示"到**已选点集**的最短边权"，**不是到起点的距离**！这是和 Dijkstra 最大的区别。

| 对比项       | Dijkstra 的 dis[i]      | Prim 的 dis[i]          |
| --------- | ---------------------- | ---------------------- |
| 含义        | 到起点的最短路径长度             | 到已选点集的最短边权             |
| 更新方式      | `dis[v] = dis[u] + w`  | `dis[v] = w`           |
| 解决问题      | 单源最短路                  | 最小生成树                  |

### 33.3.5 堆优化实现 O(m log n)

适合**稀疏图**（边数远小于 n²）。用邻接表 + 优先队列。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 5005;
const int MAXM = 400005;
const int INF = 0x3f3f3f3f;

struct Edge {
    int to, w, nxt;
} e[MAXM];
int head[MAXN], ecnt = 0;

void addEdge(int u, int v, int w) {
    e[++ecnt] = {v, w, head[u]};
    head[u] = ecnt;
}

int n, m;

int main() {
    scanf("%d %d", &n, &m);
    for (int i = 1; i <= m; i++) {
        int u, v, w;
        scanf("%d %d %d", &u, &v, &w);
        addEdge(u, v, w);
        addEdge(v, u, w);
    }

    vector<int> dis(n + 1, INF);
    vector<bool> vis(n + 1, false);
    // 优先队列: (权值, 顶点), 小根堆
    priority_queue<pair<int,int>, vector<pair<int,int>>,
                   greater<pair<int,int>>> pq;

    dis[1] = 0;
    pq.push({0, 1});

    long long ans = 0;
    int cnt = 0;
    while (!pq.empty() && cnt < n) {
        auto [d, u] = pq.top(); pq.pop();
        if (vis[u]) continue;   // 已选过, 跳过
        vis[u] = true;
        ans += d;
        cnt++;
        for (int i = head[u]; i; i = e[i].nxt) {
            int v = e[i].to, w = e[i].w;
            if (!vis[v] && w < dis[v]) {
                dis[v] = w;
                pq.push({w, v});
            }
        }
    }

    if (cnt < n) printf("orz\n");
    else printf("%lld\n", ans);
    return 0;
}
```

!!! tip "堆优化细节"
    - 队列里可能存多个同一顶点的旧记录，用 `vis[u]` 判断跳过即可。
    - `pair` 默认按第一关键字（权值）排序，所以存 `{w, v}`。
    - 用 `greater<>` 让 `priority_queue` 变成**小根堆**。

## 33.4 Kruskal vs Prim 对比

| 对比维度      | Kruskal              | Prim              |
| --------- | -------------------- | ----------------- |
| 核心思想      | 按边权排序，逐条加边           | 从点出发，逐步扩展点集       |
| 数据结构      | 边集数组 + 并查集           | 邻接矩阵 / 邻接表 + 优先队列 |
| 时间复杂度     | O(m log m)           | O(n²) 或 O(m log n) |
| **适合稀疏图** | ✅ 最优选择               | 堆优化版也可            |
| **适合稠密图** | 不优（m 大时排序慢）          | ✅ 朴素 O(n²) 最优     |
| 实现难度      | 较简单（关键是并查集）          | 朴素简单，堆优化略复杂       |
| 处理重边      | 自然支持（排序后小的在前）        | 朴素需手动 min，邻接表无所谓  |
| 是否需判连通    | cnt < n−1 即可判        | cnt < n 即可判       |

!!! info "选择建议"
    - **稀疏图（m 较小）**：选 Kruskal，写起来短，复杂度 O(m log m)。
    - **稠密图（m 接近 n²）**：选 Prim 朴素版 O(n²)。
    - **CSPJ 普及组**：绝大多数题目 Kruskal 就够了，**优先掌握 Kruskal**。

## 33.5 常见误区与避坑

### 33.5.1 Kruskal 的坑

!!! warning "误区1：忘记按边权排序"
    Kruskal 的贪心正确性**依赖于边按权值升序**。如果忘了 `sort`，结果完全错误。

    ```cpp
    // 错误: 没排序直接扫
    for (int i = 1; i <= m; i++) if(merge(e[i].u,e[i].v)) ...

    // 正确: 先排序
    sort(e + 1, e + m + 1);
    ```

!!! warning "误区2：并查集没初始化"
    `fa[i] = i` 必须先做，否则 `find` 会死循环或访问非法内存。

!!! warning "误区3：忘记判断图是否连通"
    选完所有边后若 `cnt < n−1`，说明图不连通，**不存在生成树**。题目常要求特殊输出。

!!! warning "误区4：忽视重边和自环"
    - 自环：u==v 的边，sort 后 `merge` 自然失败，不影响。
    - 重边：sort 后小的在前，先选，大的在后 `merge` 失败，自动忽略。无需特殊处理。

### 33.5.2 Prim 的坑

!!! warning "误区1：dis 含义搞混"
    Prim 的 `dis[i]` 是"到**已选点集**的最短边权"，**不是到起点的距离**。更新时是 `dis[v] = w`，不是 `dis[v] = dis[u] + w`。

!!! warning "误区2：起点 dis 不置 0"
    起点必须 `dis[s] = 0`，否则起点永远选不进来（dis 为 INF）。

!!! warning "误区3：堆优化未跳过已选点"
    堆中残留旧记录，必须 `if (vis[u]) continue;` 跳过，否则会重复累加权值。

!!! warning "误区4：邻接矩阵未处理重边"
    朴素 Prim 用邻接矩阵时，重边要用 `min` 保留最小的：
    ```cpp
    g[u][v] = min(g[u][v], w);
    ```

## 33.6 典型例题

### 33.6.1 【模板】最小生成树 P3366

**题目大意**：给定无向连通图，求最小生成树的边权之和。

**输入**：第一行 n, m；接下来 m 行每行 u, v, w。

**输出**：最小生成树边权之和（图连通保证有解）。

**思路**：直接套 Kruskal 模板即可。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXM = 200005;
const int MAXN = 5005;

struct Edge {
    int u, v, w;
    bool operator < (const Edge &o) const { return w < o.w; }
} e[MAXM];

int fa[MAXN];
int find(int x) { return fa[x]==x ? x : fa[x]=find(fa[x]); }

int main() {
    int n, m;
    scanf("%d %d", &n, &m);
    for (int i = 1; i <= m; i++)
        scanf("%d %d %d", &e[i].u, &e[i].v, &e[i].w);
    sort(e + 1, e + m + 1);
    for (int i = 1; i <= n; i++) fa[i] = i;

    int cnt = 0; long long ans = 0;
    for (int i = 1; i <= m && cnt < n - 1; i++) {
        int fu = find(e[i].u), fv = find(e[i].v);
        if (fu != fv) { fa[fu] = fv; ans += e[i].w; cnt++; }
    }
    printf("%lld\n", ans);
    return 0;
}
```

!!! tip "点评"
    模板题，背熟 Kruskal 即可 AC。注意 long long 防止答案爆 int。

### 33.6.2 买礼物 P1194

**题目大意**：有 n 个礼物要买，可以直接花钱买，也可以用已有的礼物兑换（每对礼物之间有兑换代价）。求买齐所有礼物的最小花费。

**思路**：**巧妙转化为 MST**。

- 设一个**虚拟源点 0**，从 0 到每个礼物 i 连一条边，权值为"直接买 i 的价格"。
- 礼物 i 和 j 之间的兑换代价作为它们之间的边权。
- 对这 n+1 个点跑 MST，答案即为总权值。

**为什么对？** 虚拟源点表示"花钱买"，MST 选了 0→i 这条边就表示"直接买 i"；选了 i—j 这条边表示"用 i 兑换 j"。MST 保证每个礼物要么被直接买，要么被某个已买的礼物兑换，且总花费最小。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 505;
struct Edge {
    int u, v, w;
    bool operator < (const Edge &o) const { return w < o.w; }
};
vector<Edge> e;
int fa[MAXN];

int find(int x) { return fa[x]==x ? x : fa[x]=find(fa[x]); }

int main() {
    int a, b;
    scanf("%d %d", &a, &b);
    // 0号点为虚拟源点, 直接买的价格为a
    for (int i = 1; i <= b; i++) {
        e.push_back({0, i, a});
        fa[i] = i;
    }
    fa[0] = 0;
    // 兑换代价
    for (int i = 1; i <= b; i++)
        for (int j = 1; j <= b; j++) {
            int w; scanf("%d", &w);
            if (w && i < j) e.push_back({i, j, w});  // 去重
        }
    sort(e.begin(), e.end());

    long long ans = 0; int cnt = 0;
    for (auto &ed : e) {
        int fu = find(ed.u), fv = find(ed.v);
        if (fu != fv) { fa[fu] = fv; ans += ed.w; cnt++; }
    }
    printf("%lld\n", ans);
    return 0;
}
```

!!! tip "技巧总结"
    "**虚拟源点**"是 MST 题目的常见套路：当题目有"起点花费/直接购买"等特殊操作时，建一个虚拟点把问题统一成图。

### 33.6.3 无线通讯网 P1991

**题目大意**：有 p 个哨所，任意两个哨所之间可以用卫星频道（s 个，免费，可任意距离通讯）或无线电（最大距离为 D，所有无线电通讯距离都不能超过 D）。求 D 的最小值。

**思路**：**MST + 贪心删边**。

- 把 p 个哨所两两连边，权值为欧几里得距离。
- 跑 MST，得到 n−1 条边。
- 由于有 s 个卫星频道可以"省掉" s−1 条最长的边（卫星把 p 个点分成 s 个连通块，每块内部用无线电），所以答案是 **MST 中第 (p−s) 小的边**（即去掉 s−1 条最长边后剩余的最大边）。
- 等价：把 MST 的边排序，取第 (p−s) 条（从 0 开始数）。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 505;
struct Edge {
    int u, v;
    double w;
    bool operator < (const Edge &o) const { return w < o.w; }
};
vector<Edge> e;
int fa[MAXN];
int x[MAXN], y[MAXN];

int find(int x) { return fa[x]==x ? x : fa[x]=find(fa[x]); }

double dist(int i, int j) {
    double dx = x[i]-x[j], dy = y[i]-y[j];
    return sqrt(dx*dx + dy*dy);
}

int main() {
    int s, p;
    scanf("%d %d", &s, &p);
    for (int i = 1; i <= p; i++) {
        scanf("%d %d", &x[i], &y[i]);
        fa[i] = i;
    }
    for (int i = 1; i <= p; i++)
        for (int j = i+1; j <= p; j++)
            e.push_back({i, j, dist(i, j)});
    sort(e.begin(), e.end());

    vector<double> chosen;  // MST中的边
    int cnt = 0;
    for (auto &ed : e) {
        int fu = find(ed.u), fv = find(ed.v);
        if (fu != fv) {
            fa[fu] = fv;
            chosen.push_back(ed.w);
            cnt++;
            if (cnt == p - 1) break;
        }
    }
    // s个卫星可省掉 s-1 条最长边
    // 剩余最长边即为答案: chosen[p-s-1]
    printf("%.2f\n", chosen[p - s - 1]);
    return 0;
}
```

!!! tip "思考"
    - 为什么是 s−1 条？因为 s 个卫星频道可以把 p 个点分成 s 组（每组内部用无线电），相当于把 MST 砍 s−1 刀分成 s 棵子树。
    - 所以答案就是 MST 边从小到大排序后，第 (p−1)−(s−1) = (p−s) 条边的权值（即下标 p−s−1）。

## 33.7 核心操作速查表

| 操作             | Kruskal                          | Prim                          |
| -------------- | -------------------------------- | ----------------------------- |
| 数据结构           | `struct Edge {u,v,w}` + `fa[]`   | `dis[]` + `vis[]` (+ 堆)       |
| 排序             | `sort(e+1, e+m+1)` 按边权升序         | 不需要排序                         |
| 初始化            | `fa[i]=i`                        | `dis[s]=0`, 其余 `dis=INF`      |
| 主循环            | 逐条扫边，判 `find(u)!=find(v)`        | 选 `dis` 最小未选点，更新邻居            |
| 终止条件           | `cnt == n-1`                     | `cnt == n`                    |
| 不连通判定          | `cnt < n-1`                      | `cnt < n`                     |
| 复杂度            | O(m log m)                       | O(n²) / O(m log n)            |

## 33.8 本章总结

### 核心知识回顾

1. **MST 定义**：连通所有顶点的最小权值树，n 个点恰好 n−1 条边。
2. **Kruskal**：按边权排序，贪心加边，用并查集判环。复杂度 O(m log m)，适合稀疏图。
3. **Prim**：从点出发，每次扩展最短跨边。朴素 O(n²) 适合稠密图，堆优化 O(m log n) 适合稀疏图。
4. **dis 含义区分**：Prim 的 `dis[i]` 是"到已选点集的最短边权"（`dis[v] = w`），Dijkstra 是"到起点的最短路径长度"（`dis[v] = dis[u] + w`）。
5. **常见技巧**：虚拟源点（P1194）、MST + 删边（P1991）。
6. **判连通性**：Kruskal 用 `cnt < n-1`，Prim 用 `cnt < n`。

### 易错点清单

| 编号 | 易错点 | 正确做法 |
|------|--------|----------|
| 1 | Kruskal 忘排序 | 先 `sort` 再扫边 |
| 2 | 并查集未初始化 | `fa[i] = i` |
| 3 | 忘记判连通性 | 检查 `cnt` 是否选满 |
| 4 | Prim dis 含义混淆 | 更新：`dis[v] = w`（非 `dis[u] + w`） |
| 5 | Prim 起点未置 0 | `dis[s] = 0` |
| 6 | 堆优化未跳过已选 | `if (vis[u]) continue;` |
| 7 | 答案用 int 溢出 | 用 `long long` |

### 记忆口诀

> **Kruskal 排序加边查并集，Prim 找点扩展更亲密。**
> **稀疏 Kruskal 省心，稠密 Prim 朴素赢。**
> **n 点 n 减 1 边莫忘，连通判 cnt 是真章。**
