## 一、编程语言与C++基础

> 想一想：你有没有想过，计算机只能理解 0 和 1，为什么你写 `cout << "Hello"` 它就能在屏幕上显示文字？这中间到底发生了什么？

> 💡 一句话概括：编程语言是人与计算机的"翻译官"，C++ 是信息学竞赛的官方语言。

### 1.1 什么是编程语言

「编程语言 programming language」是一套人与计算机沟通的**语法规则集合**。

计算机底层只能识别由 0 和 1 组成的「机器指令 machine instruction」，但人类直接书写 0 和 1 效率极低。编程语言充当"翻译层"：你用接近自然语言的方式写代码，再由「编译器 compiler」翻译成机器能执行的指令。

```mermaid
flowchart LR
    A[你写的代码 .cpp] -->|编译器翻译| B[机器指令 0和1]
    B -->|CPU执行| C[输出结果]
```

> 💡 生活类比
> 把编程想象成"开快餐店"：
> - **源代码**（`.cpp` 文件）= 你写在纸上的**菜谱**
> - **编译器** = 后厨的**厨师长**，把菜谱翻译成具体动作
> - **可执行文件**（`.exe`）= 做好的**成品菜**
> - **运行** = 顾客**吃菜**，看到结果
>
> 菜谱写得再好，不经过厨师长翻译成动作，顾客是吃不到的。这就是为什么写完代码**必须编译**——代码本身不能直接运行。

> 💡 提示：编译型 vs 解释型
> C++ 是**编译型语言**：代码先整体翻译成 `.exe`，再运行，速度极快。Python 是**解释型语言**：边读边执行，速度较慢但调试方便。CSP 竞赛追求运行速度，故选用 C++。

> 📌 本节要点：
> - 编程语言是人与计算机沟通的桥梁，编译器负责翻译
> - C++ 是编译型语言，需要先编译再运行，速度极快

### 1.2 计算机的基本构成

在学习编程之前，先了解一下计算机的"身体结构"。这不仅是初赛必考常识，也能帮你理解"代码到底在什么硬件上跑"。

**冯诺依曼体系结构**（1945年提出，沿用至今）将计算机分为五大部件：

| 部件 | 功能 | 常见硬件 |
|------|------|----------|
| **运算器（ALU）** | 执行算术运算和逻辑运算 | CPU 内部 |
| **控制器（CU）** | 取指令、译码、协调各部件 | CPU 内部 |
| **存储器** | 存放程序和数据 | 内存(RAM) |
| **输入设备** | 接收外部信息 | 键盘、鼠标 |
| **输出设备** | 向外部输出结果 | 显示器、打印机 |

> 💡 生活类比
> 把计算机想象成一个"厨房"：
> - **CPU**（运算器+控制器）= 厨师，负责干活和指挥
> - **内存** = 砧板，正在处理的食材放在上面（断电即丢失）
> - **硬盘** = 冰箱，长期存放食材（断电不丢失）
> - **输入设备** = 菜单递进口，你告诉厨师要做什么
> - **输出设备** = 上菜窗口，做好的菜端给你看

**CPU 的存储层次**（从快到慢，从贵到便宜）：

```
寄存器 → Cache(L1/L2/L3) → 内存(RAM) → 固态硬盘(SSD) → 机械硬盘(HDD)
←──── 越左越快越贵 ────→
```

> ⚠️ 注意：内存（RAM）断电丢失数据，CPU 能直接访问；硬盘断电不丢失，但 CPU 不能直接访问（需先调入内存）。

**计算机发展简史**（以核心元器件划分）：

| 代次 | 年代 | 元器件 | 代表机型 |
|------|------|--------|----------|
| 第一代 | 1946–1957 | 电子管 | ENIAC |
| 第二代 | 1958–1964 | 晶体管 | IBM 7094 |
| 第三代 | 1965–1970 | 集成电路 | IBM 360 |
| 第四代 | 1971–至今 | 大规模集成电路 | PC、手机 |

> 📌 要点：
> - 冯诺依曼体系核心思想：**存储程序**（程序和数据同存于内存）
> - CPU = 运算器 + 控制器（+ 寄存器 + Cache）
> - 内存是易失性存储，硬盘是非易失性存储

## 二、编辑→编译→运行三步骤

> 想一想：你写完代码按 F11，屏幕上就出现了结果。这短短一秒内，电脑到底做了什么？为什么不能跳过"编译"这一步？

> 💡 一句话概括：写代码 → 翻译成机器码 → 执行看结果，这是编程的完整流程。

### 2.1 三步流程概述

这是本章最核心的认知模型，务必牢记：

| 步骤 | 做什么 | 用什么工具 | 产生什么 |
|------|--------|-----------|---------|
| **① 编辑** | 写代码 | Dev-C++ 编辑器 | `hello.cpp` 源文件 |
| **② 编译** | 翻译成机器码 | GCC 编译器 | `hello.exe` 可执行文件 |
| **③ 运行** | CPU 执行程序 | 操作系统 | 屏幕上的输出结果 |

> 💡 生活类比
> 如果你改了菜谱（修改代码），却没让厨师长重新做菜（重新编译），顾客吃到的还是上一道旧菜。所以**改完代码一定要按 F11 重新编译运行**。

> ⚠️ 警告：最易忽略的认知
> 改完代码后**必须重新编译**才能看到新结果。直接"运行"只会执行上一次编译好的旧程序。这是初学者最常踩的坑：明明改了代码，输出却没变——因为忘了重新编译。

> 📌 本节要点：
> - 编辑、编译、运行是三个独立步骤，顺序不可颠倒
> - 修改代码后必须重新编译，否则结果不变

### 2.2 安装 Dev-C++

CSP 考场预装的就是 **Dev-C++**，平时用它练手最稳妥，考场上不会"水土不服"。推荐 **小熊猫 Dev-C++**（Red Panda Dev-C++），它是经典版的现代化改进，界面友好、支持中文。

**下载**：官网 <https://royqh.net/redpandacpp/>，选 Windows 64 位版本（文件名含 `x64` 或 `MinGW64`）。

**安装步骤**（Windows）：

1. 双击 `RedPandaCPP-*.exe`
2. 语言选"简体中文"，点 OK
3. 同意协议 → 安装类型选 Typical（默认即可）
4. 路径建议 `D:\Dev-Cpp`（避开 C 盘和中文路径）
5. 完成后勾选"运行 Dev-C++"

**首次启动配置**：

| 设置项 | 建议值 |
|--------|--------|
| 界面语言 | 简体中文 |
| 字体 | Consolas，字号 14 |
| 编译器 | 默认 GNU GCC Compiler |

> 💡 提示：界面变中文
> 若安装后界面是英文：`Tools → Environment Options → General → Language`，选 `Chinese`，重启即可。

### 2.3 三步骤实操

**第一步：编辑（写代码）**

1. `Ctrl + N` 新建源文件
2. 在编辑区输入 HelloWorld 代码（见下文"典型例题"）
3. `Ctrl + S` 保存，文件名 `hello.cpp`，**保存类型选 C++ Source**

> ⚠️ 警告：路径禁忌
> 文件路径**绝不能含中文和空格**！`D:\我的 文件\hello.cpp` 会导致编译报错，请用 `D:\code\hello.cpp`。

**第二步：编译（翻译）**

- 按 `F9` 编译，Dev-C++ 底部状态栏显示"Done"表示成功
- 若底部出现红色错误提示，需根据报错修错后重新编译

**第三步：运行（执行）**

- 按 `F10` 仅运行，或按 `F11` 一键"编译并运行"（最常用）

下表对比了三个快捷键的功能与使用场景：

| 快捷键 | 功能 | 使用场景 |
|--------|------|---------|
| `F9` | 编译 | 检查代码是否有语法错误 |
| `F10` | 运行 | 代码未改动时直接看结果 |
| `F11` | 编译并运行 | **最常用**，改完代码一键搞定 |

因此，日常练习中直接按 `F11` 即可，无需分别按 `F9` 和 `F10`。

> 📌 本节要点：
> - 新建 `.cpp` 文件 → 写代码 → F11 编译运行，一条龙操作
> - 路径不能含中文和空格，这是初学者常见报错来源

## 三、Hello World 程序详解

> 想一想：你写的第一个程序只有 6 行代码，但这 6 行构成了所有 C++ 程序的骨架。你能说出每一行是"干什么的"吗？

> 💡 一句话概括：Hello World 是每个程序员的"成人礼"，它的六行代码构成了所有 C++ 程序的骨架。

### 3.1 完整代码

**题目描述**：在屏幕上输出一行文字 `Hello World!`。

**参考代码**：

```cpp
#include <bits/stdc++.h>              // ① 引入万能头文件
using namespace std;                  // ② 使用标准命名空间

int main() {                          // ③ 主函数，程序入口
    cout << "Hello World!" << endl;   // ④ 输出文字并换行
    return 0;                         // ⑤ 程序正常结束
}                                     // ⑥ 主函数结束
```

// 输出：Hello World!

### 3.2 逐行解释

下表逐行解析了 HelloWorld 程序的每一部分：

| 行 | 代码 | 详细含义 |
|----|------|---------|
| ① | `#include <bits/stdc++.h>` | 预处理指令，引入"万能头文件"，内含 `iostream` 等几乎所有标准库。竞赛常用，省去逐个记头文件名的麻烦 |
| ② | `using namespace std;` | 声明使用标准命名空间 `std`，这样可直接写 `cout`，而无需写成 `std::cout` |
| ③ | `int main() {` | 主函数开始。`int` 是返回值类型（整数），`main` 是程序**唯一入口名**，`()` 表示不接受参数，`{` 标志函数体开始 |
| ④ | `cout << "Hello World!" << endl;` | `cout`（读 see-out）是输出流对象；`<<` 把右侧内容"送"向屏幕；`"Hello World!"` 是要输出的字符串；`endl` 表示换行并刷新缓冲区 |
| ⑤ | `return 0;` | 返回 0 给操作系统，约定俗成表示"程序正常结束"。返回非 0 通常表示异常 |
| ⑥ | `}` | 主函数结束。大括号 `{}` 必须**成对出现**，少一个就报错 |

📖 通俗解释：`cout << "Hello World!" << endl;` 这行代码可以理解为：把"Hello World!"这个文字通过 `cout` 这个"管道"送到屏幕上，然后 `endl` 让光标跳到下一行。

> 💡 提示：关于万能头文件
> `#include <bits/stdc++.h>` 是竞赛圈常用的"万能头"，包含了几乎所有标准库。优点：不用记一堆头文件名；缺点：编译稍慢（对竞赛无影响）。CSP 考试允许使用，新手直接记这一个即可。若学校教学要求严谨，也可用 `#include <iostream>` 代替。

> 💡 提示：cout 的链式输出
> `cout << "Hello" << " " << "World" << "!" << endl;` 是合法的——多个 `<<` 串联，按从左到右顺序依次输出。这叫"链式输出"，后续会大量使用。

> 📌 本节要点：
> - 每个 C++ 程序必须有且只有一个 `main` 函数作为入口
> - `cout <<` 是输出，`<<` 指向数据流向屏幕的方向
> - 六行代码构成了 C++ 程序的最简骨架，后续所有程序都在此基础上扩展

## 四、常见误区与避坑指南

> 想一想：为什么你明明照着书抄的代码，一编译就报 10 个错？真的是你"不适合学编程"吗？

> 💡 一句话概括：初学者 90% 的报错来自分号、中文标点、大小写这三类问题。

### 4.1 误区一：忘记写分号

❌ **错误写法**：
```cpp
cout << "Hello World!" << endl   // 末尾漏了分号
return 0;
```

✅ **正确写法**：
```cpp
cout << "Hello World!" << endl;  // 句末加分号
return 0;
```

**后果说明**：C++ 中每条语句末尾**必须**加分号 `;`，把它当成"一句话说完的句号"。报错信息 `[Error] expected ';' before 'return'` 表示在 `return` **之前**缺了分号，但实际缺失的位置是**上一行末尾**。

📖 通俗解释：编译器看到 `return` 时发现上一句没结束，就像读到"今天天气很好我们去吃饭"时发现少了句号一样困惑。

### 4.2 误区二：使用中文标点

❌ **错误写法**：
```cpp
cout << "Hello World！" << endl;   // 末尾是中文感叹号！
cout << "你好" << endl;            // 用了中文双引号 ""
```

✅ **正确写法**：
```cpp
cout << "Hello World!" << endl;    // 英文感叹号
cout << "你好" << endl;            // 英文双引号
```

**后果说明**：编译器不认识中文标点符号，会报 `[Error] stray '\243' in program`（数字可能不同）。中文输入法是初学者最大的"隐形杀手"——双引号、分号、括号、感叹号都会"长得像却不是"。

📖 通俗解释：中英文标点虽然长得像，但对编译器来说就像"A"和"А"（一个是英文A，一个是俄文А）——看起来一样，实际是不同的字符。

### 4.3 误区三：大小写混淆

❌ **错误写法**：
```cpp
int Main() { ... }     // Main 不是 main
Cout << "hi";          // Cout 不是 cout
Return 0;              // Return 不是 return
```

✅ **正确写法**：
```cpp
int main() { ... }     // 全部小写
cout << "hi";          // 全部小写
return 0;              // 全部小写
```

**后果说明**：C++ **严格区分大小写**。`main`、`cout`、`int`、`return` 全部小写，一个字母都不能错。报错信息 `[Error] 'Main' was not declared in this scope` 表示 `Main` 没有被定义过。

📖 通俗解释：C++ 的关键字全是小写字母。记住这句话就够了——不存在首字母大写或全大写的 C++ 关键字。

> 💡 提示：避坑总原则——只看第一条报错
> 编译器常一次报十几个错，但往往是**第一个错引发连锁反应**。修好第一条，重新编译，后面的错可能自动消失。千万不要被满屏红色报错吓到——盯住第一条修就行。

> 📌 本节要点：
> - 每条语句末尾必须加分号 `;`
> - 写代码时切换到英文输入法，所有标点用英文半角
> - C++ 关键字全部小写，严格区分大小写

## 五、本章练习

> **第01章特殊说明**：本章为入门章，练习**不要求独立编程**，而是通过"修改 HelloWorld 代码"观察输出变化，建立对"代码 ↔ 运行结果"的直觉。每题都基于上面的 HelloWorld 程序修改，按 `F11` 运行后观察。

### 🟢 基础修改（观察输出）

**练习 1**：修改输出内容
> 把 `"Hello World!"` 改成 `"我学会C++啦！"`，按 `F11` 运行。
> - 观察：中文字符能否正常显示？
> - 思考：双引号内的内容改了，输出就改了——这说明 `cout` 对双引号内的内容如何处理？

**练习 2**：删除换行符
> 把 `endl` 删掉，第 4 行变成 `cout << "Hello World!";`，按 `F11` 运行。
> - 观察：输出和原来有什么不同？（提示：注意光标位置）
> - 再把 `endl` 加回去，对比两次结果，理解 `endl` 的作用。

### 🟡 进阶修改（理解机制）

**练习 3**：链式输出拆分
> 把第 4 行改成：
> ```cpp
> cout << "Hello" << " " << "World" << "!" << endl;
> ```
> // 输出：Hello World!
>
> - 观察：输出是否与原版完全相同？
> - 思考：多个 `<<` 串联时，输出顺序是怎样的？`<<` 在这里扮演什么角色？

**练习 4**：输出计算结果
> 把第 4 行改成：
> ```cpp
> cout << "1+1=" << 1 + 1 << endl;
> ```
> // 输出：1+1=2
>
> - 观察：输出是什么？
> - 思考：双引号内的 `1+1` 和双引号外的 `1 + 1`，`cout` 处理方式有何不同？（前者原样输出，后者先计算再输出）

### 🔴 挑战修改（发现规律）

**练习 5**：多行输出与换行
> 在 `return 0;` 之前再加两行 `cout`：
> ```cpp
> cout << "第一行" << endl;
> cout << "第二行" << endl;
> ```
> // 输出：
> // Hello World!
> // 第一行
> // 第二行
>
> - 观察：三行输出的顺序和位置。
> - 进阶：删掉第一个 `endl`（即 `cout << "第一行";`），观察输出变成什么样，**为什么**？

**练习 6**：故意制造错误并修复
> 依次做以下三种修改，**每次只改一处**，按 `F11` 记录报错原文，再改回正确代码：
> 1. 删掉第 4 行末尾的分号 `;`

## 📖 本章总结

### 核心概念
- 编程语言
  - 定义：人机沟通的语法规则集合
  - 编译器：代码 → 机器指令的"翻译官"
  - C++：CSP-J / CSP-S 竞赛官方语言
- 开发流程（三步骤，务必牢记）
  - 编辑：`Ctrl+N` 写代码，`Ctrl+S` 存为 `.cpp` 文件
  - 编译：按 `F9`，翻译成 `.exe` 可执行文件
  - 运行：按 `F10` / `F11`，看输出结果

### 程序骨架（六大部件）
- ① `#include <bits/stdc++.h>`：万能头文件
- ② `using namespace std;`：标准命名空间
- ③ `int main() {`：主函数（程序唯一入口）
- ④ `cout << ... ;`：输出语句
- ⑤ `return 0;`：正常结束
- ⑥ `}`：主函数结束

### 输出机制
- `cout << 内容`：把内容"送"到屏幕
- `<<`：方向箭头，可链式串联多个输出
- `endl` / `\n`：换行

### 常见陷阱
- ❌ 漏写分号 → ✅ 每条语句末尾必须加 `;`
- ❌ 使用中文标点 → ✅ 全部用英文半角标点，写代码时切换英文输入法
- ❌ 大小写混用 → ✅ C++ 关键字全部小写，严格区分大小写
- ❌ 改代码后直接运行 → ✅ 必须按 `F11` 重新编译运行

### 关键代码模板

```cpp
#include <bits/stdc++.h>          // 万能头文件
using namespace std;              // 标准命名空间

int main() {                      // 主函数入口
    // 你的代码写在这里
    cout << "输出内容" << endl;   // 输出并换行
    return 0;                     // 程序正常结束
}
```

### 黄金记忆点

- ✅ 写完代码**必须重新编译**才能看到新结果（按 `F11`）
- ✅ 报错只看**第一条**，修好它后面的可能自动消失
- ✅ 代码路径**不含中文和空格**
- ✅ 每个 C++ 程序有且只有**一个 `main` 函数**
- ✅ `cout <<` 是输出，`<<` 箭头指向"流的去向"
- ✅ 写代码时**切换英文输入法**，远离中文标点
