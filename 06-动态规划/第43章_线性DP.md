## 💡 生活类比

打个比方：你和同学们玩"成语接龙"——每个人接的词，必须以**前一个人说的词的末字**开头。你不能跳过前一个人，也不能参考还没轮到的人。每一步的决策，只依赖"上一步的状态"。

线性 DP 就是这个接龙游戏：

- **阶段** = 序列中的第 $i$ 个位置（接龙轮到第 $i$ 个人）
- **状态** = 到第 $i$ 个位置为止的某种最优值（接龙到目前为止的最长长度）
- **转移** = 从第 $i$ 个位置的"前驱"（前面某些位置）推导过来（前一个成语决定你能接什么）

关键特征：**状态只向后看，不向前看**——这就是"无后效性"在序列上的体现。

## 第1节 线性DP的概念

### 43.1 什么是线性DP

线性 DP 是最简单的一类动态规划：**状态沿着一条序列的下标推进**，`f[i]` 只依赖于 `f[j]`（$j \le i$），不存在复杂的拓扑结构。

| 特征 | 说明 |
|------|------|
| **阶段** | 序列下标 $i = 1, 2, \dots, n$ |
| **状态** | `f[i]` 表示前 $i$ 个元素的某种最优值 |
| **转移** | `f[i]` 由 `f[j]`（$j < i$）推出 |
| **无后效性** | `f[i]` 一旦确定，后续决策不改变它 |

常见的线性 DP 模型有一维（`f[i]`）和二维（`f[i][j]`）两种：

- **一维**：LIS、最大子段和——只有一个下标
- **二维**：LCS、编辑距离——两个序列各一个下标

### 43.2 与背包DP的关系

上一章的背包 DP 其实也是"线性"的——物品按编号 $1 \sim n$ 推进，`f[i][j]` 依赖 `f[i-1][...]`。它们的区别在于**转移的结构**：

| 维度 | 线性 DP | 背包 DP |
|------|---------|---------|
| 阶段推进 | 沿序列下标 | 沿物品编号 |
| 核心约束 | 子序列的顺序/匹配关系 | 容量限制 |
| 典型状态 | `f[i]` / `f[i][j]` | `f[i][j]`（前 $i$ 件物品、容量 $j$） |
| 转移来源 | 前驱位置 $j$ | 上一物品 $i-1$ |

可以把背包 DP 看作线性 DP 的一个**特例**——它也有"线性推进"的特征，只是加上了"容量"这个额外维度。本章专注于**不含容量约束**的经典线性模型。

## 第2节 最长上升子序列（LIS）

### 43.3 O(n²) 朴素DP

**问题**：给定序列 $a_1, a_2, \dots, a_n$，求最长的严格上升子序列的长度。

**状态设计**：`f[i]` 表示以 $a[i]$ **结尾**的最长上升子序列长度。

**转移**：枚举 $a[i]$ 前面所有比它小的元素作为前驱：

$$f[i] = \max_{j < i,\ a[j] < a[i]} (f[j] + 1)$$

边界：`f[i] = 1`（每个元素自身构成长度为 1 的子序列）。答案 $= \max(f[i])$。

**代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 1005;
int a[MAXN], f[MAXN];

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) scanf("%d", &a[i]);
    int ans = 0;
    for (int i = 1; i <= n; i++) {
        f[i] = 1;                    // 至少包含自己
        for (int j = 1; j < i; j++) {
            if (a[j] < a[i])         // 严格上升
                f[i] = max(f[i], f[j] + 1);
        }
        ans = max(ans, f[i]);
    }
    printf("%d\n", ans);
    return 0;
}
```

**复杂度**：时间 $O(n^2)$，空间 $O(n)$。当 $n \le 10^4$ 时可通过。

### 43.4 O(nlogn) 二分优化

当 $n$ 达到 $10^5$，$O(n^2)$ 会超时。观察到：对于相同长度的上升子序列，**末尾元素越小越有利**（后面能接的数更多）。

**核心定义**：维护数组 `d[]`，其中 `d[k]` 表示**长度为 $k$ 的上升子序列中，末尾元素的最小值**。

!!! warning "关键理解"
    `d[]` 数组存的不是某个真实子序列，而是"每个长度对应的最优末尾"。`d[]` 一定单调递增。

**转移**：对每个 $a[i]$，在 `d[1..len]` 中用 `lower_bound` 找到第一个 $\ge a[i]$ 的位置 `pos`：

- `d[pos] = a[i]`：用更小的值替换，保持"最小末尾"性质
- 若 `pos > len`：说明 $a[i]$ 比所有末尾都大，可以接长，`len++`

**代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 100005;
int a[MAXN], d[MAXN];   // d[k]: 长度为k的上升子序列的最小末尾

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 1; i <= n; i++) scanf("%d", &a[i]);
    int len = 0;
    for (int i = 1; i <= n; i++) {
        // 找 d 中第一个 >= a[i] 的位置
        int pos = lower_bound(d + 1, d + len + 1, a[i]) - d;
        d[pos] = a[i];
        if (pos > len) len = pos;    // 能接长则更新
    }
    printf("%d\n", len);
    return 0;
}
```

**演示**：序列 `3 1 2 5 4`

| 步骤 | $a[i]$ | 操作 | `d[]` | `len` |
|------|--------|------|-------|-------|
| 1 | 3 | d[1]=3 | `[3]` | 1 |
| 2 | 1 | 替换 d[1]=1 | `[1]` | 1 |
| 3 | 2 | d[2]=2（接长） | `[1,2]` | 2 |
| 4 | 5 | d[3]=5（接长） | `[1,2,5]` | 3 |
| 5 | 4 | 替换 d[3]=4 | `[1,2,4]` | 3 |

答案 = 3（子序列 `1,2,4` 或 `1,2,5`）。

!!! tip "lower_bound vs upper_bound"
    - **严格上升**（LIS）：用 `lower_bound`（找第一个 $\ge a[i]$）
    - **不下降**（允许相等）：用 `upper_bound`（找第一个 $> a[i]$）

### 43.5 两种复杂度对比

| 维度 | $O(n^2)$ 朴素 | $O(n\log n)$ 二分 |
|------|---------------|-------------------|
| 适用 $n$ | $\le 10^4$ | $\le 10^5$ |
| 能否求方案 | ✅ 可回溯前驱 | ❌ `d[]` 不是真实子序列 |
| 代码难度 | 简单 | 中等 |
| 空间 | $O(n)$ | $O(n)$ |

## 第3节 最长公共子序列（LCS）

### 43.6 状态设计与转移

**问题**：给定两个序列 $a$ 和 $b$，求它们的最长公共子序列长度。

**状态设计**：`f[i][j]` 表示 $a$ 的前 $i$ 个字符与 $b$ 的前 $j$ 个字符的 LCS 长度。

**转移**：

$$f[i][j] = \max(f[i-1][j],\ f[i][j-1])$$

若 $a[i] = b[j]$，则还可以：

$$f[i][j] = \max(f[i][j],\ f[i-1][j-1] + 1)$$

**代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;
char a[1005], b[1005];
int f[1005][1005];

int main() {
    scanf("%s%s", a + 1, b + 1);
    int n = strlen(a + 1), m = strlen(b + 1);
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            f[i][j] = max(f[i-1][j], f[i][j-1]);
            if (a[i] == b[j])
                f[i][j] = max(f[i][j], f[i-1][j-1] + 1);
        }
    }
    printf("%d\n", f[n][m]);
    return 0;
}
```

### 43.7 转移表演示

设 $a = \text{ABCB}$，$b = \text{BDCA}$：

| | 空 | B | D | C | A |
|---|---|---|---|---|---|
| **空** | 0 | 0 | 0 | 0 | 0 |
| **A** | 0 | 0 | 0 | 0 | **1** |
| **B** | 0 | **1** | 1 | 1 | 1 |
| **C** | 0 | 1 | 1 | **2** | 2 |
| **B** | 0 | 1 | 1 | 2 | 2 |

- `f[1][4]=1`：$a[1]=A$ 与 $b[4]=A$ 匹配，$f[0][3]+1=1$
- `f[3][3]=2`：$a[3]=C$ 与 $b[3]=C$ 匹配，$f[2][2]+1=2$
- 最终 `f[4][4]=2`，LCS 为 `BC`

!!! info "空间优化"
    `f[i][j]` 只依赖第 $i-1$ 行和第 $i$ 行，可用**滚动数组**把空间降到 $O(\min(n,m))$。但若需要回溯方案，必须保留完整二维表。

## 第4节 最大子段和

### 43.8 一维DP与滚动优化

**问题**（P1115）：给定序列，求连续子段的最大和。

**状态设计**：`f[i]` 表示以 $a[i]$ **结尾**的最大子段和。

**转移**：

$$f[i] = \max(a[i],\ f[i-1] + a[i])$$

含义：要么从 $a[i]$ 重新开始，要么接上前面的子段。

**滚动优化**：`f[i]` 只依赖 `f[i-1]`，用一个变量 `sum` 滚动即可：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, x, sum = 0, ans = INT_MIN;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        scanf("%d", &x);
        sum = max(x, sum + x);     // f[i] = max(a[i], f[i-1]+a[i])
        ans = max(ans, sum);
    }
    printf("%d\n", ans);
    return 0;
}
```

**复杂度**：时间 $O(n)$，空间 $O(1)$。

## 第5节 编辑距离

### 43.9 三种操作的转移

**问题**（P2758）：给定字符串 $a$ 和 $b$，每次可以进行**删除/插入/替换**一个字符，求把 $a$ 变成 $b$ 的最少操作次数。

**状态设计**：`f[i][j]` 表示 $a$ 的前 $i$ 个字符变成 $b$ 的前 $j$ 个字符的最少操作数。

**边界**：

- `f[i][0] = i`：把 $a$ 的前 $i$ 个字符全删掉
- `f[0][j] = j`：把空串插入 $j$ 个字符变成 $b$ 的前 $j$ 个

**转移**（三取最小）：

$$f[i][j] = \min\begin{cases} f[i-1][j] + 1 & \text{删除 } a[i] \\ f[i][j-1] + 1 & \text{插入 } b[j] \\ f[i-1][j-1] + [a[i] \ne b[j]] & \text{替换（相同则代价0）} \end{cases}$$

| 操作 | 转移来源 | 含义 |
|------|---------|------|
| 删除 $a[i]$ | `f[i-1][j] + 1` | $a$ 前 $i{-}1$ 已匹配 $b$ 前 $j$，多出的 $a[i]$ 删掉 |
| 插入 $b[j]$ | `f[i][j-1] + 1` | $a$ 前 $i$ 已匹配 $b$ 前 $j{-}1$，再插入 $b[j]$ |
| 替换 | `f[i-1][j-1] + (a[i]!=b[j])` | $a$ 前 $i{-}1$ 匹配 $b$ 前 $j{-}1$，把 $a[i]$ 改成 $b[j]$ |

**代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;
char a[2005], b[2005];
int f[2005][2005];

int main() {
    scanf("%s%s", a + 1, b + 1);
    int n = strlen(a + 1), m = strlen(b + 1);
    for (int i = 0; i <= n; i++) f[i][0] = i;   // 删 i 次
    for (int j = 0; j <= m; j++) f[0][j] = j;   // 插 j 次
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (a[i] == b[j]) {
                f[i][j] = f[i-1][j-1];          // 相同，无需操作
            } else {
                f[i][j] = min({f[i-1][j] + 1,    // 删除
                               f[i][j-1] + 1,    // 插入
                               f[i-1][j-1] + 1});// 替换
            }
        }
    }
    printf("%d\n", f[n][m]);
    return 0;
}
```

**复杂度**：时间 $O(nm)$，空间 $O(nm)$（可用滚动数组优化到 $O(\min(n,m))$）。

## 第6节 路径DP

### 43.10 数字三角形

**问题**：从三角形顶部走到底部，每步只能向左下或右下，求路径最大和。

**状态**：`f[i][j]` 表示走到 $(i,j)$ 的最大和。

**转移**：`f[i][j] = a[i][j] + max(f[i-1][j-1], f[i-1][j])`。

可从底向上递推避免边界处理：`f[i][j] = a[i][j] + max(f[i+1][j], f[i+1][j+1])`。

### 43.11 方格取数——两条路径同时走

**问题**（P1004）：$n \times n$ 方格中有数字，从 $(1,1)$ 走到 $(n,n)$ 走两次（只能向右或向下），求两次取数之和的最大值。同一格只算一次。

**思路**：两条路径**同时走**，保证步数相同。设 `f[i1][j1][i2][j2]` 表示两条路径分别走到 $(i1,j1)$ 和 $(i2,j2)$ 时的最大和。由于 $i1+j1 = i2+j2 = k$（步数），可降为三维 `f[k][i1][i2]`。

**转移**：四种来源（两条路径各从"上"或"左"来）：

```
当前格取数 t = a[i1][j1]，若 (i1,j1) != (i2,j2) 再加 a[i2][j2]
f[k][i1][i2] = max(四种来源) + t
```

详细代码见第 9 节例题三。

## 第7节 线性DP优化思想总结

### 43.12 从朴素到优化

线性 DP 的优化通常沿以下路径推进：

| 优化层次 | 方法 | 典型应用 |
|---------|------|---------|
| 朴素 | 枚举所有前驱 | LIS $O(n^2)$ |
| 观察单调性 | 维护单调数组 + 二分 | LIS $O(n\log n)$ |
| 滚动变量 | 只依赖上一阶段 | 最大子段和 $O(1)$ 空间 |
| 滚动数组 | 只依赖上一行 | LCS / 编辑距离空间减半 |
| 单调队列 | 滑动窗口最值 | 后续章节详讲 |

!!! tip "优化思路口诀"
    **先写朴素，再找单调；能用二分，别用枚举；只看上一步，滚动省空间。**

核心思想：**朴素 DP 写对后，观察转移时"决策是否有单调性"**——如果有，就能用二分或单调队列把内层循环的 $O(n)$ 降到 $O(\log n)$ 或 $O(1)$。

## 第8节 常见误区

!!! warning "误区1：LIS 二分优化中 d 数组存的是子序列本身"
    `d[]` 存的是"长度为 $k$ 的上升子序列的**最小末尾**"，不是某个真实子序列。替换操作会打乱元素来源，因此**不能用 `d[]` 回溯方案**。需要方案时必须用 $O(n^2)$ 朴素法并记录前驱。

!!! warning "误区2：LCS 空间优化后无法求方案"
    滚动数组只保留两行，丢失了历史信息。若要回溯 LCS 方案，必须保留完整 $O(nm)$ 的二维表，从 `f[n][m]` 反向追踪。

!!! warning "误区3：编辑距离边界初始化遗漏"
    `f[0][j] = j`（空串插入 $j$ 个字符）和 `f[i][0] = i`（删掉 $i$ 个字符）必须显式初始化。漏掉会导致全 0，答案错误。

!!! warning "误区4：方格取数中两条路径分两次走"
    分两次贪心走是**错的**——第一次取最优路径后，第二次的最优路径可能受影响。必须两条路径**同时走、同时 DP**，才能保证全局最优。

!!! warning "误区5：严格上升与不下降混淆"
    - 严格上升（LIS）：`a[j] < a[i]`，二分用 `lower_bound`
    - 不下降（允许相等）：`a[j] <= a[i]`，二分用 `upper_bound`
    
    混淆会导致答案差 1。

## 第9节 配套习题精讲

### 例题一：[P1020] 导弹拦截（LIS）

**题意**：导弹依次飞来，高度为 $h_1, h_2, \dots, h_n$。一套拦截系统每次发射的导弹高度不能高于上一次。求：① 一套系统最多拦截多少枚；② 拦截所有导弹最少需要多少套系统。

**思路**：

- 第一问 = 最长**不上升**子序列长度（允许相等，逐次 $\le$）
- 第二问 = 最长**严格上升**子序列长度（Dilworth 定理：最少不上升链覆盖数 = 最长上升链长度）

$n \le 10^5$，必须用 $O(n\log n)$。

**关键**：不上升子序列的 `d[]` 是**非递增**的，用 `upper_bound` + `greater<int>()` 找第一个严格小于当前值的位置。

**代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;
const int MAXN = 100005;
int a[MAXN], d[MAXN];

int main() {
    int n = 0, x;
    while (scanf("%d", &x) != EOF) a[++n] = x;
    // 第一问：最长不上升子序列
    int len1 = 0;
    for (int i = 1; i <= n; i++) {
        // d 非递增，找第一个 < a[i] 的位置
        int pos = upper_bound(d + 1, d + len1 + 1, a[i],
                              greater<int>()) - d;
        d[pos] = a[i];
        if (pos > len1) len1 = pos;
    }
    // 第二问：最长上升子序列（Dilworth定理）
    int len2 = 0;
    memset(d, 0, sizeof(d));
    for (int i = 1; i <= n; i++) {
        int pos = lower_bound(d + 1, d + len2 + 1, a[i]) - d;
        d[pos] = a[i];
        if (pos > len2) len2 = pos;
    }
    printf("%d\n%d\n", len1, len2);
    return 0;
}
```

**复杂度**：时间 $O(n\log n)$，空间 $O(n)$。

### 例题二：[P2758] 编辑距离

**题意**：给定两个字符串，每次操作可删除/插入/替换一个字符，求最少操作次数使两串相等。

**思路**：见第 5 节，三转移取 min，边界 `f[0][j]=j`、`f[i][0]=i`。相同字符无需操作，不同字符从删除/插入/替换三种操作中取最小。

**代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;
char a[2005], b[2005];
int f[2005][2005];

int main() {
    scanf("%s%s", a + 1, b + 1);
    int n = strlen(a + 1), m = strlen(b + 1);
    for (int i = 0; i <= n; i++) f[i][0] = i;   // 边界：删i次
    for (int j = 0; j <= m; j++) f[0][j] = j;   // 边界：插j次
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (a[i] == b[j]) {
                f[i][j] = f[i-1][j-1];          // 相同，无需操作
            } else {
                f[i][j] = min({f[i-1][j] + 1,    // 删除a[i]
                               f[i][j-1] + 1,    // 插入b[j]
                               f[i-1][j-1] + 1});// 替换
            }
        }
    }
    printf("%d\n", f[n][m]);
    return 0;
}
```

**复杂度**：时间 $O(nm)$，空间 $O(nm)$。

### 例题三：[P1004] 方格取数

**题意**：$n \times n$（$n \le 9$）方格中有数字，从 $(1,1)$ 走到 $(n,n)$ 走两次，每次只能向右或向下，同一格的数只取一次。求两次取数之和的最大值。

**思路**：两条路径同时走，步数 $k = i + j$ 相同。`f[k][i1][i2]` 表示两条路径各走到 $(i1, k{-}i1)$ 和 $(i2, k{-}i2)$ 时的最大和。四种来源取 max，重叠格子只算一次。

**代码**：

```cpp
#include <bits/stdc++.h>
using namespace std;
int a[15][15];
int f[30][15][15];   // f[k][i1][i2]，k = i1+j1

int main() {
    int n;
    scanf("%d", &n);
    int x, y, v;
    while (scanf("%d%d%d", &x, &y, &v) == 3 && x)
        a[x][y] = v;
    memset(f, 0xc0, sizeof(f));  // 初始化为负无穷，避免非法状态被 max 选中
    f[2][1][1] = a[1][1];      // 起点，两条路径都在(1,1)
    for (int k = 3; k <= 2 * n; k++) {
        for (int i1 = 1; i1 <= n; i1++) {
            for (int i2 = 1; i2 <= n; i2++) {
                int j1 = k - i1, j2 = k - i2;
                if (j1 < 1 || j1 > n || j2 < 1 || j2 > n) continue;
                int t = a[i1][j1];
                if (i1 != i2) t += a[i2][j2];   // 不同格，都取
                int mx = 0;
                mx = max(mx, f[k-1][i1-1][i2-1]); // 都从上
                mx = max(mx, f[k-1][i1-1][i2]);   // 1上2左
                mx = max(mx, f[k-1][i1][i2-1]);   // 1左2上
                mx = max(mx, f[k-1][i1][i2]);     // 都从左
                f[k][i1][i2] = mx + t;
            }
        }
    }
    printf("%d\n", f[2*n][n][n]);
    return 0;
}
```

**复杂度**：时间 $O(n^3)$，空间 $O(n^3)$。

## 第10节 多维动态规划

> 2025 年 S 组新增考点（难度 7）。前面学的线性 DP 状态最多二维（如 LCS 的 `f[i][j]`）。当问题需要更多维度的信息才能描述状态时，就进入**多维 DP** 的范畴。

### 43.13 多维 DP 的概念

**多维 DP**：状态有**三个或更多维度**，每个维度对应问题中的一个独立要素（位置、步数、路径编号、决策状态等）。

| 维度数 | 典型状态 | 典型问题 |
|--------|---------|---------|
| 一维 | `f[i]` | LIS、最大子段和 |
| 二维 | `f[i][j]` | LCS、编辑距离、数字三角形 |
| 三维 | `f[k][i1][i2]` | 方格取数（两条路径同时走） |
| 状态压缩+多维 | `dp[mask][i]` | TSP（旅行商问题） |

!!! info "与一维 DP 的区别"
    - 一维/二维 DP：状态要素少，转移直接
    - 多维 DP：状态要素多，需**精心设计维度**避免状态爆炸；常配合**降维**与**滚动数组**优化空间
    - 维度越多，时间/空间复杂度越高，更要关注优化

### 43.14 常见多维 DP 模型

#### 模型一：二维网格 DP（方格取数的扩展）

在 $n \times m$ 网格中从左上走到右下，求最大/最小路径和。状态 `f[i][j]` 表示走到 $(i,j)$ 的最优值，转移来自上方和左方：

$$f[i][j] = a[i][j] + \max(f[i-1][j],\ f[i][j-1])$$

#### 模型二：三维 DP（两条路径同时走）

方格取数（P1004）就是典型三维 DP：`f[k][i1][i2]`，用步数 $k=i+j$ 把四维降成三维。两条路径同时推进，避免分两次贪心导致的次优解。

#### 模型三：状态压缩 + 多维（如 TSP）

旅行商问题（TSP）：访问所有城市的最短回路。状态 `dp[mask][i]` 表示已访问城市集合为 `mask`、当前位于城市 $i$ 时的最短路径。`mask` 用二进制位表示集合（状态压缩），配合当前位置 $i$ 构成多维 DP。

$$dp[mask][i] = \min_{j \in mask,\ j \ne i} \big(dp[mask \setminus \{i\}][j] + dis[j][i]\big)$$

复杂度 $O(2^n \cdot n^2)$，适用于 $n \le 20$。

### 43.15 多维 DP 的空间优化：滚动数组

多维 DP 状态空间大，常需**滚动数组**优化。若转移只依赖"上一层"，可只保留两层交替使用，把空间降一个维度。

例如方格取数 `f[k][i1][i2]` 只依赖 `f[k-1][...]`，可用滚动数组把第一维 $k$ 去掉，空间从 $O(n^3)$ 降到 $O(n^2)$。

!!! tip "何时能滚动"
    当状态 `f[k][...]` **只依赖** `f[k-1][...]`（上一阶段）时，就可以滚动。若依赖更早的阶段（如 `f[k-2]`），则不能简单滚动。

### 43.16 代码示例：三维 DP 典型结构

以方格取数为模板，展示三维 DP 配合滚动数组优化的标准写法：

```cpp
#include <bits/stdc++.h>
using namespace std;
int a[15][15];
int f[2][15][15];   // 滚动数组：f[k&1][i1][i2]，只保留两层

int main() {
    int n;
    scanf("%d", &n);
    int x, y, v;
    while (scanf("%d%d%d", &x, &y, &v) == 3 && x)
        a[x][y] = v;

    memset(f, 0xc0, sizeof(f));     // 初始化为极小值
    f[2 & 1][1][1] = a[1][1];       // 起点
    for (int k = 3; k <= 2 * n; k++) {
        int cur = k & 1, pre = (k - 1) & 1;
        memset(f[cur], 0xc0, sizeof(f[cur]));
        for (int i1 = 1; i1 <= n; i1++) {
            for (int i2 = 1; i2 <= n; i2++) {
                int j1 = k - i1, j2 = k - i2;
                if (j1 < 1 || j1 > n || j2 < 1 || j2 > n) continue;
                int t = a[i1][j1];
                if (i1 != i2) t += a[i2][j2];      // 不同格都取
                int mx = INT_MIN;
                mx = max(mx, f[pre][i1-1][i2-1]);  // 都从上
                mx = max(mx, f[pre][i1-1][i2]);    // 1上2左
                mx = max(mx, f[pre][i1][i2-1]);    // 1左2上
                mx = max(mx, f[pre][i1][i2]);      // 都从左
                f[cur][i1][i2] = mx + t;
            }
        }
    }
    printf("%d\n", f[(2 * n) & 1][n][n]);
    return 0;
}
```

!!! tip "多维 DP 要点"
    - **状态维度**：多维 DP 状态有三个及以上维度，常见模型：二维网格、三维双路径、状态压缩+多维（TSP）
    - **维度顺序**：按"依赖关系"安排循环顺序，确保计算当前状态时其依赖已就绪
    - **边界初始化**：多维状态更易漏初始化，建议统一初始化为极小/极大值
    - **滚动数组**：是核心空间优化手段，当只依赖上一阶段时可降一个维度；用 `&1`（奇偶）或 `%2` 切换两层，注意每层开始时清空当前层
    - **避免状态爆炸**：维度越多越要关注状态设计与边界初始化

## 📖 本章总结

### 思维导图

- 线性 DP
  - 一维模型
    - LIS：O(n²) 朴素 / O(n log n) 二分优化
    - 最大子段和：滚动变量 O(n) 空间 O(1)
  - 二维模型
    - LCS：O(nm) 二维DP，可滚动数组优化
    - 编辑距离：删除/插入/替换三转移取 min
  - 路径模型
    - 数字三角形：自底向上递推
    - 方格取数：两条路径同时走，三维 DP（k = i+j 降维）

### 核心口诀

| 口诀 | 含义 |
|------|------|
| **状态沿下标走，转移看前驱** | 线性 DP 的本质——`f[i]` 由 `f[j]`（$j<i$）推出 |
| **LIS 两解法，朴素二分各一招** | $O(n^2)$ 枚举前驱，$O(n\log n)$ 维护最小末尾 |
| **LCS 看两串，对齐取 max** | `f[i][j]=max(f[i-1][j],f[i][j-1])`，相等加一 |
| **编辑三操作，删插换取 min** | 删除、插入、替换三转移取最小值 |
| **两路同时走，步数定降维** | 方格取数用 $k=i+j$ 把四维降三维 |

### 速查表

| 模型 | 状态设计 | 转移方程 | 复杂度 | 典型题 |
|------|---------|---------|--------|--------|
| LIS 朴素 | `f[i]` | `f[i]=max(f[j]+1)` | $O(n^2)$ | P1020 |
| LIS 二分 | `d[k]` | `lower_bound` 替换 | $O(n\log n)$ | P1020 |
| LCS | `f[i][j]` | `max(f[i-1][j],f[i][j-1])` | $O(nm)$ | P2543 |
| 最大子段和 | `f[i]` | `max(a[i],f[i-1]+a[i])` | $O(n)$ | P1115 |
| 编辑距离 | `f[i][j]` | `min(删,插,换)` | $O(nm)$ | P2758 |
| 方格取数 | `f[k][i1][i2]` | 四来源取 max | $O(n^3)$ | P1004 |
