## 💡 生活类比

> 🤔 想一想：你有没有想过，编程中的输入输出和生活中的收发快递有什么相似之处？

把程序想象成一家**快递驿站**：

- **`cout <<`**：把包裹**寄出去**到屏幕，箭头朝外 `<<`，就像快递员把包裹递给收件人。
- **`cin >>`**：把包裹**收进来**到变量，箭头朝里 `>>`，就像驿站从快递车上卸货放进货架。
- **变量**：就是货架上的格子，每个格子有名字（变量名）和规格（数据类型）。
- **运算符**：就是驿站里的加工设备——加法机把两箱苹果合并、除法机把一箱苹果分装、取余机算最后剩几个。

> **记住一句话**：**箭头永远指向数据的去向**。`cout << x` 是 x 流向屏幕，`cin >> x` 是数据流向 x。

## 核心概念

> 🤔 想一想：你有没有想过，C++ 中数据是如何从键盘流进程序，又如何在程序内部被一步步加工处理的？

### 一、cin 与 cout 的用法

> 💡 一句话概括：`cin` 负责读，`cout` 负责写，箭头永远指向数据流向。

「`cin`」读作 "see-in"，是 "character input"（字符输入）的缩写；「`cout`」读作 "see-out"，是 "character output"（字符输出）的缩写。两者来自头文件 `<iostream>`。

| 操作 | 语法 | 说明 |
|------|------|------|
| 读一个值 | `cin >> x;` | 把键盘数据读进变量 x |
| 连续读多个 | `cin >> a >> b >> c;` | 用空格/回车/Tab 分隔 |
| 输出一个值 | `cout << x;` | 把 x 输出到屏幕 |
| 链式输出 | `cout << "a=" << a;` | 多个数据串着输出 |
| 换行 | `cout << endl;` 或 `cout << "\n";` | 输出换行 |

> ⚠️ 警告：cin 的分隔符
> 
> `cin` 默认以**空格、回车、Tab** 作为数据的分隔符。输入 `10 20 30` 和分三行输入效果一样，但**不能**输入 `10,20,30`（带逗号），`cin` 会读不到正确数据。

#### endl 与 \n 的区别

> 💡 一句话概括：两者都换行，但 `endl` 还会"催促"系统立刻把内容写出来，代价是更慢。

| 对比项 | `endl` | `\n` |
|--------|--------|------|
| 是否换行 | 是 | 是 |
| 是否刷新缓冲区 | **是**（flush） | **否** |
| 速度 | 较慢（每次刷新） | 较快 |
| 用法 | `cout << endl;` | `cout << "\n";` 或 `cout << '\n';` |

📖 通俗解释：缓冲区就像一个"临时候车室"，内容先在这里排队，凑满一批再一起输出。`endl` 等于"别等了，立刻出发"，`\n` 等于"继续排队，不急"。所以大数据量时用 `\n` 更高效。

> 💡 提示：竞赛建议
> 
> - **日常练习**：用 `endl` 更直观，代码可读性好。
> - **大数据输出**（≥ 10⁵ 行）：用 `"\n"` 更快，避免频繁刷新缓冲区拖慢程序。
> - 两者**换行效果完全一样**，区别只在性能与缓冲区行为。

📌 本节要点：
- 箭头指向数据去向：`cin >>` 数据流入变量，`cout <<` 数据流向屏幕
- `endl` = 换行 + 刷新缓冲区（慢），`\n` = 只换行（快）
- `cin` 以空格/回车/Tab 为分隔符，不能读带逗号的数据

### 二、运算符分类总表

> 💡 一句话概括：五类运算符各有分工，记住优先级表能避免 90% 的表达式错误。

| 类别 | 运算符 | 说明 |
|------|--------|------|
| 算术运算符 | `+` `-` `*` `/` `%` | 数学运算 |
| 关系运算符 | `==` `!=` `<` `>` `<=` `>=` | 比较大小，结果为 bool |
| 逻辑运算符 | `&&` `||` `!` | 与、或、非 |
| 赋值运算符 | `=` `+=` `-=` `*=` `/=` `%=` | 赋值与复合赋值 |
| 自增自减 | `++` `--` | 变量加 1 / 减 1 |

#### 算术运算符优先级

| 优先级 | 运算符 | 说明 |
|--------|--------|------|
| 1（最高） | `()` | 括号最优先 |
| 2 | `*` `/` `%` | 先乘除取余 |
| 3（最低） | `+` `-` | 后加减 |

#### 完整运算符优先级（本章涉及）

下表列出了所有运算符的优先级，从上到下优先级递减：

| 优先级 | 运算符 | 类别 |
|--------|--------|------|
| 1（最高） | `()` | 括号 |
| 2 | `!` `++` `--`（前置） | 单目 |
| 3 | `*` `/` `%` | 算术 |
| 4 | `+` `-` | 算术 |
| 5 | `<` `<=` `>` `>=` | 关系 |
| 6 | `==` `!=` | 关系 |
| 7 | `&&` | 逻辑与 |
| 8 | `||` | 逻辑或 |
| 9（最低） | `=` `+=` `-=` `*=` `/=` `%=` | 赋值 |

📖 通俗解释：优先级就是"谁先算"。`*` 比 `+` 优先，所以 `3+4*5` 先算 `4*5=20` 再算 `3+20=23`。记不住时**多加括号**，括号不影响运行速度。

> 💡 提示：黄金法则
> 
> 拿不准优先级时，**多加括号**！括号不影响运行速度，但能让代码更易读、不易出错。

📌 本节要点：
- 括号最优先，单目次之，算术 > 关系 > 逻辑 > 赋值
- `&&` 优先级高于 `||`，`a || b && c` 等价于 `a || (b && c)`
- 拿不准就加括号，安全第一

## 代码实现

> 🤔 想一想：你有没有想过，看懂概念是一回事，把它们变成真正能运行的代码又是另一回事？

### 1. 输入输出示例

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int age;
    cin >> age;                          // 读一个整数
    cout << "你今年" << age << "岁\n";

    int a, b, c;
    cin >> a >> b >> c;                  // 连续读三个整数
    cout << "三个数的和是：" << a + b + c << endl;

    string name;
    cin >> name;                         // 读一个单词（遇空格停止）
    cout << "你好，" << name << "\n";
    return 0;
}
```

输入：
```
12
10 20 30
ZhangSan
```
输出：
```
你今年12岁
三个数的和是：60
你好，ZhangSan
```

> ⚠️ 警告：读字符串遇空格停止
> 
> `cin >> name` 遇到**空格就停止读取**。如果输入 `Zhang San`，`name` 只会存 `Zhang`。想读整行（含空格）要用 `getline(cin, name);`。

### 2. 算术运算符示例

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << 3 + 5 << "\n";      // 8
    cout << 8 - 3 << "\n";      // 5
    cout << 4 * 6 << "\n";      // 24
    cout << 10 / 3 << "\n";     // 3  （整数除法，舍去小数）
    cout << 10 % 3 << "\n";     // 1  （取余）

    // 浮点除法：只要有一个是小数，结果就有小数
    cout << 7.0 / 2 << "\n";    // 3.5
    cout << (double)7 / 2 << "\n";  // 3.5（强制转换）

    // 取余的妙用：取各位数字
    int n = 123;
    cout << n % 10 << "\n";         // 3（个位）
    cout << n / 10 % 10 << "\n";    // 2（十位）
    cout << n / 100 % 10 << "\n";   // 1（百位）
    return 0;
}
// 输出：
// 8
// 5
// 24
// 3
// 1
// 3.5
// 3.5
// 3
// 2
// 1
```

📖 通俗解释：`10 / 3` 在 C++ 里等于 3 而不是 3.5，因为两个整数相除，结果自动"砍掉"小数部分（不是四舍五入）。想要小数结果，必须让其中一个变成小数，比如 `10.0 / 3`。

### 3. 关系与逻辑运算符示例

关系运算符的结果是 `bool` 类型（`true` = 1，`false` = 0）：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << (5 == 5) << "\n";     // 1（true）
    cout << (5 != 3) << "\n";     // 1
    cout << (5 > 3) << "\n";      // 1
    cout << (5 < 3) << "\n";      // 0（false）
    cout << (5 >= 5) << "\n";     // 1
    cout << (5 <= 3) << "\n";     // 0

    // 逻辑运算符
    int age = 18;
    bool isStudent = true;
    cout << (age >= 6 && age <= 18) << "\n";   // 1（且）
    cout << (age < 6 || age > 60) << "\n";     // 0（或）
    cout << (!isStudent) << "\n";              // 0（非）
    return 0;
}
// 输出：
// 1
// 1
// 1
// 0
// 1
// 0
// 1
// 0
// 0
```

| 逻辑运算符 | 含义 | 真值表 |
|-----------|------|--------|
| `&&` | 与（且） | 两边都真才真 |
| `||` | 或 | 一边真即真 |
| `!` | 非 | 真变假，假变真 |

> 💡 提示：短路求值
> 
> - `&&`：左边为 `false` 时，**右边不再计算**（已经确定结果为 false）。
> - `||`：左边为 `true` 时，**右边不再计算**（已经确定结果为 true）。
> 
> 这个特性常用来防止越界，例如 `if (i < n && a[i] != 0)`。

### 4. 赋值运算符示例

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a = 10;        // 赋值：把 10 放进 a
    a += 5;            // 等价于 a = a + 5，a 变 15
    a -= 3;            // 等价于 a = a - 3，a 变 12
    a *= 2;            // 等价于 a = a * 2，a 变 24
    a /= 4;            // 等价于 a = a / 4，a 变 6
    a %= 4;            // 等价于 a = a % 4，a 变 2
    cout << a << "\n"; // 2

    // 自增自减
    int b = 5;
    b++;               // b 变 6（后置，单独使用时与 ++b 等价）
    ++b;               // b 变 7（前置）
    b--;               // b 变 6
    cout << b << "\n"; // 6
    return 0;
}
// 输出：
// 2
// 6
```

**变量 a 的值变化追踪：**

| 操作 | a 的值 |
|------|--------|
| `int a = 10` | 10 |
| `a += 5` | 15 |
| `a -= 3` | 12 |
| `a *= 2` | 24 |
| `a /= 4` | 6 |
| `a %= 4` | 2 |

| 复合运算符 | 等价写法 | 示例 |
|----------|---------|------|
| `+=` | `a = a + b` | `a += 5` |
| `-=` | `a = a - b` | `a -= 3` |
| `*=` | `a = a * b` | `a *= 2` |
| `/=` | `a = a / b` | `a /= 4` |
| `%=` | `a = a % b` | `a %= 10` |

> ⚠️ 警告：前置与后置的区别
> 
> - `a++`（后置）：**先使用 a 的值，再加 1**
> - `++a`（前置）：**先加 1，再使用 a 的值**
> 
> ```cpp
> int a = 5, b;
> b = a++;          // b 得到 5，然后 a 变 6
> cout << a << " " << b;    // 输出 6 5
> ```
> 
> **不要在复杂表达式里混用**，如 `b = a++ + ++a`，行为不确定，容易出错。

## ⚠️ 常见误区

> 🤔 想一想：你有没有想过，为什么有些看似正确的代码，运行结果却和预期完全不同？

### 误区 1：整数除法 3/2=1（不是 1.5）

两个**整数**相除，结果还是整数，**直接舍去小数部分**（不是四舍五入）：

| 写法 | 结果 | 说明 |
|------|------|------|
| ❌ `cout << 7 / 2;` | 3 | 整数除法，丢小数 |
| ❌ `cout << 1 / 2;` | 0 | 不是 0.5 |
| ✅ `cout << 7.0 / 2;` | 3.5 | 有小数参与，按浮点除 |
| ✅ `cout << (double)7 / 2;` | 3.5 | 强制转换 |

**规律**：只要运算中有一个是浮点数，就按浮点除法计算，结果有小数。

> ⚠️ 警告：并联电阻公式陷阱
> 
> 计算并联电阻 `R = 1 / (1/r1 + 1/r2)` 时，若 `r1` 是 `int`，`1/r1` 会做整数除法得到 0！必须写成 `1.0 / r1`。

### 误区 2：% 运算只能用于整数

`%`（取余）**只能用于整数**，用于浮点数会编译报错：

- ❌ `cout << 10.5 % 3;` → 编译失败！
- ✅ `cout << 10 % 3;` → 输出 1

> 💡 提示：浮点数取余
> 
> 浮点数想求"余数"要用 `fmod` 函数（需 `#include <cmath>`）：`fmod(10.5, 3)` 得 `1.5`。

### 误区 3：= 与 == 混淆

| 写法 | 含义 | 后果 |
|------|------|------|
| ❌ `if (x = 5)` | 赋值，x 被赋成 5，表达式值为 5（真） | **永远为真**，条件判断失效 |
| ✅ `if (x == 5)` | 判断 x 是否等于 5 | 正确比较 |

`=` 是**赋值**，`==` 才是**判断相等**。新手极易混淆！

### 误区 4：scanf 读 double 用 %lf，printf 输出 double 用 %f

| 操作 | 格式符 | 说明 |
|------|--------|------|
| ❌ `scanf("%f", &x);` | `%f` | 读 double 必须用 `%lf` |
| ✅ `scanf("%lf", &x);` | `%lf` | 正确读入 |
| ✅ `printf("%f", x);` | `%f` | 输出 double 用 `%f` |
| ✅ `printf("%.2f", x);` | `%.2f` | 保留 2 位小数 |

> ⚠️ 警告：long long 的格式符
> 
> `long long` 必须用 `%lld`，用 `%d` 会输出错误结果！
> 
> ```cpp
> long long big = 1000000000LL;
> printf("%lld", big);   // 正确
> ```

### 误区 5：scanf 忘记加 &

| 写法 | 后果 |
|------|------|
| ❌ `scanf("%d", a);` | 缺少 `&`，程序崩溃 |
| ✅ `scanf("%d", &a);` | 正确，变量前要加取地址符 `&` |

> 💡 提示：例外
> 
> 读字符串到字符数组（`char s[100]`）时**不加 `&`**，因为数组名本身就是地址：`scanf("%s", s);`

## 典型例题

> 🤔 想一想：你有没有想过，如何把学到的输入输出和运算知识综合运用到一个完整的题目中？

**【例题】两数运算**：输入两个整数 `a` 和 `b`，依次输出它们的和、差、积、商（商保留 2 位小数）。

**输入**：`10 3`
**输出**：`13 7 30 3.33`

### 版本一：cin / cout 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << " " << a - b << " " << a * b << " ";
    cout << fixed << setprecision(2) << (double)a / b << "\n";
    return 0;
}
// 输入：10 3
// 输出：13 7 30 3.33
```

### 版本二：scanf / printf 实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b;
    scanf("%d %d", &a, &b);
    printf("%d %d %d %.2f\n", a + b, a - b, a * b, (double)a / b);
    return 0;
}
// 输入：10 3
// 输出：13 7 30 3.33
```

> 💡 提示：对比分析
> 
> - `cin` / `cout` 写法直观，但保留小数需要 `fixed << setprecision(2)`（需 `<iomanip>`，`bits/stdc++.h` 已包含）。
> - `scanf` / `printf` 用格式符 `%.2f` 直接控制小数位数，**更简洁**，且**速度更快**。
> - 数据量大时（≥ 10⁵），优先用 `scanf` / `printf`；或加 `ios::sync_with_stdio(false); cin.tie(0);` 给 `cin` / `cout` 提速。

### cin / cout 提速技巧

```cpp
ios::sync_with_stdio(false);     // 关闭与 stdio 的同步，cin/cout 提速
cin.tie(0);                       // 解除 cin 与 cout 的绑定
```

> ⚠️ 警告：提速后不要混用
> 
> 加了 `ios::sync_with_stdio(false)` 后，**不要**再混用 `cin` 和 `scanf`，会出错。

**练习 4**：[P5705] 数字反转 - https://www.luogu.com.cn/problem/P5705
> 输入一个不小于 5 位的实数（小数点后恰好 1 位），反转输出。例如输入 `123.4`，输出 `4.321`。
**提示**：把输入当成字符串读入（`string s; cin >> s;`），找到小数点位置，把整数部分和小数部分分别反转拼接。也可以用 `scanf("%d.%d", &a, &b)` 拆分整数和小数部分，再用循环反转。

**练习 5**：[P5708] 三角形面积 - https://www.luogu.com.cn/problem/P5708
> 输入三角形三边 `a`、`b`、`c`，用海伦公式计算面积，保留 1 位小数。海伦公式：`p = (a+b+c)/2`，`S = sqrt(p*(p-a)*(p-b)*(p-c))`。
**提示**：三边用 `double` 读入（`scanf("%lf", &a)`），`sqrt` 需要 `#include <cmath>`（`bits/stdc++.h` 已包含）。输出 `printf("%.1f\n", S)`。注意 `p` 也要是 `double`，否则 `(a+b+c)/2` 整数除法丢精度。

### 🔴 综合应用题（CSP-S 入门，综合运用）

**练习 6**：[P1424] 小鱼的游泳时间 - https://www.luogu.com.cn/problem/P1424
> 小鱼从周 `x` 开始，每天上午游泳，周末（周六、周日）休息。给定从周 `x` 起经过的天数 `n`，求小鱼实际游泳了多少天。
**提示**：每周 7 天，周末 2 天不游。用 `%` 取余算出完整周数和剩余天数，再判断剩余天数里有多少个周末。复习"取余运算的妙用"——用 `% 7` 计算星期几。关键：把周 `x` 转换成 0~6 的内部编号（周一=0，周日=6），逐天判断是否为周末（编号 ≥ 5）。

## 📖 本章总结

> 🤔 想一想：你有没有想过，如果把这一章的知识点串成一条线，它们之间是什么关系？

### 核心要点回顾

- ✅ `cin >>` 读数据，`cout <<` 输出数据，**箭头指向数据去向**
- ✅ `endl` 换行并刷新缓冲区（慢），`\n` 只换行（快），大数据用 `\n`
- ✅ `cin` 默认用空格/回车分隔，读含空格的字符串要用 `getline`
- ✅ **算术运算符** `+ - * / %`：整数除法舍小数（`7/2=3`），`%` 只能用于整数
- ✅ **关系运算符** `== != < > <= >=`：结果是 `bool`（`true`=1，`false`=0）
- ✅ **逻辑运算符** `&& || !`：注意短路求值，`&&` 优先级高于 `||`
- ✅ **赋值运算符** `= += -= *= /= %=`：`a += 5` 等价于 `a = a + 5`
- ✅ `=` 是赋值，`==` 是判断相等，**新手最易混淆**
- ✅ `scanf` / `printf` 比 `cin` / `cout` 快，大数据必用
- ✅ `scanf` 读 `double` 用 `%lf`，`printf` 输出 `double` 用 `%f`
- ✅ `long long` 用 `%lld`，`scanf` 变量前要加 `&`

### 常见陷阱

- ❌ 整数除法 `7/2=3`（不是 3.5）→ ✅ 至少一个浮点数：`7.0/2` 或 `(double)7/2`
- ❌ `%` 用于浮点数 → ✅ `%` 只能用于整数，浮点数用 `fmod()`
- ❌ `if (x = 5)` 赋值而非判断 → ✅ 判断用 `if (x == 5)`
- ❌ `scanf("%d", a)` 忘记 `&` → ✅ `scanf("%d", &a)`
- ❌ `scanf` 读 double 用 `%f` → ✅ 读用 `%lf`，输出用 `%f`

### 输入输出速查表

| 操作 | cin / cout | scanf / printf |
|------|-----------|----------------|
| 读整数 | `cin >> a;` | `scanf("%d", &a);` |
| 读大整数 | `cin >> a;` | `scanf("%lld", &a);` |
| 读小数 | `cin >> a;` | `scanf("%lf", &a);` |
| 读字符 | `cin >> ch;` | `scanf("%c", &c);` |
| 输出整数 | `cout << a;` | `printf("%d", a);` |
| 输出保留2位小数 | `cout << fixed << setprecision(2) << a;` | `printf("%.2f", a);` |
| 换行 | `cout << endl;` 或 `cout << "\n";` | `printf("\n");` |

### 运算符速查表

| 类别 | 运算符 | 优先级（高→低） |
|------|--------|----------------|
| 括号 | `()` | 1 |
| 单目 | `!` `++` `--`（前置） | 2 |
| 算术 | `*` `/` `%` | 3 |
| 算术 | `+` `-` | 4 |
| 关系 | `<` `<=` `>` `>=` | 5 |
| 关系 | `==` `!=` | 6 |
| 逻辑 | `&&` | 7 |
| 逻辑 | `||` | 8 |
| 赋值 | `=` `+=` `-=` `*=` `/=` `%=` | 9 |

### 知识脉络

#### 核心概念
- 输入输出
  - cin/cout：慢但易用，箭头指向数据去向
  - scanf/printf：快但需记格式符，大数据首选
  - endl vs \n：都换行，endl 额外刷新缓冲区（慢）
- 运算符
  - 算术：`+ - * / %`，整数除法舍小数，`%` 只能用于整数
  - 关系：`== != < > <= >=`，结果为 bool
  - 逻辑：`&& || !`，注意短路求值
  - 赋值：`= += -= *= /= %=`，`a += 5` 等价于 `a = a + 5`
  - 自增自减：`++ --`，前置先加后用，后置先用后加
- 提速技巧
  - `ios::sync_with_stdio(false)` 关闭同步
  - `cin.tie(0)` 解除绑定
  - 提速后不能混用 cin 和 scanf
