# 第32章 最短路III：Floyd

> 前两章我们学习了 Dijkstra 与 Bellman-Ford/SPFA，它们解决的都是**单源最短路**问题——从一个起点出发，求到其他各点的最短距离。但若题目问的是"**任意两点之间**的最短距离"呢？难道要跑 n 次 Dijkstra 吗？本章介绍 **Floyd 算法**——一个仅用三重循环就能求出**全源最短路**的优雅算法，它的核心思想是**动态规划**。

## 💡 生活类比

### 类比一：中转站

想象你在一座城市里查地图，想知道从地点 A 到地点 B 的最短路线。你通常会想：

> "直达的路线有多长？如果先经过某个**中转站** C，会不会更短？"

Floyd 算法就是这个思路的极致推广——**尝试让每一个点都当中转站**，看能不能让任意两点的距离变短。

```
   直达 A ──────── B   (距离 10)
        ╲           ╱
         ╲         ╱
          ╲       ╱
           C 中转
   A ──→ C ──→ B   (距离 3 + 4 = 7 < 10，更短！)
```

### 类比二：动态规划——逐步开放中转站

把 Floyd 想象成"逐步开放新机场"：一开始只有直达航班（初始边），然后城市 1 开放作为中转站，所有航班都可以经 1 中转；接着城市 2 也开放……每开放一个城市，都检查一遍"经这个新城市中转会不会更短"。当所有城市都开放后，就得到了任意两点之间的最短距离。

!!! tip "一句话记忆"
    Floyd 像"逐步开放中转站"——k 在外层表示"当前开放第 k 个中转站"，i 和 j 是任意起点终点，核心操作 `d[i][j] = min(d[i][j], d[i][k] + d[k][j])` 就是"经 k 中转会不会更短"。

## 32.1 全源最短路问题

### 32.1.1 从单源到全源

**单源最短路 (SSSP)**：给定一个源点 s，求 s 到其他所有点的最短距离。Dijkstra、Bellman-Ford、SPFA 都属于此类。

**全源最短路 (APSP, All-Pairs Shortest Path)**：求图中**任意两点** (i, j) 之间的最短距离，共 n² 个答案。

```
     ┌─────────────────────────────┐
     │  对所有 (i,j) 求 d[i][j]    │
     │                             │
     │  1→2? 1→3? 1→4? ...        │
     │  2→1? 2→3? 2→4? ...        │
     │  3→1? 3→2? 3→4? ...        │
     │  ...                        │
     └─────────────────────────────┘
```

### 32.1.2 朴素思路的代价

一个直观想法：对每个点跑一次 Dijkstra，共 n 次，总复杂度 O(n·(n+m)log n)。对于稠密图（m ≈ n²），这约等于 O(n³ log n)。

而 Floyd 算法直接给出 O(n³) 的解法，代码仅有三重循环，且能处理负权边（但不能有负环）。当 n ≤ 500 时，Floyd 是首选。

!!! info "Floyd 的适用范围"
    - 点数 n 较小（通常 n ≤ 500，CSPJ 中常见 n ≤ 100）
    - 需要**任意两点**最短路，或多次查询不同起点终点
    - 图中可以有负权边，但**不能有负权环**

## 32.2 Floyd 算法核心思想

### 32.2.1 动态规划视角

Floyd 的本质是**动态规划**。定义状态：

$$d[k][i][j] = \text{只允许经过 } 1, 2, \dots, k \text{ 这些点作为中转时，} i \text{ 到 } j \text{ 的最短距离}$$

**状态转移**：考虑第 k 个点是否作为中转。

- **不经过 k**：`d[k][i][j] = d[k-1][i][j]`
- **经过 k**：`d[k][i][j] = d[k-1][i][k] + d[k-1][k][j]`

两者取最小值：

$$d[k][i][j] = \min\big(d[k-1][i][j],\ d[k-1][i][k] + d[k-1][k][j]\big)$$

### 32.2.2 空间优化

观察转移方程：第 k 层只依赖第 k-1 层。更进一步，由于 `d[k-1][i][k]` 和 `d[k-1][k][j]` 在第 k 层迭代中**不会改变**（因为中转点 k 到自身的距离为 0），所以可以省去第一维，直接用二维数组：

```
d[i][j] = min(d[i][j], d[i][k] + d[k][j])
```

这就是 Floyd 最经典的形态。最终 `d[i][j]` 即为 i 到 j 的最短距离。

!!! tip "为什么能省掉第一维？"
    在第 k 轮迭代中，`d[i][k]` 和 `d[k][j]` 的值实际等于 `d[k-1][i][k]` 和 `d[k-1][k][j]`（因为以 k 为中转不会改变 k 相关的距离）。因此二维数组"原地更新"是正确的。

## 32.3 Floyd 算法实现

### 32.3.1 算法流程

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 初始化 `d[i][i] = 0` | 自己到自己距离为 0 |
| 2 | 初始化 `d[i][j] = INF`（i ≠ j） | 初始不可达 |
| 3 | 读入边：`d[u][v] = min(d[u][v], w)` | 处理重边取最小 |
| 4 | 三重循环：k → i → j | k 必须在最外层 |
| 5 | 松弛：`d[i][j] = min(d[i][j], d[i][k]+d[k][j])` | 核心操作 |

### 32.3.2 初始化要点

```cpp
memset(d, 0x3f, sizeof(d));  // 全部设为 INF
for (int i = 1; i <= n; i++) d[i][i] = 0;  // 对角线设 0

// 读入边（注意处理重边与无向边）
for (int i = 0; i < m; i++) {
    int u, v, w;
    cin >> u >> v >> w;
    d[u][v] = min(d[u][v], w);  // 重边取较小
    // d[v][u] = min(d[v][u], w); // 无向图加这句
}
```

!!! warning "INF 的取值"
    常用 `INF = 0x3f3f3f3f`（约 1e9）。两个 INF 相加为约 2e9，不会溢出 int。若用 `INT_MAX`（约 2.1e9），相加会溢出变成负数，导致严重错误！

### 32.3.3 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

const int INF = 0x3f3f3f3f;
int n, m;
int d[105][105];

void floyd() {
    for (int k = 1; k <= n; k++)
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
}

int main() {
    cin >> n >> m;
    memset(d, 0x3f, sizeof(d));
    for (int i = 1; i <= n; i++) d[i][i] = 0;
    
    for (int i = 0; i < m; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        d[u][v] = min(d[u][v], w);
        d[v][u] = min(d[v][u], w); // 无向图
    }
    
    floyd();
    
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++)
            cout << (d[i][j] >= INF ? -1 : d[i][j]) << " ";
        cout << "\n";
    }
    return 0;
}
```

### 32.3.4 ASCII 演示

以 4 个点的图为例，演示 Floyd 的执行过程：

```
初始图（无向）:
        2
   1 -------- 2
   |          |
  6|          |1
   |          |
   3 -------- 4
        3

初始距离矩阵 d:
      1    2    3    4
  1 [ 0    2    6   INF ]
  2 [ 2    0   INF   1  ]
  3 [ 6   INF   0    3  ]
  4 [INF   1    3    0  ]

k=1 (尝试以1为中转):
  d[2][3] = min(INF, d[2][1]+d[1][3]) = 2+6 = 8
  d[3][2] = min(INF, d[3][1]+d[1][2]) = 6+2 = 8
  更新后 d[2][3]=d[3][2]=8

k=2 (尝试以2为中转):
  d[1][4] = min(INF, d[1][2]+d[2][4]) = 2+1 = 3  ← 更短！
  d[3][4] = min(3, d[3][2]+d[2][4]) = 8+1 = 9 (不更新)
  d[4][1] 同理 = 3

k=3 (尝试以3为中转):
  无更短更新

k=4 (尝试以4为中转):
  d[1][3] = min(6, d[1][4]+d[4][3]) = 3+3 = 6 (相等，不更新)
  d[2][3] = min(8, d[2][4]+d[4][3]) = 1+3 = 4 ← 更短！
  d[3][2] = min(8, d[3][4]+d[4][2]) = 3+1 = 4 ← 更短！

最终:
  d[1][4] = 3 (路径 1→2→4)
  d[2][3] = 4 (路径 2→4→3)
```

### 32.3.5 复杂度分析

| 维度 | 复杂度 | 说明 |
|------|--------|------|
| 时间 | O(n³) | 三重循环，与边数无关 |
| 空间 | O(n²) | 二维距离矩阵 |

!!! info "O(n³) 意味着什么"
    - n = 100：约 1e6 次运算，瞬间完成
    - n = 500：约 1.25e8 次运算，1 秒内可过
    - n = 1000：约 1e9 次运算，可能超时，需谨慎

### 32.3.6 记录路径（路径还原）

有时题目不仅要求最短距离，还要求输出具体路径。Floyd 可通过额外记录"中转点"来还原路径。

**思路**：维护 `path[i][j]` 表示 i 到 j 的最短路中"最后一个中转点"。初始化为 j（即直达）。更新时记录中转点 k，最后递归还原路径。

```cpp
int d[105][105], path[105][105];

void floyd() {
    for (int k = 1; k <= n; k++)
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                if (d[i][k] + d[k][j] < d[i][j]) {
                    d[i][j] = d[i][k] + d[k][j];
                    path[i][j] = k;  // 记录中转点
                }
}

// 递归输出 i 到 j 的路径（不含端点 j）
void print_path(int i, int j) {
    if (path[i][j] == j) return; // 直达，无中转
    int k = path[i][j];
    print_path(i, k);   // 先输出 i 到 k
    cout << k << " ";   // 输出中转点 k
    print_path(k, j);   // 再输出 k 到 j
}
// 调用：cout << i << " "; print_path(i, j); cout << j;
```

!!! tip "路径还原的初始化"
    读入边后，设 `path[i][j] = j`（表示当前 i 到 j 是直连的）。当发生松弛时，更新为新的中转点 k。递归输出时，若 `path[i][j] == j` 说明无中转，直接输出即可。

## 32.4 关键：k 为什么在最外层

### 32.4.1 DP 阶段的正确性

Floyd 的三重循环顺序必须是 **k → i → j**，即中转点 k 在最外层。这是初学者最容易犯的错误。

**原因**：Floyd 是动态规划，k 代表"阶段"——第 k 阶段表示"允许经过 1..k 作为中转"。每个阶段必须**完整地更新**整个矩阵后，才能进入下一阶段。若 k 不在最外层，会导致同一阶段内使用"半新半旧"的数据，破坏 DP 的无后效性。

### 32.4.2 错误顺序的后果

```cpp
// ❌ 错误写法：i 在最外层
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= n; j++)
        for (int k = 1; k <= n; k++)
            d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
```

这种写法在某些图上**碰巧正确**，但在另一些图上会**得到错误答案**。原因是：更新 `d[i][j]` 时，`d[i][k]` 和 `d[k][j]` 可能已经被本轮修改过，不再是"仅经过 1..k-1 中转"的值，而是混入了更大范围的路径信息，导致逻辑混乱。

!!! warning "经典错误"
    把 k 放到最内层是 Floyd 最常见的错误。记住口诀：**"k 在外，i、j 在内"**。可以记作"**先选桥，再连两端**"。

### 32.4.3 正确性验证

```cpp
// ✅ 正确写法
for (int k = 1; k <= n; k++)        // 中转点
    for (int i = 1; i <= n; i++)    // 起点
        for (int j = 1; j <= n; j++)// 终点
            d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
```

## 32.5 Floyd 求传递闭包

### 32.5.1 什么是传递闭包

给定一个有向图，问"从点 i 能否到达点 j"。对所有点对求可达性，得到的 n×n 布尔矩阵称为**传递闭包**。

```
若 i→k 可达 且 k→j 可达，则 i→j 可达
```

这与 Floyd 的形式完全一致，只需把"加法"改为"逻辑与"，"取 min"改为"逻辑或"。

### 32.5.2 代码实现

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, m;
bool reach[105][105];

void transitive_closure() {
    for (int k = 1; k <= n; k++)
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                reach[i][j] = reach[i][j] | (reach[i][k] & reach[k][j]);
}

int main() {
    cin >> n >> m;
    for (int i = 1; i <= n; i++) reach[i][i] = true; // 自己可达自己
    for (int i = 0; i < m; i++) {
        int u, v;
        cin >> u >> v;
        reach[u][v] = true;
    }
    transitive_closure();
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++)
            cout << reach[i][j] << " ";
        cout << "\n";
    }
    return 0;
}
```

!!! tip "用 bitset 优化"
    传递闭包可用 `bitset` 加速：`reach[i] |= reach[k]`（当 `reach[i][k]` 为真时）。复杂度降为 O(n³/64)，对 n ≤ 1000 也可行。

### 32.5.3 应用场景

| 场景 | 说明 |
|------|------|
| 可达性判断 | 判断图中 i 是否能到 j |
| 连通分量 | 无向图中，互相可达的点属于同一连通块 |
| 关系传递 | 如"A 是 B 的祖先，B 是 C 的祖先 → A 是 C 的祖先" |
| 拓扑判断 | 配合入度可辅助分析图的结构 |

## 32.6 常见误区与陷阱

| 编号 | 误区 | 正确做法 |
|------|------|----------|
| 1 | k 循环顺序随意 | **k 必须在最外层**，否则破坏 DP 阶段 |
| 2 | INF 取 INT_MAX | 用 `0x3f3f3f3f`，两个 INF 相加不溢出 |
| 3 | 忘记初始化 d[i][i] = 0 | 对角线必须设为 0，否则 i=k 或 k=j 时加 INF |
| 4 | 重边直接覆盖 | 用 `d[u][v] = min(d[u][v], w)` |
| 5 | Floyd 直接判负环 | 可检测 `d[i][i] < 0` 辅助发现，但正式判负环用 Bellman-Ford 或 SPFA |
| 6 | 忽视无向图的对称性 | 无向图需**双向加边** `d[v][u] = min(d[v][u], w)` |

## 32.7 三种最短路算法综合对比

本章学完 Floyd 后，CSPJ 普及组涉及的四大最短路算法已全部介绍完毕。综合对比如下：

| 特性 | Dijkstra | Bellman-Ford | SPFA | Floyd |
|------|----------|--------------|------|-------|
| **问题类型** | 单源最短路 | 单源最短路 | 单源最短路 | **全源最短路** |
| **适用图** | 非负权图 | 一般图（含负权） | 一般图（含负权） | 一般图（含负权） |
| **能否处理负权边** | ❌ 不能 | ✅ 能 | ✅ 能 | ✅ 能 |
| **能否检测负环** | ❌ 不能 | ✅ 能（第 n 轮） | ✅ 能（cnt≥n） | ⚠️ 仅辅助（d[i][i]<0） |
| **时间复杂度** | O((n+m)log n) 堆优化 | O(nm) | 期望 O(km)，最坏 O(nm) | **O(n³)** |
| **空间复杂度** | O(n+m) | O(n+m) | O(n+m) | **O(n²)** |
| **核心思想** | 贪心 | 逐轮松弛 | 队列驱动松弛 | **动态规划** |
| **数据结构** | 优先队列 | 边表 | 队列+邻接表 | 邻接矩阵 |
| **实现难度** | 中等 | 简单 | 简单 | **极简** |
| **稳定性** | 稳定 | 稳定 | 易被卡 | 稳定 |
| **常用场景** | 非负权单源 | 理论/判负环 | 含负权实际题 | 小图全源/多查询 |

!!! tip "算法选择决策树"
    ```
    需要求任意两点最短路？
    ├── 是 → 点数 n ≤ 500 → Floyd O(n³)
    │       └── 点数较大 → n 次 Dijkstra（非负权）
    └── 否（单源最短路）
        ├── 边权非负 → Dijkstra（堆优化）O((n+m)log n)
        └── 有负权边 → SPFA（警惕被卡）/ Bellman-Ford（稳定）
            └── 需判负环 → SPFA（cnt≥n）/ Bellman-Ford（第 n 轮）
    ```

!!! warning "Floyd 的适用边界"
    Floyd 适用于 **n ≤ 500** 的稠密图或多查询场景。若 n 较大（如 1e5）且图为稀疏图，应改用 n 次 Dijkstra 或按需查询。CSPJ 中 Floyd 题目通常 n ≤ 100。

## 32.8 典型例题

### 32.8.1 [B3601] 最短路问题

**题意**：给定 n 个点 m 条边的无向图，q 次查询，每次问点 u 到点 v 的最短距离。n ≤ 100, m ≤ 4500, q ≤ 100。

**思路**：n 很小，直接 Floyd 预处理全源最短路，O(1) 回答每次查询。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int INF = 0x3f3f3f3f;
int n, m, q;
int d[105][105];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> m >> q;
    memset(d, 0x3f, sizeof(d));
    for (int i = 1; i <= n; i++) d[i][i] = 0;
    for (int i = 0; i < m; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        d[u][v] = min(d[u][v], w);
        d[v][u] = min(d[v][u], w);
    }
    // Floyd
    for (int k = 1; k <= n; k++)
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
    // 回答查询
    while (q--) {
        int u, v;
        cin >> u >> v;
        cout << (d[u][v] >= INF ? -1 : d[u][v]) << "\n";
    }
    return 0;
}
```

!!! info "B3601 小结"
    这是 Floyd 的标准模板题。当 n ≤ 100、查询次数多时，Floyd 远比每次跑 Dijkstra 高效。

### 32.8.2 [P2910] 寻宝之路

**题意**：有 n 个地点（编号 1..n），给定一个长度为 m 的访问序列 a[1..m]，按顺序依次经过这些地点。相邻地点间的最短距离由一个 n×n 矩阵直接给出。求总路径长度。

**思路**：本题距离矩阵已给出，无需自己跑 Floyd，只需按访问序列累加相邻两点的距离即可。但若距离矩阵是"边"而非"最短距离"，则需先 Floyd 预处理。这里直接累加。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int INF = 0x3f3f3f3f;
int n, m;
int d[105][105];
int path[10005];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> m;
    for (int i = 0; i < m; i++) cin >> path[i];
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= n; j++)
            cin >> d[i][j];
    // 题目保证给的是最短距离矩阵，无需再 Floyd
    // 若给的是边权，则取消下面注释
    // for (int k = 1; k <= n; k++)
    //     for (int i = 1; i <= n; i++)
    //         for (int j = 1; j <= n; j++)
    //             d[i][j] = min(d[i][j], d[i][k] + d[k][j]);
    long long ans = 0;
    for (int i = 0; i < m - 1; i++)
        ans += d[path[i]][path[i + 1]];
    cout << ans << "\n";
    return 0;
}
```

!!! tip "P2910 的变式"
    若题目改为"给出边集而非完整矩阵"，则需先用 Floyd 求出全源最短路，再按序列累加。这是 Floyd 的典型应用——**预处理后 O(1) 查询**。

### 32.8.3 [P1119] 灾后重建

**题意**：n 个村庄，m 条无向边。村庄 i 在时刻 t[i] 重建完成。q 次查询 (x, y, T)：问在时刻 T 时（仅能经过 t[k] ≤ T 的村庄作为中转），x 到 y 的最短距离。保证 t 单调递增。n ≤ 200, q ≤ 50000。

**思路**：本题是 Floyd 的经典应用，完美体现了"k 在最外层"的意义。

- 将查询**按时间 T 排序**
- 维护指针 p，表示下一个可作为中转的村庄
- 对每个查询，将所有 `t[p] ≤ T` 的村庄 p 依次作为中转点，执行 Floyd 的第 p 轮迭代
- 查询时若 x 或 y 尚未重建（t[x]>T 或 t[y]>T），输出 -1；否则输出 d[x][y]

```cpp
#include <bits/stdc++.h>
using namespace std;

const int INF = 0x3f3f3f3f;
int n, m;
int d[205][205];
int t[205];

struct Query {
    int x, y, T, id;
} q[50005];

int ans[50005];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> m;
    for (int i = 0; i < n; i++) cin >> t[i];
    memset(d, 0x3f, sizeof(d));
    for (int i = 0; i < n; i++) d[i][i] = 0;
    for (int i = 0; i < m; i++) {
        int u, v, w;
        cin >> u >> v >> w;
        d[u][v] = min(d[u][v], w);
        d[v][u] = min(d[v][u], w);
    }
    int Q;
    cin >> Q;
    for (int i = 0; i < Q; i++) {
        cin >> q[i].x >> q[i].y >> q[i].T;
        q[i].id = i;
    }
    // 按时间排序查询
    sort(q, q + Q, [](const Query &a, const Query &b) {
        return a.T < b.T;
    });
    // 增量 Floyd：逐步加入可作中转的村庄
    int p = 0; // 下一个待加入的中转点（村庄按 t 升序，因题目保证 t 单调递增）
    for (int i = 0; i < Q; i++) {
        // 加入所有 t[k] <= q[i].T 的村庄作为中转
        while (p < n && t[p] <= q[i].T) {
            for (int u = 0; u < n; u++)
                for (int v = 0; v < n; v++)
                    d[u][v] = min(d[u][v], d[u][p] + d[p][v]);
            p++;
        }
        int x = q[i].x, y = q[i].y;
        if (t[x] > q[i].T || t[y] > q[i].T)
            ans[q[i].id] = -1;
        else
            ans[q[i].id] = (d[x][y] >= INF ? -1 : d[x][y]);
    }
    for (int i = 0; i < Q; i++)
        cout << ans[i] << "\n";
    return 0;
}
```

!!! warning "P1119 的精髓"
    本题的巧妙之处在于：**Floyd 的 k 循环可以"分段执行"**。每次只跑以某个 k 为中转的那一轮，结果依然正确。这正是因为 Floyd 是 DP——每个阶段独立累加中转点。这种"**在线增量**"思想是 Floyd 区别于其他最短路算法的独特优势。

!!! tip "P1119 的复杂度"
    - 排序查询：O(q log q)
    - 增量 Floyd：共 n 轮，每轮 O(n²)，总计 O(n³)
    - 回答查询：O(q)
    - 总计：O(n³ + q log q)，n=200 时约 8e6，轻松通过

## 32.9 本章总结

### 核心知识回顾

1. **Floyd 算法**通过三重循环 `for(k) for(i) for(j)` 求全源最短路，时间 O(n³)，空间 O(n²)。
2. **核心代码**：`d[i][j] = min(d[i][j], d[i][k] + d[k][j])`，本质是动态规划。
3. **初始化**：`d[i][i]=0`，`d[i][j]=INF`（用 `0x3f3f3f3f`，勿用 `INT_MAX`）。
4. **k 必须在最外层**：k 代表 DP 阶段，顺序错误会导致结果错误。
5. **传递闭包**：将 min/+ 改为 |/&，即可求可达性矩阵。
6. **增量 Floyd**（P1119）：可分段执行 k 循环，支持"逐步开放中转点"的在线查询。

### 易错点清单

| 编号 | 易错点 | 正确做法 |
|------|--------|----------|
| 1 | k 不在最外层 | k → i → j 顺序固定 |
| 2 | INF 用 INT_MAX | 用 `0x3f3f3f3f`，防溢出 |
| 3 | 忘记 d[i][i]=0 | 初始化对角线为 0 |
| 4 | 重边直接覆盖 | 用 `min` 取较小 |
| 5 | 无向图忘加反向边 | 双向加边 |
| 6 | n 过大仍用 Floyd | n ≤ 500 方可用，否则改 n 次 Dijkstra |
| 7 | 传递闭包忘初始化 reach[i][i]=true | 自己可达自己 |

### 四大算法一句话总结

- **Dijkstra**：贪心选最近，非负权单源首选。
- **Bellman-Ford**：n-1 轮全边松弛，能判负环，理论扎实。
- **SPFA**：队列优化版 Bellman-Ford，快但易被卡，"它死了"。
- **Floyd**：三重循环求全源，DP 思想优雅，小图之王。
