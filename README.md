# 📚 从零基础到 CSP-S 一等奖

> 一套完整的 CSP-J/S 竞赛教材，覆盖 2025 版 NOI 大纲全部考点。
> **58 章 · 8 大板块 · 3 个附录 · 配套电子书阅读器**

[![License](https://img.shields.io/badge/license-CC%20BY--NC--SA%204.0-blue)](LICENSE)
[![Chapters](https://img.shields.io/badge/chapters-58%2B3-brightgreen)](#-全书结构)
[![NOI大纲](https://img.shields.io/badge/NOI%E5%A4%A7%E7%BA%B2-2025%E7%89%88-red)](#-考纲覆盖)

面向 **CSP-J（入门级）→ CSP-S（提高级）** 的系统化竞赛教材。从 HelloWorld 起步，循序渐进讲到平衡树、扫描线等省选级知识，帮助零基础学习者用 14~18 个月达成 CSP-S 一等奖目标。教材已完成**出版级终审**，核心算法代码均逐行验证，2025 版 NOI 大纲覆盖率 **100%**。

---

## ✨ 教材特色

- 🌱 **零基础友好** — 从安装 IDE、写 HelloWorld 开始，不预设任何编程基础
- 🔄 **双轨教学** — 关键数据结构同时讲解"数组模拟"与"STL 实现"
- 🎯 **考纲全覆盖** — 含 2025 新增 7 考点（前缀和、差分、引用、bitset、扫描线、Manacher、多维 DP）
- 🧪 **配套练习** — 每章配洛谷练习题，标注难度梯度
- 📊 **可视化学习** — 配套电子书阅读器，支持搜索、进度跟踪、代码高亮
- 🛠️ **调试实战** — 专门附录讲解对拍四件套、RE/TLE/WA 排查

| 板块 | 章节 | 核心内容 |

| 八、进阶专题 | 51-58 | 树状数组、线段树、SCC/差分约束、Manacher/扫描线、单调栈、STL/bitset、期望 DP、平衡树 |

**推荐方式**：双击根目录的 **`book.html`** 即可在浏览器中阅读，支持侧边栏导航、全文搜索、进度跟踪、代码高亮、Mermaid 图表和 KaTeX 公式渲染。

## 🗺️ 学习路径

```
零基础 → 第一卷语法基础（2-3月）→ 第二卷基础算法（1-2月）→ 第三卷数据结构（2-3月）
       → 第四卷搜索图论（2月）→ 第五六卷数学+DP（2-3月）→ 第七八卷冲刺进阶（2-3月）→ 🏆 CSP-S 一等奖
```

| 阶段 | 目标 | 时长 | 详情 |
|------|------|:----:|------|
| CSP-J 入门级 | ≥ 300 分 | 6-8 月 | 24 章必修 + 2 章过渡 |
| CSP-S 提高级 | ≥ 250 分 | 6-8 月 | 23 章 S 组必修 + 9 章拔高 |
| 冲刺省一 | NOIP 省一 | 2-3 月 | 真题刷透 + 模板默写 + 对拍训练 |

📋 **详细路径与验收标准**：[00_学习路径规划.md](00_学习路径规划.md)
